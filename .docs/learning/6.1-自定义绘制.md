# 6.1 自定义绘制

> "在 Compose 的世界里，自定义绘制就像是拿到了一支'魔法画笔'
>
，让你可以突破常规组件的限制，画出任何你能想象的界面！从简单的彩色圆形到复杂的数据可视化图表，只要你敢想，就能画出来！"
🎨

## 概念介绍

自定义绘制是 Jetpack Compose 中一项强大的功能，它允许开发者直接访问底层的 Canvas API，实现标准组件无法满足的独特
UI
效果。通过自定义绘制，你可以创建各种自定义形状、图表、动画效果和交互体验，为你的应用增添独特的视觉风格。

在 Compose 中，自定义绘制主要通过 `Canvas` 组件或 `Modifier.drawBehind`/`Modifier.drawWithContent`
等修饰符实现。Canvas
提供了一个绘制表面，你可以在其上使用各种绘制操作（如绘制线条、矩形、圆形、路径等）来创建自定义 UI。

与传统的 Android View 系统中的自定义绘制相比，Compose
的自定义绘制更加简洁和声明式，无需处理复杂的生命周期和失效逻辑。你只需要描述"要绘制什么"，而不是"
如何绘制"，Compose
会在适当的时候自动调用你的绘制代码。

## 知识要点

- Compose 中自定义绘制的主要方式：`Canvas` 组件和 `Modifier.drawXXX` 修饰符
- Canvas 的基本绘制操作：drawLine、drawRect、drawCircle、drawArc、drawPath 等
- 使用 Paint 对象控制绘制样式：颜色、描边宽度、阴影、渐变等
- 坐标系统和尺寸单位：像素（px）和密度无关像素（dp）
- 路径（Path）的创建和操作：移动、线段、曲线、闭合等
- 图形变换：平移、旋转、缩放、倾斜等
- 裁剪（Clipping）：限制绘制区域
- 图层（Layer）：创建独立的绘制层，应用特殊效果
- 动画绘制：结合 Compose 动画系统实现平滑过渡
- 性能优化：避免不必要的重绘和复杂计算

## 基础代码示例

下面是一个简单的例子，展示如何使用 Canvas 绘制一个自定义的进度指示器：

```kotlin
@Composable
fun CircularProgressIndicator(
    progress: Float,
    modifier: Modifier = Modifier,
    color: Color = MaterialTheme.colorScheme.primary,
    strokeWidth: Dp = 8.dp
) {
    // 确保进度值在 0f 到 1f 之间
    val progressValue = progress.coerceIn(0f, 1f)

    Canvas(
        modifier = modifier
            .size(100.dp)
            .padding(strokeWidth / 2)
    ) {
        // 绘制背景圆环
        drawCircle(
            color = color.copy(alpha = 0.2f),
            style = Stroke(width = strokeWidth.toPx())
        )

        // 计算扫过的角度
        val sweepAngle = 360f * progressValue

        // 绘制进度弧
        drawArc(
            color = color,
            startAngle = -90f, // 从顶部开始
            sweepAngle = sweepAngle,
            useCenter = false,
            style = Stroke(
                width = strokeWidth.toPx(),
                cap = StrokeCap.Round
            )
        )

        // 绘制进度文本
        val textPaint = Paint().asFrameworkPaint().apply {
            this.color = color.toArgb()
            this.textSize = 24.sp.toPx()
            this.textAlign = android.graphics.Paint.Align.CENTER
        }

        val progressText = (progressValue * 100).toInt().toString() + "%"
        val textHeight = textPaint.descent() - textPaint.ascent()
        val textOffset = textHeight / 2 - textPaint.descent()

        drawContext.canvas.nativeCanvas.drawText(
            progressText,
            center.x,
            center.y + textOffset,
            textPaint
        )
    }
}

    }
}
```

## 进阶用法

### 1. 使用 Modifier.drawBehind 实现自定义背景

`Modifier.drawBehind` 是一种更轻量级的自定义绘制方式，适合为现有组件添加自定义背景：

```kotlin
@Composable
fun CustomBackgroundButton(
    text: String,
    onClick: () -> Unit,
    modifier: Modifier = Modifier
) {
    Button(
        onClick = onClick,
        modifier = modifier,
        contentPadding = PaddingValues(0.dp), // 移除默认内边距
        colors = ButtonDefaults.buttonColors(
            containerColor = Color.Transparent, // 透明背景
            contentColor = Color.White
        ),
        elevation = null // 移除阴影
    ) {
        Box(
            modifier = Modifier
                .drawBehind {
                    // 创建渐变背景
                    val gradient = Brush.linearGradient(
                        colors = listOf(
                            Color(0xFF6200EE),
                            Color(0xFF3700B3)
                        ),
                        start = Offset(0f, 0f),
                        end = Offset(size.width, size.height)
                    )

                    // 绘制圆角矩形
                    drawRoundRect(
                        brush = gradient,
                        cornerRadius = CornerRadius(16.dp.toPx())
                    )

                    // 添加闪光效果
                    drawRoundRect(
                        color = Color.White.copy(alpha = 0.2f),
                        cornerRadius = CornerRadius(16.dp.toPx()),
                        topLeft = Offset(0f, 0f),
                        size = Size(size.width, size.height / 2)
                    )
                }
                .padding(horizontal = 16.dp, vertical = 8.dp)
        ) {
            Text(
                text = text,
                fontSize = 16.sp,
                fontWeight = FontWeight.Bold,
                modifier = Modifier.align(Alignment.Center)
            )
        }
    }
}
```

### 2. 创建自定义图表

下面是一个简单的柱状图实现，展示如何使用 Canvas 创建数据可视化组件：

```kotlin
@Composable
fun BarChart(
    data: List<Float>,
    labels: List<String>,
    modifier: Modifier = Modifier,
    barColor: Color = MaterialTheme.colorScheme.primary,
    axisColor: Color = MaterialTheme.colorScheme.onSurface.copy(alpha = 0.3f),
    textColor: Color = MaterialTheme.colorScheme.onSurface
) {
    // 确保数据和标签数量一致
    require(data.size == labels.size) { "Data and labels must have the same size" }

    // 找出最大值，用于计算比例
    val maxValue = data.maxOrNull() ?: 0f

    Canvas(
        modifier = modifier
            .fillMaxWidth()
            .height(300.dp)
            .padding(
                top = 20.dp,
                bottom = 40.dp,
                start = 40.dp,
                end = 20.dp
            )
    ) {
        val barWidth = (size.width - 40.dp.toPx()) / data.size * 0.8f
        val barSpacing = (size.width - 40.dp.toPx()) / data.size * 0.2f
        val chartHeight = size.height - 40.dp.toPx()

        // 绘制 Y 轴
        drawLine(
            color = axisColor,
            start = Offset(0f, 0f),
            end = Offset(0f, chartHeight),
            strokeWidth = 2.dp.toPx()
        )

        // 绘制 X 轴
        drawLine(
            color = axisColor,
            start = Offset(0f, chartHeight),
            end = Offset(size.width, chartHeight),
            strokeWidth = 2.dp.toPx()
        )

        // 绘制 Y 轴刻度和网格线
        val ySteps = 5
        for (i in 0..ySteps) {
            val y = chartHeight - (chartHeight * i / ySteps)

            // 绘制刻度线
            drawLine(
                color = axisColor,
                start = Offset(-5.dp.toPx(), y),
                end = Offset(0f, y),
                strokeWidth = 1.dp.toPx()
            )

            // 绘制网格线
            drawLine(
                color = axisColor.copy(alpha = 0.3f),
                start = Offset(0f, y),
                end = Offset(size.width, y),
                strokeWidth = 0.5.dp.toPx(),
                pathEffect = PathEffect.dashPathEffect(floatArrayOf(5f, 5f))
            )

            // 绘制 Y 轴标签
            val valueText = ((maxValue * i / ySteps)).toInt().toString()
            val textPaint = Paint().asFrameworkPaint().apply {
                this.color = textColor.toArgb()
                this.textSize = 10.sp.toPx()
                this.textAlign = android.graphics.Paint.Align.RIGHT
            }

            drawContext.canvas.nativeCanvas.drawText(
                valueText,
                -10.dp.toPx(),
                y - 2.dp.toPx(),
                textPaint
            )
        }

        // 绘制柱状图和 X 轴标签
        data.forEachIndexed { index, value ->
            val barHeight = (value / maxValue) * chartHeight
            val left = index * (barWidth + barSpacing) + barSpacing / 2
            val top = chartHeight - barHeight

            // 绘制柱子
            drawRoundRect(
                color = barColor,
                topLeft = Offset(left, top),
                size = Size(barWidth, barHeight),
                cornerRadius = CornerRadius(4.dp.toPx())
            )

            // 绘制柱子上方的数值
            val valueText = value.toInt().toString()
            val textPaint = Paint().asFrameworkPaint().apply {
                this.color = textColor.toArgb()
                this.textSize = 10.sp.toPx()
                this.textAlign = android.graphics.Paint.Align.CENTER
            }

            drawContext.canvas.nativeCanvas.drawText(
                valueText,
                left + barWidth / 2,
                top - 5.dp.toPx(),
                textPaint
            )

            // 绘制 X 轴标签
            val labelPaint = Paint().asFrameworkPaint().apply {
                this.color = textColor.toArgb()
                this.textSize = 10.sp.toPx()
                this.textAlign = android.graphics.Paint.Align.CENTER
            }

            drawContext.canvas.nativeCanvas.drawText(
                labels[index],
                left + barWidth / 2,
                chartHeight + 20.dp.toPx(),
                labelPaint
            )
        }
    }
}

// 使用示例
@Composable
fun BarChartExample() {
    val data = listOf(120f, 220f, 180f, 320f, 250f, 300f)
    val labels = listOf("一月", "二月", "三月", "四月", "五月", "六月")

    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp)
    ) {
        Text(
            text = "月度销售额（万元）",
            style = MaterialTheme.typography.titleLarge,
            modifier = Modifier.padding(bottom = 16.dp)
        )

        BarChart(
            data = data,
            labels = labels,
            modifier = Modifier
                .fillMaxWidth()
                .height(300.dp)
                .background(
                    color = MaterialTheme.colorScheme.surface,
                    shape = RoundedCornerShape(8.dp)
                )
                .padding(8.dp)
        )
    }
}
```

### 3. 创建自定义时钟

下面是一个自定义时钟的实现，展示如何使用 Canvas 创建复杂的交互式组件：

```kotlin
@Composable
fun AnalogClock(
    modifier: Modifier = Modifier,
    hourHandColor: Color = MaterialTheme.colorScheme.primary,
    minuteHandColor: Color = MaterialTheme.colorScheme.secondary,
    secondHandColor: Color = MaterialTheme.colorScheme.tertiary,
    dialColor: Color = MaterialTheme.colorScheme.surface,
    markersColor: Color = MaterialTheme.colorScheme.onSurface
) {
    // 获取当前时间
    val currentTime = remember { mutableStateOf(Calendar.getInstance()) }

    // 每秒更新时间
    LaunchedEffect(Unit) {
        while (true) {
            currentTime.value = Calendar.getInstance()
            delay(1000)
        }
    }

    // 计算时针、分针和秒针的角度
    val hours = currentTime.value.get(Calendar.HOUR_OF_DAY) % 12
    val minutes = currentTime.value.get(Calendar.MINUTE)
    val seconds = currentTime.value.get(Calendar.SECOND)

    val hourAngle = (hours * 30f) + (minutes * 0.5f)
    val minuteAngle = minutes * 6f
    val secondAngle = seconds * 6f

    Canvas(
        modifier = modifier
            .size(300.dp)
            .padding(16.dp)
    ) {
        val center = Offset(size.width / 2, size.height / 2)
        val radius = size.minDimension / 2

        // 绘制表盘背景
        drawCircle(
            color = dialColor,
            radius = radius,
            center = center,
            style = Fill
        )

        // 绘制表盘边框
        drawCircle(
            color = markersColor.copy(alpha = 0.5f),
            radius = radius,
            center = center,
            style = Stroke(width = 2.dp.toPx())
        )

        // 绘制刻度
        for (i in 0 until 60) {
            val angle = i * 6f
            val isHourMark = i % 5 == 0
            val markLength = if (isHourMark) 20.dp.toPx() else 10.dp.toPx()
            val markWidth = if (isHourMark) 2.dp.toPx() else 1.dp.toPx()

            val start = polarToCartesian(
                center = center,
                angle = angle,
                radius = radius - markLength
            )

            val end = polarToCartesian(
                center = center,
                angle = angle,
                radius = radius
            )

            drawLine(
                color = markersColor.copy(alpha = if (isHourMark) 0.8f else 0.5f),
                start = start,
                end = end,
                strokeWidth = markWidth
            )

            // 绘制数字
            if (isHourMark) {
                val hourNumber = if (i == 0) 12 else i / 5
                val textRadius = radius - 40.dp.toPx()
                val textPosition = polarToCartesian(
                    center = center,
                    angle = angle,
                    radius = textRadius
                )

                val textPaint = Paint().asFrameworkPaint().apply {
                    this.color = markersColor.toArgb()
                    this.textSize = 16.sp.toPx()
                    this.textAlign = android.graphics.Paint.Align.CENTER
                }

                val textHeight = textPaint.descent() - textPaint.ascent()
                val textOffset = textHeight / 2 - textPaint.descent()

                drawContext.canvas.nativeCanvas.drawText(
                    hourNumber.toString(),
                    textPosition.x,
                    textPosition.y + textOffset,
                    textPaint
                )
            }
        }

        // 绘制时针
        drawHand(
            center = center,
            angle = hourAngle,
            length = radius * 0.5f,
            width = 4.dp.toPx(),
            color = hourHandColor
        )

        // 绘制分针
        drawHand(
            center = center,
            angle = minuteAngle,
            length = radius * 0.7f,
            width = 3.dp.toPx(),
            color = minuteHandColor
        )

        // 绘制秒针
        drawHand(
            center = center,
            angle = secondAngle,
            length = radius * 0.8f,
            width = 2.dp.toPx(),
            color = secondHandColor
        )

        // 绘制中心点
        drawCircle(
            color = secondHandColor,
            radius = 8.dp.toPx(),
            center = center
        )

        drawCircle(
            color = dialColor,
            radius = 4.dp.toPx(),
            center = center
        )
    }
}

// 辅助函数：将极坐标转换为笛卡尔坐标
private fun polarToCartesian(center: Offset, angle: Float, radius: Float): Offset {
    // 角度转弧度，并调整起始位置（12点钟方向为0度）
    val radians = Math.toRadians((angle - 90).toDouble()).toFloat()
    return Offset(
        x = center.x + radius * cos(radians),
        y = center.y + radius * sin(radians)
    )
}

// 辅助函数：绘制时钟指针
private fun DrawScope.drawHand(
    center: Offset,
    angle: Float,
    length: Float,
    width: Float,
    color: Color
) {
    // 计算指针端点
    val end = polarToCartesian(center, angle, length)

    // 绘制指针
    drawLine(
        color = color,
        start = center,
        end = end,
        strokeWidth = width,
        cap = StrokeCap.Round
    )
}

// 使用示例
@Composable
fun AnalogClockExample() {
    Box(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        contentAlignment = Alignment.Center
    ) {
        AnalogClock(
            modifier = Modifier
                .size(300.dp)
                .shadow(
                    elevation = 8.dp,
                    shape = CircleShape
                )
        )
    }
}
```

## 常见问题

### 1. Canvas 和 Modifier.drawXXX 有什么区别？

**回答**：Canvas 和 Modifier.drawXXX 都可以用于自定义绘制，但它们有几个关键区别：

- **用途不同**：
    - `Canvas` 是一个独立的可组合函数，用于创建完全自定义的绘制区域
    - `Modifier.drawXXX` 是修饰符，用于为现有组件添加自定义绘制效果

- **适用场景**：
    - 当需要创建完全自定义的 UI 元素时，使用 `Canvas`
    - 当需要为现有组件添加背景、装饰或覆盖层时，使用 `Modifier.drawXXX`

- **常见的 Modifier.drawXXX 变体**：
    - `Modifier.drawBehind`：在组件内容之前绘制（背景）
    - `Modifier.drawWithContent`：在绘制组件内容的同时进行自定义绘制
    - `Modifier.drawWithCache`：缓存绘制操作，提高性能

选择指南：如果你需要创建一个完全自定义的 UI 元素（如图表、时钟等），使用 Canvas；如果你只需要为现有组件添加自定义背景或装饰，使用
Modifier.drawXXX。

### 2. 如何处理触摸事件和交互？

**回答**：在自定义绘制中处理触摸事件和交互有几种方法：

1. **使用 pointerInput 修饰符**：

```kotlin
Canvas(
    modifier = Modifier
        .pointerInput(Unit) {
            detectTapGestures { offset ->
                // 处理点击事件
                // offset 包含点击位置的 x 和 y 坐标
            }
        }
) {
    // 绘制代码
}
```

2. **使用 detectDragGestures 处理拖动**：

```kotlin
var position by remember { mutableStateOf(Offset.Zero) }

Canvas(
    modifier = Modifier
        .pointerInput(Unit) {
            detectDragGestures { change, dragAmount ->
                change.consume()
                position += dragAmount
            }
        }
) {
    // 使用 position 进行绘制
    drawCircle(
        color = Color.Red,
        radius = 50f,
        center = position
    )
}
```

3. **使用 transformable 修饰符处理缩放和旋转**：

```kotlin
var scale by remember { mutableStateOf(1f) }
var rotation by remember { mutableStateOf(0f) }
var offset by remember { mutableStateOf(Offset.Zero) }

val state = rememberTransformableState { zoomChange, offsetChange, rotationChange ->
    scale *= zoomChange
    rotation += rotationChange
    offset += offsetChange
}

Canvas(
    modifier = Modifier
        .transformable(state = state)
) {
    // 应用变换
    withTransform({
        translate(offset.x, offset.y)
        rotate(rotation)
        scale(scale)
    }) {
        // 绘制代码
    }
}
```

4. **检测点击特定形状**：

```kotlin
Canvas(
    modifier = Modifier
        .pointerInput(Unit) {
            detectTapGestures { offset ->
                // 计算点击位置到圆心的距离
                val distance = (offset - center).getDistance()

                // 检查是否点击了圆形
                if (distance <= radius) {
                    // 处理圆形点击事件
                }
            }
        }
) {
    // 绘制圆形
    drawCircle(
        color = Color.Blue,
        radius = radius,
        center = center
    )
}
```

### 3. 如何优化自定义绘制的性能？

**回答**：优化自定义绘制性能的几种方法：

1. **使用 drawWithCache**：

```kotlin
Modifier.drawWithCache {
    // 创建和缓存绘制对象
    val path = Path().apply {
        // 配置路径
    }

    val brush = Brush.linearGradient(
        colors = listOf(Color.Red, Color.Blue)
    )

    // 返回绘制操作
    onDrawBehind {
        // 使用缓存的对象进行绘制
        drawPath(path, brush)
    }
}
```

2. **避免在绘制回调中创建对象**：

```kotlin
// 不好的做法
Canvas {
    val paint = Paint() // 每次重绘都创建新对象
    // 使用 paint 绘制
}

// 好的做法
val paint = remember { Paint() } // 只创建一次
Canvas {
    // 使用 paint 绘制
}
```

3. **使用 graphicsLayer 进行硬件加速**：

```kotlin
Box(
    modifier = Modifier
        .graphicsLayer {
            // 启用硬件加速
            renderEffect = android.graphics.RenderEffect.createBlurEffect(
                10f, 10f, android.graphics.Shader.TileMode.DECAL
            )
        }
) {
    // 内容
}
```

4. **限制重组和重绘**：

```kotlin
// 使用 remember 缓存计算结果
val points = remember(data) {
    // 根据数据计算点的位置
    calculatePoints(data)
}

Canvas {
    // 使用缓存的点进行绘制
    for (point in points) {
        drawCircle(center = point, radius = 5f, color = Color.Red)
    }
}
```

5. **使用适当的绘制原语**：

```kotlin
// 不好的做法：使用多个 drawLine 绘制矩形
drawLine(start = Offset(0f, 0f), end = Offset(100f, 0f), strokeWidth = 1f)
drawLine(start = Offset(100f, 0f), end = Offset(100f, 100f), strokeWidth = 1f)
drawLine(start = Offset(100f, 100f), end = Offset(0f, 100f), strokeWidth = 1f)
drawLine(start = Offset(0f, 100f), end = Offset(0f, 0f), strokeWidth = 1f)

// 好的做法：直接使用 drawRect
drawRect(topLeft = Offset(0f, 0f), size = Size(100f, 100f), color = Color.Red)
```

### 4. 如何在自定义绘制中使用动画？

**回答**：在自定义绘制中使用动画有几种方法：

1. **使用 animateXxxAsState**：

```kotlin
var progress by remember { mutableStateOf(0f) }

// 创建动画值
val animatedProgress by animateFloatAsState(
    targetValue = progress,
    animationSpec = tween(durationMillis = 1000)
)

Canvas {
    // 使用动画值进行绘制
    drawArc(
        startAngle = 0f,
        sweepAngle = 360f * animatedProgress,
        // 其他参数
    )
}

// 在某处更新 progress 值
LaunchedEffect(Unit) {
    progress = 1f
}
```

2. **使用 Animatable**：

```kotlin
// 创建 Animatable 对象
val animatedValue = remember { Animatable(0f) }

// 启动动画
LaunchedEffect(key1 = Unit) {
    animatedValue.animateTo(
        targetValue = 1f,
        animationSpec = spring(dampingRatio = 0.7f)
    )
}

Canvas {
    // 使用当前动画值进行绘制
    val currentValue = animatedValue.value
    // 绘制代码
}
```

3. **使用 InfiniteTransition 创建无限循环动画**：

```kotlin
val infiniteTransition = rememberInfiniteTransition()

// 创建无限循环的动画值
val rotation by infiniteTransition.animateFloat(
    initialValue = 0f,
    targetValue = 360f,
    animationSpec = infiniteRepeatable(
        animation = tween(2000, easing = LinearEasing),
        repeatMode = RepeatMode.Restart
    )
)

Canvas {
    // 应用旋转变换
    rotate(rotation) {
        // 绘制代码
    }
}
```

4. **使用 updateTransition 处理状态变化**：

```kotlin
// 定义状态
enum class CircleState { Small, Large }
var state by remember { mutableStateOf(CircleState.Small) }

// 创建过渡
val transition = updateTransition(state, label = "Circle Transition")

// 定义动画值
val radius by transition.animateFloat(
    transitionSpec = { spring(stiffness = 50f) },
    label = "Circle Radius"
) { circleState ->
    when (circleState) {
        CircleState.Small -> 50f
        CircleState.Large -> 150f
    }
}

Canvas {
    // 使用动画半径绘制圆形
    drawCircle(
        color = Color.Red,
        radius = radius
    )
}

// 切换状态
Button(onClick = {
    state = when (state) {
        CircleState.Small -> CircleState.Large
        CircleState.Large -> CircleState.Small
    }
}) {
    Text("Toggle Size")
}
```
