# 4.19 ModifierLocal（Provider & Consumer）

> "在 Modifier 链中传递数据就像组件间的悄悄话，ModifierLocal 就是这个传话筒，让修饰符之间也能'八卦'
> 起来！" 🤫

## 概念介绍

ModifierLocal 是 Jetpack Compose 中一个强大而精巧的机制，它允许在 Modifier 链中从上游向下游传递数据。这与
CompositionLocal
类似，但专门用于 Modifier 的上下文。通过 ModifierLocal，我们可以在 Modifier
链中的某个点提供（Provider）数据，然后在链中的后续修饰符中消费（Consumer）这些数据，而无需显式地将这些数据作为参数传递。

这种机制特别适合于需要在多个修饰符之间共享信息的场景，例如主题样式、布局约束或交互状态等。ModifierLocal
由两部分组成：Provider（提供者）和 Consumer（消费者），它们共同构成了 Modifier 链中的数据传递机制。

## 知识要点

- ModifierLocal 是 Modifier 链中的数据传递机制，类似于 CompositionLocal 但专用于修饰符
- 它由 Provider 和 Consumer 两部分组成，分别负责提供和消费数据
- Provider 在 Modifier 链中注入数据，Consumer 在链中的后续部分读取这些数据
- ModifierLocal 是单向的，只能从链的前面向后面传递数据
- 每个 ModifierLocal 实例都有一个默认值，当没有对应的 Provider 时会使用该值
- ModifierLocal 适用于需要在多个修饰符之间共享信息的场景
- 它是 Compose 1.2.0 及以上版本引入的相对较新的 API

## 基础代码示例

下面是一个简单的例子，展示如何使用 ModifierLocal 在 Modifier 链中传递和使用数据：

```kotlin
@Composable
fun ModifierLocalExample() {
    // 1. 创建一个 ModifierLocal 实例
    // 这里我们创建一个用于传递颜色的 ModifierLocal
    val colorModifierLocal = remember {
        ModifierLocal(defaultValue = Color.Gray) // 默认值为灰色
    }

    Box(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        contentAlignment = Alignment.Center
    ) {
        Box(
            modifier = Modifier
                // 2. 使用 modifierLocalProvider 提供值
                .modifierLocalProvider(colorModifierLocal, Color.Blue)
                // 3. 创建一个自定义修饰符，它会消费 ModifierLocal 中的值
                .then(
                    Modifier.composed {
                        // 4. 使用 modifierLocalConsumer 消费值
                        val color = modifierLocalConsumer(colorModifierLocal)
                        Modifier.background(color, RoundedCornerShape(8.dp))
                    }
                )
                .size(200.dp)
        ) {
            Text(
                text = "使用 ModifierLocal 传递的颜色",
                color = Color.White,
                modifier = Modifier.align(Alignment.Center)
            )
        }
    }
}
```

## 进阶用法

### 1. 创建主题感知的边框修饰符

使用 ModifierLocal 可以创建一个主题感知的边框修饰符，它会根据上游提供的主题信息自动调整边框样式：

```kotlin
@Composable
fun ThemeAwareBorderExample() {
    // 创建用于传递边框样式的 ModifierLocal
    val borderStyleLocal = remember {
        data class BorderStyle(
            val width: Dp = 1.dp,
            val color: Color = Color.Black,
            val shape: Shape = RectangleShape
        )

        ModifierLocal(defaultValue = BorderStyle())
    }

    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(16.dp)
    ) {
        // 创建一个自定义的边框修饰符函数
        fun Modifier.themeAwareBorder(): Modifier = composed {
            val borderStyle = modifierLocalConsumer(borderStyleLocal)
            Modifier.border(
                width = borderStyle.width,
                color = borderStyle.color,
                shape = borderStyle.shape
            )
        }

        // 默认样式
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(100.dp)
                .themeAwareBorder()
                .padding(16.dp)
        ) {
            Text(
                text = "默认边框样式",
                modifier = Modifier.align(Alignment.Center)
            )
        }

        // 自定义样式 1
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(100.dp)
                .modifierLocalProvider(
                    borderStyleLocal,
                    borderStyleLocal.defaultValue.copy(
                        width = 2.dp,
                        color = MaterialTheme.colorScheme.primary,
                        shape = RoundedCornerShape(8.dp)
                    )
                )
                .themeAwareBorder()
                .padding(16.dp)
        ) {
            Text(
                text = "主题色圆角边框",
                modifier = Modifier.align(Alignment.Center)
            )
        }

        // 自定义样式 2
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(100.dp)
                .modifierLocalProvider(
                    borderStyleLocal,
                    borderStyleLocal.defaultValue.copy(
                        width = 3.dp,
                        color = MaterialTheme.colorScheme.error,
                        shape = CutCornerShape(16.dp)
                    )
                )
                .themeAwareBorder()
                .padding(16.dp)
        ) {
            Text(
                text = "错误色切角边框",
                modifier = Modifier.align(Alignment.Center)
            )
        }
    }
}
```

### 2. 创建嵌套层级感知的内边距

使用 ModifierLocal 可以创建一个能够感知嵌套层级的内边距修饰符，随着嵌套层级的增加，内边距会自动调整：

```kotlin
@Composable
fun NestedPaddingExample() {
    // 创建用于传递嵌套级别的 ModifierLocal
    val nestLevelLocal = remember { ModifierLocal(defaultValue = 0) }

    // 创建一个自定义的嵌套容器修饰符
    fun Modifier.nestedContainer(
        color: Color = MaterialTheme.colorScheme.surface,
        content: @Composable BoxScope.() -> Unit
    ): Modifier = composed {
        // 获取当前嵌套级别
        val currentLevel = modifierLocalConsumer(nestLevelLocal)
        // 计算基于级别的内边距
        val padding = 16.dp - (currentLevel * 4).dp.coerceAtLeast(4.dp)

        // 创建一个新的 Composable 来渲染内容
        Modifier.composed {
            Box(
                modifier = Modifier
                    .fillMaxWidth()
                    .background(
                        color = color.copy(alpha = 1f - (currentLevel * 0.1f).coerceAtMost(0.7f)),
                        shape = RoundedCornerShape(8.dp)
                    )
                    .padding(padding)
                    // 为子内容提供增加后的嵌套级别
                    .modifierLocalProvider(nestLevelLocal, currentLevel + 1),
                content = content
            )
            Modifier
        }
    }

    // 使用嵌套容器
    Box(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp)
    ) {
        Modifier
            .nestedContainer(color = MaterialTheme.colorScheme.primary) {
                Text(
                    text = "第一层嵌套",
                    color = Color.White,
                    modifier = Modifier.padding(vertical = 8.dp)
                )

                Modifier
                    .nestedContainer(color = MaterialTheme.colorScheme.secondary) {
                        Text(
                            text = "第二层嵌套",
                            color = Color.White,
                            modifier = Modifier.padding(vertical = 8.dp)
                        )

                        Modifier
                            .nestedContainer(color = MaterialTheme.colorScheme.tertiary) {
                                Text(
                                    text = "第三层嵌套",
                                    color = Color.White,
                                    modifier = Modifier.padding(vertical = 8.dp)
                                )

                                Modifier
                                    .nestedContainer(color = MaterialTheme.colorScheme.error) {
                                        Text(
                                            text = "第四层嵌套",
                                            color = Color.White,
                                            modifier = Modifier.padding(vertical = 8.dp)
                                        )
                                    }
                            }
                    }
            }
    }
}
```

### 3. 实现坐标系转换传递

使用 ModifierLocal 可以在绘制修饰符之间传递坐标系转换信息，实现复杂的绘制效果：

```kotlin
@Composable
fun CoordinateTransformExample() {
    // 创建用于传递坐标变换的 ModifierLocal
    val transformLocal = remember {
        data class Transform(
            val scale: Float = 1f,
            val rotation: Float = 0f,
            val offset: Offset = Offset.Zero
        )

        ModifierLocal(defaultValue = Transform())
    }

    // 创建一个应用变换的修饰符
    fun Modifier.withTransform(
        scale: Float = 1f,
        rotation: Float = 0f,
        offset: Offset = Offset.Zero
    ): Modifier = composed {
        val currentTransform = modifierLocalConsumer(transformLocal)
        val newTransform = transformLocal.defaultValue.copy(
            scale = currentTransform.scale * scale,
            rotation = currentTransform.rotation + rotation,
            offset = currentTransform.offset + offset
        )

        Modifier.modifierLocalProvider(transformLocal, newTransform)
    }

    // 创建一个使用变换信息的绘制修饰符
    fun Modifier.drawWithTransform(
        onDraw: DrawScope.(Transform) -> Unit
    ): Modifier = drawBehind {
        val transform = modifierLocalConsumer(transformLocal)

        // 应用变换
        withTransform({
            scale(transform.scale)
            rotate(transform.rotation)
            translate(transform.offset.x, transform.offset.y)
        }) {
            onDraw(transform)
        }
    }

    Box(
        modifier = Modifier
            .fillMaxSize()
            .padding(32.dp),
        contentAlignment = Alignment.Center
    ) {
        var rotation by remember { mutableStateOf(0f) }
        var scale by remember { mutableStateOf(1f) }

        // 创建动画
        LaunchedEffect(Unit) {
            while (true) {
                withFrameMillis { frameTime ->
                    rotation = (frameTime / 20f) % 360
                    scale = 0.8f + (sin(frameTime / 1000f) * 0.2f).toFloat()
                }
            }
        }

        Box(
            modifier = Modifier
                .size(300.dp)
                // 应用第一层变换
                .withTransform(
                    scale = scale,
                    rotation = rotation
                )
                // 绘制外层圆
                .drawWithTransform { transform ->
                    drawCircle(
                        color = MaterialTheme.colorScheme.primary,
                        radius = size.minDimension / 2
                    )
                }
                // 应用第二层变换
                .withTransform(
                    rotation = -rotation * 2,
                    offset = Offset(80f, 0f)
                )
                // 绘制第二层圆
                .drawWithTransform { transform ->
                    drawCircle(
                        color = MaterialTheme.colorScheme.secondary,
                        radius = size.minDimension / 4
                    )
                }
                // 应用第三层变换
                .withTransform(
                    rotation = rotation * 3,
                    offset = Offset(40f, 0f)
                )
                // 绘制第三层圆
                .drawWithTransform { transform ->
                    drawCircle(
                        color = MaterialTheme.colorScheme.tertiary,
                        radius = size.minDimension / 8
                    )
                }
        )
    }
}
```

## 常见问题

### 1. ModifierLocal 和 CompositionLocal 有什么区别？

**回答**：虽然两者都是用于传递数据的机制，但它们有几个关键区别：

- `ModifierLocal` 专门用于 Modifier 链中的数据传递，而 `CompositionLocal` 用于 Composition 树中的数据传递
- `ModifierLocal` 只能从 Modifier 链的前面向后面单向传递数据，而 `CompositionLocal` 可以在整个组合树中访问
- `ModifierLocal` 的作用域限于单个 Modifier 链，而 `CompositionLocal` 的作用域可以跨越多个组件
- `ModifierLocal` 使用 `modifierLocalProvider` 和 `modifierLocalConsumer` 函数，而 `CompositionLocal`
  使用
  `CompositionLocalProvider` 和 `current` 属性
- `ModifierLocal` 是 Compose 1.2.0 及以上版本引入的较新 API，而 `CompositionLocal` 从早期版本就存在

### 2. 为什么我的 ModifierLocal 值没有被正确传递？

**回答**：可能的原因包括：

- Modifier 链的顺序问题：Provider 必须在 Consumer 之前的链中
- 使用了 `then()` 方法但顺序不正确：`then()` 方法会将右侧的修饰符添加到链的末尾
- 在不同的 Modifier 链中：ModifierLocal 只在同一个连续的 Modifier 链中有效
- 使用了旧版本的 Compose：ModifierLocal 需要 Compose 1.2.0 或更高版本

示例修复：

```kotlin
// 错误：Consumer 在 Provider 之前
Modifier
    .composed { modifierLocalConsumer(myLocal) } // 无法获取值
    .modifierLocalProvider(myLocal, value)

// 正确：Provider 在 Consumer 之前
Modifier
    .modifierLocalProvider(myLocal, value)
    .composed { modifierLocalConsumer(myLocal) } // 可以获取值
```

### 3. 如何在多个 ModifierLocal 之间共享或组合数据？

**回答**：有几种方法可以在多个 ModifierLocal 之间共享或组合数据：

1. **嵌套 Provider**：在一个 Provider 内部使用另一个 Provider 的值

```kotlin
Modifier
    .modifierLocalProvider(localA, valueA)
    .composed {
        val valueFromA = modifierLocalConsumer(localA)
        Modifier.modifierLocalProvider(localB, createValueB(valueFromA))
    }
```

2. **创建复合数据类**：设计一个包含多个相关值的数据类

```kotlin
data class ThemeValues(
    val colors: Colors,
    val typography: Typography,
    val shapes: Shapes
)

val themeLocal = ModifierLocal(defaultValue = ThemeValues(
    colors = Colors.Default,
    typography = Typography.Default,
    shapes = Shapes.Default
))
```

3. **使用扩展函数组合多个 ModifierLocal**：

```kotlin
fun Modifier.withTheme(
    colors: Colors? = null,
    typography: Typography? = null,
    shapes: Shapes? = null
): Modifier = composed {
    val currentColors = modifierLocalConsumer(colorsLocal)
    val currentTypography = modifierLocalConsumer(typographyLocal)
    val currentShapes = modifierLocalConsumer(shapesLocal)

    this
        .modifierLocalProvider(colorsLocal, colors ?: currentColors)
        .modifierLocalProvider(typographyLocal, typography ?: currentTypography)
        .modifierLocalProvider(shapesLocal, shapes ?: currentShapes)
}
```

### 4. ModifierLocal 会影响性能吗？

**回答**：ModifierLocal 的性能影响通常很小，但在某些情况下需要注意：

- 每个 ModifierLocal 实例都会在 Modifier 链中维护一个值，所以创建大量 ModifierLocal 实例可能会增加内存使用
- 频繁更改 ModifierLocal 的值可能会触发重组，影响性能
- 在热路径上过度使用 ModifierLocal 可能会增加布局和绘制的计算开销
- 与直接传递参数相比，ModifierLocal 有轻微的间接开销，但通常可以忽略不计

最佳实践：

- 只为真正需要在多个修饰符之间共享的数据创建 ModifierLocal
- 避免在 ModifierLocal 中存储大型对象或频繁变化的数据
- 考虑使用 `remember` 缓存 ModifierLocal 实例
- 在性能关键的路径上，可以考虑直接传递参数而不是使用 ModifierLocal
