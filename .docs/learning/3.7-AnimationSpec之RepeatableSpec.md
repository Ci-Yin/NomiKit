# 3.7 AnimationSpec 之 RepeatableSpec

> "如果说SpringSpec是弹簧床，TweenSpec是公交车，那么RepeatableSpec就是DJ打碟现场！'再来一遍！再来一遍！'
> ——它让你的动画像洗脑神曲一样循环播放，根本停不下来！" 🔄

## 概念介绍

RepeatableSpec是Jetpack
Compose动画系统中专门用于创建重复动画的规格类型。它通过包装其他动画规格（如TweenSpec、SpringSpec等）并添加重复行为，使单次动画可以按照指定的方式和次数重复执行。

RepeatableSpec的核心思想是：

- 将一个基础动画规格包装起来
- 定义重复的次数（有限次数）
- 指定重复的模式（如何在每次重复时处理动画）

重复模式主要有两种：

- **Restart**：每次重复都从初始值重新开始动画
- **Reverse**：每次重复都反转动画方向，形成来回的效果

RepeatableSpec特别适合以下场景：

- 需要引起用户注意的提示动画
- 加载指示器和进度反馈
- 强调某个元素的重要性
- 创建有节奏感的UI元素
- 需要有限次数重复的任何动画效果

与无限重复的InfiniteRepeatableSpec不同，RepeatableSpec会在指定的重复次数后停止，适用于那些需要重复但最终应该结束的动画场景。

## 知识要点

- **基本概念**：RepeatableSpec的工作原理和组成部分
- **关键参数**：
    - `iterations`：重复次数（必须大于0）
    - `animation`：基础动画规格
    - `repeatMode`：重复模式（Restart或Reverse）
- **重复模式**：Restart和Reverse的区别和适用场景
- **计数规则**：重复次数的计算方式（包括初始动画）
- **与其他规格组合**：如何选择合适的基础动画规格
- **性能考虑**：重复动画的性能影响和优化方法
- **适用场景**：何时选择RepeatableSpec而非其他动画规格
- **与InfiniteRepeatableSpec的区别**：有限重复与无限重复的选择

```kotlin
@Composable
fun BasicRepeatableSpecExample() {
    // 创建一个状态来跟踪动画是否应该运行
    var isAnimating by remember { mutableStateOf(false) }

    // 使用RepeatableSpec创建重复动画
    val offset by animateDpAsState(
        targetValue = if (isAnimating) 200.dp else 0.dp,
        // 使用RepeatableSpec包装TweenSpec，重复3次，使用Restart模式
        animationSpec = repeatable(
            iterations = 3,
            animation = tween(durationMillis = 1000, easing = LinearEasing),
            repeatMode = RepeatMode.Restart
        ),
        // 动画结束后重置状态
        finishedListener = { isAnimating = false }
    )

    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(
            text = "RepeatableSpec基本示例",
            style = MaterialTheme.typography.headlineMedium,
            modifier = Modifier.padding(bottom = 32.dp)
        )

        // 动画轨道
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(100.dp)
                .background(Color.LightGray.copy(alpha = 0.3f))
                .border(1.dp, Color.Gray),
            contentAlignment = Alignment.CenterStart
        ) {
            // 移动对象
            Box(
                modifier = Modifier
                    .offset(x = offset)
                    .size(50.dp)
                    .background(
                        color = Color(0xFF6200EE),
                        shape = CircleShape
                    ),
                contentAlignment = Alignment.Center
            ) {
                Text(
                    text = "🚀",
                    fontSize = 24.sp
                )
            }
        }

        Spacer(modifier = Modifier.height(32.dp))

        // 控制按钮
        Button(
            onClick = { isAnimating = true },
            enabled = !isAnimating,
            modifier = Modifier.width(200.dp)
        ) {
            Text(text = if (isAnimating) "动画中..." else "开始动画")
        }

        Spacer(modifier = Modifier.height(32.dp))

        // 说明文本
        Card(
```

```kotlin
@Composable
```

```kotlin
    // 创建状态来跟踪动画
    var isAnimatingTween by remember { mutableStateOf(false) }
    var isAnimatingSpring by remember { mutableStateOf(false) }
    var isAnimatingKeyframes by remember { mutableStateOf(false) }

    // 使用TweenSpec作为基础的RepeatableSpec
    val tweenOffset by animateDpAsState(
        targetValue = if (isAnimatingTween) 200.dp else 0.dp,
        animationSpec = repeatable(
            iterations = 2,
            animation = tween(durationMillis = 1000, easing = FastOutSlowInEasing),
            repeatMode = RepeatMode.Reverse
        ),
        finishedListener = { isAnimatingTween = false }
    )

    // 使用SpringSpec作为基础的RepeatableSpec
    val springOffset by animateDpAsState(
        targetValue = if (isAnimatingSpring) 200.dp else 0.dp,
        animationSpec = repeatable(
            iterations = 2,
            animation = spring(
                dampingRatio = Spring.DampingRatioMediumBouncy,
                stiffness = Spring.StiffnessMedium
            ),
            repeatMode = RepeatMode.Reverse
        ),
        finishedListener = { isAnimatingSpring = false }
    )

    // 使用KeyframesSpec作为基础的RepeatableSpec
```

### 重复次数示例

```kotlin
@Composable
fun IterationsExample() {
    // 创建状态来跟踪动画和当前重复次数
    var selectedIterations by remember { mutableStateOf(3) }
    var isAnimating by remember { mutableStateOf(false) }
    var currentIteration by remember { mutableStateOf(0) }

    // 使用RepeatableSpec创建动画
    val progress by animateFloatAsState(
        targetValue = if (isAnimating) 1f else 0f,
        animationSpec = repeatable(
            iterations = selectedIterations,
            animation = tween(durationMillis = 1000),
            repeatMode = RepeatMode.Restart
        ),
        finishedListener = { 
            isAnimating = false
            currentIteration = 0
        }
    )

    // 跟踪当前迭代次数
    LaunchedEffect(isAnimating, progress) {
        if (isAnimating && progress == 1f) {
            // 当一次迭代完成时更新计数
            // 注意：这种方法在实际应用中可能不够精确，因为动画可能会跳过某些值
            currentIteration++
        }
    }

    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(
            text = "重复次数示例",
            style = MaterialTheme.typography.headlineMedium,
            modifier = Modifier.padding(bottom = 32.dp)
        )

        // 重复次数选择
        Text(
            text = "重复次数: $selectedIterations",
            style = MaterialTheme.typography.titleMedium,
            modifier = Modifier.align(Alignment.Start)
        )

        Slider(
            value = selectedIterations.toFloat(),
            onValueChange = { selectedIterations = it.toInt() },
            valueRange = 1f..5f,
            steps = 3,
            modifier = Modifier.fillMaxWidth()
        )

        Spacer(modifier = Modifier.height(32.dp))

        // 动画进度指示器
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(20.dp)
                .background(
                    color = Color.LightGray.copy(alpha = 0.3f),
                    shape = RoundedCornerShape(10.dp)

            Box(

        }

        Spacer(modifier = Modifier.height(16.dp))

        // 显示当前迭代
        Text(
            text = "当前迭代: ${if (isAnimating) currentIteration + 1 else if (currentIteration > 0) selectedIterations else 0}/$selectedIterations",
            style = MaterialTheme.typography.titleMedium
        )

        Spacer(modifier = Modifier.height(32.dp))

        // 控制按钮
        Button(
            onClick = { 
                isAnimating = true
                currentIteration = 0
            },
            enabled = !isAnimating,
            modifier = Modifier.width(200.dp)
        ) {
            Text(text = if (isAnimating) "动画中..." else "开始动画")
        }

        Spacer(modifier = Modifier.height(32.dp))

        // 说明文本
        Card(
            modifier = Modifier.fillMaxWidth(),
            elevation = CardDefaults.cardElevation(4.dp)
        ) {
            Column(modifier = Modifier.padding(16.dp)) {
                Text(
                    text = "重复次数说明",
                    style = MaterialTheme.typography.titleMedium,
                    modifier = Modifier.padding(bottom = 8.dp)
                )

                Text("• iterations参数控制动画重复的次数")
                Text("• iterations必须大于0")
                Text("• 第一次动画也计入重复次数")
                Text("• 使用滑块调整重复次数，观察动画行为")

                Spacer(modifier = Modifier.height(8.dp))

                Text(
                    text = "注意：当repeatMode = Reverse时，一个完整的来回算作两次迭代",

            }
        }
    }
```

## 常见问题

### 1. RepeatableSpec与InfiniteRepeatableSpec有什么区别？

**答**：RepeatableSpec和InfiniteRepeatableSpec的主要区别在于：

1. **重复次数**：
    - RepeatableSpec：有限次数重复，由iterations参数指定
    - InfiniteRepeatableSpec：无限重复，直到动画被取消或组件被移除

2. **使用场景**：
    - RepeatableSpec：适用于需要特定次数重复的动画，如提示、反馈等
    - InfiniteRepeatableSpec：适用于持续运行的动画，如加载指示器、背景效果等

3. **结束行为**：
    - RepeatableSpec：完成指定次数后自动结束，可以使用finishedListener监听结束
    - InfiniteRepeatableSpec：理论上永不结束，需要外部逻辑来停止

4. **性能考虑**：
    - RepeatableSpec：由于有明确的结束点，系统可以更好地管理资源
    - InfiniteRepeatableSpec：需要注意在不需要时停止动画，避免资源浪费

选择哪一个取决于你的具体需求：如果动画应该在特定次数后停止，使用RepeatableSpec；如果动画应该持续运行直到明确停止，使用InfiniteRepeatableSpec。

### 2. 如何正确计算RepeatableSpec的总持续时间？

**答**：计算RepeatableSpec的总持续时间需要考虑以下因素：

1. **基础动画规格的持续时间**：
    - 对于TweenSpec：直接使用durationMillis
    - 对于SpringSpec：没有固定时长，但可以估算
    - 对于KeyframesSpec：使用其durationMillis

2. **重复次数(iterations)**：
    - 包括第一次动画在内的总次数

3. **重复模式(repeatMode)**：
    - Restart模式：每次重复都是完整的基础动画时长
    - Reverse模式：第一次后的重复可能只是"回程"，需要特别计算

**计算公式**：

- 对于Restart模式：总时长 ≈ 基础动画时长 × iterations
- 对于Reverse模式：总时长 ≈ 基础动画时长 × (iterations + 1) ÷ 2

**注意事项**：

- SpringSpec没有固定时长，所以使用SpringSpec作为基础时，总时长是不确定的
- 动画可能会因为其他因素（如组件重组）提前结束
- 实际动画时长可能会因系统负载等因素略有不同

如果需要精确控制总持续时间，建议使用TweenSpec或KeyframesSpec作为基础动画规格。

### 3. 为什么我的RepeatableSpec动画看起来不平滑？

**答**：RepeatableSpec动画不平滑可能有以下几个原因：

1. **重复模式问题**：
    - 使用Restart模式时，每次重复都会从初始值重新开始，可能造成视觉上的"跳变"
    - 解决方法：考虑使用Reverse模式创建更平滑的来回效果

2. **基础动画规格选择不当**：
    - 某些基础动画规格可能不适合重复，如某些SpringSpec配置
    - 解决方法：尝试不同的基础动画规格或调整其参数

3. **缓动函数(Easing)问题**：
    - 使用不适合重复的缓动函数可能导致衔接处不平滑
    - 解决方法：对于Restart模式，考虑使用循环友好的缓动函数；对于Reverse模式，确保缓动函数在起点和终点的速度相似

4. **重组或状态更新干扰**：
    - 组件重组或状态更新可能中断动画
    - 解决方法：确保动画状态稳定，避免不必要的重组

5. **性能问题**：
    - 设备性能不足可能导致帧率下降
    - 解决方法：简化动画，减少同时运行的动画数量

6. **动画值类型问题**：
    - 某些类型的值在动画过程中可能不够平滑
    - 解决方法：考虑使用更适合动画的值类型，如Float而非Int

通过调整这些因素，可以显著提高RepeatableSpec动画的平滑度和视觉质量。

### 4. 如何在RepeatableSpec动画中途停止或更改参数？

**答**：在RepeatableSpec动画中途停止或更改参数有几种方法：

1. **通过状态变化停止**：
    - 更改驱动动画的状态值，使目标值等于当前值
    - 这会使动画自然结束当前周期

   ```kotlin
   var targetValue by remember { mutableStateOf(100f) }
   val animatedValue by animateFloatAsState(
       targetValue = targetValue,
       animationSpec = repeatable(
           iterations = 3,
           animation = tween(durationMillis = 500),
           repeatMode = RepeatMode.Restart
       )
   )

   // 停止动画
   fun stopAnimation() {
       // 获取当前值并设置为目标值
       targetValue = animatedValue
   }
   ```

2. **使用Animatable代替animateXxxAsState**：
    - Animatable提供了更多控制，包括stop()方法
    - 可以在协程中精确控制动画流程

   ```kotlin
   val animatable = remember { Animatable(0f) }

   LaunchedEffect(key1) {
       // 启动动画
       animatable.animateTo(
           targetValue = 1f,
           animationSpec = repeatable(
               iterations = 3,
               animation = tween(durationMillis = 500),
               repeatMode = RepeatMode.Restart
           )
       )
   }

   // 在另一个协程中停止
   fun stopAnimation() {
       scope.launch {
           animatable.stop()
       }
   }
   ```

3. **使用动画键(key)重置**：
    - 更改LaunchedEffect的键值可以取消当前动画并启动新动画
    - 适用于需要完全重置动画的场景

   ```kotlin
   var animationKey by remember { mutableStateOf(0) }

   LaunchedEffect(animationKey) {
       // 动画逻辑
   }

   // 重置动画
   fun resetAnimation() {
       animationKey++
   }
   ```

4. **更改参数**：
    - 要更改RepeatableSpec的参数，需要创建一个新的RepeatableSpec实例
    - 可以使用状态变量来控制参数

   ```kotlin
   var iterations by remember { mutableStateOf(3) }

   val animatedValue by animateFloatAsState(
       targetValue = 1f,
       animationSpec = repeatable(
           iterations = iterations,
           animation = tween(500),
           repeatMode = RepeatMode.Reverse
       )
   )

   // 更改重复次数
   fun changeIterations(newValue: Int) {
       iterations = newValue
   }
   ```

选择哪种方法取决于你的具体需求和动画复杂度。对于简单场景，状态变化方法通常足够；对于复杂场景，Animatable提供了更精细的控制。
