# 6.7 自定义触摸：二维滑动监测

> "在 Compose 的世界里，二维滑动就像是给你的 App 装上了全方位雷达，不仅能感知上下左右，还能捕捉到用户指尖的每一个微妙变化。掌握了二维滑动，你的
> UI 就能像《钢铁侠》里的 Jarvis 一样，全方位响应用户的每一个手势！" 🕹️

## 概念介绍

二维滑动监测是 Jetpack Compose
中触摸事件处理的高级应用，它允许我们同时检测和响应用户在水平和垂直两个方向上的滑动手势。与一维滑动不同，二维滑动能够捕获更复杂的手势交互，如对角线拖动、自由绘制、缩放旋转等，为用户提供更加丰富和直观的交互体验。

在 Compose 中，二维滑动监测主要通过 `Modifier.pointerInput` 修饰符结合更底层的手势 API 实现。这些 API
提供了对原始触摸事件的完整访问，使开发者能够构建自定义的手势检测器，实现各种复杂的交互效果。

二维滑动在许多现代应用中都有广泛应用，例如地图应用中的平移和缩放、图像编辑器中的自由绘制、游戏中的控制器等。通过掌握二维滑动监测，我们可以为用户创造更加自然、直观和沉浸式的交互体验。

## 基础代码示例

下面是一个简单的例子，展示如何使用 `Modifier.pointerInput` 实现基本的二维拖动功能：

```kotlin
@Composable
fun TwoDimensionalDragExample() {
    // 记录拖动位置
    var offsetX by remember { mutableStateOf(0f) }
    var offsetY by remember { mutableStateOf(0f) }
    
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(Color.LightGray),
        contentAlignment = Alignment.Center
    ) {
        // 可拖动的元素
        Box(
            modifier = Modifier
                .size(100.dp)
                .offset { IntOffset(offsetX.roundToInt(), offsetY.roundToInt()) }
                .background(Color.Blue, shape = RoundedCornerShape(8.dp))
                // 添加二维拖动功能
                .pointerInput(Unit) {
                    // 使用 detectDragGestures 检测拖动手势
                    detectDragGestures { change, dragAmount ->
                        // 消费触摸事件
                        change.consume()
                        
                        // 更新位置（同时处理水平和垂直方向）
                        offsetX += dragAmount.x
                        offsetY += dragAmount.y
                    }
                }
        )
        
        // 添加提示文本
        Text(
            text = "拖动蓝色方块\n当前位置: (${offsetX.roundToInt()}, ${offsetY.roundToInt()})",
            textAlign = TextAlign.Center,
            modifier = Modifier
                .align(Alignment.TopCenter)
                .padding(top = 16.dp),
            color = Color.Black,
            fontSize = 16.sp
        )
    }
}
```

在这个例子中，我们使用 `detectDragGestures` 函数来检测二维拖动手势，并根据拖动的距离同时更新元素在水平和垂直方向上的位置。

下面是一个更复杂的例子，展示如何实现自定义的二维滑动检测：

```kotlin
@Composable
fun CustomTwoDimensionalGestureExample() {
    // 记录触摸点的位置
    var currentPosition by remember { mutableStateOf(Offset.Zero) }
    // 记录所有触摸轨迹
    val touchPaths = remember { mutableStateListOf<List<Offset>>() }
    // 当前正在绘制的轨迹
    val currentPath = remember { mutableStateListOf<Offset>() }
    
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(Color.White)
            // 添加自定义触摸处理
            .pointerInput(Unit) {
                // 使用 awaitPointerEventScope 获取更底层的触摸事件
                awaitPointerEventScope {
                    while (true) {
                        // 等待按下事件
                        val downEvent = awaitFirstDown()
                        currentPosition = downEvent.position
                        
                        // 清空当前轨迹
                        currentPath.clear()
                        // 添加起始点
                        currentPath.add(currentPosition)
                        
                        // 处理移动事件
                        do {
                            val event = awaitPointerEvent()
                            // 获取第一个触摸点
                            val pointer = event.changes.first()
                            
                            // 更新当前位置
                            currentPosition = pointer.position
                            // 添加到轨迹中
                            currentPath.add(currentPosition)
                            
                            // 消费事件
                            pointer.consume()
                        } while (event.changes.any { it.pressed })
                        
                        // 当手指抬起时，保存当前轨迹
                        touchPaths.add(currentPath.toList())
                    }
                }
            }
    ) {
        // 绘制所有轨迹
        Canvas(modifier = Modifier.fillMaxSize()) {
            // 绘制已保存的轨迹
            touchPaths.forEach { path ->
                drawPath(
                    path = Path().apply {
                        if (path.isNotEmpty()) {
                            moveTo(path.first().x, path.first().y)
                            path.drop(1).forEach { point ->
                                lineTo(point.x, point.y)
                            }
                        }
                    },
                    color = Color.Blue,
                    style = Stroke(width = 5f, cap = StrokeCap.Round, join = StrokeJoin.Round)
                )
            }
            
            // 绘制当前轨迹
            drawPath(
                path = Path().apply {
                    if (currentPath.isNotEmpty()) {
                        moveTo(currentPath.first().x, currentPath.first().y)
                        currentPath.drop(1).forEach { point ->
                            lineTo(point.x, point.y)
                        }
                    }
                },
                color = Color.Red,
                style = Stroke(width = 5f, cap = StrokeCap.Round, join = StrokeJoin.Round)
            )
        }
        
        // 添加清除按钮
        Button(
            onClick = { 
                touchPaths.clear()
                currentPath.clear()
            },
            modifier = Modifier
                .align(Alignment.BottomCenter)
                .padding(bottom = 16.dp)
        ) {
            Text("清除")
        }
        
        // 添加提示文本
        Text(
            text = "在屏幕上自由绘制",
            modifier = Modifier
                .align(Alignment.TopCenter)
                .padding(top = 16.dp),
            color = Color.Black,
            fontSize = 16.sp
        )
    }
}
```

在这个例子中，我们使用了更底层的 `awaitPointerEventScope`
和相关函数来直接处理触摸事件，实现了一个简单的绘图应用。用户可以在屏幕上自由绘制，程序会记录和显示触摸轨迹。

### 1. 实现缩放和旋转手势

下面是一个实现图片缩放和旋转功能的例子：

```kotlin
@Composable
fun ImageZoomAndRotateExample() {
    // 缩放比例
    var scale by remember { mutableStateOf(1f) }
    // 旋转角度
    var rotationAngle by remember { mutableStateOf(0f) }
    // 平移偏移量
    var offset by remember { mutableStateOf(Offset.Zero) }
    
    // 图片资源
    val imageRes = painterResource(id = R.drawable.sample_image)
    
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(Color.Black),
        contentAlignment = Alignment.Center
    ) {
        // 图片容器
        Box(
            modifier = Modifier
                .fillMaxSize()
                // 添加变换
                .graphicsLayer(
                    scaleX = scale,
                    scaleY = scale,
                    rotationZ = rotationAngle,
                    translationX = offset.x,
                    translationY = offset.y
                )
                // 添加手势检测
                .pointerInput(Unit) {
                    // 检测变换手势（缩放、旋转、平移）

// 检测变换手势的扩展函数
suspend fun PointerInputScope.detectTransformGestures(
    panZoomLock: Boolean = false,
    onGesture: (centroid: Offset, pan: Offset, zoom: Float, rotation: Float) -> Unit
) {
    awaitPointerEventScope {
        var rotation = 0f
        var zoom = 1f
        var pan = Offset.Zero
        var pastTouchSlop = false
        val touchSlop = viewConfiguration.touchSlop
        
        awaitFirstDown(requireUnconsumed = false)
        
        do {
            val event = awaitPointerEvent()
            val canceled = event.changes.any { it.positionChanged() }
            
            if (event.changes.size == 2) {
                // 获取两个触摸点
                val first = event.changes[0]
                val second = event.changes[1]
                
                // 如果有一个触摸点已经被消费，跳过处理
                if (first.consumed.positionChange || second.consumed.positionChange) {
                    continue
                }
                
                // 计算两个触摸点的中心点
                val centroid = (first.position + second.position) / 2f
                
                // 计算两个触摸点之间的距离和角度
                val firstPrevPos = first.previousPosition
                val secondPrevPos = second.previousPosition
                
                val prevCentroid = (firstPrevPos + secondPrevPos) / 2f
                val prevDelta = secondPrevPos - firstPrevPos
                val currDelta = second.position - first.position
                
                // 计算缩放比例
                val prevDistance = prevDelta.getDistance()
                val currDistance = currDelta.getDistance()
                val newZoom = if (prevDistance > 0) currDistance / prevDistance else 1f
                
                // 计算旋转角度
                val prevAngle = atan2(prevDelta.y, prevDelta.x)
                val currAngle = atan2(currDelta.y, currDelta.x)
                val newRotation = (currAngle - prevAngle) * 180f / PI.toFloat()
                
                // 计算平移距离
                val newPan = centroid - prevCentroid
                
                if (!pastTouchSlop) {
                    // 检查是否超过触摸阈值
                    zoom *= newZoom
                    rotation += newRotation
                    pan += newPan
                    
                    val panDistance = pan.getDistance()
                    val zoomChange = abs(zoom - 1f)
                    val rotationChange = abs(rotation)
                    
                    if (panDistance > touchSlop || zoomChange > 0.1f || rotationChange > 1f) {
                        pastTouchSlop = true
                    }
                }
                
                if (pastTouchSlop) {
                    // 如果已经超过触摸阈值，调用回调函数
                    if (panZoomLock) {
                        // 如果启用了平移缩放锁定，只允许平移或缩放/旋转
                        if (newZoom != 1f || newRotation != 0f) {
                            onGesture(centroid, Offset.Zero, newZoom, newRotation)
                        } else {
                            onGesture(centroid, newPan, 1f, 0f)
                        }
                    } else {
                        // 否则，允许同时进行平移、缩放和旋转
                        onGesture(centroid, newPan, newZoom, newRotation)
                    }
                    
                    // 消费事件
                    first.consume()
                    second.consume()
                }
            }
        } while (!canceled && event.changes.any { it.pressed })
    }
}
```

在这个例子中，我们实现了一个自定义的 `detectTransformGestures`
函数，用于检测缩放、旋转和平移手势。用户可以使用双指在屏幕上进行缩放、旋转和平移操作，实现对图片的交互式控制。

### 2. 实现多点触控绘图板

下面是一个支持多点触控的绘图板实现：

```kotlin
@Composable
fun MultiTouchDrawingBoard() {
    // 存储所有触摸轨迹，按触摸点 ID 分组
    val touchPaths = remember { mutableStateMapOf<Int, MutableList<Offset>>() }
    // 当前选择的颜色
    var currentColor by remember { mutableStateOf(Color.Black) }
    // 当前选择的笔触宽度
    var strokeWidth by remember { mutableStateOf(5f) }
    
    // 可选的颜色列表
    val colors = listOf(
        Color.Black,
        Color.Red,
        Color.Green,
        Color.Blue,
        Color.Yellow,
        Color.Magenta,
        Color.Cyan
    )
    
    Column(
        modifier = Modifier.fillMaxSize()
    ) {
        // 绘图区域
        Box(
            modifier = Modifier
                .weight(1f)
                .fillMaxWidth()
                .background(Color.White)
                // 添加多点触控支持
                .pointerInput(Unit) {
                    awaitPointerEventScope {
                        while (true) {
                            // 等待触摸事件
                            val event = awaitPointerEvent()
                            
                            // 处理所有触摸点
                            event.changes.forEach { pointerInputChange ->
                                // 获取触摸点 ID
                                val pointerId = pointerInputChange.id.value
                                
                                when {
                                    // 触摸点按下
                                    pointerInputChange.pressed && pointerInputChange.previousPressed -> {
                                        // 获取或创建该触摸点的轨迹
                                        val path = touchPaths.getOrPut(pointerId) { mutableListOf() }
                                        // 添加当前位置到轨迹中
                                        path.add(pointerInputChange.position)
                                    }
                                    // 触摸点刚刚按下
                                    pointerInputChange.pressed && !pointerInputChange.previousPressed -> {
                                        // 创建新轨迹
                                        val path = mutableListOf<Offset>()
                                        // 添加起始点
                                        path.add(pointerInputChange.position)
                                        // 存储轨迹
                                        touchPaths[pointerId] = path
                                    }
                                    // 触摸点抬起
                                    !pointerInputChange.pressed && pointerInputChange.previousPressed -> {
                                        // 不需要特殊处理，保留轨迹
                                    }
                                }
                                
                                // 消费事件
                                pointerInputChange.consume()
                            }
                        }
                    }
                }
        ) {
            // 绘制所有轨迹
            Canvas(modifier = Modifier.fillMaxSize()) {
                // 为每个触摸点绘制轨迹
                touchPaths.forEach { (pointerId, path) ->
                    // 根据触摸点 ID 选择不同的颜色
                    val pathColor = colors[pointerId % colors.size]
                    
                    // 绘制轨迹
                    if (path.size > 1) {
                        drawPath(
                            path = Path().apply {
                                moveTo(path.first().x, path.first().y)
                                path.drop(1).forEach { point ->
                                    lineTo(point.x, point.y)
                                }
                            },
                            color = pathColor,
                            style = Stroke(
                                width = strokeWidth,
                                cap = StrokeCap.Round,
                                join = StrokeJoin.Round
                            )
                        )
                    }
                }
            }
            
            // 添加提示文本
            Text(
                text = "使用多个手指同时绘制",
                modifier = Modifier
                    .align(Alignment.TopCenter)
                    .padding(top = 16.dp)
                    .background(Color.White.copy(alpha = 0.7f))
                    .padding(8.dp),
                color = Color.Black,
                fontSize = 16.sp
            )
        }
        
        // 控制面板
        Row(
            modifier = Modifier
                .fillMaxWidth()
                .height(80.dp)
                .background(Color.LightGray)
                .padding(horizontal = 16.dp),
            horizontalArrangement = Arrangement.SpaceBetween,
            verticalAlignment = Alignment.CenterVertically
        ) {
            // 颜色选择器
            LazyRow(
                modifier = Modifier.weight(1f),
                horizontalArrangement = Arrangement.spacedBy(8.dp),
                verticalAlignment = Alignment.CenterVertically
            ) {
                items(colors) { color ->
                    Box(
                        modifier = Modifier
                            .size(32.dp)
                            .background(color, shape = CircleShape)
                            .border(
                                width = 2.dp,
                                color = if (color == currentColor) Color.White else Color.Transparent,
                                shape = CircleShape
                            )
                            .clickable { currentColor = color }
                    )
                }
            }
            
            // 笔触宽度滑块
            Slider(
                value = strokeWidth,
                onValueChange = { strokeWidth = it },
                valueRange = 1f..20f,
                modifier = Modifier.weight(1f)
            )
            
            // 清除按钮
            Button(
                onClick = { touchPaths.clear() },
                modifier = Modifier.padding(start = 8.dp)
            ) {
                Text("清除")
            }
        }
    }
}
```

在这个例子中，我们实现了一个支持多点触控的绘图板，用户可以使用多个手指同时在屏幕上绘制。程序会为每个触摸点分配不同的颜色，并记录和显示所有触摸轨迹。用户还可以选择颜色和调整笔触宽度。

### 3. 实现自定义地图控件

下面是一个简单的自定义地图控件实现，支持平移、缩放和标记点：

```kotlin
@Composable
fun CustomMapControl() {
    // 地图状态
    var scale by remember { mutableStateOf(1f) }
    var offset by remember { mutableStateOf(Offset.Zero) }
    // 标记点列表
    val markers = remember { mutableStateListOf<Offset>() }
    
    // 地图尺寸
    val mapWidth = 2000f
    val mapHeight = 1500f
    
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(Color.White)
    ) {
        // 地图容器
        Box(
            modifier = Modifier
                .fillMaxSize()
                .clipToBounds()
                // 添加手势检测
                .pointerInput(Unit) {
                    // 检测拖动手势
                    detectTransformGestures { centroid, pan, zoom, _ ->
                        // 更新缩放比例（限制范围）
                        scale = (scale * zoom).coerceIn(0.5f, 5f)
                        // 更新平移偏移量（限制范围，确保地图不会完全移出视图）
                        val maxX = (mapWidth * scale - size.width) / 2f
                        val maxY = (mapHeight * scale - size.height) / 2f
                        
                        offset = Offset(
                            x = (offset.x + pan.x).coerceIn(-maxX, maxX),
                            y = (offset.y + pan.y).coerceIn(-maxY, maxY)
                        )
                    }
                }
                // 添加双击手势
                .pointerInput(Unit) {
                    detectTapGestures(
                        onDoubleTap = { position ->
                            // 将屏幕坐标转换为地图坐标
                            val mapX = (position.x - size.width / 2f - offset.x) / scale + mapWidth / 2f
                            val mapY = (position.y - size.height / 2f - offset.y) / scale + mapHeight / 2f
                            
                            // 添加标记点
                            if (mapX in 0f..mapWidth && mapY in 0f..mapHeight) {
                                markers.add(Offset(mapX, mapY))
                            }
                        }
                    )
                }
        ) {
            // 绘制地图和标记点
            Canvas(modifier = Modifier.fillMaxSize()) {
                // 计算地图在屏幕上的位置
                val left = size.width / 2f - mapWidth * scale / 2f + offset.x
                val top = size.height / 2f - mapHeight * scale / 2f + offset.y
                
                // 绘制地图背景
                drawRect(
                    color = Color.LightGray,
                    topLeft = Offset(left, top),
                    size = Size(mapWidth * scale, mapHeight * scale)
                )
                
                // 绘制网格线
                val gridSize = 100f
                val gridColor = Color.Gray.copy(alpha = 0.3f)
                
                // 绘制垂直网格线
                for (x in 0..(mapWidth / gridSize).toInt()) {
                    val xPos = left + x * gridSize * scale
                    drawLine(
                        color = gridColor,
                        start = Offset(xPos, top),
                        end = Offset(xPos, top + mapHeight * scale),
                        strokeWidth = 1f
                    )
                }
                
                // 绘制水平网格线
                for (y in 0..(mapHeight / gridSize).toInt()) {
                    val yPos = top + y * gridSize * scale
                    drawLine(
                        color = gridColor,
                        start = Offset(left, yPos),
                        end = Offset(left + mapWidth * scale, yPos),
                        strokeWidth = 1f
                    )
                }
                
                // 绘制标记点
                markers.forEach { marker ->
                    // 将地图坐标转换为屏幕坐标
                    val screenX = left + marker.x * scale
                    val screenY = top + marker.y * scale
                    
                    // 绘制标记点
                    drawCircle(
                        color = Color.Red,
                        radius = 10f * scale,
                        center = Offset(screenX, screenY)
                    )
                    
                    // 绘制标记点阴影
                    drawCircle(
                        color = Color.Red.copy(alpha = 0.3f),
                        radius = 20f * scale,
                        center = Offset(screenX, screenY)
                    )
                }
            }
        }
        
        // 控制面板
        Column(
            modifier = Modifier
                .align(Alignment.TopStart)
                .padding(16.dp)
                .background(Color.White.copy(alpha = 0.7f))
                .padding(8.dp)
        ) {
            Text(
                text = "缩放比例: ${String.format("%.2f", scale)}x",
                fontSize = 14.sp
            )
            
            Text(
                text = "偏移量: (${offset.x.toInt()}, ${offset.y.toInt()})",
                fontSize = 14.sp
            )
            
            Text(
                text = "标记点数量: ${markers.size}",
                fontSize = 14.sp
            )
        }
        
        // 操作说明
        Column(
            modifier = Modifier
                .align(Alignment.BottomStart)
                .padding(16.dp)
                .background(Color.White.copy(alpha = 0.7f))
                .padding(8.dp)
        ) {
            Text(
                text = "• 拖动: 平移地图",
                fontSize = 14.sp
            )
            
            Text(
                text = "• 双指捏合: 缩放地图",
                fontSize = 14.sp
            )
            
            Text(
```

### 3. 如何处理手势冲突？

**回答**：处理手势冲突的几种方法：

1. **使用 `consume()` 方法**：
   最基本的方法是使用 `consume()` 方法来消费事件，防止事件传递给其他手势检测器。

   ```kotlin
   Modifier.pointerInput(Unit) {
       detectDragGestures { change, dragAmount ->
           // 消费事件，防止传递
           change.consume()
           // 处理拖动
       }
   }
   ```

   ```kotlin
       .pointerInput(Unit) {
   ```

5. **使用互斥锁**：
   对于复杂的手势系统，可以使用互斥锁来确保同一时间只有一个手势检测器处于活动状态。

   ```kotlin
   // 创建手势锁
   val gestureLock = GestureLock()
   
   Modifier
       .pointerInput(Unit) {
           // 第一个手势检测器
           detectDragGestures(
               onDragStart = {
                   // 尝试获取锁
                   if (gestureLock.tryLock("drag")) {
                       // 获取锁成功，可以处理拖动
                   }
               },
               onDragEnd = {
                   // 释放锁
                   gestureLock.unlock("drag")
               },
               onDrag = { change, dragAmount ->
                   // 只有持有锁时才处理拖动
                   if (gestureLock.isHeldBy("drag")) {
                       change.consume()
                       // 处理拖动
                   }
               }
           )
       }
       .pointerInput(Unit) {
           // 第二个手势检测器
           detectTransformGestures { centroid, pan, zoom, rotation ->
               // 尝试获取锁
               if (gestureLock.tryLock("transform")) {
                   // 获取锁成功，可以处理变换
                   // 处理变换
               }
               // 释放锁
               gestureLock.unlock("transform")
           }
       }
   
   // 手势锁类
   class GestureLock {
       private var currentHolder: String? = null
       
       fun tryLock(holder: String): Boolean {
           if (currentHolder == null) {
               currentHolder = holder
               return true
           }
           return currentHolder == holder
       }
       
       fun unlock(holder: String) {
           if (currentHolder == holder) {
               currentHolder = null
           }
       }
       
       fun isHeldBy(holder: String): Boolean {
           return currentHolder == holder
       }
   }
   ```

### 4. 如何优化二维滑动的性能和流畅度？

**回答**：优化二维滑动性能和流畅度的几种方法：

1. **使用 `remember` 缓存计算结果**：
   避免在每次重组时重新创建对象或进行复杂计算。

   ```kotlin
   // 缓存手势状态
   val gestureState = remember { mutableStateOf(GestureState.NONE) }
   // 缓存变换参数
   val transformParams = remember { TransformParams() }
   
   Modifier.pointerInput(Unit) {
       // 使用缓存的状态和参数
       detectTransformGestures { centroid, pan, zoom, rotation ->
           // 更新缓存的参数
           transformParams.apply {
               this.scale *= zoom
               this.rotation += rotation
               this.offset += pan
           }
       }
   }
   
   // 变换参数类
   class TransformParams {
       var scale: Float = 1f
       var rotation: Float = 0f
       var offset: Offset = Offset.Zero
   }
   ```

2. **使用 `graphicsLayer` 进行硬件加速**：
   对于需要频繁更新的 UI 元素，使用 `graphicsLayer` 可以提高性能。

   ```kotlin
   Box(
       modifier = Modifier
           .graphicsLayer(
               scaleX = scale,
               scaleY = scale,
               rotationZ = rotation,
               translationX = offset.x,
               translationY = offset.y
           )
   ) {
       // 内容
   }
   ```

3. **使用 `derivedStateOf` 减少不必要的重组**：
   对于依赖于其他状态的计算，使用 `derivedStateOf` 可以减少重组次数。

   ```kotlin
   // 原始状态
   var scale by remember { mutableStateOf(1f) }
   var rotation by remember { mutableStateOf(0f) }
   var offset by remember { mutableStateOf(Offset.Zero) }
   
   // 派生状态
   val transformMatrix by remember {
       derivedStateOf {
           Matrix().apply {
               scale(scale, scale)
               rotateZ(rotation)
               translate(offset.x, offset.y)
           }
       }
   }
   
   // 使用派生状态
   Box(
       modifier = Modifier
           .graphicsLayer {
               this.transformMatrix = transformMatrix
           }
   ) {
       // 内容
   }
   ```

4. **使用 `LaunchedEffect` 处理动画**：
   对于需要平滑过渡的手势，使用 `LaunchedEffect` 和动画 API 可以提高流畅度。

   ```kotlin
   // 目标状态
   var targetScale by remember { mutableStateOf(1f) }
   // 当前状态
   var currentScale by remember { mutableStateOf(1f) }
   
   // 使用动画平滑过渡
   LaunchedEffect(targetScale) {
       animate(
           initialValue = currentScale,
           targetValue = targetScale,
           animationSpec = spring(
               dampingRatio = 0.8f,
               stiffness = Spring.StiffnessLow
           )
       ) { value, _ ->
           currentScale = value
       }
   }
   
   // 处理手势
   Modifier.pointerInput(Unit) {
       detectTransformGestures { _, _, zoom, _ ->
           // 更新目标状态，而不是直接更新当前状态
           targetScale = (targetScale * zoom).coerceIn(0.5f, 5f)
       }
   }
   ```

5. **使用 `awaitPointerEventScope` 的高级功能**：
   对于需要精细控制的手势，使用 `awaitPointerEventScope` 的高级功能可以提高响应性。

   ```kotlin
   Modifier.pointerInput(Unit) {
       awaitPointerEventScope {
           while (true) {
               // 等待第一个触摸点
               val down = awaitFirstDown()
               
               // 使用 awaitTouchSlopOrCancellation 检测是否超过触摸阈值
               val drag = awaitTouchSlopOrCancellation(down.id) { change, over ->
                   // 消费位置变化
                   change.consume()
               }
               
               // 如果超过触摸阈值，开始拖动
               if (drag != null) {
                   // 处理拖动
                   drag(drag.id) { change, dragAmount ->
                       change.consume()
                       // 更新位置
                   }
               }
           }
       }
   }
   ```

6. **使用 `VelocityTracker` 实现惯性滑动**：
   对于需要惯性滑动效果的手势，使用 `VelocityTracker` 可以提高用户体验。

   ```kotlin
   Modifier.pointerInput(Unit) {
       // 创建速度跟踪器
       val velocityTracker = VelocityTracker()
       
       detectDragGestures(
           onDragStart = {
               // 重置速度跟踪器
               velocityTracker.resetTracking()
           },
           onDragEnd = {
               // 计算最终速度
               val velocity = velocityTracker.calculateVelocity()
               
               // 启动惯性滑动动画
               scope.launch {
                   // 使用 animateDecay 实现惯性滑动
                   animateDecay(
                       initialValue = offset,
                       initialVelocity = velocity,
                       animationSpec = splineBasedDecay(this@pointerInput)
                   ) { value, _ ->
                       // 更新位置
                       offset = value
                   }
               }
           },
           onDrag = { change, dragAmount ->
               // 更新速度跟踪器
               velocityTracker.addPosition(
                   change.uptimeMillis,
                   change.position
               )
               
               // 更新位置
               offset += dragAmount
           }
       )
   }
   ```
