# 6.3 自定义布局：SubcomposeLayout()

> "在 Compose 的世界里，SubcomposeLayout 就像是一位'时空魔术师'
>
，它能让你在布局过程中根据测量结果动态创建和测量新的组件，实现那些看似不可能的布局效果！这简直就是布局界的'薛定谔的猫'
> ，组件既存在又不存在，直到你测量它们！" 🔮

## 概念介绍

SubcomposeLayout 是 Jetpack Compose 中一个高级的布局 API，它提供了比普通 Layout
更强大的功能：在布局过程中动态创建和测量子组件。这种能力使得
SubcomposeLayout 能够实现一些普通 Layout 无法轻松实现的复杂布局效果，如根据内容自适应的布局、相互依赖的组件布局等。

在标准的 Layout 中，所有子组件都是预先定义的，布局过程只能测量和放置这些已知的子组件。而
SubcomposeLayout
打破了这一限制，它允许你在测量阶段根据已测量的结果动态创建新的子组件，然后再次测量这些新创建的组件。这种"
二次测量"的能力使得
SubcomposeLayout 能够处理那些需要先了解某些组件尺寸才能确定其他组件布局的场景。

SubcomposeLayout 的工作原理基于 Compose 的"子组合"
（Subcomposition）概念，它允许在主组合流程中创建独立的子组合。这些子组合可以根据主组合中的测量结果动态生成，从而实现更灵活的布局逻辑。

## 知识要点

- SubcomposeLayout 的基本概念和使用方法
- 子组合（Subcomposition）的概念和工作原理
- 使用 `subcompose` 函数创建和测量子组件
- 多阶段测量过程：先测量部分组件，再根据结果创建和测量其他组件
- 使用 Slot API 标识不同的子组合
- 处理子组件之间的依赖关系
- 性能考虑：子组合的成本和优化技巧
- 与标准 Layout 的结合使用
- 常见应用场景：自适应布局、内容感知布局等
- 避免常见陷阱：无限循环、过度子组合等

## 基础代码示例

下面是一个简单的例子，展示如何使用 SubcomposeLayout 创建一个自适应的标题布局，标题文本和图标会根据可用空间自动调整：

```kotlin
@Composable
fun AdaptiveHeaderLayout(
    title: @Composable () -> Unit,
    icon: @Composable () -> Unit,
    modifier: Modifier = Modifier
) {
    SubcomposeLayout(modifier = modifier) { constraints ->
        // 第一阶段：测量标题
        val titlePlaceable = subcompose("title", title).map {
            it.measure(constraints)
        }.first()
        
        // 根据标题宽度计算图标的约束
        val iconConstraints = constraints.copy(
            maxWidth = (constraints.maxWidth - titlePlaceable.width).coerceAtLeast(0)
        )
        
        // 第二阶段：测量图标
        val iconPlaceable = subcompose("icon", icon).map {
            it.measure(iconConstraints)
        }.first()
        
        // 计算布局的尺寸
        val width = titlePlaceable.width + iconPlaceable.width
        val height = maxOf(titlePlaceable.height, iconPlaceable.height)
        
        // 返回布局的尺寸和放置策略
        layout(width, height) {
            // 放置标题
            titlePlaceable.place(0, (height - titlePlaceable.height) / 2)
            
            // 放置图标
            iconPlaceable.place(
                titlePlaceable.width,
                (height - iconPlaceable.height) / 2
            )
        }
    }
}

// 使用示例
@Composable
fun AdaptiveHeaderExample() {
    AdaptiveHeaderLayout(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp)
            .background(
                color = MaterialTheme.colorScheme.primaryContainer,
                shape = RoundedCornerShape(8.dp)
            )
            .padding(16.dp),
        title = {
            Text(
                text = "这是一个自适应的标题，它会根据可用空间调整",
                style = MaterialTheme.typography.titleLarge,
                color = MaterialTheme.colorScheme.onPrimaryContainer
            )
        },
        icon = {
            Icon(
                imageVector = Icons.Default.Info,
                contentDescription = "信息",
                tint = MaterialTheme.colorScheme.onPrimaryContainer,
                modifier = Modifier.size(24.dp)
            )
        }
    )
}
```

## 进阶用法

### 1. 创建内容感知的卡片布局

下面是一个内容感知的卡片布局，它会根据内容的高度自动调整图片的高度：

```kotlin
@Composable
fun ContentAwareCard(
    image: @Composable () -> Unit,
    content: @Composable () -> Unit,
    modifier: Modifier = Modifier
) {
    SubcomposeLayout(modifier = modifier) { constraints ->
        // 第一阶段：测量内容
        val contentPlaceables = subcompose("content", content).map {
            it.measure(constraints)
        }
        
        // 获取内容的高度
        val contentHeight = contentPlaceables.maxByOrNull { it.height }?.height ?: 0
        
        // 创建图片的约束，高度至少与内容相同
        val imageConstraints = constraints.copy(
            minHeight = contentHeight,
            maxHeight = contentHeight
        )
        
        // 第二阶段：测量图片
        val imagePlaceables = subcompose("image", image).map {
            it.measure(imageConstraints)
        }
        
        // 获取图片的宽度
        val imageWidth = imagePlaceables.maxByOrNull { it.width }?.width ?: 0
        
        // 计算布局的尺寸
        val width = constraints.maxWidth
        val height = contentHeight + imageWidth
        
        // 返回布局的尺寸和放置策略
        layout(width, height) {
            // 放置图片
            imagePlaceables.forEach { placeable ->
                placeable.place(0, 0)
            }
            
            // 放置内容
            contentPlaceables.forEach { placeable ->
                placeable.place(0, imageWidth)
            }
        }
    }
}
```

### 2. 实现自定义标签页布局

下面是一个自定义标签页布局，它会根据标签的宽度自动调整内容区域的宽度：

```kotlin
@Composable
fun CustomTabLayout(
    tabs: List<String>,
    selectedTabIndex: Int,
    onTabSelected: (Int) -> Unit,
    content: @Composable (Int) -> Unit,
    modifier: Modifier = Modifier
) {
    SubcomposeLayout(modifier = modifier) { constraints ->
        // 第一阶段：测量所有标签
        val tabMeasurables = subcompose("tabs") {
            Row {
                tabs.forEachIndexed { index, tab ->
                    TabItem(
                        text = tab,
                        selected = index == selectedTabIndex,
                        onClick = { onTabSelected(index) }
                    )
                }
            }
        }
        
        val tabPlaceables = tabMeasurables.map { measurable ->
            measurable.measure(constraints)
        }
        
        // 获取标签行的高度
        val tabRowHeight = tabPlaceables.maxByOrNull { it.height }?.height ?: 0
        
        // 创建内容的约束
        val contentConstraints = constraints.copy(
            maxHeight = constraints.maxHeight - tabRowHeight
        )
        
        // 第二阶段：测量当前选中的内容
        val contentMeasurables = subcompose("content") {
            content(selectedTabIndex)
        }
        
        val contentPlaceables = contentMeasurables.map { measurable ->
            measurable.measure(contentConstraints)
        }
        
        // 计算布局的尺寸
        val width = constraints.maxWidth
        val height = tabRowHeight + (contentPlaceables.maxByOrNull { it.height }?.height ?: 0)
        
        // 返回布局的尺寸和放置策略
        layout(width, height) {
            // 放置标签行
            tabPlaceables.forEach { placeable ->
                placeable.place(0, 0)
            }
            
            // 放置内容
            contentPlaceables.forEach { placeable ->
                placeable.place(0, tabRowHeight)
            }
        }
    }
}
```

### 3. 创建自适应的文本布局

下面是一个自适应的文本布局，它会根据可用空间自动调整文本的字体大小：

```kotlin
@Composable
fun AdaptiveTextLayout(
    text: String,
    modifier: Modifier = Modifier,
    minFontSize: TextUnit = 12.sp,
    maxFontSize: TextUnit = 24.sp,
    fontSizeStep: TextUnit = 1.sp,
    maxLines: Int = Int.MAX_VALUE,
    style: TextStyle = MaterialTheme.typography.bodyLarge
) {
    SubcomposeLayout(modifier = modifier) { constraints ->
        // 将 TextUnit 转换为像素
        val minFontSizePx = minFontSize.toPx()
        val maxFontSizePx = maxFontSize.toPx()
        val fontSizeStepPx = fontSizeStep.toPx()
        
        // 从最大字体大小开始尝试
        var currentFontSizePx = maxFontSizePx
        var placeable: Placeable? = null
        
        // 二分查找最适合的字体大小
        while (currentFontSizePx >= minFontSizePx) {
            val currentStyle = style.copy(
                fontSize = currentFontSizePx.toSp()
            )
            
            // 测量当前字体大小下的文本
            val textMeasurables = subcompose("text") {
                Text(
                    text = text,
                    style = currentStyle,
                    maxLines = maxLines,
                    overflow = TextOverflow.Ellipsis
                )
            }
            
            val textPlaceable = textMeasurables.first().measure(constraints)
            
            // 检查是否符合约束
            if (textPlaceable.width <= constraints.maxWidth && 
                textPlaceable.height <= constraints.maxHeight) {
                placeable = textPlaceable
                break
            }
            
            // 减小字体大小
            currentFontSizePx -= fontSizeStepPx
        }
        
        // 如果没有找到合适的字体大小，使用最小字体大小
        if (placeable == null) {
            val textMeasurables = subcompose("text") {
                Text(
                    text = text,
                    style = style.copy(fontSize = minFontSize),
                    maxLines = maxLines,
                    overflow = TextOverflow.Ellipsis
                )
            }
            
            placeable = textMeasurables.first().measure(constraints)
        }
        
        // 返回布局的尺寸和放置策略
        layout(placeable.width, placeable.height) {
            placeable.place(0, 0)
        }
    }
}
```

## 常见问题

### 1. SubcomposeLayout 和普通 Layout 有什么区别？

**回答**：SubcomposeLayout 和普通 Layout 的主要区别在于：

- **测量能力**：
    - 普通 Layout 只能测量预先定义的子组件
    - SubcomposeLayout 可以根据已测量的结果动态创建和测量新的子组件

- **使用场景**：
    - 普通 Layout 适用于子组件之间没有相互依赖的布局
    - SubcomposeLayout 适用于需要先测量某些组件，然后根据结果决定其他组件布局的场景

- **性能考虑**：
    - 普通 Layout 通常性能更好，因为它只需要一次测量过程
    - SubcomposeLayout 可能需要多次测量，性能开销较大

- **灵活性**：
    - SubcomposeLayout 提供了更高的灵活性，可以实现更复杂的布局逻辑
    - 普通 Layout 更简单，适合大多数常见布局需求

选择指南：如果布局需要根据某些组件的测量结果来决定其他组件的布局，或者需要动态创建组件，应该使用
SubcomposeLayout；否则，优先使用普通
Layout。

### 2. 如何避免 SubcomposeLayout 中的性能问题？

**回答**：避免 SubcomposeLayout 性能问题的几种方法：

1. **最小化子组合次数**：

```kotlin
// 不好的做法：对每个子项都进行子组合
items.forEachIndexed { index, item ->
    val placeable = subcompose(index) {
        ItemContent(item)
    }.first().measure(constraints)
    // ...
}

// 好的做法：对相似的子项进行批量子组合
val headerPlaceable = subcompose("header") {
    HeaderContent()
}.first().measure(constraints)

val itemPlaceables = subcompose("items") {
    items.forEach { item ->
        ItemContent(item)
    }
}.map { it.measure(constraints) }
```

2. **使用键值缓存子组合结果**：

```kotlin
// 使用 remember 缓存子组合结果
val cachedResult = remember(key1, key2) {
    // 复杂计算或子组合
}

// 在 SubcomposeLayout 中使用缓存结果
SubcomposeLayout { constraints ->
    // 使用 cachedResult
}
```

3. **避免不必要的重组合**：

```kotlin
// 使用 derivedStateOf 避免不必要的重组合
val derivedValue = remember {
    derivedStateOf {
        // 根据其他状态计算派生值
    }
}

    // 使用 derivedValue.value
}
```

4. **优化测量约束**：

```kotlin

    minWidth = 0,
    minHeight = 0

    measurable.measure(childConstraints)

```

5. **避免无限循环**：

```kotlin
// 设置最大迭代次数，避免无限循环
var iteration = 0
var currentSize = initialSize
val maxIterations = 3

while (needsAdjustment && iteration < maxIterations) {
    // 调整和测量
    iteration++
```

### 4. 如何在 SubcomposeLayout 中实现自适应布局？

**回答**：在 SubcomposeLayout 中实现自适应布局的几种方法：

1. **二分查找最佳尺寸**：

```kotlin
SubcomposeLayout { constraints ->
    // 初始范围
    var minSize = minValue
    var maxSize = maxValue
    var currentSize = (minSize + maxSize) / 2
    var bestPlaceable: Placeable? = null
    
    // 二分查找最佳尺寸
    while (minSize <= maxSize) {
        val placeable = subcompose("content") {
            Content(size = currentSize)
        }.first().measure(constraints)
        
        if (fitsConstraints(placeable, constraints)) {
            // 当前尺寸符合约束，尝试更大的尺寸
            bestPlaceable = placeable
            minSize = currentSize + 1
        } else {
            // 当前尺寸不符合约束，尝试更小的尺寸
            maxSize = currentSize - 1
        }
        
        currentSize = (minSize + maxSize) / 2
    }
    
    // 使用找到的最佳尺寸
    layout(bestPlaceable?.width ?: 0, bestPlaceable?.height ?: 0) {
        bestPlaceable?.place(0, 0)
    }
}
```

2. **逐步调整尺寸**：

```kotlin
SubcomposeLayout { constraints ->
    // 初始尺寸
    var currentSize = initialSize
    var placeable: Placeable? = null
    
    // 逐步调整尺寸
    while (true) {
        placeable = subcompose("content") {
            Content(size = currentSize)
        }.first().measure(constraints)
        
        // 检查是否需要调整
        val adjustment = calculateAdjustment(placeable, constraints)
        if (adjustment == 0) break
        
        // 调整尺寸
        currentSize += adjustment
    }
    
    // 使用最终尺寸
    layout(placeable?.width ?: 0, placeable?.height ?: 0) {
        placeable?.place(0, 0)
    }
}
```

3. **测量多个变体并选择最佳的**：

```kotlin
SubcomposeLayout { constraints ->
    // 定义多个尺寸变体
    val sizeVariants = listOf(small, medium, large)

        val placeable = subcompose("variant-$size") {

        }.first().measure(constraints)
        
        size to placeable
    }
    
    // 选择最佳变体
    val (bestSize, bestPlaceable) = placeables
        .filter { (_, placeable) -> fitsConstraints(placeable, constraints) }
        .maxByOrNull { (size, _) -> size } ?: placeables.first()
    
    // 使用最佳变体
    layout(bestPlaceable.width, bestPlaceable.height) {
        bestPlaceable.place(0, 0)
    }
}
```

4. **根据内容调整容器**：

```kotlin
SubcomposeLayout { constraints ->
    // 先测量内容
    val contentPlaceable = subcompose("content") {
        Content()
    }.first().measure(constraints)
    
    // 根据内容尺寸创建容器
    val containerPlaceable = subcompose("container") {
        Container(
            width = contentPlaceable.width + padding,
            height = contentPlaceable.height + padding
        )
    }.first().measure(constraints)
    
    // 布局
    layout(containerPlaceable.width, containerPlaceable.height) {
        containerPlaceable.place(0, 0)
        contentPlaceable.place(padding / 2, padding / 2)
    }
}
```
