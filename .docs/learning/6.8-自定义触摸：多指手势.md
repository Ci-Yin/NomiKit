# 6.8 自定义触摸：多指手势

> "在 Compose 的世界里，多指手势就像是给你的 App 装上了'灵魂感应'
> ，让用户可以像《奇异博士》一样用双手施展魔法，变换、旋转、缩放，一切皆由指尖掌控。掌握了多指手势，你的
> UI 就能让用户感受到'指尖上的魔法'！" ✨

## 概念介绍

多指手势是 Jetpack Compose
中触摸事件处理的高级应用，它允许我们检测和响应用户使用多个手指同时在屏幕上进行的交互操作。与单指触摸相比，多指手势能够提供更加丰富和直观的交互方式，如捏合缩放、双指旋转、多点拖拽等，为用户创造更加自然和沉浸式的体验。

在 Compose 中，多指手势处理主要通过 `Modifier.pointerInput` 修饰符结合专门的多点触控 API 实现。Compose
提供了一系列内置的多指手势检测器，如
`detectTransformGestures`（检测变换手势）、`detectTapGestures`（检测点击手势）等，同时也允许开发者通过底层的
`awaitPointerEventScope` API 构建完全自定义的多指手势检测器。

多指手势在现代移动应用中有着广泛的应用，例如地图应用中的缩放和旋转、图片编辑器中的多点选择和变换、游戏中的多点控制等。通过掌握多指手势处理技术，我们可以为用户提供更加直观、高效和愉悦的交互体验。

## 基础代码示例

下面是一个简单的例子，展示如何使用 `detectTransformGestures` 实现基本的多指缩放和旋转功能：

```kotlin
@Composable
fun BasicMultiTouchExample() {
    // 缩放比例
    var scale by remember { mutableStateOf(1f) }
    // 旋转角度
    var angle by remember { mutableStateOf(0f) }
    // 平移偏移量
    var offset by remember { mutableStateOf(Offset.Zero) }
    
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(Color.LightGray),
        contentAlignment = Alignment.Center
    ) {
        // 可变换的元素
        Box(
            modifier = Modifier
                .size(150.dp)
                .graphicsLayer(
                    scaleX = scale,
                    scaleY = scale,
                    rotationZ = angle,
                    translationX = offset.x,
                    translationY = offset.y
                )
                .background(Color.Blue, shape = RoundedCornerShape(8.dp))
                // 添加多指手势检测
                .pointerInput(Unit) {
                    detectTransformGestures { centroid, pan, zoom, rotation ->
                        // 更新缩放比例
                        scale *= zoom
                        // 更新旋转角度
                        angle += rotation
                        // 更新平移偏移量
                        offset += pan
                    }
                }
        ) {
            // 显示当前变换信息
            Column(
                modifier = Modifier
                    .fillMaxSize()
                    .padding(16.dp),
                verticalArrangement = Arrangement.Center,
                horizontalAlignment = Alignment.CenterHorizontally
            ) {
                Text(
                    text = "缩放: ${String.format("%.2f", scale)}x",
                    color = Color.White
                )
                Spacer(modifier = Modifier.height(4.dp))
                Text(
                    text = "旋转: ${String.format("%.1f", angle)}°",
                    color = Color.White
                )
                Spacer(modifier = Modifier.height(4.dp))
                Text(
                    text = "平移: (${offset.x.toInt()}, ${offset.y.toInt()})",
                    color = Color.White
                )
            }
        }
        
        // 添加提示文本
        Text(
            text = "使用多个手指进行缩放、旋转和平移",
            modifier = Modifier
                .align(Alignment.TopCenter)
                .padding(top = 16.dp),
            color = Color.Black,
            fontSize = 16.sp
        )
        
        // 添加重置按钮
        Button(
            onClick = { 
                scale = 1f
                angle = 0f
                offset = Offset.Zero
            },
            modifier = Modifier
                .align(Alignment.BottomCenter)
                .padding(bottom = 16.dp)
        ) {
            Text("重置")
        }
    }
}
```

```kotlin
@Composable
fun CustomMultiTouchGestureExample() {
    // 触摸点列表
    val touchPoints = remember { mutableStateListOf<TouchPoint>() }

    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(Color.White)
            // 添加自定义多指触摸处理
            .pointerInput(Unit) {
                awaitPointerEventScope {
                    while (true) {
                        // 等待触摸事件
                        val event = awaitPointerEvent()

                        // 处理所有触摸点
                        event.changes.forEach { pointerInputChange ->
                            // 获取触摸点 ID
                            val pointerId = pointerInputChange.id.value
                            // 获取触摸点位置
                            val position = pointerInputChange.position

                            // 根据触摸点状态更新列表
                            when {
                                // 触摸点按下或移动
                                pointerInputChange.pressed -> {
                                    // 查找现有触摸点
                                    val existingPoint = touchPoints.find { it.id == pointerId }

                                    if (existingPoint != null) {
                                        // 更新现有触摸点位置
                                        val index = touchPoints.indexOf(existingPoint)
                                        touchPoints[index] = existingPoint.copy(position = position)
                                    } else {
                                        // 添加新触摸点
                                        touchPoints.add(
                                            TouchPoint(
                                                id = pointerId,
                                                position = position,
                                                color = getRandomColor()
                                            )
                                        )
                                    }
                                }
                                // 触摸点抬起
                                else -> {
                                    // 移除触摸点
                                    touchPoints.removeAll { it.id == pointerId }
                                }
                            }

                            // 消费事件
                            pointerInputChange.consume()
                        }
                    }
                }
            }
    ) {
        // 绘制所有触摸点
        Canvas(modifier = Modifier.fillMaxSize()) {
            // 绘制触摸点之间的连线
            if (touchPoints.size >= 2) {
                for (i in 0 until touchPoints.size - 1) {
                    for (j in i + 1 until touchPoints.size) {
                        val point1 = touchPoints[i]
                        val point2 = touchPoints[j]

                        // 绘制连线
                        drawLine(
                            color = Color.Gray.copy(alpha = 0.5f),
                            start = point1.position,
                            end = point2.position,
                            strokeWidth = 2f
                        )

                        // 计算并显示两点之间的距离
                        val distance = (point2.position - point1.position).getDistance()
                        val midPoint = (point1.position + point2.position) / 2f

                        drawContext.canvas.nativeCanvas.apply {
                            drawText(
                                "${distance.toInt()} px",
                                midPoint.x,
                                midPoint.y,
                                Paint().apply {
                                    color = android.graphics.Color.BLACK
                                    textSize = 30f
                                    textAlign = Paint.Align.CENTER
                                }
                            )
                        }
                    }
                }
            }

            // 绘制每个触摸点
            touchPoints.forEach { point ->
                // 绘制触摸点
                drawCircle(
                    color = point.color,
                    radius = 50f,
                    center = point.position,
                    alpha = 0.5f
                )

                // 绘制触摸点 ID
                drawContext.canvas.nativeCanvas.apply {
                    drawText(
                        "ID: ${point.id}",
                        point.position.x,
                        point.position.y,
                        Paint().apply {
                            color = android.graphics.Color.WHITE
                            textSize = 30f
                            textAlign = Paint.Align.CENTER
                        }
                    )
                }
            }
        }

        // 显示触摸点数量
        Text(
            text = "触摸点数量: ${touchPoints.size}",
            modifier = Modifier
                .align(Alignment.TopCenter)
                .padding(top = 16.dp)
                .background(Color.White.copy(alpha = 0.7f))
                .padding(8.dp),
            color = Color.Black,
            fontSize = 16.sp
        )

        // 添加提示文本
        Text(
            text = "使用多个手指触摸屏幕",
            modifier = Modifier
                .align(Alignment.BottomCenter)
                .padding(bottom = 16.dp)
                .background(Color.White.copy(alpha = 0.7f))
                .padding(8.dp),
            color = Color.Black,
            fontSize = 16.sp
        )
    }
}

// 触摸点数据类
data class TouchPoint(
    val id: Int,
    val position: Offset,
    val color: Color
)

// 生成随机颜色
fun getRandomColor(): Color {
    return Color(
        red = Random.nextFloat(),
        green = Random.nextFloat(),
        blue = Random.nextFloat(),
        alpha = 1f
    )
}
```

ID，并绘制触摸点之间的连线和距离。

```kotlin
// 扩展函数：检测变换手势
suspend fun PointerInputScope.detectTransformGestures(
    onGestureStart: () -> Unit = {},
    onGestureEnd: () -> Unit = {},
    onGesture: (centroid: Offset, pan: Offset, zoom: Float, rotation: Float) -> Unit
) {
    awaitPointerEventScope {
        var rotation = 0f
        var zoom = 1f
        var pan = Offset.Zero
        var pastTouchSlop = false
        val touchSlop = viewConfiguration.touchSlop
        var lockedToPanZoom = false
        
        awaitFirstDown(requireUnconsumed = false)
        onGestureStart()
        
        do {
            val event = awaitPointerEvent()
            val canceled = event.changes.any { it.positionChanged() }
            var relevant = true
            
            if (event.changes.size == 2) {
                // 获取两个触摸点
                val first = event.changes[0]
                val second = event.changes[1]
                
                // 如果有一个触摸点已经被消费，跳过处理
                if (first.consumed.positionChange || second.consumed.positionChange) {
                    relevant = false
                }
                
                if (relevant) {
                    // 计算两个触摸点的中心点
                    val centroid = (first.position + second.position) / 2f
                    
                    // 计算两个触摸点之间的距离和角度
                    val firstPrevPos = first.previousPosition
                    val secondPrevPos = second.previousPosition
                    
                    val prevCentroid = (firstPrevPos + secondPrevPos) / 2f
                    val prevDelta = secondPrevPos - firstPrevPos
                    val currDelta = second.position - first.position
                    
                    // 计算缩放比例
                    val prevDistance = prevDelta.getDistance()
                    val currDistance = currDelta.getDistance()
                    val newZoom = if (prevDistance > 0) currDistance / prevDistance else 1f
                    
                    // 计算旋转角度
                    val prevAngle = atan2(prevDelta.y, prevDelta.x)
                    val currAngle = atan2(currDelta.y, currDelta.x)
                    val newRotation = (currAngle - prevAngle) * 180f / PI.toFloat()
                    
                    // 计算平移距离
                    val newPan = centroid - prevCentroid
                    
                    if (!pastTouchSlop) {
                        // 检查是否超过触摸阈值
                        zoom *= newZoom
                        rotation += newRotation
                        pan += newPan
                        
                        val panDistance = pan.getDistance()
                        val zoomChange = abs(zoom - 1f)
                        val rotationChange = abs(rotation)
                        
                        if (panDistance > touchSlop || zoomChange > 0.1f || rotationChange > 1f) {
                            pastTouchSlop = true
                            
                            // 如果平移距离远大于缩放和旋转变化，锁定为平移模式
                            lockedToPanZoom = panDistance > 4 * touchSlop && 
                                    zoomChange < 0.2f && 
                                    rotationChange < 5f
                        }
                    }
                    
                    if (pastTouchSlop) {
                        // 如果已经超过触摸阈值，调用回调函数
                        if (lockedToPanZoom) {
                            // 如果锁定为平移模式，只处理平移和缩放
                            onGesture(centroid, newPan, newZoom, 0f)
                        } else {
                            // 否则处理所有变换
                            onGesture(centroid, newPan, newZoom, newRotation)
                        }
                        
                        // 消费事件
                        first.consume()
                        second.consume()
                    }
                }
            } else {
                relevant = false
            }
            
            // 如果事件不相关或所有触摸点都抬起，结束手势
            if (!relevant && !canceled && event.changes.none { it.pressed }) {
                onGestureEnd()
                break
            }
        } while (!canceled && event.changes.any { it.pressed })
    }
}

// 扩展函数：等待第二个触摸点
suspend fun AwaitPointerEventScope.awaitSecondDown(): PointerInputChange? {
    var event: PointerEvent
    do {
        event = awaitPointerEvent(PointerEventPass.Main)
    } while (event.changes.size < 2 && 
             event.changes.none { it.positionChanged() } && 
             event.changes.all { it.pressed })
    
    return if (event.changes.size >= 2) event.changes[1] else null
}

// 扩展函数：等待触摸点抬起或取消
suspend fun AwaitPointerEventScope.waitForUpOrCancellation(): PointerInputChange? {
    while (true) {
        val event = awaitPointerEvent(PointerEventPass.Main)
        if (event.changes.all { !it.pressed }) {
            // 所有触摸点都抬起
            return event.changes.firstOrNull()
        }
        
        if (event.changes.any { it.positionChanged() }) {
            // 有触摸点移动，取消等待
            return null
        }
    }
}
```

```kotlin
@Composable
fun MultiFingerDrawingBoard() {

    val pathsByPointerId = remember { mutableStateMapOf<Int, MutableList<PathSegment>>() }
    // 当前选择的颜色

    val colors = listOf(
        Color.Black,
        Color.Red,
        Color.Green,
        Color.Blue,
        Color.Yellow,
        Color.Magenta,
        Color.Cyan

        modifier = Modifier.fillMaxSize()
    ) {
        // 绘图区域

                .weight(1f)
                .fillMaxWidth()
                .background(Color.White)

                    awaitPointerEventScope {
                        while (true) {
                            // 等待触摸事件
                            val event = awaitPointerEvent()
                            
                            // 处理所有触摸点
                            event.changes.forEach { pointerInputChange ->
                                // 获取触摸点 ID
                                val pointerId = pointerInputChange.id.value
                                // 获取触摸点位置
                                val position = pointerInputChange.position
                                
                                when {
                                    // 触摸点按下或移动

                                        if (pointerInputChange.previousPressed) {
                                            // 触摸点移动，添加新的路径段
                                            val prevPosition = pointerInputChange.previousPosition
                                            path.add(
                                                PathSegment(
                                                    start = prevPosition,
                                                    end = position,
                                                    color = if (eraserMode) Color.White else currentColor,
                                                    strokeWidth = strokeWidth,
                                                    isEraser = eraserMode
                                                )
                                            )
                                        }
                                    }
                                    // 触摸点抬起
                                    !pointerInputChange.pressed && pointerInputChange.previousPressed -> {
                                        // 如果有路径，添加到撤销历史
                                        val path = pathsByPointerId[pointerId]
                                        if (path != null && path.isNotEmpty()) {
                                            undoHistory.add(UndoAction.AddPath(pointerId, path.toList()))
                                        }
                                        
                                        // 移除触摸点
                                        pathsByPointerId.remove(pointerId)
                                    }
                                }
                                
                                // 消费事件
                                pointerInputChange.consume()
                            }
                        }
                    }
                }
        ) {
            // 绘制所有路径
            Canvas(modifier = Modifier.fillMaxSize()) {
                // 绘制所有已保存的路径
                pathsByPointerId.forEach { (_, segments) ->
                    segments.forEach { segment ->
                        drawLine(
                            color = segment.color,
                            start = segment.start,
                            end = segment.end,
                            strokeWidth = segment.strokeWidth,
                            cap = StrokeCap.Round,
                            pathEffect = if (segment.isEraser) PathEffect.dashPathEffect(floatArrayOf(10f, 10f)) else null
                        )
                    }
                }
            }
            
            // 添加提示文本
            Text(
                text = "使用多个手指同时绘制",
                modifier = Modifier
                    .align(Alignment.TopCenter)
                    .padding(top = 16.dp)
                    .background(Color.White.copy(alpha = 0.7f))
                    .padding(8.dp),
                color = Color.Black,
                fontSize = 16.sp
            )
        }
        
        // 工具栏
        Row(
            modifier = Modifier
                .fillMaxWidth()
                .height(60.dp)
                .background(Color.LightGray)
                .padding(horizontal = 16.dp),
            verticalAlignment = Alignment.CenterVertically,
            horizontalArrangement = Arrangement.SpaceBetween
        ) {
            // 颜色选择器
            LazyRow(
                modifier = Modifier.weight(1f),
                horizontalArrangement = Arrangement.spacedBy(8.dp),
                verticalAlignment = Alignment.CenterVertically
            ) {
                items(colors) { color ->
                    Box(
                        modifier = Modifier
                            .size(32.dp)
                            .background(color, shape = CircleShape)
                            .border(
                                width = 2.dp,
                                color = if (color == currentColor && !eraserMode) Color.White else Color.Transparent,
                                shape = CircleShape
                            )
                            .clickable { 
                                currentColor = color
                                eraserMode = false
                            }
                    )
                }
            }
            
            // 橡皮擦按钮
            IconButton(
                onClick = { eraserMode = !eraserMode },
                modifier = Modifier
                    .size(40.dp)
                    .background(
                        color = if (eraserMode) Color.Gray else Color.Transparent,
                        shape = CircleShape
                    )
            ) {
                Icon(
                    imageVector = Icons.Default.Clear,
                    contentDescription = "橡皮擦",
                    tint = if (eraserMode) Color.White else Color.Black
                )
            }
            
            // 撤销按钮
            IconButton(
                onClick = {
                    if (undoHistory.isNotEmpty()) {
                        val lastAction = undoHistory.removeAt(undoHistory.lastIndex)
                        when (lastAction) {
                            is UndoAction.AddPath -> {
                                // 移除最后添加的路径
                                pathsByPointerId.remove(lastAction.pointerId)
                            }
                            is UndoAction.Clear -> {
                                // 恢复清除前的路径
                                lastAction.paths.forEach { (pointerId, segments) ->
                                    pathsByPointerId[pointerId] = segments.toMutableList()
                                }
                            }
                        }
                    }
                },
                enabled = undoHistory.isNotEmpty(),
                modifier = Modifier.size(40.dp)
            ) {
                Icon(
                    imageVector = Icons.Default.Undo,
                    contentDescription = "撤销",
                    tint = if (undoHistory.isNotEmpty()) Color.Black else Color.Gray
                )
            }
            
            // 清除按钮
            Button(
                onClick = {
                    // 保存当前路径到撤销历史
                    if (pathsByPointerId.isNotEmpty()) {
                        undoHistory.add(UndoAction.Clear(pathsByPointerId.toMap()))
                    }
                    // 清除所有路径
                    pathsByPointerId.clear()
                },
                modifier = Modifier.padding(start = 8.dp)
            ) {
                Text("清除")
            }
        }
        
        // 笔触设置
        Row(
            modifier = Modifier
                .fillMaxWidth()
                .height(60.dp)
                .background(Color.LightGray)
                .padding(horizontal = 16.dp),
            verticalAlignment = Alignment.CenterVertically
        ) {
            // 笔触宽度标签
            Text(
                text = "笔触宽度:",
                modifier = Modifier.padding(end = 8.dp)
            )
            
            // 笔触宽度滑块
            Slider(
                value = strokeWidth,
                onValueChange = { strokeWidth = it },
                valueRange = 1f..30f,
                modifier = Modifier.weight(1f)
            )
            
            // 显示当前宽度
            Text(
                text = "${strokeWidth.toInt()} px",
                modifier = Modifier.padding(start = 8.dp)
            )
        }
    }
}
```

### 3. 实现多指游戏控制器

下面是一个多指游戏控制器的实现，包括虚拟摇杆和按钮：

```kotlin
@Composable
fun MultiTouchGameController() {
    // 游戏状态
    var playerPosition by remember { mutableStateOf(Offset(500f, 500f)) }
    var playerRotation by remember { mutableStateOf(0f) }
    var playerSpeed by remember { mutableStateOf(0f) }
    var isFiring by remember { mutableStateOf(false) }
    var isJumping by remember { mutableStateOf(false) }

    // 虚拟摇杆状态
    var leftJoystickPosition by remember { mutableStateOf(Offset.Zero) }
    var rightJoystickPosition by remember { mutableStateOf(Offset.Zero) }

    // 按钮状态
    val buttonStates = remember { mutableStateMapOf<String, Boolean>() }

    // 触摸点映射
    val touchAssignments = remember { mutableStateMapOf<Int, String>() }

    // 定义控制器元素
    val leftJoystick = remember { ControllerElement("leftJoystick", Offset(150f, 500f), 120f) }
    val rightJoystick = remember { ControllerElement("rightJoystick", Offset(850f, 500f), 120f) }
    val fireButton = remember { ControllerElement("fireButton", Offset(850f, 300f), 80f) }
    val jumpButton = remember { ControllerElement("jumpButton", Offset(700f, 400f), 80f) }

    // 所有控制器元素
    val controllerElements = remember {
        listOf(leftJoystick, rightJoystick, fireButton, jumpButton)
    }

    // 游戏循环
    LaunchedEffect(leftJoystickPosition, rightJoystickPosition, isFiring, isJumping) {
        // 更新玩家位置
        val direction = leftJoystickPosition.normalized()
        playerSpeed = leftJoystickPosition.getDistance() / leftJoystick.radius

        if (playerSpeed > 0) {
            playerPosition += direction * playerSpeed * 5f

            // 限制玩家在屏幕范围内
            playerPosition = Offset(
                playerPosition.x.coerceIn(50f, 950f),
                playerPosition.y.coerceIn(50f, 950f)
            )
        }

        // 更新玩家旋转
        if (rightJoystickPosition != Offset.Zero) {
            playerRotation = atan2(rightJoystickPosition.y, rightJoystickPosition.x) * 180f / PI.toFloat()
        }

        // 更新开火状态
        isFiring = buttonStates["fireButton"] == true

        // 更新跳跃状态
        isJumping = buttonStates["jumpButton"] == true
    }

    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(Color.Black)
            // 添加多指触摸处理
            .pointerInput(Unit) {
                awaitPointerEventScope {
                    while (true) {
                        // 等待触摸事件
                        val event = awaitPointerEvent()

                        // 处理所有触摸点
                        event.changes.forEach { pointerInputChange ->
                            // 获取触摸点 ID
                            val pointerId = pointerInputChange.id.value
                            // 获取触摸点位置
                            val position = pointerInputChange.position

                            when {
                                // 触摸点按下
                                pointerInputChange.pressed && !pointerInputChange.previousPressed -> {
                                    // 查找触摸的控制器元素
                                    val element = controllerElements.find { element ->
                                        (position - element.position).getDistance() <= element.radius
                                    }

                                    if (element != null) {
                                        // 分配触摸点到控制器元素
                                        touchAssignments[pointerId] = element.id

                                        // 处理按钮按下
                                        if (element.id == "fireButton" || element.id == "jumpButton") {
                                            buttonStates[element.id] = true
                                        }
                                    }
                                }
                                // 触摸点移动
                                pointerInputChange.pressed && pointerInputChange.previousPressed -> {
                                    // 获取分配的控制器元素
                                    val elementId = touchAssignments[pointerId]

                                    if (elementId != null) {
                                        when (elementId) {
                                            "leftJoystick" -> {
                                                // 更新左摇杆位置
                                                val delta = position - leftJoystick.position
                                                leftJoystickPosition = if (delta.getDistance() <= leftJoystick.radius) {
                                                    delta
                                                } else {
                                                    delta.normalized() * leftJoystick.radius
                                                }
                                            }
                                            "rightJoystick" -> {
                                                // 更新右摇杆位置
                                                val delta = position - rightJoystick.position
                                                rightJoystickPosition =
                                                    if (delta.getDistance() <= rightJoystick.radius) {
                                                        delta
                                                    } else {
                                                        delta.normalized() * rightJoystick.radius
                                                    }
                                            }
                                        }
                                    }
                                }
                                // 触摸点抬起
                                !pointerInputChange.pressed && pointerInputChange.previousPressed -> {
                                    // 获取分配的控制器元素
                                    val elementId = touchAssignments[pointerId]

                                    if (elementId != null) {
                                        when (elementId) {
                                            "leftJoystick" -> {
                                                // 重置左摇杆位置
                                                leftJoystickPosition = Offset.Zero
                                            }
                                            "rightJoystick" -> {
                                                // 重置右摇杆位置
                                                rightJoystickPosition = Offset.Zero
                                            }
                                            "fireButton", "jumpButton" -> {
                                                // 重置按钮状态
                                                buttonStates[elementId] = false
                                            }
                                        }

                                        // 移除触摸点分配
                                        touchAssignments.remove(pointerId)
                                    }
                                }
                            }

                            // 消费事件
                            pointerInputChange.consume()
                        }
                    }
                }
            }
    ) {
        // 绘制游戏场景
        Canvas(modifier = Modifier.fillMaxSize()) {
            // 绘制背景网格
            val gridSize = 50f
            val gridColor = Color.Gray.copy(alpha = 0.3f)

            // 绘制垂直网格线
            for (x in 0..(size.width / gridSize).toInt()) {
                drawLine(
                    color = gridColor,
                    start = Offset(x * gridSize, 0f),
                    end = Offset(x * gridSize, size.height),
                    strokeWidth = 1f
                )
            }

            // 绘制水平网格线
            for (y in 0..(size.height / gridSize).toInt()) {
                drawLine(
                    color = gridColor,
                    start = Offset(0f, y * gridSize),
                    end = Offset(size.width, y * gridSize),
                    strokeWidth = 1f
                )
            }

            // 绘制玩家
            drawCircle(
                color = Color.Green,
                radius = 30f,
                center = playerPosition
            )

            // 绘制玩家方向指示器
            val directionEnd = Offset(
                playerPosition.x + cos(playerRotation * PI.toFloat() / 180f) * 40f,
                playerPosition.y + sin(playerRotation * PI.toFloat() / 180f) * 40f
            )

            drawLine(
                color = Color.Yellow,
                start = playerPosition,
                end = directionEnd,
                strokeWidth = 5f,
                cap = StrokeCap.Round
            )

            // 如果正在开火，绘制激光
            if (isFiring) {
                val laserEnd = Offset(
                    playerPosition.x + cos(playerRotation * PI.toFloat() / 180f) * 1000f,
                    playerPosition.y + sin(playerRotation * PI.toFloat() / 180f) * 1000f
                )

                drawLine(
                    color = Color.Red,
                    start = playerPosition,
                    end = laserEnd,
                    strokeWidth = 3f,
                    pathEffect = PathEffect.dashPathEffect(floatArrayOf(20f, 10f))
                )
            }

            // 如果正在跳跃，绘制跳跃效果
            if (isJumping) {
                drawCircle(
                    color = Color.Cyan.copy(alpha = 0.5f),
                    radius = 50f,
                    center = playerPosition
                )
            }

            // 绘制左摇杆
            drawCircle(
                color = Color.White.copy(alpha = 0.3f),
                radius = leftJoystick.radius,
                center = leftJoystick.position
            )

            drawCircle(
                color = Color.White,
                radius = 40f,
                center = leftJoystick.position + leftJoystickPosition
            )

            // 绘制右摇杆
            drawCircle(
                color = Color.White.copy(alpha = 0.3f),
                radius = rightJoystick.radius,
                center = rightJoystick.position
            )

            drawCircle(
                color = Color.White,
                radius = 40f,
                center = rightJoystick.position + rightJoystickPosition
            )

            // 绘制开火按钮
            drawCircle(
                color = if (buttonStates["fireButton"] == true) Color.Red else Color.Red.copy(alpha = 0.5f),
                radius = fireButton.radius,
                center = fireButton.position
            )

            drawContext.canvas.nativeCanvas.apply {
                drawText(
                    "开火",
                    fireButton.position.x,
                    fireButton.position.y + 10f,
                    Paint().apply {
                        color = android.graphics.Color.WHITE
                        textSize = 30f
                        textAlign = Paint.Align.CENTER
                    }
                )
            }

            // 绘制跳跃按钮
            drawCircle(
                color = if (buttonStates["jumpButton"] == true) Color.Blue else Color.Blue.copy(alpha = 0.5f),
                radius = jumpButton.radius,
                center = jumpButton.position
            )

            drawContext.canvas.nativeCanvas.apply {
                drawText(
                    "跳跃",
                    jumpButton.position.x,
                    jumpButton.position.y + 10f,
                    Paint().apply {
                        color = android.graphics.Color.WHITE
                        textSize = 30f
                        textAlign = Paint.Align.CENTER
                    }
                )
            }
        }

        // 显示游戏状态
        Column(
            modifier = Modifier
                .align(Alignment.TopStart)
                .padding(16.dp)
                .background(Color.Black.copy(alpha = 0.7f))
                .padding(8.dp)
        ) {
            Text(
                text = "位置: (${playerPosition.x.toInt()}, ${playerPosition.y.toInt()})",
                color = Color.White,
                fontSize = 14.sp
            )
            Spacer(modifier = Modifier.height(4.dp))
            Text(
                text = "旋转: ${playerRotation.toInt()}°",
                color = Color.White,
                fontSize = 14.sp
            )
            Spacer(modifier = Modifier.height(4.dp))
            Text(
                text = "速度: ${(playerSpeed * 100).toInt()}%",
                color = Color.White,
                fontSize = 14.sp
            )
            Spacer(modifier = Modifier.height(4.dp))
            Text(
                text = "开火: ${if (isFiring) "是" else "否"}",
                color = Color.White,
                fontSize = 14.sp
            )
            Spacer(modifier = Modifier.height(4.dp))
            Text(
                text = "跳跃: ${if (isJumping) "是" else "否"}",
                color = Color.White,
                fontSize = 14.sp
            )
        }

        // 显示操作提示
        Text(
            text = "使用左摇杆移动，右摇杆旋转，按钮执行动作",
            modifier = Modifier
                .align(Alignment.TopCenter)
                .padding(top = 16.dp)
                .background(Color.Black.copy(alpha = 0.7f))
                .padding(8.dp),
            color = Color.White,
            fontSize = 16.sp
        )
    }
}
```

## 常见问题

### 1. 如何处理多指手势的冲突？

**回答**：处理多指手势冲突的几种方法：

1. **使用触摸点 ID 分配**：
   为每个触摸点分配特定的功能区域或手势类型，避免一个触摸点同时触发多个手势。

   ```kotlin
   // 触摸点分配映射
   val touchAssignments = remember { mutableStateMapOf<Int, String>() }
   
   // 处理触摸事件
   pointerInput(Unit) {
       awaitPointerEventScope {
           while (true) {
               val event = awaitPointerEvent()
               
               event.changes.forEach { change ->
                   val pointerId = change.id.value
                   
                   when {
                       // 触摸点按下
                       change.pressed && !change.previousPressed -> {
                           // 确定触摸区域
                           val area = determineArea(change.position)
                           // 分配触摸点
                           touchAssignments[pointerId] = area
                       }
                       // 触摸点移动
                       change.pressed && change.previousPressed -> {
                           // 根据分配处理移动
                           when (touchAssignments[pointerId]) {
                               "leftJoystick" -> handleLeftJoystick(change)
                               "rightJoystick" -> handleRightJoystick(change)
                               // 其他区域...
                           }
                       }
                       // 触摸点抬起
                       !change.pressed && change.previousPressed -> {
                           // 移除分配
                           touchAssignments.remove(pointerId)
                       }
                   }
               }
           }
       }
   }
   ```

2. **使用手势优先级**：
   为不同的手势设置优先级，当多个手势同时被检测到时，只响应优先级最高的手势。

   ```kotlin
   // 手势优先级枚举
   enum class GesturePriority {
       LOW, MEDIUM, HIGH
   }
   
   // 当前活动手势
   var activeGesture by remember { mutableStateOf<String?>(null) }
   var activeGesturePriority by remember { mutableStateOf(GesturePriority.LOW) }
   
   // 尝试激活手势
   fun tryActivateGesture(gesture: String, priority: GesturePriority): Boolean {
       return if (activeGesture == null || priority > activeGesturePriority) {
           activeGesture = gesture
           activeGesturePriority = priority
           true
       } else {
           false
       }
   }
   
   // 释放手势
   fun releaseGesture(gesture: String) {
       if (activeGesture == gesture) {
           activeGesture = null
           activeGesturePriority = GesturePriority.LOW
       }
   }
   ```

3. **使用手势状态机**：
   实现一个状态机来管理手势状态，确保在任何时刻只有一种手势类型处于活动状态。

   ```kotlin

   enum class GestureState {
       NONE, DRAGGING, SCALING, ROTATING
   }
   
   // 当前手势状态
   var gestureState by remember { mutableStateOf(GestureState.NONE) }
   
   // 处理触摸事件
   pointerInput(Unit) {
       awaitPointerEventScope {
           while (true) {
               val event = awaitPointerEvent()
               
               when (gestureState) {
                   GestureState.NONE -> {
                       // 检测新手势
                       if (event.changes.size == 1) {
                           gestureState = GestureState.DRAGGING
                       } else if (event.changes.size >= 2) {
                           // 根据初始移动判断是缩放还是旋转
                           // ...
                       }
                   }
                   GestureState.DRAGGING -> {
                       // 处理拖动
                       // ...
                       
                       // 如果所有触摸点都抬起，重置状态
                       if (event.changes.none { it.pressed }) {
                           gestureState = GestureState.NONE
                       }
                   }
                   // 其他状态...
               }
           }
       }
   }
   ```

4. **使用区域限制**：
   将屏幕划分为不同的区域，每个区域只响应特定类型的手势。

   ```kotlin
   // 定义区域
   val leftRegion = Rect(0f, 0f, size.width / 2, size.height)
   val rightRegion = Rect(size.width / 2, 0f, size.width, size.height)

                           // ...
                       }
                   }
   ```
   ```kotlin
               }
           }
       }
   }
   ```

### 2. 如何实现精确的多指手势识别？

**回答**：实现精确的多指手势识别的几种方法：

1. **使用触摸阈值**：
   设置适当的触摸阈值，避免误触和抖动。

   ```kotlin
   val touchSlop = viewConfiguration.touchSlop
   var pastTouchSlop = false
   
   // 累积移动距离
   var accumulatedDistance = 0f
   ```

### 3. 如何优化多指手势的性能？

**回答**：优化多指手势性能的几种方法：

   ```kotlin
                   // 处理触摸事件并更新状态

               } else {
   ```
