# 6.5 自定义触摸和一维滑动监测

> "在 Compose 的世界里，触摸事件就像是 UI 的第六感，让你的应用能够感知用户的每一次轻抚和滑动。掌握了触摸事件，你的
> App
> 就从'看得见'升级到了'能感受'！" 👆

## 概念介绍

在 Jetpack Compose 中，触摸事件处理是构建交互式 UI 的基础。与传统的 Android View 系统不同，Compose
提供了更加声明式和函数式的方式来处理用户的触摸输入。一维滑动监测是触摸事件处理的一个重要应用场景，它允许我们检测和响应用户在单一方向（水平或垂直）上的滑动手势。

Compose 中的触摸事件处理主要通过 `Modifier.pointerInput`
修饰符实现，它提供了一个挂起函数的作用域，在这个作用域中，我们可以使用各种手势检测器来监听和响应用户的触摸操作。对于一维滑动监测，Compose
提供了 `detectDragGestures` 和 `detectHorizontalDragGestures`/`detectVerticalDragGestures` 等
API，让我们能够轻松实现滑动检测和响应。

一维滑动在很多 UI 交互中都非常常见，例如滑动删除列表项、拖动调整进度条、滑动切换页面等。通过掌握 Compose
中的一维滑动监测，我们可以为用户提供更加直观和自然的交互体验。

## 知识要点

- Compose 中触摸事件处理的基本原理

- 滑动阈值和灵敏度调整
- 滑动距离和速度的计算
- 处理滑动冲突
- 结合 `draggable` 修饰符实现拖动效果
- 自定义滑动行为和动画
- 实现常见的滑动交互模式：滑动删除、滑动调整、滑动切换等

## 基础代码示例

下面是一个简单的例子，展示如何使用 `Modifier.pointerInput` 和 `detectDragGestures` 实现一个可拖动的方块：

```kotlin
@Composable
fun DraggableBox() {
    // 记录方块的位置
    var offsetX by remember { mutableStateOf(0f) }
    var offsetY by remember { mutableStateOf(0f) }
    
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(Color.LightGray),
        contentAlignment = Alignment.Center
    ) {
        Box(
            modifier = Modifier
                .size(100.dp)
                .offset { IntOffset(offsetX.roundToInt(), offsetY.roundToInt()) }
                .background(Color.Blue, shape = RoundedCornerShape(8.dp))
                // 添加触摸输入处理
                .pointerInput(Unit) {
                    // 检测拖动手势
                    detectDragGestures { change, dragAmount ->
                        // 消费触摸事件，防止其他组件接收到
                        change.consume()
                        
                        // 更新方块位置
                        offsetX += dragAmount.x
                        offsetY += dragAmount.y
                    }
                }
        )
        
        // 添加提示文本
        Text(
            text = "拖动蓝色方块",
            modifier = Modifier
                .align(Alignment.TopCenter)
                .padding(top = 16.dp),
            color = Color.Black,
            fontSize = 18.sp
        )
    }
}
```

在这个例子中，我们使用 `Modifier.pointerInput` 和 `detectDragGestures` 来检测用户的拖动手势，并根据拖动的距离更新方块的位置。
`change.consume()` 确保触摸事件被消费，不会传递给其他组件。

如果我们只关心水平方向的拖动，可以使用 `detectHorizontalDragGestures`：

## 进阶用法

### 1. 实现滑动删除列表项

下面是一个实现滑动删除列表项的例子，当用户向左滑动列表项时，会显示删除按钮：

```kotlin
@Composable
fun SwipeToDismissList() {
    // 列表项数据
    val items = remember {
        mutableStateListOf(
            "项目 1",
            "项目 2",
            "项目 3",
            "项目 4",
            "项目 5"
        )
    }
    
    LazyColumn(
        modifier = Modifier.fillMaxSize(),
        contentPadding = PaddingValues(16.dp),
        verticalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        items(items.size) { index ->
            SwipeToDismissItem(
                text = items[index],
                onDismiss = {
                    // 从列表中移除项目
                    items.removeAt(index)
                }
            )
        }
    }
}

@Composable
fun SwipeToDismissItem(
    text: String,
    onDismiss: () -> Unit
) {
    // 记录滑动偏移量
    var offsetX by remember { mutableStateOf(0f) }
    // 是否显示删除按钮
    val showDeleteButton = offsetX < -100f
    
    Box(
        modifier = Modifier
            .fillMaxWidth()
            .height(60.dp)
    ) {
        // 删除按钮（在列表项下方）
        if (showDeleteButton) {
            Button(
                onClick = onDismiss,
                modifier = Modifier
                    .align(Alignment.CenterEnd)
                    .padding(end = 16.dp),
                colors = ButtonDefaults.buttonColors(containerColor = Color.Red)
            ) {
                Text("删除")
            }
        }
        
        // 列表项
        Card(
            modifier = Modifier
                .fillMaxSize()
                .offset { IntOffset(offsetX.roundToInt(), 0) }
                .pointerInput(Unit) {
                    detectHorizontalDragGestures(
                        onDragEnd = {
                            // 拖动结束时，如果偏移量足够大，则触发删除
                            // 否则回弹到原位置
                            if (offsetX < -200f) {
                                onDismiss()
                            } else {
                                // 使用动画回弹
                                offsetX = 0f
                            }
                        },
                        onDragCancel = {
                            // 拖动取消时回弹
                            offsetX = 0f
                        },
                        onHorizontalDrag = { change, dragAmount ->
                            change.consume()
                            
                            // 只允许向左滑动（负值）
                            val newOffset = (offsetX + dragAmount).coerceAtMost(0f)
                            // 限制最大滑动距离
                            offsetX = newOffset.coerceAtLeast(-300f)
                        }
                    )
                }
        ) {
            Row(
                modifier = Modifier
                    .fillMaxSize()
                    .padding(horizontal = 16.dp),
                verticalAlignment = Alignment.CenterVertically
            ) {
                Text(
                    text = text,
                    fontSize = 18.sp
                )
            }
        }
    }
}
```

在这个例子中，我们使用 `detectHorizontalDragGestures`
来检测水平滑动，并根据滑动距离显示或隐藏删除按钮。当用户滑动足够远时，会触发删除操作；否则，列表项会回弹到原位置。

### 2. 实现自定义滑块控件

下面是一个自定义滑块控件的实现，用户可以通过拖动滑块来调整值：

```kotlin
@Composable
fun CustomSlider(
    value: Float,
    onValueChange: (Float) -> Unit,
    modifier: Modifier = Modifier,
    valueRange: ClosedFloatingPointRange<Float> = 0f..1f,
    steps: Int = 0,
    enabled: Boolean = true
) {
    // 计算轨道宽度
    val trackWidth = remember { mutableStateOf(0) }
    
    // 计算滑块位置
    val thumbPosition = (value - valueRange.start) / (valueRange.endInclusive - valueRange.start)
    
    Box(
        modifier = modifier
            .height(48.dp)
            .fillMaxWidth()
            .onSizeChanged { size ->
                trackWidth.value = size.width
            }
            .pointerInput(enabled) {
                if (enabled) {
                    detectHorizontalDragGestures { change, _ ->
                        change.consume()
                        
                        // 计算触摸点相对于轨道的位置
                        val x = change.position.x
                        val newPosition = (x / trackWidth.value).coerceIn(0f, 1f)
                        
                        // 如果有步进值，则计算最接近的步进位置
                        val newValue = if (steps > 0) {
                            val stepSize = 1f / (steps + 1)
                            val stepPosition = (newPosition / stepSize).roundToInt() * stepSize
                            valueRange.start + stepPosition * (valueRange.endInclusive - valueRange.start)
                        } else {
                            valueRange.start + newPosition * (valueRange.endInclusive - valueRange.start)
                        }
                        
                        // 更新值
                        onValueChange(newValue)
                    }
                }
            }
    ) {
        // 绘制轨道
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(4.dp)
                .align(Alignment.Center)
                .background(
                    color = if (enabled) Color.LightGray else Color.Gray,
                    shape = RoundedCornerShape(2.dp)
                )
        )
        
        // 绘制已选择部分的轨道
        Box(
            modifier = Modifier
                .fillMaxWidth(thumbPosition)
                .height(4.dp)
                .align(Alignment.CenterStart)
                .background(
                    color = if (enabled) MaterialTheme.colorScheme.primary else MaterialTheme.colorScheme.primary.copy(alpha = 0.5f),
                    shape = RoundedCornerShape(2.dp)
                )
        )
        
        // 绘制步进标记（如果有）
        if (steps > 0) {
            for (i in 1..steps) {
                val stepPosition = i.toFloat() / (steps + 1)
                Box(
                    modifier = Modifier
                        .size(4.dp)
                        .align(Alignment.CenterStart)
                        .offset(x = (trackWidth.value * stepPosition).dp - 2.dp)
                        .background(
                            color = Color.White,
                            shape = CircleShape
                        )
                        .border(
                            width = 1.dp,
                            color = Color.LightGray,
                            shape = CircleShape
                        )
                )
            }
        }
        
        // 绘制滑块
        Box(
            modifier = Modifier
                .size(20.dp)
                .offset(x = (trackWidth.value * thumbPosition).dp - 10.dp)
                .align(Alignment.CenterStart)
                .background(
                    color = if (enabled) MaterialTheme.colorScheme.primary else MaterialTheme.colorScheme.primary.copy(alpha = 0.5f),
                    shape = CircleShape
                )
                .border(
                    width = 2.dp,
                    color = Color.White,
                    shape = CircleShape
                )
        )
    }
}

// 使用示例
@Composable
fun CustomSliderExample() {
    var sliderValue by remember { mutableStateOf(0.5f) }
    
    Column(

            .fillMaxSize()

```

在这个例子中，我们使用 `detectHorizontalDragGestures`
来检测滑块的拖动，并根据触摸点的位置计算新的值。我们还实现了步进功能，允许滑块在预定义的位置上对齐。

### 3. 实现可拖动排序列表

下面是一个可拖动排序列表的实现，用户可以通过垂直拖动来重新排序列表项：

```kotlin
@Composable
fun DraggableOrderList() {
    // 列表项数据
    val items = remember {
        mutableStateListOf(
            "项目 1",
            "项目 2",
            "项目 3",
            "项目 4",
            "项目 5"
        )
    }
    
    // 当前拖动的项目索引
    var draggedItemIndex by remember { mutableStateOf<Int?>(null) }
    
    LazyColumn(
        modifier = Modifier.fillMaxSize(),
        contentPadding = PaddingValues(16.dp),
        verticalArrangement = Arrangement.spacedBy(8.dp)
    ) {
        itemsIndexed(items) { index, item ->
            // 是否是当前拖动的项目
            val isDragging = index == draggedItemIndex
            
            DraggableOrderItem(
                text = item,
                isDragging = isDragging,
                onDragStart = {
                    draggedItemIndex = index
                },
                onDragEnd = {
                    draggedItemIndex = null
                },
                onDrag = { dragAmount ->
                    // 如果拖动距离足够大，则交换位置
                    if (abs(dragAmount) > 50 && draggedItemIndex != null) {
                        val targetIndex = if (dragAmount > 0) {
                            // 向下拖动
                            (draggedItemIndex!! + 1).coerceAtMost(items.size - 1)
                        } else {
                            // 向上拖动
                            (draggedItemIndex!! - 1).coerceAtLeast(0)
                        }
                        
                        if (targetIndex != draggedItemIndex) {
                            // 交换位置
                            val temp = items[draggedItemIndex!!]
                            items[draggedItemIndex!!] = items[targetIndex]
                            items[targetIndex] = temp
                            
                            // 更新拖动索引
                            draggedItemIndex = targetIndex
                        }
                    }
                }
            )
        }
    }
}

@Composable
fun DraggableOrderItem(
    text: String,
    isDragging: Boolean,
    onDragStart: () -> Unit,
    onDragEnd: () -> Unit,
    onDrag: (Float) -> Unit
) {
    // 记录垂直偏移量
    var offsetY by remember { mutableStateOf(0f) }
    
    Card(
        modifier = Modifier
            .fillMaxWidth()
            .height(60.dp)
            .offset { IntOffset(0, offsetY.roundToInt()) }
            .pointerInput(Unit) {
                detectVerticalDragGestures(
                    onDragStart = {
                        onDragStart()
                    },
                    onDragEnd = {
                        offsetY = 0f
                        onDragEnd()
                    },
                    onDragCancel = {
                        offsetY = 0f
                        onDragEnd()
                    },
                    onVerticalDrag = { change, dragAmount ->
                        change.consume()
                        
                        // 更新垂直偏移量
                        offsetY += dragAmount
                        
                        // 通知拖动事件
                        onDrag(dragAmount)
                    }
                )
            },
        elevation = CardDefaults.cardElevation(
            defaultElevation = if (isDragging) 8.dp else 2.dp
        ),
        colors = CardDefaults.cardColors(
            containerColor = if (isDragging) 
                MaterialTheme.colorScheme.primaryContainer 
            else 
                MaterialTheme.colorScheme.surface
        )
    ) {
        Row(
            modifier = Modifier
                .fillMaxSize()
                .padding(horizontal = 16.dp),
            verticalAlignment = Alignment.CenterVertically
        ) {
            // 拖动手柄图标
            Icon(
                imageVector = Icons.Default.DragIndicator,
                contentDescription = "拖动",
                tint = if (isDragging) 
                    MaterialTheme.colorScheme.onPrimaryContainer 
                else 
                    MaterialTheme.colorScheme.onSurface.copy(alpha = 0.5f)
            )
            
            Spacer(modifier = Modifier.width(16.dp))
            
            Text(
                text = text,
                fontSize = 18.sp,
                color = if (isDragging) 
                    MaterialTheme.colorScheme.onPrimaryContainer 
                else 
                    MaterialTheme.colorScheme.onSurface
            )
        }
    }
}
```

在这个例子中，我们使用 `detectVerticalDragGestures`
来检测垂直拖动，并根据拖动距离交换列表项的位置。当用户开始拖动时，我们会高亮显示当前拖动的项目，并增加其阴影效果，提供视觉反馈。

## 常见问题

### 1. 如何处理多个组件之间的滑动冲突？

**回答**：处理滑动冲突的几种方法：

1. **使用 `consume()` 方法**：
   当你调用 `change.consume()` 时，触摸事件会被标记为已消费，不会传递给其他组件。这是最基本的冲突处理方式。

   ```kotlin
   detectDragGestures { change, dragAmount ->
       // 消费事件，防止传递
       change.consume()
       // 处理拖动
   }
   ```

2. **条件性消费事件**：
   根据特定条件决定是否消费事件，例如只在特定方向上消费。

   ```kotlin
   detectDragGestures { change, dragAmount ->
       // 只在水平拖动距离大于垂直拖动距离时消费事件
       if (abs(dragAmount.x) > abs(dragAmount.y)) {
           change.consume()
           // 处理水平拖动
       }
       // 否则不消费，让垂直方向的父组件处理
   }
   ```

3. **使用专门的方向检测器**：
   使用 `detectHorizontalDragGestures` 或 `detectVerticalDragGestures` 可以只关注特定方向的拖动，减少冲突。

   ```kotlin
   // 只检测水平拖动
   detectHorizontalDragGestures { change, dragAmount ->
       change.consume()
       // 处理水平拖动
   }
   ```

4. **使用 `awaitFirstDown` 和 `awaitTouchSlopOrCancellation`**：
   这种方法可以更精细地控制何时开始消费事件。

   ```kotlin
   pointerInput(Unit) {
       awaitEachGesture {
           // 等待第一次按下
           val down = awaitFirstDown()
           
           // 等待移动超过触摸阈值
           val drag = awaitTouchSlopOrCancellation(down.id) { change, over ->
               // 判断是否应该处理这个手势
               val shouldHandleGesture = /* 你的条件 */
               
               if (shouldHandleGesture) {
                   change.consume()
               }
           }
           
           // 如果开始拖动，继续处理后续移动
           if (drag != null) {
               // 处理拖动
           }
       }
   }
   ```

5. **使用嵌套的 `pointerInput` 块**：
   在不同层级的组件上使用 `pointerInput`，并根据需要决定是否消费事件。

   ```kotlin
   // 外层组件
   Box(
       modifier = Modifier
           .pointerInput(Unit) {
               detectDragGestures { change, dragAmount ->
                   // 只处理垂直拖动
                   if (abs(dragAmount.y) > abs(dragAmount.x)) {
                       change.consume()
                       // 处理垂直拖动
                   }
               }
           }
   ) {
       // 内层组件
       Box(
           modifier = Modifier
               .pointerInput(Unit) {
                   detectDragGestures { change, dragAmount ->
                       // 只处理水平拖动
                       if (abs(dragAmount.x) > abs(dragAmount.y)) {
                           change.consume()
                           // 处理水平拖动
                       }
                   }
               }
       )
   }
   ```

### 2. 如何实现带有惯性的滑动效果？

**回答**：实现带有惯性的滑动效果的几种方法：

1. **使用 `detectDragGestures` 结合 `AnimationState`**：

   ```kotlin
   @Composable
   fun InertialDraggableBox() {
       // 记录方块的位置
       var offsetX by remember { mutableStateOf(0f) }
       var offsetY by remember { mutableStateOf(0f) }
       
       // 创建动画状态
       val animationState = remember { AnimationState(0f) }
       
       // 记录最后的速度
       val velocityTracker = remember { VelocityTracker() }
       
       Box(
           modifier = Modifier
               .fillMaxSize()
               .background(Color.LightGray),
           contentAlignment = Alignment.Center
       ) {
           Box(
               modifier = Modifier
                   .size(100.dp)
                   .offset { IntOffset(offsetX.roundToInt(), offsetY.roundToInt()) }
                   .background(Color.Blue, shape = RoundedCornerShape(8.dp))
                   .pointerInput(Unit) {
                       detectDragGestures(
                           onDragStart = {
                               // 停止任何正在进行的动画
                               animationState.stop()
                               velocityTracker.resetTracking()
                           },
                           onDragEnd = {
                               // 获取最终速度
                               val velocity = velocityTracker.calculateVelocity()
                               
                               // 启动惯性动画
                               coroutineScope.launch {
                                   animationState.animateTo(
                                       targetValue = 1f,
                                       animationSpec = spring(
                                           dampingRatio = 0.7f,
                                           stiffness = 100f
                                       ),
                                       initialVelocity = velocity.x
                                   ) {
                                       // 根据动画值和初始速度更新位置
                                       offsetX += velocity.x * this.value * 0.01f
                                       offsetY += velocity.y * this.value * 0.01f
                                       
                                       // 边界检查
                                       offsetX = offsetX.coerceIn(-500f, 500f)
                                       offsetY = offsetY.coerceIn(-500f, 500f)
                                   }
                               }
                           },
                           onDrag = { change, dragAmount ->
                               change.consume()
                               
                               // 更新速度跟踪器
                               velocityTracker.addPosition(
                                   change.uptimeMillis,
                                   change.position
                               )
                               
                               // 更新位置
                               offsetX += dragAmount.x
                               offsetY += dragAmount.y
                               
                               // 边界检查
                               offsetX = offsetX.coerceIn(-500f, 500f)
                               offsetY = offsetY.coerceIn(-500f, 500f)
                           }
                       )
                   }
           )
       }
   }
   ```

### 3. 如何限制拖动范围？

**回答**：限制拖动范围的几种方法：

1. **使用 `coerceIn` 函数**：
   最简单的方法是使用 `coerceIn` 函数限制偏移量的范围。

   ```kotlin
   // 限制水平拖动范围
   offsetX = (offsetX + dragAmount.x).coerceIn(minX, maxX)
   
   // 限制垂直拖动范围
   offsetY = (offsetY + dragAmount.y).coerceIn(minY, maxY)
   ```

2. **使用条件判断**：
   根据当前位置判断是否允许继续拖动。

   ```kotlin
   detectDragGestures { change, dragAmount ->
       change.consume()
       
       // 判断是否允许水平拖动
       if ((offsetX + dragAmount.x >= minX) && (offsetX + dragAmount.x <= maxX)) {
           offsetX += dragAmount.x
       }
       
       // 判断是否允许垂直拖动
       if ((offsetY + dragAmount.y >= minY) && (offsetY + dragAmount.y <= maxY)) {
           offsetY += dragAmount.y
       }
   }
   ```

3. **使用 `draggable` 修饰符的 `reverseDirection` 参数**：
   当拖动超出范围时，可以使用 `reverseDirection` 参数创建反向力的效果。

   ```kotlin
   @Composable
   fun BoundedDraggable() {
       // 记录方块的位置
       var offsetX by remember { mutableStateOf(0f) }
       
       // 定义拖动范围
       val minX = -200f
       val maxX = 200f
       
       Box(
           modifier = Modifier
               .fillMaxSize()
               .background(Color.LightGray),
           contentAlignment = Alignment.Center
       ) {
           Box(
               modifier = Modifier
                   .size(100.dp)
                   .offset { IntOffset(offsetX.roundToInt(), 0) }
                   .background(Color.Blue, shape = RoundedCornerShape(8.dp))
                   .draggable(
                       orientation = Orientation.Horizontal,
                       state = rememberDraggableState { delta ->
                           // 计算新的偏移量
                           val newOffset = offsetX + delta
                           
                           // 如果在范围内，正常更新
                           if (newOffset in minX..maxX) {
                               offsetX = newOffset
                           } else {
                               // 如果超出范围，只更新一小部分，创建阻尼效果
                               offsetX += delta * 0.2f
                               
                               // 确保不会太远超出范围
                               offsetX = offsetX.coerceIn(minX - 50, maxX + 50)
                           }
                       },
                       onDragStopped = { velocity ->
                           // 拖动结束时，如果超出范围，回弹到边界
                           if (offsetX < minX) {
                               offsetX = minX
                           } else if (offsetX > maxX) {
                               offsetX = maxX
                           }
                       }
                   )
           )
           
           // 显示拖动范围
           Box(
               modifier = Modifier
                   .width(400.dp)
                   .height(2.dp)
                   .background(Color.Red)
           )
       }
   }
   ```

   ```kotlin
   @Composable
   fun CustomDrawnTouchFeedback() {
       // 记录触摸位置
       var touchPosition by remember { mutableStateOf<Offset?>(null) }
       // 记录波纹半径

               .fillMaxSize()
               .background(Color.LightGray),

                   .size(200.dp)
                   .clip(RoundedCornerShape(8.dp))

                           onPress = { offset ->
                               // 记录触摸位置

                               // 重置波纹半径

                               // 开始波纹动画

                               tryAwaitRelease()

                       )

                       drawContent()
                       
                       // 绘制波纹效果
                       touchPosition?.let { position ->
                           drawCircle(
                               color = Color.White.copy(alpha = 0.3f),
                               radius = animatedRippleRadius,
                               center = position
                           )
                       }
                   }
           )
       }
   ```
