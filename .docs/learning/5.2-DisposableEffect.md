# 5.2 DisposableEffect()

> "资源管理就像收拾房间，用了就要记得清理，DisposableEffect 就是你的贴心'管家'
> ，帮你处理那些需要妥善'收纳'的资源！" 🧹

## 概念介绍

DisposableEffect 是 Jetpack Compose 中专门用于处理需要清理的副作用的 API。在 Android
应用开发中，我们经常需要注册各种监听器、观察者或者获取需要手动释放的资源，如果不正确地清理这些资源，可能会导致内存泄漏或其他问题。

DisposableEffect
提供了一种声明式的方式来管理这些资源的生命周期。它在组件进入组合时执行一段代码，并在组件离开组合或者键值变化时执行清理操作。这种机制确保了资源的获取和释放是成对的，即使在复杂的
UI 状态变化中也能保持一致性。

与 SideEffect 不同，DisposableEffect
有明确的生命周期概念，它不会在每次重组时都执行，而是只在键值变化或组件离开组合时才会触发清理和重新执行。这使得它特别适合管理那些需要长期存在但最终需要清理的资源。

## 知识要点

- DisposableEffect 用于管理需要清理的资源，如事件监听器、系统服务连接等
- 它在组件进入组合时执行初始化代码，在组件离开组合或键值变化时执行清理代码
- DisposableEffect 接受一个或多个键值参数，当这些键值变化时，会触发清理和重新执行
- 清理操作通过 `onDispose` 闭包定义，确保资源被正确释放
- DisposableEffect 返回一个 `DisposableEffectResult`，其中必须包含 `onDispose` 块
- 与 SideEffect 不同，DisposableEffect 不会在每次重组时都执行
- DisposableEffect 适用于需要与外部系统建立长期连接的场景，如生命周期观察、传感器监听等

## 基础代码示例

下面是一个简单的例子，展示如何使用 DisposableEffect 管理事件监听器：

```kotlin
@Composable
fun BackPressHandler(onBackPressed: () -> Unit) {
    // 获取当前的 Activity
    val currentActivity = LocalContext.current as? ComponentActivity ?: return
    
    // 使用 DisposableEffect 管理返回键监听器
    DisposableEffect(Unit) {
        // 创建回调
        val callback = object : OnBackPressedCallback(true) {
            override fun handleOnBackPressed() {
                onBackPressed()
            }
        }
        
        // 注册回调
        currentActivity.onBackPressedDispatcher.addCallback(callback)
        
        // 返回清理函数
        onDispose {
            // 移除回调
            callback.remove()
        }
    }
}

@Composable
fun MyScreen() {
    var showDialog by remember { mutableStateOf(false) }
    
    // 使用自定义的返回键处理
    BackPressHandler {
        if (showDialog) {
            // 如果对话框显示，关闭它
            showDialog = false
        } else {
            // 否则执行默认行为（通常是退出当前页面）
            // 这里可以调用 Activity 的 finish() 或导航回退
        }
    }
    
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        verticalArrangement = Arrangement.Center,
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Button(onClick = { showDialog = true }) {
            Text("显示对话框")
        }
        
        if (showDialog) {
            AlertDialog(
                onDismissRequest = { showDialog = false },
                title = { Text("提示") },
                text = { Text("按返回键可以关闭此对话框") },
                confirmButton = {
                    TextButton(onClick = { showDialog = false }) {
                        Text("确定")
                    }
                }
            )
        }
    }
}
```

## 进阶用法

### 1. 管理系统服务连接

DisposableEffect 非常适合管理系统服务的连接和断开：

```kotlin
@Composable
fun SensorMonitor(onSensorChanged: (SensorEvent) -> Unit) {
    // 获取传感器管理器
    val context = LocalContext.current
    val sensorManager = remember {
        context.getSystemService(Context.SENSOR_SERVICE) as SensorManager
    }
    
    // 获取加速度传感器
    val accelerometer = remember {
        sensorManager.getDefaultSensor(Sensor.TYPE_ACCELEROMETER)
    }
    
    // 使用 DisposableEffect 管理传感器监听
    DisposableEffect(sensorManager, accelerometer) {
        // 创建传感器事件监听器
        val sensorEventListener = object : SensorEventListener {
            override fun onSensorChanged(event: SensorEvent) {
                onSensorChanged(event)
            }
            
            override fun onAccuracyChanged(sensor: Sensor, accuracy: Int) {
                // 可以处理精度变化
            }
        }
        
        // 注册监听器
        sensorManager.registerListener(
            sensorEventListener,
            accelerometer,
            SensorManager.SENSOR_DELAY_NORMAL
        )
        
        // 返回清理函数
        onDispose {
            // 取消注册监听器
            sensorManager.unregisterListener(sensorEventListener)
        }
    }
}
```

### 2. 生命周期感知组件

使用 DisposableEffect 创建生命周期感知的组件：

```kotlin
@Composable
fun LifecycleAwareComponent(
    onStart: () -> Unit,
    onStop: () -> Unit,
    content: @Composable () -> Unit
) {
    // 获取当前的生命周期所有者
    val lifecycleOwner = LocalLifecycleOwner.current

    // 使用 DisposableEffect 监听生命周期变化
    DisposableEffect(lifecycleOwner) {
        // 创建生命周期观察者
        val observer = LifecycleEventObserver { _, event ->
            when (event) {
                Lifecycle.Event.ON_START -> onStart()
                Lifecycle.Event.ON_STOP -> onStop()
                else -> { /* 忽略其他事件 */
                }
            }
        }

        // 添加观察者
        lifecycleOwner.lifecycle.addObserver(observer)

        // 返回清理函数
        onDispose {
            // 移除观察者
            lifecycleOwner.lifecycle.removeObserver(observer)
        }
    }

    // 渲染内容
    content()
}

@Composable
fun AutoPauseVideoPlayer(videoUri: Uri) {
    var isPlaying by remember { mutableStateOf(false) }
    val context = LocalContext.current
    val mediaPlayer = remember {
        MediaPlayer.create(context, videoUri).apply {
            setOnPreparedListener { isPlaying = true }
        }
    }

    // 使用生命周期感知组件
    LifecycleAwareComponent(
        onStart = {
            // 当应用进入前台时恢复播放
            if (isPlaying) {
                mediaPlayer.start()
            }
        },
        onStop = {
            // 当应用进入后台时暂停播放
            if (mediaPlayer.isPlaying) {
                mediaPlayer.pause()
            }
        }
    ) {
        // 播放器 UI
        Column(
            modifier = Modifier
                .fillMaxWidth()
                .height(300.dp)
                .background(Color.Black),
            verticalArrangement = Arrangement.Center,
            horizontalAlignment = Alignment.CenterHorizontally
        ) {
            // 这里可以添加视频预览和控制按钮
            Text(
                text = if (isPlaying) "视频播放中" else "视频已暂停",
                color = Color.White
            )

            Row(
                modifier = Modifier.padding(top = 16.dp),
                horizontalArrangement = Arrangement.spacedBy(8.dp)
            ) {
                Button(onClick = {
                    if (isPlaying) {
                        mediaPlayer.pause()
                    } else {
                        mediaPlayer.start()
                    }
                    isPlaying = !isPlaying
                }) {
                    Text(if (isPlaying) "暂停" else "播放")
                }

                Button(onClick = {
                    mediaPlayer.seekTo(0)
                    mediaPlayer.start()
                    isPlaying = true
                }) {
                    Text("重新播放")
                }
            }
        }
    }

    // 清理 MediaPlayer
    DisposableEffect(mediaPlayer) {
        onDispose {
            mediaPlayer.release()
        }
    }
}
```

### 3. 键值变化触发的资源重新分配

DisposableEffect 可以根据键值变化自动清理和重新分配资源：

```kotlin
@Composable
fun NetworkMonitor(networkType: NetworkType, onNetworkAvailable: () -> Unit) {
    val context = LocalContext.current
    val connectivityManager = remember {
        context.getSystemService(Context.CONNECTIVITY_SERVICE) as ConnectivityManager
    }
    
    // 使用 networkType 作为键，当网络类型变化时重新注册监听器
    DisposableEffect(networkType) {
        // 创建网络回调
        val networkCallback = object : ConnectivityManager.NetworkCallback() {
            override fun onAvailable(network: Network) {
                onNetworkAvailable()
            }
        }
        
        // 创建网络请求
        val request = when (networkType) {
            NetworkType.WIFI -> {
                NetworkRequest.Builder()
                    .addTransportType(NetworkCapabilities.TRANSPORT_WIFI)
                    .build()
            }
            NetworkType.CELLULAR -> {
                NetworkRequest.Builder()
                    .addTransportType(NetworkCapabilities.TRANSPORT_CELLULAR)
                    .build()
            }
            NetworkType.ANY -> {
                NetworkRequest.Builder().build()
            }
        }
        
        // 注册网络回调
        connectivityManager.registerNetworkCallback(request, networkCallback)
        
        // 返回清理函数
        onDispose {
            // 取消注册网络回调
            connectivityManager.unregisterNetworkCallback(networkCallback)
        }
    }
}

// 网络类型枚举
enum class NetworkType {
    WIFI, CELLULAR, ANY
}

@Composable
fun NetworkAwareComponent() {
    var networkType by remember { mutableStateOf(NetworkType.ANY) }
    var isNetworkAvailable by remember { mutableStateOf(false) }
    
    // 使用网络监视器
    NetworkMonitor(networkType) {
        isNetworkAvailable = true
    }
    
    // UI
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(16.dp)
    ) {
        Text(
            text = "网络监控",
            style = MaterialTheme.typography.headlineMedium
        )
        
        // 网络类型选择
        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.spacedBy(8.dp)
        ) {
            NetworkTypeButton("任意网络", NetworkType.ANY) {
                networkType = it
                isNetworkAvailable = false
            }
            
            NetworkTypeButton("仅 WiFi", NetworkType.WIFI) {
                networkType = it
                isNetworkAvailable = false
            }
            
            NetworkTypeButton("仅移动网络", NetworkType.CELLULAR) {
                networkType = it
                isNetworkAvailable = false
            }
        }
        
        // 网络状态
        Card(
            modifier = Modifier.fillMaxWidth(),
            colors = CardDefaults.cardColors(
                containerColor = if (isNetworkAvailable) 
                    MaterialTheme.colorScheme.primaryContainer 
                else 
                    MaterialTheme.colorScheme.errorContainer
            )
        ) {
            Text(
                text = if (isNetworkAvailable) 
                    "网络可用 (${networkType.name})" 
                else 
                    "等待网络连接...",
                modifier = Modifier.padding(16.dp),
                color = if (isNetworkAvailable) 
                    MaterialTheme.colorScheme.onPrimaryContainer 
                else 
                    MaterialTheme.colorScheme.onErrorContainer
            )
        }
    }
}

@Composable
private fun NetworkTypeButton(
    text: String,
    type: NetworkType,
    onClick: (NetworkType) -> Unit
) {
    Button(
        onClick = { onClick(type) },
        modifier = Modifier.weight(1f)
    ) {
        Text(text)
    }
}
```

## 常见问题

### 1. DisposableEffect 和 SideEffect 有什么区别？

**回答**：两者都用于处理副作用，但有几个关键区别：

- `DisposableEffect` 有明确的生命周期，会在组件离开组合或键值变化时执行清理操作
- `SideEffect` 没有生命周期概念，在每次成功重组后都会执行
- `DisposableEffect` 主要用于管理需要清理的资源，如监听器、连接等
- `SideEffect` 主要用于同步 Compose 状态到非 Compose 系统
- `DisposableEffect` 需要返回一个包含 `onDispose` 块的 `DisposableEffectResult`
- `SideEffect` 只接受一个执行块，不需要返回任何内容

选择指南：

- 如果需要在组件离开组合时执行清理操作，使用 `DisposableEffect`
- 如果只需要在每次重组后同步状态，使用 `SideEffect`

### 2. 为什么我的 DisposableEffect 清理函数没有被调用？

**回答**：DisposableEffect 的清理函数可能没有被调用的原因包括：

- 组件没有真正离开组合，可能只是被条件渲染隐藏了
- 键值没有变化，所以没有触发重新执行
- 在嵌套的组合中，父组件的重组没有导致子组件的重组
- 应用异常终止，没有机会执行清理代码

解决方法：

- 确保使用正确的键值，使其在需要时变化
- 使用 `rememberUpdatedState` 捕获最新值，避免不必要的重新执行
- 在适当的作用域中使用 DisposableEffect，确保它能感知到组件的生命周期
- 对于应用级资源，考虑在 Application 或 Activity 级别管理

### 3. 如何在 DisposableEffect 中处理异步操作？

**回答**：DisposableEffect 本身不支持异步操作，但可以通过以下方式处理：

1. **启动协程并在清理时取消**：

```kotlin
DisposableEffect(key) {
    val job = CoroutineScope(Dispatchers.IO).launch {
        // 异步操作
    }
    
    onDispose {
        job.cancel() // 取消协程
    }
}
```

2. **结合 LaunchedEffect 使用**：

```kotlin
// 使用 LaunchedEffect 处理异步操作
LaunchedEffect(key) {
    // 异步操作
}

// 使用 DisposableEffect 处理资源清理
DisposableEffect(key) {
    // 设置资源
    
    onDispose {
        // 清理资源
    }
}
```

3. **使用 rememberCoroutineScope**：

```kotlin
val scope = rememberCoroutineScope()

DisposableEffect(key) {
    // 设置资源
    val job = scope.launch {
        // 异步操作
    }
    
    onDispose {
        job.cancel() // 取消协程
        // 清理其他资源
    }
}
```

### 4. DisposableEffect 的键值应该如何选择？

**回答**：选择 DisposableEffect 的键值需要考虑以下几点：

- **键值应该反映资源的依赖关系**：当这些依赖变化时，资源需要重新分配
- **避免使用过于频繁变化的键值**：这会导致资源频繁地清理和重新分配
- **使用 Unit 作为键值**：如果资源只需要在组件进入和离开组合时分配和清理
- **使用多个键值**：如果资源依赖于多个因素，可以提供多个键值
- **使用 rememberUpdatedState**：捕获频繁变化的值，避免不必要的资源重新分配

示例：

```kotlin
// 只在组件生命周期变化时执行
DisposableEffect(Unit) { /* ... */ }

// 当 userId 变化时重新执行
DisposableEffect(userId) { /* ... */ }

// 当 userId 或 resourceType 变化时重新执行
DisposableEffect(userId, resourceType) { /* ... */ }

// 使用 rememberUpdatedState 捕获频繁变化的回调
val latestCallback = rememberUpdatedState(callback)
DisposableEffect(Unit) {
    // 使用 latestCallback.value 而不是直接使用 callback
    // ...
}
```
