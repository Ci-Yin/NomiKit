## 概念介绍

在前几节中，我们学习了`Modifier`的基本概念以及各种组合和扩展方式。本节将深入探讨`LayoutModifier`接口和
`Modifier.layout()`
函数，它们是Compose布局系统中最强大的自定义工具，允许我们精确控制UI元素的测量和放置过程。

`LayoutModifier`是一个接口，继承自`Modifier.Element`
，专门用于修改组件的布局行为。它定义了如何测量和放置一个组件，可以改变组件的尺寸、位置，甚至完全重新定义其布局逻辑。

`Modifier.layout()`是一个便捷函数，它创建一个`LayoutModifier`
的实现，使我们能够以声明式的方式自定义布局逻辑，而无需直接实现接口。通过这个函数，我们可以拦截组件的测量和放置过程，应用自定义的布局算法。

与普通的修饰符不同，`LayoutModifier`直接参与Compose的布局过程，它可以：

1. 修改组件的测量约束
2. 改变组件的测量结果
3. 控制组件在父容器中的放置位置
4. 影响组件的内在尺寸（intrinsic measurements）
5. 实现复杂的自定义布局效果

理解`LayoutModifier`和`Modifier.layout()`
的工作原理，对于创建高度自定义的UI布局至关重要，它们是Compose布局系统的核心构建块，为UI设计提供了无限的可能性。

## 知识要点

- **LayoutModifier接口**：
    - 继承自`Modifier.Element`
    - 定义了`MeasureScope.measure()`方法，用于自定义测量逻辑
    - 可选实现`IntrinsicMeasurable`接口的方法，用于支持内在尺寸测量
    - 是所有布局修饰符的基础接口

- **Modifier.layout()函数**：
    - 签名：
      `fun Modifier.layout(measureBlock: MeasureScope.(Measurable, Constraints) -> MeasureResult): Modifier`
    - 创建一个`LayoutModifier`的实现
    - 参数是一个lambda函数，接收可测量对象和约束，返回测量结果
    - 提供了`MeasureScope`作为接收者，可以访问密度等信息

- **布局过程的关键概念**：
    - `Measurable`：表示可以被测量的组件
    - `Constraints`：定义了宽高的最小和最大限制
    - `MeasureScope`：提供测量相关的工具和上下文
    - `MeasureResult`：包含测量后的尺寸和放置信息
    - `Placeable`：表示已测量且可放置的组件

- **测量过程**：
    - 父组件向子组件传递约束（Constraints）
    - 子组件根据约束计算自己的尺寸
    - 子组件返回测量结果（宽度和高度）
    - `LayoutModifier`可以在这个过程中修改约束和结果

- **放置过程**：
    - 父组件决定子组件的位置
    - 调用子组件的`placeRelative()`或`place()`方法
    - `LayoutModifier`可以修改子组件的放置位置

- **约束（Constraints）**：
    - `minWidth`和`minHeight`：组件的最小宽度和高度
    - `maxWidth`和`maxHeight`：组件的最大宽度和高度
    - `Constraints.fixed()`：创建固定尺寸的约束
    - `Constraints.tight()`：创建紧约束（最小值等于最大值）
    - `Constraints.loose()`：创建松约束（最小值为0，有最大值）

- **内在尺寸（Intrinsic Measurements）**：
    - `minIntrinsicWidth`和`minIntrinsicHeight`：组件在给定高度/宽度下的最小内在宽度/高度
    - `maxIntrinsicWidth`和`maxIntrinsicHeight`：组件在给定高度/宽度下的最大内在宽度/高度
    - 用于处理复杂的布局场景，如文本换行

- **常见的布局修饰符**：
    - `padding()`：在组件周围添加内边距
    - `size()`：设置组件的固定尺寸
    - `fillMaxWidth()`/`fillMaxHeight()`：使组件填充最大可用宽度/高度
    - `aspectRatio()`：保持组件的宽高比
    - 这些都是通过`LayoutModifier`实现的

### 使用Modifier.layout()创建简单的偏移修饰符

```kotlin
@Composable
fun SimpleLayoutModifierExample() {
    // 创建一个简单的偏移修饰符
    fun Modifier.offset(x: Dp, y: Dp) = layout { measurable, constraints ->
        // 测量子元素
        val placeable = measurable.measure(constraints)
        
        // 创建测量结果，应用偏移
        layout(placeable.width, placeable.height) {
            // 放置子元素，应用偏移
            placeable.placeRelative(x.roundToPx(), y.roundToPx())
        }
    }
    
    Box(
        modifier = Modifier
            .fillMaxWidth()
            .height(200.dp)
            .background(Color.LightGray)
            .padding(16.dp)
    ) {
        Box(
            modifier = Modifier
                .size(100.dp)
                .offset(x = 20.dp, y = 30.dp)
                .background(Color.Blue)
        )
        
        Box(
            modifier = Modifier
                .size(100.dp)
                .offset(x = 50.dp, y = 50.dp)
                .background(Color.Red.copy(alpha = 0.7f))
        )
    }
}
```

```kotlin
fun ScaleLayoutModifierExample() {
    // 创建一个缩放修饰符
    fun Modifier.scale(scale: Float) = layout { measurable, constraints ->
        // 计算缩放后的约束
        val looseConstraints = constraints.copy(
            minWidth = 0,
            minHeight = 0
        )
        
        // 使用松约束测量子元素
        val placeable = measurable.measure(looseConstraints)
        
        // 计算缩放后的尺寸
        val scaledWidth = (placeable.width * scale).roundToInt()
        val scaledHeight = (placeable.height * scale).roundToInt()

            // 计算偏移，使缩放居中

                scaleY = scale

            }

            .fillMaxWidth()
            .padding(16.dp)

        Row(
            modifier = Modifier.fillMaxWidth(),
```

```kotlin
@Composable
fun RotateLayoutModifierExample() {
    // 创建一个旋转修饰符
    fun Modifier.rotate(degrees: Float) = layout { measurable, constraints ->
        // 测量子元素
        val placeable = measurable.measure(constraints)
        
        // 计算旋转后的尺寸（使用勾股定理）
        val rad = Math.toRadians(degrees.toDouble())
        val sin = kotlin.math.abs(sin(rad).toFloat())
        val cos = kotlin.math.abs(cos(rad).toFloat())
        
        val rotatedWidth = (placeable.width * cos + placeable.height * sin).roundToInt()
        val rotatedHeight = (placeable.width * sin + placeable.height * cos).roundToInt()
        
        // 创建测量结果
        layout(rotatedWidth, rotatedHeight) {
            // 计算中心点
            val centerX = rotatedWidth / 2 - placeable.width / 2
            val centerY = rotatedHeight / 2 - placeable.height / 2
            
            // 放置子元素，应用旋转变换
            placeable.placeRelativeWithLayer(centerX, centerY) {
                rotationZ = degrees
            }
        }
    }
    
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Box(
            modifier = Modifier
                .size(150.dp)
                .background(Color.LightGray),
            contentAlignment = Alignment.Center
        ) {
            Box(
                modifier = Modifier
                    .rotate(45f)
                    .size(100.dp)
                    .background(Color.Blue),

                Text("旋转45°", color = Color.White)
```

### 实现一个自定义的LayoutModifier接口

```kotlin
// 自定义LayoutModifier实现
class CustomPaddingModifier(
    private val start: Dp = 0.dp,
    private val top: Dp = 0.dp,
    private val end: Dp = 0.dp,
    private val bottom: Dp = 0.dp
) : LayoutModifier {
    override fun MeasureScope.measure(
        measurable: Measurable,
        constraints: Constraints
    ): MeasureResult {
        // 转换dp为像素
        val startPx = start.roundToPx()
        val topPx = top.roundToPx()
        val endPx = end.roundToPx()
        val bottomPx = bottom.roundToPx()
        
        // 计算水平和垂直方向的总内边距
        val horizontal = startPx + endPx
        val vertical = topPx + bottomPx
        
        // 创建新的约束，减去内边距
        val newConstraints = constraints.copy(
            maxWidth = if (constraints.maxWidth != Constraints.Infinity) {
                (constraints.maxWidth - horizontal).coerceAtLeast(0)
            } else {
                Constraints.Infinity
            },
            maxHeight = if (constraints.maxHeight != Constraints.Infinity) {
                (constraints.maxHeight - vertical).coerceAtLeast(0)
            } else {
                Constraints.Infinity
            }
        )
        
        // 使用新约束测量子元素
        val placeable = measurable.measure(newConstraints)
        
        // 计算包含内边距的总尺寸
        val width = placeable.width + horizontal
        val height = placeable.height + vertical
        
        // 创建测量结果
        return layout(width, height) {
            // 放置子元素，应用内边距偏移
            placeable.placeRelative(startPx, topPx)
        }
    }
    
    // 实现内在尺寸测量方法
    override fun IntrinsicMeasureScope.minIntrinsicWidth(
        measurable: IntrinsicMeasurable,
        height: Int
    ): Int {
        // 计算子元素的最小内在宽度，加上水平内边距
        val startPx = start.roundToPx()
        val endPx = end.roundToPx()
        return measurable.minIntrinsicWidth(height) + startPx + endPx
    }
    
    override fun IntrinsicMeasureScope.minIntrinsicHeight(
        measurable: IntrinsicMeasurable,
        width: Int
    ): Int {
        // 计算子元素的最小内在高度，加上垂直内边距
        val topPx = top.roundToPx()
        val bottomPx = bottom.roundToPx()
        return measurable.minIntrinsicHeight(width) + topPx + bottomPx
    }
    
    override fun IntrinsicMeasureScope.maxIntrinsicWidth(
        measurable: IntrinsicMeasurable,
        height: Int
    ): Int {
        // 计算子元素的最大内在宽度，加上水平内边距
        val startPx = start.roundToPx()
        val endPx = end.roundToPx()
        return measurable.maxIntrinsicWidth(height) + startPx + endPx
    }
    
    override fun IntrinsicMeasureScope.maxIntrinsicHeight(
        measurable: IntrinsicMeasurable,
        width: Int
    ): Int {
        // 计算子元素的最大内在高度，加上垂直内边距
        val topPx = top.roundToPx()
        val bottomPx = bottom.roundToPx()
        return measurable.maxIntrinsicHeight(width) + topPx + bottomPx
    }
    
    override fun equals(other: Any?): Boolean {
        if (this === other) return true
        if (other !is CustomPaddingModifier) return false
        
        return start == other.start &&
               top == other.top &&
               end == other.end &&
               bottom == other.bottom
    }
    
    override fun hashCode(): Int {
        var result = start.hashCode()
        result = 31 * result + top.hashCode()
        result = 31 * result + end.hashCode()
        result = 31 * result + bottom.hashCode()
        return result
    }
}
```

### 创建一个自适应网格布局修饰符

```kotlin
@Composable
fun AdaptiveGridLayoutModifierExample() {
    // 创建一个自适应网格布局修饰符
    fun Modifier.adaptiveGrid(
        columns: Int,
        spacing: Dp = 8.dp
    ) = layout { measurable, constraints ->
        // 计算每个单元格的宽度
        val spacingPx = spacing.roundToPx()
        val totalSpacingWidth = spacingPx * (columns - 1)
        val cellWidth = ((constraints.maxWidth - totalSpacingWidth) / columns)
            .coerceAtLeast(0)
        
        // 创建单元格约束
        val cellConstraints = Constraints.fixed(
            width = cellWidth,
            height = cellWidth // 正方形单元格
        )
        
        // 测量子元素
        val placeable = measurable.measure(cellConstraints)
        
        // 计算网格的总宽度和高度
        val width = constraints.maxWidth
        val height = placeable.height
        
        // 创建测量结果
        layout(width, height) {
            // 放置子元素
            var xPosition = 0
            
            // 放置单元格
            placeable.placeRelative(xPosition, 0)
            xPosition += cellWidth + spacingPx
        }
    }
    
    // 创建一个包含多个项目的网格布局
    fun Modifier.itemsGrid(
        items: List<String>,
        columns: Int = 3,
        spacing: Dp = 8.dp
    ) = layout { measurable, constraints ->
        // 计算每个单元格的宽度
        val spacingPx = spacing.roundToPx()
        val totalSpacingWidth = spacingPx * (columns - 1)
        val cellWidth = ((constraints.maxWidth - totalSpacingWidth) / columns)
            .coerceAtLeast(0)
        
        // 创建单元格约束
        val cellConstraints = Constraints.fixed(
            width = cellWidth,
            height = cellWidth // 正方形单元格
        )
        
        // 测量所有子元素
        val placeables = measurable.measure(cellConstraints)
        
        // 计算行数
        val rows = (items.size + columns - 1) / columns
        
        // 计算网格的总宽度和高度
        val width = constraints.maxWidth
        val height = rows * cellWidth + (rows - 1) * spacingPx
        
        // 创建测量结果
        layout(width, height) {
            // 放置所有子元素
            var xPosition = 0
            var yPosition = 0
            var itemsInCurrentRow = 0
            
            // 放置单元格
            placeables.placeRelative(xPosition, yPosition)
            
            itemsInCurrentRow++
            if (itemsInCurrentRow >= columns) {
                // 移动到下一行
                itemsInCurrentRow = 0
                xPosition = 0
                yPosition += cellWidth + spacingPx
            } else {
                // 移动到下一列
                xPosition += cellWidth + spacingPx
            }
        }
    }
    
    // 使用示例
    val items = listOf("项目1", "项目2", "项目3", "项目4", "项目5", "项目6", "项目7", "项目8", "项目9")
    
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp)
    ) {
        Text(
            text = "自适应网格布局",
            style = MaterialTheme.typography.headlineSmall,
            modifier = Modifier.padding(bottom = 16.dp)
        )
        
        LazyVerticalGrid(
            columns = GridCells.Fixed(3),
            horizontalArrangement = Arrangement.spacedBy(8.dp),
            verticalArrangement = Arrangement.spacedBy(8.dp),
            modifier = Modifier.fillMaxWidth()
        ) {
            items(items) { item ->
                Box(
                    modifier = Modifier
                        .aspectRatio(1f)
                        .background(Color(0xFF2196F3)),
                    contentAlignment = Alignment.Center
                ) {
                    Text(
                        text = item,
                        color = Color.White,
                        fontWeight = FontWeight.Bold
                    )
                }
            }
        }
    }
}
```

### 创建一个圆形布局修饰符

```kotlin
@Composable
fun CircularLayoutModifierExample() {
    // 创建一个圆形布局修饰符
    fun Modifier.circularLayout(
        radius: Dp,
        startAngle: Float = 0f,
        sweepAngle: Float = 360f,
        childCount: Int
    ) = layout { measurable, constraints ->
        // 转换半径为像素
        val radiusPx = radius.roundToPx()
        
        // 创建松约束
        val looseConstraints = constraints.copy(
            minWidth = 0,
            minHeight = 0
        )
        
        // 测量子元素
        val placeable = measurable.measure(looseConstraints)
        
        // 计算布局的总尺寸
        val diameter = radiusPx * 2
        val width = diameter.coerceAtMost(constraints.maxWidth)
        val height = diameter.coerceAtMost(constraints.maxHeight)
        
        // 创建测量结果
        layout(width, height) {
            // 计算中心点
            val centerX = width / 2
            val centerY = height / 2
            
            // 计算每个子元素的角度
            val angleStep = sweepAngle / childCount
            
            // 放置子元素
            for (i in 0 until childCount) {
                val angle = Math.toRadians((startAngle + i * angleStep).toDouble())
                val x = centerX + (radiusPx * cos(angle)).toInt() - placeable.width / 2
                val y = centerY + (radiusPx * sin(angle)).toInt() - placeable.height / 2
                
                placeable.placeRelative(x, y)
            }
        }
    }
    
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(
            text = "圆形布局",
            style = MaterialTheme.typography.headlineSmall,
            modifier = Modifier.padding(bottom = 16.dp)
        )
        
        Box(
            modifier = Modifier
                .size(300.dp)
                .background(Color.LightGray.copy(alpha = 0.3f)),
            contentAlignment = Alignment.Center
        ) {
            // 中心点
            Box(
                modifier = Modifier
                    .size(20.dp)
                    .background(Color.Red, CircleShape)
            )
            
            // 圆形布局的项目
            for (i in 0 until 8) {
                Box(
                    modifier = Modifier
                        .circularLayout(
                            radius = 120.dp,
                            startAngle = 0f,
                            sweepAngle = 360f,
                            childCount = 8
                        )
                        .size(40.dp)
                        .background(
                            color = Color(
                                red = (i * 30) % 255,
                                green = (i * 50) % 255,
                                blue = (i * 70) % 255
                            ),
                            shape = CircleShape
                        ),
                    contentAlignment = Alignment.Center
                ) {
                    Text(
                        text = "${i + 1}",
                        color = Color.White,
                        fontWeight = FontWeight.Bold
                    )
                }
            }
        }
    }
}
```

## 常见问题

### 1. LayoutModifier和Modifier.layout()有什么区别？

**问题**：我应该直接实现`LayoutModifier`接口还是使用`Modifier.layout()`函数？

**解答**：这两种方式都可以实现自定义布局，选择取决于你的需求：

- **使用`Modifier.layout()`**：
    - 优点：更简洁，适合简单的一次性布局逻辑
    - 适用场景：临时需要的布局修改，不需要重用的布局逻辑
    - 示例：`Modifier.layout { measurable, constraints -> ... }`

- **实现`LayoutModifier`接口**：
    - 优点：更结构化，支持完整的内在尺寸测量，便于重用
    - 适用场景：需要创建可重用的布局修饰符，需要支持内在尺寸测量
    - 示例：`class MyLayoutModifier : LayoutModifier { ... }`

一般来说，如果你只需要简单的布局逻辑，使用`Modifier.layout()`更方便；如果你需要创建可重用的复杂布局修饰符，或者需要支持内在尺寸测量，则应该实现
`LayoutModifier`接口。

### 2. 如何处理布局中的约束（Constraints）？

**问题**：在自定义布局中，如何正确处理和修改约束？

**解答**：处理约束是自定义布局的核心部分，以下是一些关键点：

1. **理解约束的含义**：
    - `minWidth`/`minHeight`：组件必须至少这么大
    - `maxWidth`/`maxHeight`：组件最多只能这么大
    - 约束必须满足：`0 <= minWidth <= maxWidth`和`0 <= minHeight <= maxHeight`

2. **常见的约束修改模式**：
    - **放宽约束**：`constraints.copy(minWidth = 0, minHeight = 0)`
    - **固定尺寸**：`Constraints.fixed(width, height)`
    - **设置最大尺寸**：`constraints.copy(maxWidth = newMax, maxHeight = newMax)`
    - **保持宽高比**：调整约束使宽高满足特定比例

3. **注意事项**：
    - 永远不要创建无法满足的约束（如`minWidth > maxWidth`）
    - 修改约束时考虑原始约束的限制
    - 处理`Constraints.Infinity`的特殊情况

```kotlin
// 示例：创建一个保持宽高比的约束
fun Constraints.withAspectRatio(ratio: Float): Constraints {
    val maxWidth = this.maxWidth
    val maxHeight = this.maxHeight
    
    return when {
        // 如果宽度是无限的，根据高度计算宽度
        maxWidth == Constraints.Infinity && maxHeight != Constraints.Infinity -> {
            val width = (maxHeight * ratio).toInt()
            this.copy(maxWidth = width)
        }
        // 如果高度是无限的，根据宽度计算高度
        maxHeight == Constraints.Infinity && maxWidth != Constraints.Infinity -> {
            val height = (maxWidth / ratio).toInt()
            this.copy(maxHeight = height)
        }
        // 如果宽高比大于目标比例，以高度为基准
        maxWidth / maxHeight.toFloat() > ratio -> {
            val width = (maxHeight * ratio).toInt()
            this.copy(maxWidth = width)
        }
        // 否则以宽度为基准
        else -> {
            val height = (maxWidth / ratio).toInt()
            this.copy(maxHeight = height)
        }
    }
}
```

### 3. 什么是内在尺寸（Intrinsic Measurements）？为什么它们很重要？

**问题**：内在尺寸测量是什么？我什么时候需要实现它们？

**解答**：内在尺寸是组件在特定约束下的"理想"尺寸，它们在处理复杂布局（特别是文本布局）时非常重要：

1. **内在尺寸的类型**：
    - `minIntrinsicWidth`：在给定高度下，内容不换行所需的最小宽度
    - `minIntrinsicHeight`：在给定宽度下，显示所有内容所需的最小高度
    - `maxIntrinsicWidth`：在给定高度下，内容完全展开所需的宽度
    - `maxIntrinsicHeight`：在给定宽度下，内容完全展开所需的高度

2. **何时需要实现内在尺寸**：
    - 创建可能在复杂布局中使用的自定义`LayoutModifier`
    - 处理需要换行或动态调整大小的内容（如文本）
    - 实现需要协商尺寸的布局（如表格单元格）

3. **实现内在尺寸的原则**：
    - 正确传递内在尺寸请求给子元素
    - 考虑修饰符添加的额外空间（如内边距）
    - 确保结果与实际测量行为一致

如果你的布局修饰符简单且不涉及文本换行或复杂布局，可能不需要实现内在尺寸方法。但对于可能在任何地方使用的通用修饰符，建议实现这些方法以确保最大的兼容性。

### 4. 如何在布局修饰符中处理RTL（从右到左）布局？

**问题**：如何确保我的自定义布局修饰符在RTL语言中正常工作？

**解答**：支持RTL布局是国际化应用的重要部分，以下是在自定义布局修饰符中处理RTL的关键点：

1. **使用相对位置术语**：
    - 使用`start`/`end`而不是`left`/`right`
    - 在代码中使用`layoutDirection`来确定实际方向

2. **使用正确的放置方法**：
    - 使用`placeRelative()`而不是`place()`
    - `placeRelative()`会根据当前的`layoutDirection`自动调整位置

3. **访问布局方向**：
    - 在`MeasureScope`中可以访问`layoutDirection`属性
    - 使用`layoutDirection`来决定元素的放置位置

```kotlin
fun Modifier.rtlAwarePadding(
    start: Dp = 0.dp,
    top: Dp = 0.dp,
    end: Dp = 0.dp,
    bottom: Dp = 0.dp
) = layout { measurable, constraints ->
    val placeable = measurable.measure(constraints)
    
    val startPx = start.roundToPx()
    val endPx = end.roundToPx()
    val topPx = top.roundToPx()
    val bottomPx = bottom.roundToPx()
    
    val width = placeable.width + startPx + endPx
    val height = placeable.height + topPx + bottomPx
    
    layout(width, height) {
        // placeRelative会根据layoutDirection自动调整水平位置
        placeable.placeRelative(startPx, topPx)
    }
}
```

### 5. 如何优化自定义布局修饰符的性能？

**问题**：创建自定义布局修饰符时，应该注意哪些性能问题？

**解答**：布局操作可能是计算密集型的，以下是一些优化自定义布局修饰符性能的建议：

1. **避免不必要的测量**：
    - 只在必要时重新测量子元素
    - 缓存测量结果，避免重复计算

2. **优化约束处理**：
    - 避免创建过于复杂的约束
    - 尽可能使用原始约束，只修改必要的部分

3. **实现equals()和hashCode()**：
    - 确保修饰符可以正确参与重组优化
    - 比较所有影响布局的属性

4. **避免在测量过程中分配大量对象**：
    - 重用对象和数据结构
    - 避免创建不必要的临时列表或数组

5. **使用适当的作用域函数**：
    - 利用`MeasureScope`提供的工具函数
    - 使用`layout`函数创建测量结果

```kotlin
// 性能优化示例：实现equals和hashCode
class OptimizedLayoutModifier(private val padding: Dp) : LayoutModifier {
    // 布局逻辑...
    
    override fun equals(other: Any?): Boolean {
        if (this === other) return true
        if (other !is OptimizedLayoutModifier) return false
        return padding == other.padding
    }
    
    override fun hashCode(): Int {
        return padding.hashCode()
    }
}
```

```kotlin
@Composable
fun WaterfallLayoutModifierExample() {
    // 创建一个简化版的瀑布流布局修饰符
    // 注意：完整的瀑布流布局通常需要使用自定义Layout实现
    fun Modifier.simpleWaterfall(
        columns: Int = 2,
        spacing: Dp = 8.dp,
        items: List<Int> // 每个项目的高度比例
    ): Modifier = layout { measurable, constraints ->
        // 计算列宽
        val spacingPx = spacing.roundToPx()
        val totalSpacingWidth = spacingPx * (columns - 1)
        val columnWidth = ((constraints.maxWidth - totalSpacingWidth) / columns)
            .coerceAtLeast(0)
        
        // 创建列约束
        val columnConstraints = constraints.copy(
            minWidth = columnWidth,
            maxWidth = columnWidth
        )
        
        // 测量子元素
        val placeable = measurable.measure(columnConstraints)
        
        // 计算每列的高度
        val columnHeights = IntArray(columns) { 0 }
        val itemPositions = mutableListOf<Pair<Int, Int>>() // (x, y)坐标
        
        // 为每个项目分配位置
        items.forEach { heightRatio ->
            // 找到最短的列
            val shortestColumnIndex = columnHeights.indices.minByOrNull { columnHeights[it] }
                ?: 0
            
            // 计算项目位置
            val x = shortestColumnIndex * (columnWidth + spacingPx)
            val y = columnHeights[shortestColumnIndex]
            
            // 更新列高度
            val itemHeight = (placeable.height * heightRatio / 100)
            columnHeights[shortestColumnIndex] += itemHeight + spacingPx
            
            // 保存项目位置
            itemPositions.add(x to y)
        }
        
        // 计算布局高度
        val height = columnHeights.maxOrNull() ?: 0
        
        // 创建测量结果
        layout(constraints.maxWidth, height) {
            // 放置子元素
            itemPositions.forEachIndexed { index, (x, y) ->
                placeable.placeRelative(x, y)
            }
        }
    }
    
    // 使用示例
    val itemHeightRatios = listOf(100, 150, 80, 120, 90, 110, 130, 70)
    
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp)
    ) {
        Text(
            text = "瀑布流布局示例",
            style = MaterialTheme.typography.headlineSmall,
            modifier = Modifier.padding(bottom = 16.dp)
        )
        
        // 在实际应用中，应该使用LazyVerticalGrid或自定义Layout实现完整的瀑布流
        // 这里使用简化版展示布局修饰符的原理
        LazyVerticalGrid(
            columns = GridCells.Fixed(2),
            horizontalArrangement = Arrangement.spacedBy(8.dp),
            verticalArrangement = Arrangement.spacedBy(8.dp),
            modifier = Modifier.fillMaxWidth()
        ) {
            items(itemHeightRatios) { ratio ->
                Box(
                    modifier = Modifier
                        .fillMaxWidth()
                        .height((ratio * 1.5).dp)
                        .background(
                            color = Color(
                                red = (ratio * 2) % 255,
                                green = (ratio * 3) % 255,
                                blue = (ratio * 5) % 255
                            ),
                            shape = RoundedCornerShape(8.dp)
                        ),
                    contentAlignment = Alignment.Center
                ) {
                    Text(
                        text = "高度: $ratio",
                        color = Color.White,
                        fontWeight = FontWeight.Bold
                    )
                }
            }
        }
    }
}
```
