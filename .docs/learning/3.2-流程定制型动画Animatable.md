# 3.2 流程定制型动画 Animatable

> "如果说AnimateXxxAsState是动画界的'傻瓜相机'
> ，那么Animatable就是专业单反，让你能够精确控制动画的每一帧，实现那些让用户惊叹的复杂效果！" 🎬

## 概念介绍

Animatable是Jetpack
Compose中一个强大的动画API，它提供了对动画过程的完全控制能力。与状态转移型动画（AnimateXxxAsState）不同，Animatable允许开发者精确控制动画的启动、暂停、恢复和停止，以及动画的目标值和边界条件。

Animatable是一个可变状态持有者，它封装了一个值和将该值动画化的能力。通过Animatable，你可以：

- 手动启动和控制动画
- 设置动画的边界约束
- 链接多个动画序列
- 在协程中控制动画流程
- 实现复杂的交互式动画

这种灵活性使Animatable成为实现高度自定义动画效果的理想选择，特别是当你需要对动画流程进行精细控制时。

## 知识要点

- **Animatable的基本概念**：可变状态持有者与动画控制器
- **创建与初始化**：如何创建和初始化Animatable实例
- **动画控制方法**：animateTo、snapTo、animateDecay等核心方法
- **动画约束**：如何设置和使用动画边界
- **协程与动画**：在协程中控制动画流程
- **动画序列**：如何链接多个动画步骤
- **手势集成**：将Animatable与手势输入结合
- **性能考虑**：Animatable的性能特性和优化

```kotlin
@Composable
fun BasicAnimatableExample() {
    // 创建一个Animatable实例，初始值为0f
    val animatable = remember { Animatable(0f) }
    
    // 在协程中启动动画
    LaunchedEffect(key1 = Unit) {
        // 延迟一秒后开始动画
        delay(1000)
        // 动画到目标值1f
        animatable.animateTo(
            targetValue = 1f,
            // 使用弹簧动画规格
            animationSpec = spring(
                dampingRatio = Spring.DampingRatioMediumBouncy,
                stiffness = Spring.StiffnessLow
            )
        )
    }
    
    // 使用动画值
    Box(
        modifier = Modifier.fillMaxSize(),
        contentAlignment = Alignment.Center
    ) {
        Box(
            modifier = Modifier
                .size(200.dp * animatable.value)
                .background(
                    color = Color(
                        red = 0.2f + (0.6f * animatable.value),
                        green = 0.2f,
                        blue = 0.8f,
                        alpha = 1f
                    ),
                    shape = RoundedCornerShape(
                        size = 16.dp * animatable.value
                    )
                )
        )
    }
}
```

```kotlin
@Composable
fun ManualControlAnimatableExample() {

                        // 立即跳转到0
                        animatable.snapTo(0f)
                    }
                }
            ) {
                Text("重置")
            }
            
            // 播放按钮
            Button(
                onClick = {
                    scope.launch {
                        // 动画到1
                        animatable.animateTo(
                            targetValue = 1f,
                            animationSpec = tween(1500)
                        )
                    }
                },
                enabled = animatable.value < 1f
            ) {
                Text("播放")
            }
            
            // 暂停按钮（实际上是停止当前动画）
            Button(
                onClick = {
                    scope.launch {
                        // 停止当前动画，保持在当前值

                    }
                },
                enabled = animatable.isRunning
            ) {
                Text("暂停")

        }
        
        Spacer(modifier = Modifier.height(16.dp))

        // 显示动画状态

        Text(
            text = "动画状态: ${if (animatable.isRunning) "运行中" else "已停止"}",
```

### 动画序列与链接

```kotlin
@Composable
fun AnimationSequenceExample() {
    // 创建Animatable实例
    val animatable = remember { Animatable(0f) }
    
    // 创建状态跟踪当前动画阶段
    var currentStep by remember { mutableStateOf(0) }
    val totalSteps = 4
    
    // 创建协程作用域
    val scope = rememberCoroutineScope()
    
    // 动画序列函数
    fun startAnimationSequence() {
        scope.launch {
            currentStep = 1
            // 第一步：快速动画到0.4
            animatable.animateTo(
                targetValue = 0.4f,
                animationSpec = tween(
                    durationMillis = 500,
                    easing = FastOutSlowInEasing
                )
            )
            
            currentStep = 2
            // 第二步：弹性动画到0.8
            animatable.animateTo(
                targetValue = 0.8f,
                animationSpec = spring(
                    dampingRatio = Spring.DampingRatioMediumBouncy,
                    stiffness = Spring.StiffnessLow
                )
            )
            
            currentStep = 3
            // 第三步：使用关键帧动画到1.0
            animatable.animateTo(
                targetValue = 1f,
                animationSpec = keyframes {
                    durationMillis = 1000
                    0.8f at 0
                    0.7f at 200
                    0.9f at 400
                    0.8f at 600
                    1f at 1000
                }
            )
            
            currentStep = 4
            // 第四步：延迟后重置
            delay(500)
            animatable.snapTo(0f)
            currentStep = 0
        }
    }
    
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(
            text = "动画序列示例",
            style = MaterialTheme.typography.headlineMedium,
            modifier = Modifier.padding(bottom = 32.dp)
        )
        
        // 显示动画进度
        Text(
            text = "进度: ${String.format("%.2f", animatable.value)}",
            style = MaterialTheme.typography.titleLarge,
            modifier = Modifier.padding(bottom = 16.dp)
        )
        
        // 进度条
        LinearProgressIndicator(
            progress = animatable.value,
            modifier = Modifier
                .fillMaxWidth()
                .height(12.dp)
        )
        
        Spacer(modifier = Modifier.height(32.dp))
        
        // 动画对象
        Box(
            modifier = Modifier
                .size(200.dp)
                .padding(16.dp),
            contentAlignment = Alignment.Center
        ) {
            Box(
                modifier = Modifier
                    .size(150.dp * (0.5f + animatable.value * 0.5f))
                    .rotate(animatable.value * 360f)
                    .background(
                        color = lerp(
                            Color(0xFF6200EE),
                            Color(0xFF03DAC5),
                            animatable.value
                        ),
                        shape = RoundedCornerShape(animatable.value * 40)
                    ),
                contentAlignment = Alignment.Center
            ) {
                Text(
                    text = "${(animatable.value * 100).toInt()}%",
                    color = Color.White,
                    style = MaterialTheme.typography.headlineSmall,
                    fontWeight = FontWeight.Bold
                )
            }
        }
        
        Spacer(modifier = Modifier.height(32.dp))
        
        // 显示当前动画阶段
        Text(
            text = "当前阶段: ${
                when (currentStep) {
                    0 -> "准备开始"
                    1 -> "第一阶段：快速动画"
                    2 -> "第二阶段：弹性动画"
                    3 -> "第三阶段：关键帧动画"
                    4 -> "完成，准备重置"
                    else -> "未知"
                }
            }",
            style = MaterialTheme.typography.titleMedium,
            modifier = Modifier.padding(bottom = 16.dp)
        )
        
        // 动画阶段指示器
        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.SpaceEvenly
        ) {
            for (i in 1..totalSteps) {
                Box(
                    modifier = Modifier
                        .size(24.dp)
                        .background(
                            color = if (i <= currentStep) Color(0xFF6200EE) else Color.LightGray,
                            shape = CircleShape
                        ),
                    contentAlignment = Alignment.Center
                ) {
                    Text(
                        text = "$i",
                        color = Color.White,
                        fontWeight = FontWeight.Bold
                    )
                }
                
                // 连接线（除了最后一个点）
                if (i < totalSteps) {
                    Box(
                        modifier = Modifier
                            .width(30.dp)
                            .height(2.dp)
                            .background(
                                color = if (i < currentStep) Color(0xFF6200EE) else Color.LightGray
                            )
                    )
                }
            }
        }
        
        Spacer(modifier = Modifier.height(32.dp))
        
        // 启动按钮
        Button(
            onClick = { startAnimationSequence() },
            enabled = currentStep == 0,
            modifier = Modifier.width(200.dp)
        ) {
            Text("启动动画序列")
        }
    }
}
```

### 与手势结合的拖拽动画

```kotlin
@Composable
fun DraggableAnimatableExample() {
    // 创建两个Animatable实例，分别控制X和Y坐标
    val offsetX = remember { Animatable(0f) }
    val offsetY = remember { Animatable(0f) }
    
    // 协程作用域
    val scope = rememberCoroutineScope()
    
    // 屏幕尺寸
    val screenSize = LocalConfiguration.current.run {
        Size(screenWidthDp.dp.toPx(), screenHeightDp.dp.toPx())
    }
    
    // 设置边界约束
    LaunchedEffect(key1 = screenSize) {
        // 假设拖动对象大小为100dp
        val objectSize = 100.dp.toPx()
        
        offsetX.updateBounds(
            lowerBound = -screenSize.width / 2 + objectSize / 2,
            upperBound = screenSize.width / 2 - objectSize / 2
        )
        
        offsetY.updateBounds(
            lowerBound = -screenSize.height / 2 + objectSize / 2,
            upperBound = screenSize.height / 2 - objectSize / 2
        )
    }
    
    // 拖动状态
    val dragState = rememberDraggableState { delta ->
        scope.launch {
            // 更新X坐标
            offsetX.snapTo(offsetX.value + delta)
        }
    }
    
    // 垂直拖动状态
    val verticalDragState = rememberDraggableState { delta ->
        scope.launch {
            // 更新Y坐标
            offsetY.snapTo(offsetY.value + delta)
        }
    }
    
    Box(
        modifier = Modifier
            .fillMaxSize(),
        contentAlignment = Alignment.Center
    ) {
        // 拖动对象
        Box(
            modifier = Modifier
                .offset {
                    IntOffset(
                        offsetX.value.roundToInt(),
                        offsetY.value.roundToInt()
                    )
                }
                .size(100.dp)
                .background(
                    color = Color(0xFF6200EE),
                    shape = RoundedCornerShape(16.dp)
                )
                // 水平拖动
                .draggable(
                    state = dragState,
                    orientation = Orientation.Horizontal,
                    onDragStopped = { velocity ->
                        // 拖动停止时，根据速度添加衰减动画
                        scope.launch {
                            offsetX.animateDecay(
                                initialVelocity = velocity,
                                animationSpec = splineBasedDecay(density = LocalDensity.current)
                            )
                        }
                    }
                )
                // 垂直拖动
                .draggable(
                    state = verticalDragState,
                    orientation = Orientation.Vertical,
                    onDragStopped = { velocity ->
                        scope.launch {
                            offsetY.animateDecay(
                                initialVelocity = velocity,
                                animationSpec = splineBasedDecay(density = LocalDensity.current)
                            )
                        }
                    }
                ),
            contentAlignment = Alignment.Center
        ) {
            Text(
                text = "拖动我",
                color = Color.White,
                fontWeight = FontWeight.Bold
            )
        }
        
        // 重置按钮
        Button(
            onClick = {
                scope.launch {
                    // 同时动画两个值回到原点
                    launch { offsetX.animateTo(0f) }
                    launch { offsetY.animateTo(0f) }
                }
            },
            modifier = Modifier
                .align(Alignment.BottomCenter)
                .padding(bottom = 32.dp)
        ) {
            Text("重置位置")
        }
        
        // 坐标显示
        Text(
            text = "坐标: (${offsetX.value.toInt()}, ${offsetY.value.toInt()})",
            modifier = Modifier
                .align(Alignment.TopCenter)
                .padding(top = 32.dp),
            style = MaterialTheme.typography.titleMedium
        )
    }
}
```

### 复杂动画效果：弹性菜单

```kotlin
@Composable
fun ElasticMenuExample() {
    // 菜单项数量
    val itemCount = 5
    
    // 菜单展开状态
    var isExpanded by remember { mutableStateOf(false) }
    
    // 主按钮旋转动画
    val rotation = remember { Animatable(0f) }
    
    // 菜单项动画列表
    val itemAnimatables = remember {
        List(itemCount) { Animatable(0f) }
    }
    
    // 协程作用域
    val scope = rememberCoroutineScope()
    
    // 切换菜单状态
    fun toggleMenu() {
        isExpanded = !isExpanded
        
        scope.launch {
            // 主按钮旋转动画
            rotation.animateTo(
                targetValue = if (isExpanded) 45f else 0f,
                animationSpec = tween(300)
            )
            
            // 菜单项动画
            if (isExpanded) {
                // 展开菜单：依次显示每个菜单项
                itemAnimatables.forEachIndexed { index, animatable ->
                    launch {
                        delay(index * 50L) // 错开每个项的动画开始时间
                        animatable.animateTo(
                            targetValue = 1f,
                            animationSpec = spring(
                                dampingRatio = Spring.DampingRatioMediumBouncy,
                                stiffness = Spring.StiffnessLow
                            )
                        )
                    }
                }
            } else {
                // 收起菜单：依次隐藏每个菜单项（从最后一个开始）
                itemAnimatables.reversed().forEachIndexed { index, animatable ->
                    launch {
                        delay(index * 50L)
                        animatable.animateTo(
                            targetValue = 0f,
                            animationSpec = tween(300)
                        )
                    }
                }
            }
        }
    }
    
    // 菜单图标和颜色
    val menuIcons = listOf(
        Icons.Default.Favorite to Color(0xFFE91E63),
        Icons.Default.Star to Color(0xFFFFC107),
        Icons.Default.Share to Color(0xFF2196F3),
        Icons.Default.Settings to Color(0xFF4CAF50),
        Icons.Default.Person to Color(0xFF9C27B0)
    )
    
    Box(
        modifier = Modifier.fillMaxSize(),
        contentAlignment = Alignment.BottomEnd
    ) {
        // 菜单项
        menuIcons.forEachIndexed { index, (icon, color) ->
            val animatable = itemAnimatables[index]
            
            // 计算菜单项位置
            val offsetY = -80.dp * (index + 1) * animatable.value
            val scale = 0.8f + (0.2f * animatable.value)
            val alpha = animatable.value
            
            // 菜单项按钮
            FloatingActionButton(
                onClick = { /* 处理菜单项点击 */ },
                modifier = Modifier
                    .padding(16.dp)
                    .size(48.dp * scale)
                    .offset(y = offsetY)
                    .alpha(alpha)
                    .scale(scale),
                containerColor = color
            ) {
                Icon(
                    imageVector = icon,
                    contentDescription = "Menu Item ${index + 1}",
                    tint = Color.White
                )
            }
        }
        
        // 主菜单按钮
        FloatingActionButton(
            onClick = { toggleMenu() },
            modifier = Modifier
                .padding(16.dp)
                .size(56.dp),
            containerColor = Color(0xFF6200EE)
        ) {
            Icon(
                imageVector = Icons.Default.Add,
                contentDescription = "Toggle Menu",
                modifier = Modifier.rotate(rotation.value),
                tint = Color.White
            )
        }
    }
}
```

```kotlin
@Composable
fun BouncingBallExample() {
    // 创建垂直位置动画
    val ballY = remember { Animatable(0f) }
    
    // 协程作用域
    val scope = rememberCoroutineScope()
    
    // 屏幕高度
    val screenHeight = LocalConfiguration.current.screenHeightDp.dp
    val maxY = screenHeight - 100.dp // 减去球的大小和一些边距
    
    // 设置边界
    LaunchedEffect(key1 = maxY) {
        ballY.updateBounds(
            lowerBound = 0f,
            upperBound = maxY.value
        )
    }
    
    // 启动弹跳动画
    fun startBouncing() {
        scope.launch {
            // 初始下落
            ballY.animateTo(
                targetValue = maxY.value,
                animationSpec = tween(
                    durationMillis = 1000,
                    easing = FastOutLinearInEasing
                )
            )
            
            // 连续弹跳
            var bounceHeight = maxY.value * 0.7f
            var duration = 700
            
            repeat(5) {
                // 向上弹起
                ballY.animateTo(
                    targetValue = maxY.value - bounceHeight,
                    animationSpec = tween(
                        durationMillis = duration,
                        easing = LinearOutSlowInEasing
                    )
                )
                
                // 下落
                ballY.animateTo(
                    targetValue = maxY.value,
                    animationSpec = tween(
                        durationMillis = duration,
                        easing = FastOutLinearInEasing
                    )
                )
                
                // 每次弹跳高度和时间减少
                bounceHeight *= 0.6f
                duration = (duration * 0.8f).toInt()
            }
```

## 常见问题

### 1. Animatable和AnimateXxxAsState有什么区别？

**答**：Animatable和AnimateXxxAsState的主要区别在于：

- **控制方式**：
    - AnimateXxxAsState是声明式的，你只需指定目标值，动画会自动运行
    - Animatable是命令式的，你需要手动调用animateTo()等方法来启动动画

- **灵活性**：
    - AnimateXxxAsState适合简单的状态转换动画
    - Animatable提供更精细的控制，适合复杂动画序列和交互式动画

- **协程集成**：
    - AnimateXxxAsState在内部管理协程
    - Animatable需要在协程中使用，但这也使它能够与其他协程操作（如delay、launch等）结合

- **API丰富度**：
    - AnimateXxxAsState功能相对简单
    - Animatable提供更多API，如snapTo()、animateDecay()、stop()等

选择哪个取决于你的需求：如果需要简单的状态转换动画，使用AnimateXxxAsState；如果需要更精细的控制或复杂的动画序列，使用Animatable。

### 2. 如何处理Animatable动画过程中的异常？

**答**：Animatable动画可能会抛出以下异常：

1. **AnimationException**：当动画无法达到目标值时抛出，通常是因为目标值超出了边界约束。

2. **CancellationException**：当动画被取消时抛出，例如通过Job.cancel()或动画协程被取消。

处理这些异常的方法：

```kotlin
scope.launch {
    try {
        // 尝试执行动画
        animatable.animateTo(targetValue)
    } catch (e: AnimationException) {
        // 处理动画无法达到目标值的情况
        Log.e("Animation", "Animation could not reach target: ${e.message}")
    } catch (e: CancellationException) {
        // 处理动画被取消的情况
        Log.d("Animation", "Animation was cancelled")
        throw e  // 通常应该重新抛出CancellationException
    }
}
```

对于边界问题，最好的做法是使用updateBounds()方法预先设置合适的边界，而不是依赖于异常处理。

### 3. 如何同时控制多个Animatable并保持它们同步？

**答**：同时控制多个Animatable并保持同步有几种方法：

1. **并行启动**：使用协程的launch在同一个父协程中并行启动多个动画

```kotlin
scope.launch {
    // 并行启动多个动画
    launch { animatable1.animateTo(target1, spec) }
    launch { animatable2.animateTo(target2, spec) }
    launch { animatable3.animateTo(target3, spec) }
}
```

2. **使用相同的AnimationSpec**：确保所有动画使用完全相同的动画规格

3. **基于进度计算**：使用一个主Animatable，然后基于其进度计算其他值

```kotlin
// 主动画控制器
val progress = remember { Animatable(0f) }

// 在协程中启动主动画
LaunchedEffect(key1 = shouldAnimate) {
    if (shouldAnimate) {
        progress.animateTo(1f, animationSpec = tween(1000))
    }
}

// 基于主进度计算其他值
val color = lerp(startColor, endColor, progress.value)
val size = startSize + (endSize - startSize) * progress.value
val rotation = progress.value * 360f
```

4. **使用awaitAll**：如果需要等待所有动画完成后执行操作

```kotlin
scope.launch {
    val animations = listOf(
        async { animatable1.animateTo(target1) },
        async { animatable2.animateTo(target2) },
        async { animatable3.animateTo(target3) }
    )
    
    // 等待所有动画完成
    animations.awaitAll()
    
    // 所有动画完成后执行操作
    onAllAnimationsComplete()
}
```

### 4. Animatable的性能考虑有哪些？

**答**：使用Animatable时需要考虑以下性能因素：

1. **协程开销**：每个Animatable动画都在协程中运行，大量并发动画可能导致性能问题。

2. **重组频率**：Animatable的值变化会触发使用该值的组件重组，频繁的值变化可能导致过多重组。

3. **动画规格选择**：不同的AnimationSpec有不同的性能特性：
    - Tween通常性能较好，计算简单
    - Spring需要更复杂的计算，但提供更自然的动画效果
    - Keyframes可能需要更多的内存来存储关键帧

4. **边界检查**：每次值更新都会进行边界检查，如果不需要边界约束，可以不设置边界以减少检查开销。

5. **内存使用**：每个Animatable实例都会占用一定内存，大量Animatable可能导致内存压力。

优化建议：

- 对于简单的UI元素，优先使用AnimateXxxAsState
- 合理使用remember来缓存Animatable实例
- 当不再需要动画时，取消相关协程
- 考虑使用一个主Animatable控制多个值，而不是为每个属性创建单独的Animatable
- 使用visibilityThreshold参数设置合适的可见性阈值，避免不必要的微小动画更新
