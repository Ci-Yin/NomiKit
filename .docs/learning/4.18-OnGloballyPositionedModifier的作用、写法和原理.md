# 4.18 OnGloballyPositionedModifier 的作用、写法和原理

> "想知道你的组件在全局坐标系中的位置？OnGloballyPositionedModifier 就是你的'定位系统'，让你的 UI
> 组件再也不会迷路！" 📍

## 概念介绍

OnGloballyPositionedModifier 是 Jetpack Compose
中一个重要的布局修饰符，它能够帮助我们获取组件在全局坐标系（整个窗口或屏幕）中的精确位置信息。与其他定位相关的修饰符不同，它关注的是组件相对于整个应用窗口的绝对位置，而不仅仅是相对于父容器的位置。

当组件在屏幕上被放置或者其位置发生变化时，OnGloballyPositionedModifier
会触发回调，提供组件的详细位置信息，包括坐标、尺寸和边界等。这使得我们能够实现许多依赖于精确位置的高级
UI
效果，如自定义提示框、悬浮菜单、拖放功能等。

## 知识要点

- OnGloballyPositionedModifier 提供组件在全局坐标系中的位置信息
- 它通过 `onGloballyPositioned` 修饰符函数应用到组件上
- 回调函数提供 LayoutCoordinates 对象，包含丰富的位置和尺寸信息
- 可以获取组件的尺寸、位置、边界以及与其他组件的相对位置
- 当组件首次放置到屏幕上或位置/尺寸发生变化时会触发回调
- 与 OnPlacedModifier 不同，它专注于全局坐标系中的位置

## 基础代码示例

下面是一个简单的例子，展示如何使用 OnGloballyPositionedModifier 获取组件的位置信息：

```kotlin
@Composable
fun GlobalPositionExample() {
    // 用于存储位置信息的状态
    var boxPosition by remember { mutableStateOf(IntOffset.Zero) }
    var boxSize by remember { mutableStateOf(IntSize.Zero) }
    
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(16.dp)
    ) {
        // 显示位置信息
        Text(
            text = "Box Position: x=${boxPosition.x}, y=${boxPosition.y}",
            style = MaterialTheme.typography.bodyLarge
        )
        Text(
            text = "Box Size: width=${boxSize.width}, height=${boxSize.height}",
            style = MaterialTheme.typography.bodyLarge
        )
        
        // 使用onGloballyPositioned获取位置信息的Box
        Box(
            modifier = Modifier
                .size(100.dp)
                .background(
                    color = MaterialTheme.colorScheme.primary,
                    shape = RoundedCornerShape(8.dp)
                )
                // 应用onGloballyPositioned修饰符
                .onGloballyPositioned { coordinates ->
                    // 获取在全局坐标系中的位置
                    boxPosition = coordinates.positionInRoot().round()
                    // 获取组件尺寸
                    boxSize = coordinates.size
                }
        ) {
            Text(
                text = "Drag Me",
                color = Color.White,
                modifier = Modifier.align(Alignment.Center)
            )
        }
    }
}
```

## 进阶用法

### 1. 实现自定义悬浮提示框

OnGloballyPositionedModifier 非常适合实现自定义的悬浮提示框，它可以根据触发组件的位置自动调整提示框的位置：

```kotlin
@Composable
fun CustomTooltipExample() {
    // 控制提示框显示状态
    var showTooltip by remember { mutableStateOf(false) }
    // 存储触发组件的位置
    var buttonPosition by remember { mutableStateOf(Rect.Zero) }
    // 窗口尺寸
    var windowSize by remember { mutableStateOf(IntSize.Zero) }
    
    // 获取窗口尺寸
    BoxWithConstraints(
        modifier = Modifier
            .fillMaxSize()
            .onGloballyPositioned { coordinates ->
                windowSize = coordinates.size
            }
    ) {
        Box(modifier = Modifier.fillMaxSize()) {
            // 触发提示框的按钮
            Button(
                onClick = { showTooltip = !showTooltip },
                modifier = Modifier
                    .padding(16.dp)
                    .align(Alignment.Center)
                    .onGloballyPositioned { coordinates ->
                        // 记录按钮的全局位置
                        buttonPosition = coordinates.boundsInRoot()
                    }
            ) {
                Text(text = if (showTooltip) "隐藏提示" else "显示提示")
            }
            
            // 条件显示提示框
            if (showTooltip) {
                // 计算提示框的最佳位置
                val tooltipWidth = 200.dp
                val tooltipHeight = 100.dp
                
                // 转换为像素
                val tooltipWidthPx = with(LocalDensity.current) { tooltipWidth.toPx() }
                val tooltipHeightPx = with(LocalDensity.current) { tooltipHeight.toPx() }
                
                // 计算提示框位置（优先显示在按钮上方，空间不足则显示在下方）
                val tooltipX = buttonPosition.center.x - tooltipWidthPx / 2
                val tooltipY = if (buttonPosition.top > tooltipHeightPx + 20) {
                    // 上方有足够空间
                    buttonPosition.top - tooltipHeightPx - 10
                } else {
                    // 显示在下方
                    buttonPosition.bottom + 10
                }
                
                // 确保提示框不超出屏幕边界
                val adjustedX = tooltipX.coerceIn(
                    10f,
                    windowSize.width - tooltipWidthPx - 10
                )
                
                // 绘制提示框
                Box(
                    modifier = Modifier
                        .width(tooltipWidth)
                        .height(tooltipHeight)
                        .offset {
                            IntOffset(
                                adjustedX.roundToInt(),
                                tooltipY.roundToInt()
                            )
                        }
                        .background(
                            color = MaterialTheme.colorScheme.surfaceVariant,
                            shape = RoundedCornerShape(8.dp)
                        )
                        .border(
                            width = 1.dp,
                            color = MaterialTheme.colorScheme.outline,
                            shape = RoundedCornerShape(8.dp)
                        )
                        .padding(12.dp)
                ) {
                    Text(
                        text = "这是一个根据按钮位置自动调整的提示框。它会智能地选择显示在按钮的上方或下方。",
                        style = MaterialTheme.typography.bodyMedium
                    )
                }
            }
        }
    }
}
```

### 2. 实现拖放功能

OnGloballyPositionedModifier 结合手势检测可以实现强大的拖放功能：

```kotlin
@Composable
fun DragAndDropExample() {
    // 拖动项的位置
    var dragPosition by remember { mutableStateOf(Offset.Zero) }
    // 是否正在拖动
    var isDragging by remember { mutableStateOf(false) }
    // 拖动项的初始位置
    var dragOffset by remember { mutableStateOf(Offset.Zero) }
    // 放置区域的位置
    var dropZoneRect by remember { mutableStateOf(Rect.Zero) }
    // 是否已放置到目标区域
    var isDropped by remember { mutableStateOf(false) }
    
    // 拖动手势检测
    val dragGesture = remember {
        PointerInputModifier().pointerInput(Unit) {
            detectDragGestures(
                onDragStart = { offset ->
                    isDragging = true
                    dragOffset = offset
                },
                onDrag = { change, dragAmount ->
                    change.consume()
                    dragPosition = dragPosition + dragAmount
                    
                    // 检查是否在放置区域内
                    val dragRect = Rect(
                        dragPosition.x,
                        dragPosition.y,
                        dragPosition.x + 100f,
                        dragPosition.y + 100f
                    )
                    isDropped = dropZoneRect.overlaps(dragRect)
                },
                onDragEnd = {
                    isDragging = false
                }
            )
        }
    }
    
    Box(modifier = Modifier.fillMaxSize()) {
        // 放置区域
        Box(
            modifier = Modifier
                .size(200.dp)
                .align(Alignment.BottomEnd)
                .padding(16.dp)
                .background(
                    color = if (isDropped) 
                        MaterialTheme.colorScheme.primaryContainer 
                    else 
                        MaterialTheme.colorScheme.surfaceVariant,
                    shape = RoundedCornerShape(8.dp)
                )
                .border(
                    width = 2.dp,
                    color = MaterialTheme.colorScheme.outline,
                    shape = RoundedCornerShape(8.dp)
                )
                .onGloballyPositioned { coordinates ->
                    // 记录放置区域的全局位置
                    dropZoneRect = coordinates.boundsInRoot()
                }
        ) {
            Text(
                text = "放置区域",
                modifier = Modifier.align(Alignment.Center),
                style = MaterialTheme.typography.titleMedium
            )
        }
        
        // 可拖动的项目
        if (!isDropped) {
            Box(
                modifier = Modifier
                    .offset { IntOffset(dragPosition.x.roundToInt(), dragPosition.y.roundToInt()) }
                    .size(100.dp)
                    .background(
                        color = MaterialTheme.colorScheme.primary,
                        shape = RoundedCornerShape(8.dp)
                    )
                    .then(dragGesture)
                    .onGloballyPositioned { coordinates ->
                        // 如果是首次放置且未开始拖动，初始化位置
                        if (dragPosition == Offset.Zero && !isDragging) {
                            dragPosition = coordinates.positionInRoot()
                        }
                    }
            ) {
                Text(
                    text = "拖动我",
                    color = Color.White,
                    modifier = Modifier.align(Alignment.Center)
                )
            }
        } else {
            // 已放置到目标区域
            Box(
                modifier = Modifier
                    .align(Alignment.BottomEnd)
                    .padding(16.dp)
                    .padding(50.dp)
                    .size(100.dp)
                    .background(
                        color = MaterialTheme.colorScheme.primary,
                        shape = RoundedCornerShape(8.dp)
                    )
            ) {
                Text(
                    text = "已放置",
                    color = Color.White,
                    modifier = Modifier.align(Alignment.Center)
                )
            }
        }
    }
}
```

### 3. 实现自定义菜单

使用 OnGloballyPositionedModifier 可以创建根据触发组件位置显示的自定义菜单：

```kotlin
@Composable
fun CustomContextMenu() {
    // 菜单显示状态
    var showMenu by remember { mutableStateOf(false) }
    // 触发区域位置
    var triggerPosition by remember { mutableStateOf(Rect.Zero) }
    // 窗口尺寸
    var windowSize by remember { mutableStateOf(IntSize.Zero) }
    
    Box(
        modifier = Modifier
            .fillMaxSize()
            .onGloballyPositioned { coordinates ->
                windowSize = coordinates.size
            }
    ) {
        // 长按触发菜单的区域
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(200.dp)
                .padding(16.dp)
                .background(
                    color = MaterialTheme.colorScheme.surfaceVariant,
                    shape = RoundedCornerShape(8.dp)
                )
                .onGloballyPositioned { coordinates ->
                    triggerPosition = coordinates.boundsInRoot()
                }
                .pointerInput(Unit) {
                    detectTapGestures(
                        onLongPress = {
                            showMenu = true
                        }
                    )
                }
        ) {
            Text(
                text = "长按此区域显示自定义菜单",
                modifier = Modifier.align(Alignment.Center),
                style = MaterialTheme.typography.titleMedium
            )
        }
        
        // 自定义菜单
        if (showMenu) {
            // 计算菜单位置
            val menuWidth = 180.dp
            val menuHeight = 200.dp
            
            val menuWidthPx = with(LocalDensity.current) { menuWidth.toPx() }
            val menuHeightPx = with(LocalDensity.current) { menuHeight.toPx() }
            
            // 默认显示在触发区域右下角
            var menuX = triggerPosition.right - menuWidthPx / 2
            var menuY = triggerPosition.bottom
            
            // 确保菜单不超出屏幕边界
            if (menuX + menuWidthPx > windowSize.width) {
                menuX = windowSize.width - menuWidthPx - 10
            }
            if (menuX < 10) {
                menuX = 10f
            }
            if (menuY + menuHeightPx > windowSize.height) {
                menuY = triggerPosition.top - menuHeightPx
            }
            
            // 绘制菜单
            Card(
                modifier = Modifier
                    .offset {
                        IntOffset(
                            menuX.roundToInt(),
                            menuY.roundToInt()
                        )
                    }
                    .width(menuWidth)
                    .height(menuHeight)
                    .clickable(enabled = false) { /* 防止点击穿透 */ },
                shape = RoundedCornerShape(8.dp),
                elevation = CardDefaults.cardElevation(defaultElevation = 6.dp)
            ) {
                Column(
                    modifier = Modifier.fillMaxSize()
                ) {
                    // 菜单项
                    MenuItem("复制", Icons.Default.ContentCopy) {
                        showMenu = false
                    }
                    MenuItem("粘贴", Icons.Default.ContentPaste) {
                        showMenu = false
                    }
                    MenuItem("剪切", Icons.Default.ContentCut) {
                        showMenu = false
                    }
                    MenuItem("删除", Icons.Default.Delete) {
                        showMenu = false
                    }
                    MenuItem("取消", Icons.Default.Close) {
                        showMenu = false
                    }
                }
            }
            
            // 点击其他区域关闭菜单
            Box(
                modifier = Modifier
                    .fillMaxSize()
                    .clickable(
                        interactionSource = remember { MutableInteractionSource() },
                        indication = null
                    ) {
                        showMenu = false
                    }
            )
        }
    }
}

@Composable
private fun MenuItem(
    text: String,
    icon: ImageVector,
    onClick: () -> Unit
) {
    Row(
        modifier = Modifier
            .fillMaxWidth()
            .clickable { onClick() }
            .padding(horizontal = 16.dp, vertical = 12.dp),
        verticalAlignment = Alignment.CenterVertically
    ) {
        Icon(
            imageVector = icon,
            contentDescription = text,
            tint = MaterialTheme.colorScheme.onSurface
        )
        Spacer(modifier = Modifier.width(16.dp))
        Text(
            text = text,
            style = MaterialTheme.typography.bodyLarge
        )
    }
}
```

## 常见问题

### 1. OnGloballyPositionedModifier 和 OnPlacedModifier 有什么区别？

**回答**：两者都用于获取组件的位置信息，但有几个关键区别：

- `OnGloballyPositionedModifier` 提供组件在全局坐标系（整个窗口）中的位置
- `OnPlacedModifier` 更关注组件在其父容器中的相对位置
- `OnGloballyPositionedModifier` 通过 `onGloballyPositioned` 修饰符应用，而 `OnPlacedModifier` 通过
  `onPlaced` 修饰符应用
- `OnGloballyPositionedModifier` 在任何位置变化时都会触发，而 `OnPlacedModifier` 主要在布局阶段触发
- `OnGloballyPositionedModifier` 提供的 LayoutCoordinates 包含更多全局位置相关的方法

### 2. 为什么我获取的位置信息不准确或者延迟更新？

**回答**：可能的原因包括：

- 组件尚未完成布局过程，位置信息还未最终确定
- 在动画过程中，位置信息可能会不断变化
- 嵌套的滚动容器可能影响位置计算
- 组件的父容器位置发生变化，但回调尚未触发

解决方法：

- 确保在适当的生命周期阶段读取位置信息
- 考虑使用 `LaunchedEffect` 延迟读取位置信息
- 对于动画场景，考虑在动画完成后再读取最终位置

### 3. 如何获取组件相对于另一个组件的位置？

**回答**：可以通过以下步骤实现：

1. 使用 `onGloballyPositioned` 分别获取两个组件的全局位置
2. 使用 `LayoutCoordinates.positionInRoot()` 或 `LayoutCoordinates.boundsInRoot()` 获取全局坐标
3. 计算两个位置的差值，得到相对位置

示例代码：

```kotlin
// 组件A的位置
var componentAPosition by remember { mutableStateOf(Offset.Zero) }
// 组件B的位置
var componentBPosition by remember { mutableStateOf(Offset.Zero) }

// 组件A
Box(
    modifier = Modifier
        .onGloballyPositioned { coordinates ->
            componentAPosition = coordinates.positionInRoot()
        }
)

// 组件B
Box(
    modifier = Modifier
        .onGloballyPositioned { coordinates ->
            componentBPosition = coordinates.positionInRoot()
        }
)

// 计算B相对于A的位置
val relativePosition = componentBPosition - componentAPosition
```

### 4. 在多窗口或分屏模式下，OnGloballyPositionedModifier 的坐标系是什么？

**回答**：在多窗口或分屏模式下：

- `OnGloballyPositionedModifier` 提供的坐标是相对于当前应用窗口的，而不是整个屏幕
- `positionInRoot()` 返回的是相对于应用根视图的位置
- 如果需要获取相对于屏幕的绝对位置，需要结合 Android 的 WindowManager 或其他系统 API
- 在不同的窗口大小或方向下，坐标系可能会发生变化，需要适当处理
