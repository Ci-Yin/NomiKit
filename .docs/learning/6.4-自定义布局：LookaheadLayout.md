# 6.4 自定义布局：LookaheadLayout()

> "在 Compose 的世界里，LookaheadLayout 就像是一位'未来预言家'
> ，它能够提前预知组件将要变成的样子，让动画过渡更加丝滑！这简直就是布局界的'先知先觉'
> ，让用户体验如丝般顺滑，告别生硬的跳变！"
> 🔮

## 概念介绍

LookaheadLayout 是 Jetpack Compose 中一个强大的布局 API，它提供了"预测"
能力，可以在布局变化发生之前就知道组件将要变成的样子。这种能力使得
LookaheadLayout 能够实现更平滑的动画和过渡效果，特别是在组件尺寸和位置发生变化时。

在标准的布局流程中，当组件的尺寸或位置发生变化时，用户会看到一个突然的"跳变"，或者需要手动编写复杂的动画代码来实现平滑过渡。而
LookaheadLayout 通过提前计算组件的"目标状态"，可以自动为这些变化创建平滑的动画，大大简化了开发工作，同时提升了用户体验。

LookaheadLayout 的工作原理是在正常的布局过程之外，额外执行一次"预测性"
的布局计算。这个预测性计算会考虑即将发生的状态变化，从而得知组件在变化后的尺寸和位置。有了这些信息，LookaheadLayout
就可以创建从当前状态到目标状态的平滑动画，而不是直接跳变。

## 知识要点

- LookaheadLayout 的基本概念和使用方法
- "预测"布局的工作原理和生命周期
- LookaheadScope 的使用和功能
- 使用 `rememberLookaheadMeasureScope` 获取测量作用域
- 使用 `rememberLookaheadLayoutState` 管理布局状态
- 动画参数的配置和自定义
- 处理多个组件的同时动画
- 性能考虑：预测计算的成本和优化技巧

- 常见应用场景：列表重排序、内容展开/折叠、布局切换等
- 避免常见陷阱：过度动画、动画冲突等

## 基础代码示例

下面是一个简单的例子，展示如何使用 LookaheadLayout 创建一个平滑展开/折叠的卡片组件：

```kotlin
@Composable
fun ExpandableCard(
    expanded: Boolean,
    onExpandChange: (Boolean) -> Unit,
    modifier: Modifier = Modifier,
    content: @Composable () -> Unit
) {
    // 创建 LookaheadLayout 状态
    val lookaheadLayoutState = rememberLookaheadLayoutState()

    // 创建展开/折叠的动画规格
    val animationSpec = spring<IntOffset>(
        dampingRatio = 0.8f,
        stiffness = Spring.StiffnessLow
    )

    // 使用 LookaheadLayout 包装内容
    LookaheadLayout(
        modifier = modifier
            .clickable { onExpandChange(!expanded) }
            .background(
                color = MaterialTheme.colorScheme.surfaceVariant,
                shape = RoundedCornerShape(16.dp)
            )
            .padding(16.dp),
        lookaheadLayoutState = lookaheadLayoutState,
        content = {
            // 根据展开状态显示不同内容
            if (expanded) {
                // 展开状态显示完整内容
                Column {
                    Text(
                        text = "展开状态",
                        style = MaterialTheme.typography.titleLarge,
                        color = MaterialTheme.colorScheme.onSurfaceVariant
                    )

                    Spacer(modifier = Modifier.height(8.dp))

                    content()
                }
            } else {
                // 折叠状态只显示标题
                Text(
                    text = "折叠状态",
                    style = MaterialTheme.typography.titleLarge,
                    color = MaterialTheme.colorScheme.onSurfaceVariant
                )
            }
        },
        measurePolicy = { measurables, constraints ->
            // 测量所有子组件
            val placeables = measurables.map { measurable ->
                measurable.measure(constraints)
            }

            // 计算布局的尺寸
            val width = placeables.maxOf { it.width }
            val height = placeables.maxOf { it.height }

            // 返回布局的尺寸和放置策略
            layout(width, height) {
                // 放置所有子组件
                placeables.forEach { placeable ->
                    placeable.place(0, 0)
                }
            }
        },
        // 配置动画
        animatePlacement = { lookaheadSize, layoutCoordinates, transition ->
            // 创建位置动画
            transition.animateOffset(
                transitionSpec = { animationSpec },
                targetValueByState = { lookaheadSize.positionInRoot },
                label = "position"
            )
        }
    )
}
```

### 1. 创建平滑的列表重排序动画

下面是一个使用 LookaheadLayout 实现的列表重排序动画，当列表项的顺序发生变化时，会自动创建平滑的动画：

```kotlin
@Composable
fun AnimatedReorderList(
    items: List<String>,
    onItemClick: (String) -> Unit,
    modifier: Modifier = Modifier
) {
    // 创建 LookaheadLayout 状态
    val lookaheadLayoutState = rememberLookaheadLayoutState()

    // 创建重排序动画规格
    val animationSpec = spring<IntOffset>(
        dampingRatio = 0.7f,
        stiffness = Spring.StiffnessLow
    )

    // 使用 LookaheadLayout 包装列表
    LookaheadLayout(
        modifier = modifier,
        lookaheadLayoutState = lookaheadLayoutState,
        content = {
            Column {
                items.forEach { item ->
                    // 为每个列表项创建一个唯一的 key
                    key(item) {
                        ListItem(
                            text = item,
                            onClick = { onItemClick(item) }
                        )
                    }
                }
            }
        },
        measurePolicy = { measurables, constraints ->
            // 测量所有子组件
            val placeables = measurables.map { measurable ->
                measurable.measure(constraints)
            }

            // 计算布局的尺寸
            val width = placeables.maxOfOrNull { it.width } ?: 0
            val height = placeables.sumOf { it.height }

            // 返回布局的尺寸和放置策略
            layout(width, height) {
                // 放置所有子组件
                var y = 0
                placeables.forEach { placeable ->
                    placeable.place(0, y)
                    y += placeable.height
                }
            }
        },
        // 配置动画
        animatePlacement = { lookaheadSize, layoutCoordinates, transition ->
            // 创建位置动画
            transition.animateOffset(
                transitionSpec = { animationSpec },
                targetValueByState = { lookaheadSize.positionInRoot },
                label = "position"
            )
        }
    )
}
```

### 2. 实现平滑的布局切换动画

下面是一个使用 LookaheadLayout 实现的布局切换动画，当布局模式从网格切换到列表（或反之）时，会自动创建平滑的动画：

```kotlin
@Composable
fun AnimatedLayoutSwitch(
    isGridMode: Boolean,
    items: List<Item>,
    modifier: Modifier = Modifier
) {
    // 创建 LookaheadLayout 状态
    val lookaheadLayoutState = rememberLookaheadLayoutState()

    // 创建布局切换动画规格
    val animationSpec = spring<IntOffset>(
        dampingRatio = 0.8f,
        stiffness = Spring.StiffnessLow
    )

    // 使用 LookaheadLayout 包装内容
    LookaheadLayout(
        modifier = modifier,
        lookaheadLayoutState = lookaheadLayoutState,
        content = {
            if (isGridMode) {
                // 网格布局
                LazyVerticalGrid(
                    columns = GridCells.Fixed(2),
                    contentPadding = PaddingValues(8.dp),
                    horizontalArrangement = Arrangement.spacedBy(8.dp),
                    verticalArrangement = Arrangement.spacedBy(8.dp)
                ) {
                    items(items) { item ->
                        // 为每个项目创建一个唯一的 key
                        key(item.id) {
                            GridItem(item)
                        }
                    }
                }
            } else {
                // 列表布局
                LazyColumn(
                    contentPadding = PaddingValues(8.dp),
                    verticalArrangement = Arrangement.spacedBy(8.dp)
                ) {
                    items(items) { item ->
                        // 为每个项目创建一个唯一的 key
                        key(item.id) {
                            ListItem(item)
                        }
                    }
                }
            }
        },
        measurePolicy = { measurables, constraints ->
            // 测量所有子组件
            val placeables = measurables.map { measurable ->
                measurable.measure(constraints)
            }

            // 计算布局的尺寸
            val width = placeables.maxOfOrNull { it.width } ?: constraints.minWidth
            val height = placeables.maxOfOrNull { it.height } ?: constraints.minHeight

            // 返回布局的尺寸和放置策略
            layout(width, height) {
                // 放置所有子组件
                placeables.forEach { placeable ->
                    placeable.place(0, 0)
                }
            }
        },
        // 配置动画
        animatePlacement = { lookaheadSize, layoutCoordinates, transition ->
            // 创建位置和尺寸动画
            transition.animateOffset(
                transitionSpec = { animationSpec },
                targetValueByState = { lookaheadSize.positionInRoot },
                label = "position"
            )

            transition.animateSize(
                transitionSpec = { 
                    spring(
                        dampingRatio = 0.8f,
                        stiffness = Spring.StiffnessLow
                    )
                },
                targetValueByState = { lookaheadSize.size },
                label = "size"
            )
        }
    )
}
```

### 3. 创建自适应的内容过渡动画

下面是一个使用 LookaheadLayout 实现的内容过渡动画，当内容从一种状态切换到另一种状态时，会自动创建平滑的动画：

```kotlin
@Composable
fun AnimatedContentTransition(
    currentPage: Int,
    pageCount: Int,
    onPageChange: (Int) -> Unit,
    modifier: Modifier = Modifier
) {
    // 创建 LookaheadLayout 状态
    val lookaheadLayoutState = rememberLookaheadLayoutState()

    // 创建页面切换动画规格
    val animationSpec = spring<IntOffset>(
        dampingRatio = 0.8f,
        stiffness = Spring.StiffnessLow
    )

    Column(
        modifier = modifier
    ) {
        // 页面指示器
        Row(
            modifier = Modifier
                .fillMaxWidth()
                .padding(bottom = 16.dp),
            horizontalArrangement = Arrangement.Center
        ) {
            repeat(pageCount) { index ->
                Box(
                    modifier = Modifier
                        .padding(horizontal = 4.dp)
                        .size(12.dp)
                        .background(
                            color = if (index == currentPage) 
                                MaterialTheme.colorScheme.primary 
                            else 
                                MaterialTheme.colorScheme.surfaceVariant,
                            shape = CircleShape
                        )
                        .clickable { onPageChange(index) }
                )
            }
        }

        // 使用 LookaheadLayout 包装内容
        LookaheadLayout(
            modifier = Modifier
                .fillMaxWidth()
                .weight(1f)
                .background(
                    color = MaterialTheme.colorScheme.surface,
                    shape = RoundedCornerShape(16.dp)
                )
                .padding(16.dp),
            lookaheadLayoutState = lookaheadLayoutState,
            content = {
                // 为每个页面创建一个唯一的 key
                key(currentPage) {
                    when (currentPage) {
                        0 -> Page1()
                        1 -> Page2()
                        2 -> Page3()
                        else -> Page1()
                    }
                }
            },
            measurePolicy = { measurables, constraints ->
                // 测量所有子组件
                val placeables = measurables.map { measurable ->
                    measurable.measure(constraints)
                }

                // 计算布局的尺寸
                val width = placeables.maxOfOrNull { it.width } ?: constraints.minWidth
                val height = placeables.maxOfOrNull { it.height } ?: constraints.minHeight

                // 返回布局的尺寸和放置策略
                layout(width, height) {
                    // 放置所有子组件
                    placeables.forEach { placeable ->
                        placeable.place(0, 0)
                    }
                }
            },
            // 配置动画
            animatePlacement = { lookaheadSize, layoutCoordinates, transition ->
                // 创建位置和尺寸动画
                transition.animateOffset(
                    transitionSpec = { animationSpec },
                    targetValueByState = { lookaheadSize.positionInRoot },
                    label = "position"
                )

                transition.animateSize(
                    transitionSpec = { 
                        spring(
                            dampingRatio = 0.8f,
                            stiffness = Spring.StiffnessLow
                        )
                    },
                    targetValueByState = { lookaheadSize.size },
                    label = "size"
                )
            }
        )

        // 导航按钮
        Row(
            modifier = Modifier
                .fillMaxWidth()
                .padding(top = 16.dp),
            horizontalArrangement = Arrangement.SpaceBetween
        ) {
            Button(
                onClick = { onPageChange((currentPage - 1).coerceAtLeast(0)) },
                enabled = currentPage > 0
            ) {
                Text("上一页")
            }

            Button(
                onClick = { onPageChange((currentPage + 1).coerceAtMost(pageCount - 1)) },
                enabled = currentPage < pageCount - 1
            ) {
                Text("下一页")
            }
        }
    }
}
```

## 常见问题

### 1. LookaheadLayout 和普通 Layout 有什么区别？

**回答**：LookaheadLayout 和普通 Layout 的主要区别在于：

- **预测能力**：
    - 普通 Layout 只能处理当前状态的布局
    - LookaheadLayout 可以"预测"状态变化后的布局，从而创建平滑的过渡动画

- **使用场景**：
    - 普通 Layout 适用于静态布局或不需要平滑过渡的场景
    - LookaheadLayout 适用于需要平滑动画过渡的布局变化场景，如列表重排序、内容展开/折叠等

- **性能考虑**：
    - 普通 Layout 性能开销较小，只需要一次布局计算
    - LookaheadLayout 需要额外的预测性布局计算，性能开销较大

- **动画能力**：
    - 普通 Layout 需要手动编写动画代码来实现平滑过渡
    - LookaheadLayout 可以自动为布局变化创建平滑的动画

选择指南：如果需要在布局变化时创建平滑的动画过渡，应该使用 LookaheadLayout；如果不需要动画或者动画很简单，优先使用普通
Layout。

### 2. 如何优化 LookaheadLayout 的性能？

**回答**：优化 LookaheadLayout 性能的几种方法：

1. **限制预测范围**：

```kotlin
// 只对特定的子组件应用预测

    // ...
    content = {
        // 不需要预测的组件
        StaticContent()

        // 需要预测的组件
        LookaheadScope {
            AnimatedContent()
        }
    }
)
```

2. **使用适当的动画规格**：

```kotlin
// 使用性能更好的动画规格
val animationSpec = tween<IntOffset>(
    durationMillis = 300,
    easing = FastOutSlowInEasing
)

// 避免使用计算密集型的动画规格
// 不推荐：val animationSpec = spring<IntOffset>(dampingRatio = 0.5f, stiffness = 50f)
```

3. **避免不必要的重组**：

```kotlin
// 使用 remember 缓存计算结果
val cachedResult = remember(key1, key2) {
    // 复杂计算
}

// 在 LookaheadLayout 中使用缓存结果

    // ...

    // 使用 cachedResult
}
```

4. **使用 key 优化重组**：

```kotlin

items.forEach { item ->
    key(item.id) {
        ItemContent(item)
    }
}
```

5. **限制动画的复杂性**：

```kotlin
// 只动画必要的属性
animatePlacement = { lookaheadSize, layoutCoordinates, transition ->
    // 只动画位置，不动画尺寸

    // 不要同时动画太多属性
```

### 3. 如何处理 LookaheadLayout 中的动画冲突？

**回答**：处理 LookaheadLayout 动画冲突的几种方法：

1. **使用不同的动画作用域**：

```kotlin
// 为不同的动画使用不同的作用域
val positionTransition = transition.createChildTransition("position")
val sizeTransition = transition.createChildTransition("size")

// 使用不同的作用域应用动画
positionTransition.animateOffset(
    transitionSpec = { positionAnimationSpec },
    targetValueByState = { lookaheadSize.positionInRoot },
    label = "position"
)

sizeTransition.animateSize(
    transitionSpec = { sizeAnimationSpec },
    targetValueByState = { lookaheadSize.size },
    label = "size"
)
```

2. **设置动画优先级**：

```kotlin
// 设置动画优先级
animatePlacement = { lookaheadSize, layoutCoordinates, transition ->
    // 高优先级动画
    transition.animateOffset(
        transitionSpec = { 
            spring(
                dampingRatio = 0.8f,
                stiffness = Spring.StiffnessHigh // 高刚度，更快完成
            )
        },
        targetValueByState = { lookaheadSize.positionInRoot },
        label = "position"
    )

    // 低优先级动画
    transition.animateSize(
        transitionSpec = { 
            spring(
                dampingRatio = 0.8f,
                stiffness = Spring.StiffnessLow // 低刚度，更慢完成
            )
        },
        targetValueByState = { lookaheadSize.size },
        label = "size"
    )
}
```

3. **使用条件动画**：

```kotlin
// 根据条件应用不同的动画
animatePlacement = { lookaheadSize, layoutCoordinates, transition ->
    if (shouldAnimatePosition) {
        transition.animateOffset(
            transitionSpec = { animationSpec },
            targetValueByState = { lookaheadSize.positionInRoot },
            label = "position"
        )
    } else {
        // 不动画位置，直接设置
        layoutCoordinates.position = lookaheadSize.positionInRoot
    }

    if (shouldAnimateSize) {
        transition.animateSize(
            transitionSpec = { animationSpec },
            targetValueByState = { lookaheadSize.size },
            label = "size"
        )
    } else {
        // 不动画尺寸，直接设置
        layoutCoordinates.size = lookaheadSize.size
    }
}
```

4. **使用动画完成回调**：

```kotlin
// 使用动画完成回调处理冲突
val positionAnimation = transition.animateOffset(
    transitionSpec = { animationSpec },
    targetValueByState = { lookaheadSize.positionInRoot },
    label = "position"
)

// 在位置动画完成后开始尺寸动画
LaunchedEffect(positionAnimation.isRunning) {
    if (!positionAnimation.isRunning) {
        // 位置动画完成，开始尺寸动画
        startSizeAnimation()
    }
}
```

4. **创建自定义动画效果**：

```kotlin
// 创建自定义动画效果
animatePlacement = { lookaheadSize, layoutCoordinates, transition ->
    // 计算动画路径
    val startPosition = layoutCoordinates.positionInRoot
    val endPosition = lookaheadSize.positionInRoot

    // 创建贝塞尔曲线路径
    val path = Path().apply {
        moveTo(startPosition.x.toFloat(), startPosition.y.toFloat())

        // 控制点
        val controlX = (startPosition.x + endPosition.x) / 2f
        val controlY = startPosition.y - 100f // 向上弯曲

        quadraticBezierTo(
            controlX,
            controlY,
            endPosition.x.toFloat(),
            endPosition.y.toFloat()
        )
    }

    // 动画进度
    val progress = transition.animateFloat(
        transitionSpec = { 
            tween(
                durationMillis = 500,
                easing = FastOutSlowInEasing
            )
        },
        targetValueByState = { 1f },
        initialValue = 0f,
        label = "progress"
    )

    // 在动画更新时应用路径位置
    LaunchedEffect(progress.value) {
        val pathMeasure = android.graphics.PathMeasure(path.asAndroidPath(), false)
        val pos = FloatArray(2)

        // 根据进度获取路径上的位置
        pathMeasure.getPosTan(pathMeasure.length * progress.value, pos, null)

        // 应用位置
        layoutCoordinates.position = IntOffset(pos[0].toInt(), pos[1].toInt())
    }
}
```
