## 概念介绍

在 Jetpack Compose 中，我们已经学习了各种高级触摸 API，如 `clickable`、`draggable`、`detectDragGestures`
和
`detectTransformGestures` 等。这些 API
为我们提供了便捷的方式来处理常见的触摸交互。但在某些情况下，这些预定义的手势检测器可能无法满足我们的特殊需求，或者我们可能需要创建完全自定义的触摸交互体验。

这就是为什么 Compose 提供了最底层的触摸事件处理机制，允许开发者完全自定义触摸算法。通过直接访问原始的触摸事件流，我们可以构建任何想象得到的触摸交互模式，无论多么复杂或特殊。

在最底层，Compose 的触摸系统基于一个事件传递模型，触摸事件从根组件向下传递到叶子组件，然后再从叶子组件向上冒泡。在这个过程中，每个组件都有机会拦截、处理或传递这些事件。通过
`pointerInput` 修饰符和 `awaitPointerEventScope`，我们可以直接访问这些原始事件，并实现完全自定义的触摸处理逻辑。

## 基础代码示例

下面是一个基础示例，展示如何使用最底层的触摸 API 实现自定义触摸处理：

```kotlin
@Composable
fun RawTouchHandlingExample() {
    // 触摸状态
    var touchState by remember { mutableStateOf<String>("未触摸") }
    var touchPosition by remember { mutableStateOf(Offset.Zero) }
    var touchPressure by remember { mutableStateOf(0f) }
    var touchId by remember { mutableStateOf(-1) }
    
    // 活跃的触摸点集合
    val activePointers = remember { mutableStateListOf<PointerId>() }
    
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(Color.LightGray)
            // 添加原始触摸处理
            .pointerInput(Unit) {
                // 进入触摸事件等待循环
                awaitPointerEventScope {
                    while (true) {
                        // 等待下一个触摸事件
                        val event = awaitPointerEvent()
                        
                        // 处理所有触摸点的变化
                        event.changes.forEach { change ->
                            // 获取触摸点信息
                            val id = change.id.value
                            val position = change.position
                            val pressure = change.pressure
                            
                            // 更新状态
                            touchId = id
                            touchPosition = position
                            touchPressure = pressure
                            
                            // 根据触摸状态更新
                            when {
                                // 触摸点按下
                                change.pressed && !change.previousPressed -> {
                                    touchState = "按下"
                                    activePointers.add(change.id)
                                }
                                // 触摸点移动
                                change.pressed && change.positionChanged() -> {
                                    touchState = "移动"
                                }
                                // 触摸点抬起
                                !change.pressed && change.previousPressed -> {
                                    touchState = "抬起"
                                    activePointers.remove(change.id)
                                }
                            }
                            
                            // 消费事件（可选）
                            // 如果消费了位置变化，其他组件将不会收到此变化
                            if (change.positionChanged()) {
                                change.consume()
                            }
                        }
                    }
                }
            },
        contentAlignment = Alignment.Center
    ) {
        // 显示触摸信息
        Column(
            horizontalAlignment = Alignment.CenterHorizontally,
            verticalArrangement = Arrangement.Center
        ) {
            Text(
                text = "触摸状态: $touchState",
                fontSize = 20.sp,
                fontWeight = FontWeight.Bold
            )
            Spacer(modifier = Modifier.height(8.dp))
            Text(
                text = "触摸点 ID: $touchId",
                fontSize = 16.sp
            )
            Spacer(modifier = Modifier.height(8.dp))
            Text(
                text = "位置: (${touchPosition.x.toInt()}, ${touchPosition.y.toInt()})",
                fontSize = 16.sp
            )
            Spacer(modifier = Modifier.height(8.dp))
            Text(
                text = "压力: ${String.format("%.2f", touchPressure)}",
                fontSize = 16.sp
            )
            Spacer(modifier = Modifier.height(8.dp))
            Text(
                text = "活跃触摸点数: ${activePointers.size}",
                fontSize = 16.sp
            )
        }
        
        // 在触摸位置绘制一个圆圈
        if (touchState != "未触摸" && touchState != "抬起") {
            Canvas(modifier = Modifier.fillMaxSize()) {
                drawCircle(
                    color = Color.Red.copy(alpha = 0.5f),
                    radius = 50f * touchPressure,
                    center = touchPosition
                )
            }
        }
    }
}
```

在这个例子中，我们使用 `pointerInput` 修饰符和 `awaitPointerEventScope` 来直接处理原始触摸事件。我们跟踪触摸点的
ID、位置和压力，并根据触摸状态（按下、移动、抬起）更新 UI。我们还展示了如何消费事件，以防止其他组件接收到这些事件。

下面是一个更复杂的例子，展示如何实现自定义的多点触摸手势识别器：

```kotlin
@Composable
fun CustomGestureRecognizerExample() {
    // 手势状态
    var gestureState by remember { mutableStateOf<String>("无手势") }
    
    // 触摸轨迹
    val touchTrajectories = remember { mutableStateMapOf<Int, MutableList<Offset>>() }
    
    // 手势检测参数
    val minSwipeDistance = 100f // 最小滑动距离
    val maxTapDistance = 20f // 最大点击移动距离
    val maxTapDuration = 300L // 最大点击持续时间（毫秒）
    
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(Color.White)
            // 添加自定义手势识别
            .pointerInput(Unit) {
                // 触摸开始时间
                var touchStartTime = 0L
                
                awaitPointerEventScope {
                    while (true) {
                        // 等待第一个触摸点按下
                        val downEvent = awaitFirstDown()
                        val pointerId = downEvent.id.value
                        
                        // 记录触摸开始时间
                        touchStartTime = System.currentTimeMillis()
                        
                        // 清除之前的轨迹
                        touchTrajectories.clear()
                        
                        // 创建新的轨迹
                        touchTrajectories[pointerId] = mutableListOf(downEvent.position)
                        
                        // 初始状态
                        gestureState = "触摸开始"
                        
                        // 跟踪触摸移动
                        do {
                            val event = awaitPointerEvent()
                            
                            // 处理所有触摸点
                            event.changes.forEach { change ->
                                val id = change.id.value
                                
                                // 如果是按下状态，记录轨迹
                                if (change.pressed) {
                                    // 获取或创建轨迹
                                    val trajectory = touchTrajectories.getOrPut(id) { mutableListOf() }
                                    
                                    // 添加新位置
                                    trajectory.add(change.position)
                                    
                                    // 计算移动距离
                                    if (trajectory.size >= 2) {
                                        val start = trajectory.first()
                                        val current = change.position
                                        val distance = (current - start).getDistance()
                                        
                                        // 根据移动距离更新状态
                                        if (distance > minSwipeDistance) {
                                            // 计算方向
                                            val dx = current.x - start.x
                                            val dy = current.y - start.y
                                            
                                            gestureState = when {
                                                abs(dx) > abs(dy) && dx > 0 -> "右滑"
                                                abs(dx) > abs(dy) && dx < 0 -> "左滑"
                                                abs(dy) > abs(dx) && dy > 0 -> "下滑"
                                                abs(dy) > abs(dx) && dy < 0 -> "上滑"
                                                else -> "移动"
                                            }
                                        } else {
                                            gestureState = "移动中"
                                        }
                                    }
                                }
                                
                                // 消费事件
                                change.consume()
                            }
                        } while (event.changes.any { it.pressed })
                        
                        // 所有触摸点都抬起，手势结束
                        val touchEndTime = System.currentTimeMillis()
                        val touchDuration = touchEndTime - touchStartTime
                        
                        // 检查是否是点击
                        val mainTrajectory = touchTrajectories[pointerId] ?: emptyList()
                        if (mainTrajectory.size >= 2) {
                            val start = mainTrajectory.first()
                            val end = mainTrajectory.last()
                            val distance = (end - start).getDistance()
                            
                            if (distance < maxTapDistance && touchDuration < maxTapDuration) {
                                gestureState = "点击"
                            } else if (gestureState.contains("滑")) {
                                // 保持滑动状态
                            } else {
                                gestureState = "触摸结束"
                            }
                        } else {
                            gestureState = "触摸结束"
                        }
                    }
                }
            }
    ) {
        // 显示手势状态
        Column(
            modifier = Modifier
                .fillMaxSize()
                .padding(16.dp),
            horizontalAlignment = Alignment.CenterHorizontally,
            verticalArrangement = Arrangement.Center
        ) {
            Text(
                text = "检测到的手势:",
                fontSize = 20.sp,
                fontWeight = FontWeight.Bold
            )
            Spacer(modifier = Modifier.height(16.dp))
            Text(
                text = gestureState,
                fontSize = 32.sp,
                fontWeight = FontWeight.Bold,
                color = when (gestureState) {
                    "点击" -> Color.Blue
                    "右滑", "左滑", "上滑", "下滑" -> Color.Green
                    "触摸开始", "移动中", "触摸结束" -> Color.Gray
                    else -> Color.Black
                }
            )
            Spacer(modifier = Modifier.height(32.dp))
            Text(
                text = "轨迹点数: ${touchTrajectories.values.sumOf { it.size }}",
                fontSize = 16.sp
            )
        }
        
        // 绘制触摸轨迹
        Canvas(modifier = Modifier.fillMaxSize()) {
            touchTrajectories.forEach { (_, trajectory) ->
                if (trajectory.size >= 2) {
                    // 绘制轨迹线
                    drawPoints(
                        points = trajectory,
                        pointMode = PointMode.Polygon,
                        color = Color.Red,
                        strokeWidth = 5f
                    )
                    
                    // 绘制起点
                    drawCircle(
                        color = Color.Blue,
                        radius = 15f,
                        center = trajectory.first()
                    )
                    
                    // 绘制终点
                    drawCircle(
                        color = Color.Green,
                        radius = 15f,
                        center = trajectory.last()
                    )
                }
            }
        }
    }
}
```

在这个例子中，我们实现了一个自定义的手势识别器，可以识别点击和四个方向的滑动。我们跟踪触摸轨迹，并根据轨迹的长度、方向和持续时间来判断手势类型。我们还绘制了触摸轨迹，以便更好地可视化手势。

## 进阶用法

### 1. 实现自定义触摸状态机

下面是一个实现自定义触摸状态机的例子，可以处理复杂的触摸交互序列：

```kotlin
@Composable
fun TouchStateMachineExample() {
    // 定义触摸状态
    sealed class TouchState {
        object Idle : TouchState()
        data class Down(val position: Offset, val startTime: Long) : TouchState()
        data class Dragging(val startPosition: Offset, val currentPosition: Offset) : TouchState()
        data class LongPress(val position: Offset) : TouchState()
        data class MultiTouch(val pointers: List<Offset>) : TouchState()
    }
    
    // 当前触摸状态
    var touchState by remember { mutableStateOf<TouchState>(TouchState.Idle) }
    
    // 状态描述
    val stateDescription = when (touchState) {
        is TouchState.Idle -> "空闲"
        is TouchState.Down -> "按下"
        is TouchState.Dragging -> "拖动"
        is TouchState.LongPress -> "长按"
        is TouchState.MultiTouch -> "多点触摸"
    }
    
    // 长按阈值
    val longPressThreshold = 500L // 毫秒
    
    // 拖动阈值
    val dragThreshold = 10f // 像素
    
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(
                when (touchState) {
                    is TouchState.Idle -> Color.White
                    is TouchState.Down -> Color.LightGray
                    is TouchState.Dragging -> Color.Cyan.copy(alpha = 0.3f)
                    is TouchState.LongPress -> Color.Yellow.copy(alpha = 0.3f)
                    is TouchState.MultiTouch -> Color.Magenta.copy(alpha = 0.3f)
                }
            )
            // 添加触摸状态机
            .pointerInput(Unit) {
                // 长按检测协程
                var longPressJob: Job? = null
                
                // 活跃的触摸点
                val activePointers = mutableMapOf<PointerId, Offset>()
                
                awaitPointerEventScope {
                    while (true) {
                        val event = awaitPointerEvent()
                        
                        // 处理所有触摸点变化
                        event.changes.forEach { change ->
                            when {
                                // 触摸点按下
                                change.pressed && !change.previousPressed -> {
                                    // 添加到活跃触摸点
                                    activePointers[change.id] = change.position
                                    
                                    // 根据触摸点数量更新状态
                                    if (activePointers.size == 1) {
                                        // 单点触摸
                                        touchState = TouchState.Down(
                                            position = change.position,
                                            startTime = System.currentTimeMillis()
                                        )
                                        
                                        // 启动长按检测
                                        longPressJob?.cancel()
                                        longPressJob = coroutineScope.launch {
                                            delay(longPressThreshold)
                                            if (touchState is TouchState.Down) {
                                                touchState = TouchState.LongPress(change.position)
                                            }
                                        }
                                    } else {
                                        // 多点触摸
                                        touchState = TouchState.MultiTouch(activePointers.values.toList())
                                        
                                        // 取消长按检测
                                        longPressJob?.cancel()
                                    }
                                }
                                
                                // 触摸点移动
                                change.pressed && change.positionChanged() -> {
                                    // 更新触摸点位置
                                    activePointers[change.id] = change.position
                                    
                                    // 根据当前状态处理移动
                                    when (val currentState = touchState) {
                                        is TouchState.Down -> {
                                            // 计算移动距离
                                            val distance = (change.position - currentState.position).getDistance()
                                            
                                            // 如果超过拖动阈值，转换为拖动状态
                                            if (distance > dragThreshold) {
                                                touchState = TouchState.Dragging(
                                                    startPosition = currentState.position,
                                                    currentPosition = change.position
                                                )
                                                
                                                // 取消长按检测
                                                longPressJob?.cancel()
                                            }
                                        }
                                        is TouchState.Dragging -> {
                                            // 更新拖动位置
                                            touchState = currentState.copy(
                                                currentPosition = change.position
                                            )
                                        }
                                        is TouchState.LongPress -> {
                                            // 长按状态下的移动，可以实现特殊行为
                                            // 这里保持长按状态不变
                                        }
                                        is TouchState.MultiTouch -> {
                                            // 更新多点触摸状态
                                            touchState = TouchState.MultiTouch(activePointers.values.toList())
                                        }
                                        else -> { /* 其他状态不处理 */ }
                                    }
                                }
                                
                                // 触摸点抬起
                                !change.pressed && change.previousPressed -> {
                                    // 从活跃触摸点中移除
                                    activePointers.remove(change.id)
                                    
                                    // 根据剩余触摸点数量更新状态
                                    if (activePointers.isEmpty()) {
                                        // 所有触摸点都抬起，回到空闲状态
                                        touchState = TouchState.Idle
                                        
                                        // 取消长按检测
                                        longPressJob?.cancel()
                                    } else if (activePointers.size == 1) {
                                        // 从多点触摸变为单点触摸
                                        val remainingPointer = activePointers.entries.first()
                                        touchState = TouchState.Down(
                                            position = remainingPointer.value,
                                            startTime = System.currentTimeMillis()
                                        )
                                        
                                        // 重新启动长按检测
                                        longPressJob?.cancel()
                                        longPressJob = coroutineScope.launch {
                                            delay(longPressThreshold)
                                            if (touchState is TouchState.Down) {
                                                touchState = TouchState.LongPress(remainingPointer.value)
                                            }
                                        }
                                    } else {
                                        // 仍然是多点触摸，但点数减少
                                        touchState = TouchState.MultiTouch(activePointers.values.toList())
                                    }
                                }
                            }
                            
                            // 消费事件
                            change.consume()
                        }
                    }
                }
            }
    ) {
        // 显示当前状态
        Column(
            modifier = Modifier
                .fillMaxSize()
                .padding(16.dp),
            horizontalAlignment = Alignment.CenterHorizontally,
            verticalArrangement = Arrangement.Top
        ) {
            Text(
                text = "当前状态: $stateDescription",
                fontSize = 24.sp,
                fontWeight = FontWeight.Bold
            )
            
            Spacer(modifier = Modifier.height(16.dp))
            
            // 显示状态详情
            when (val state = touchState) {
                is TouchState.Idle -> {
                    Text("等待触摸...")
                }
                is TouchState.Down -> {
                    Text("按下位置: (${state.position.x.toInt()}, ${state.position.y.toInt()})")
                    Text("按下时间: ${System.currentTimeMillis() - state.startTime} ms")
                }
                is TouchState.Dragging -> {
                    Text("起始位置: (${state.startPosition.x.toInt()}, ${state.startPosition.y.toInt()})")
                    Text("当前位置: (${state.currentPosition.x.toInt()}, ${state.currentPosition.y.toInt()})")
                    Text("拖动距离: ${(state.currentPosition - state.startPosition).getDistance().toInt()} px")
                }
                is TouchState.LongPress -> {
                    Text("长按位置: (${state.position.x.toInt()}, ${state.position.y.toInt()})")
                }
                is TouchState.MultiTouch -> {
                    Text("触摸点数: ${state.pointers.size}")
                    state.pointers.forEachIndexed { index, position ->
                        Text("点 $index: (${position.x.toInt()}, ${position.y.toInt()})")
                    }
                }
            }
        }
        
        // 绘制触摸可视化
        Canvas(modifier = Modifier.fillMaxSize()) {
            when (val state = touchState) {
                is TouchState.Down -> {
                    // 绘制按下点
                    drawCircle(
                        color = Color.Blue,
                        radius = 30f,
                        center = state.position
                    )
                }
                is TouchState.Dragging -> {
                    // 绘制拖动线
                    drawLine(
                        color = Color.Green,
                        start = state.startPosition,
                        end = state.currentPosition,
                        strokeWidth = 5f
                    )
                    
                    // 绘制起点
                    drawCircle(
                        color = Color.Blue,
                        radius = 20f,
                        center = state.startPosition
                    )
                    
                    // 绘制当前点
                    drawCircle(
                        color = Color.Red,
                        radius = 30f,
                        center = state.currentPosition
                    )
                }
                is TouchState.LongPress -> {
                    // 绘制长按效果
                    drawCircle(
                        color = Color.Yellow,
                        radius = 50f,
                        center = state.position,
                        alpha = 0.7f
                    )
                    drawCircle(
                        color = Color.Red,
                        radius = 20f,
                        center = state.position
                    )
                }
                is TouchState.MultiTouch -> {
                    // 绘制所有触摸点
                    state.pointers.forEach { position ->
                        drawCircle(
                            color = Color.Magenta,
                            radius = 30f,
                            center = position
                        )
                    }
                    
                    // 如果有两个以上的点，绘制连线
                    if (state.pointers.size >= 2) {
                        for (i in 0 until state.pointers.size - 1) {
                            for (j in i + 1 until state.pointers.size) {
                                drawLine(
                                    color = Color.Magenta.copy(alpha = 0.5f),
                                    start = state.pointers[i],
                                    end = state.pointers[j],
                                    strokeWidth = 3f
                                )
                            }
                        }
                    }
                }
                else -> { /* 空闲状态不绘制 */ }
            }
        }
    }
}
```

在这个例子中，我们实现了一个完整的触摸状态机，可以处理单点触摸、拖动、长按和多点触摸等不同状态。我们使用密封类（sealed
class）来表示不同的触摸状态，并根据触摸事件在这些状态之间进行转换。我们还使用协程来实现长按检测，并绘制了不同状态的可视化效果。

### 2. 实现自定义手势组合器

下面是一个实现自定义手势组合器的例子，可以组合多种手势检测器：

```kotlin
@Composable
fun GestureCombinatorExample() {
    // 手势状态
    data class GestureState(
        val tap: Boolean = false,
        val doubleTap: Boolean = false,
        val longPress: Boolean = false,
        val drag: Offset = Offset.Zero,
        val scale: Float = 1f,
        val rotation: Float = 0f
    )
    
    // 当前手势状态
    var gestureState by remember { mutableStateOf(GestureState()) }
    
    // 重置计时器
    val resetDelay = 1000L // 毫秒
    val coroutineScope = rememberCoroutineScope()
    
    // 自动重置某些手势状态
    fun resetGestureState(resetTap: Boolean = true, resetDoubleTap: Boolean = true, resetLongPress: Boolean = true) {
        coroutineScope.launch {
            delay(resetDelay)
            gestureState = gestureState.copy(
                tap = if (resetTap) false else gestureState.tap,
                doubleTap = if (resetDoubleTap) false else gestureState.doubleTap,
                longPress = if (resetLongPress) false else gestureState.longPress

        }
    }

                var longPressJob: Job? = null

                var scaleState = 1f
                var rotationState = 0f

                awaitPointerEventScope {
                    while (true) {

                        val downTime = System.currentTimeMillis()

                        longPressJob = coroutineScope.launch {
                            delay(longPressTimeout)
                            gestureState = gestureState.copy(longPress = true)

                        }

                        var moveEvent: PointerEvent? = null
                        do {
                            moveEvent = awaitPointerEvent()
                            
                            // 检查是否有多个触摸点
                            if (moveEvent.changes.size >= 2) {
                                // 取消长按检测

                                val secondPointer = moveEvent.changes[1]

                                    // 消费事件

                                }
                            }
```

### 3. 实现自定义触摸事件过滤器

下面是一个实现自定义触摸事件过滤器的例子，可以根据特定条件过滤或修改触摸事件：

```kotlin
@Composable
fun TouchEventFilterExample() {
    // 过滤器状态
    var enableDragFilter by remember { mutableStateOf(true) }
    var enablePressureFilter by remember { mutableStateOf(true) }
    var enablePositionFilter by remember { mutableStateOf(true) }
    
    // 触摸状态
    var touchPosition by remember { mutableStateOf(Offset.Zero) }
    var touchPressure by remember { mutableStateOf(0f) }
    var dragAmount by remember { mutableStateOf(Offset.Zero) }
    
    // 过滤器参数
    val minPressure = 0.3f // 最小压力阈值
    val maxSpeed = 50f // 最大速度阈值（像素/帧）
    val restrictedArea = Rect(300f, 300f, 500f, 500f) // 限制区域
    
    Column(
        modifier = Modifier.fillMaxSize()
    ) {
        // 控制面板
        Row(
            modifier = Modifier
                .fillMaxWidth()
                .background(Color.LightGray)
                .padding(16.dp),
            horizontalArrangement = Arrangement.SpaceEvenly,
            verticalAlignment = Alignment.CenterVertically
        ) {
            // 拖动速度过滤器开关
            Row(
                verticalAlignment = Alignment.CenterVertically
            ) {
                Checkbox(
                    checked = enableDragFilter,
                    onCheckedChange = { enableDragFilter = it }
                )
                Text("速度过滤")
            }
            
            // 压力过滤器开关
            Row(
                verticalAlignment = Alignment.CenterVertically
            ) {
                Checkbox(
                    checked = enablePressureFilter,
                    onCheckedChange = { enablePressureFilter = it }
                )
                Text("压力过滤")
            }
            
            // 位置过滤器开关
            Row(
                verticalAlignment = Alignment.CenterVertically
            ) {
                Checkbox(
                    checked = enablePositionFilter,
                    onCheckedChange = { enablePositionFilter = it }
                )
                Text("位置过滤")
            }
        }
        
        // 触摸区域
        Box(
            modifier = Modifier
                .fillMaxSize()
                .background(Color.White)
                // 添加自定义触摸事件过滤器
                .pointerInput(Unit) {
                    // 上一帧的触摸位置
                    var previousPosition = Offset.Zero
                    // 上一帧的时间戳
                    var previousTime = 0L
                    
                    awaitPointerEventScope {
                        while (true) {
                            val event = awaitPointerEvent()
                            val currentTime = System.currentTimeMillis()
                            
                            event.changes.forEach { change ->
                                // 原始触摸数据
                                val originalPosition = change.position
                                val originalPressure = change.pressure
                                
                                // 应用过滤器
                                var filteredPosition = originalPosition
                                var filteredPressure = originalPressure
                                var allowEvent = true
                                
                                // 1. 拖动速度过滤器
                                if (enableDragFilter && change.pressed && change.previousPressed) {
                                    val timeDelta = (currentTime - previousTime).coerceAtLeast(1L)
                                    val distance = (originalPosition - previousPosition).getDistance()
                                    val speed = distance / timeDelta * 1000 // 像素/秒
                                    
                                    if (speed > maxSpeed) {
                                        // 速度过快，限制移动距离
                                        val direction = (originalPosition - previousPosition).normalized()
                                        val maxDistance = maxSpeed * timeDelta / 1000
                                        filteredPosition = previousPosition + direction * maxDistance
                                    }
                                }
                                
                                // 2. 压力过滤器
                                if (enablePressureFilter) {
                                    if (filteredPressure < minPressure) {
                                        // 压力过小，增强压力值
                                        filteredPressure = minPressure
                                    }
                                }
                                
                                // 3. 位置过滤器
                                if (enablePositionFilter) {
                                    if (restrictedArea.contains(filteredPosition)) {
                                        // 在限制区域内，阻止事件
                                        allowEvent = false
                                    }
                                }
                                
                                // 更新状态
                                if (allowEvent && change.pressed) {
                                    touchPosition = filteredPosition
                                    touchPressure = filteredPressure
                                    
                                    if (change.previousPressed) {
                                        dragAmount += filteredPosition - previousPosition
                                    }
                                    
                                    // 记录当前位置和时间，用于下一帧计算
                                    previousPosition = filteredPosition
                                    previousTime = currentTime
                                }
                                
                                // 消费事件
                                change.consume()
                            }
                        }
                    }
                }
        ) {
            // 绘制触摸可视化
            Canvas(modifier = Modifier.fillMaxSize()) {
                // 绘制限制区域
                drawRect(
                    color = Color.Red.copy(alpha = 0.3f),
                    topLeft = restrictedArea.topLeft,
                    size = restrictedArea.size
                )
                
                // 绘制触摸点
                if (touchPressure > 0) {
                    drawCircle(
                        color = Color.Blue,
                        radius = 30f * touchPressure,
                        center = touchPosition
                    )
                }
                
                // 绘制拖动轨迹
                drawLine(
                    color = Color.Green,
                    start = center,
                    end = center + dragAmount,
                    strokeWidth = 5f
                )
                
                // 绘制拖动终点
                drawCircle(
                    color = Color.Green,
                    radius = 10f,
                    center = center + dragAmount
                )
            }
            
            // 显示过滤器状态
            Column(
                modifier = Modifier
                    .align(Alignment.TopStart)
                    .padding(16.dp)
                    .background(Color.White.copy(alpha = 0.8f))
                    .padding(8.dp)
            ) {
                Text(
                    text = "触摸位置: (${touchPosition.x.toInt()}, ${touchPosition.y.toInt()})",
                    fontSize = 14.sp
                )
                Text(
                    text = "触摸压力: ${String.format("%.2f", touchPressure)}",
                    fontSize = 14.sp
                )
                Text(
                    text = "拖动量: (${dragAmount.x.toInt()}, ${dragAmount.y.toInt()})",
                    fontSize = 14.sp
                )
            }
            
            // 显示说明
            Column(
                modifier = Modifier
                    .align(Alignment.BottomStart)
                    .padding(16.dp)
                    .background(Color.White.copy(alpha = 0.8f))
                    .padding(8.dp)
            ) {
                Text(
                    text = "过滤器说明:",
                    fontWeight = FontWeight.Bold
                )
                Text("• 速度过滤: 限制拖动速度不超过 $maxSpeed 像素/秒")
                Text("• 压力过滤: 确保触摸压力不小于 $minPressure")
                Text("• 位置过滤: 阻止在红色区域内的触摸")
            }
            
            // 重置按钮
            Button(
                onClick = { dragAmount = Offset.Zero },
                modifier = Modifier
                    .align(Alignment.BottomEnd)
                    .padding(16.dp)
            ) {
                Text("重置")
            }
        }
    }
}
```

在这个例子中，我们实现了三种不同类型的触摸事件过滤器：

1. **速度过滤器**：限制拖动的最大速度，防止快速滑动导致的不精确操作。
2. **压力过滤器**：确保触摸压力不小于某个阈值，提高触摸的稳定性。
3. **位置过滤器**：阻止在特定区域内的触摸事件，实现触摸禁区功能。

## 常见问题

### 1. 如何处理触摸事件的传递和消费？

**回答**：在 Compose 中，触摸事件的传递和消费是通过以下机制实现的：

1. **事件传递流程**：
   触摸事件首先从根组件向下传递到叶子组件（捕获阶段），然后从叶子组件向上冒泡（冒泡阶段）。每个组件都有机会处理或传递这些事件。

2. **事件消费**：
   通过调用 `PointerInputChange.consume()` 方法来消费事件。一旦事件被消费，其他组件将不会收到该事件的特定变化（如位置变化）。

3. **部分消费**：
   Compose 允许部分消费事件，例如只消费位置变化但允许其他属性（如压力）继续传递：

   ```kotlin
   // 只消费位置变化
   change.consume()
   
   // 或者更明确地：
   change.consumePositionChange()
   ```

4. **检查是否已消费**：
   在处理事件前，可以检查事件是否已被其他组件消费：

   ```kotlin
   if (!change.isConsumed) {
       // 事件尚未被消费，可以处理
   }
   
   // 或者更具体地：
   if (!change.consumed.positionChange) {
       // 位置变化尚未被消费
   }
   ```

5. **事件传递控制**：
   可以使用 `awaitPointerEventScope` 的参数来控制事件传递：

   ```kotlin
   // 只接收未消费的事件
   awaitFirstDown(requireUnconsumed = true)
   
   // 接收所有事件，无论是否已消费
   awaitPointerEvent(pass = PointerEventPass.Initial)
   ```

6. **事件传递顺序**：
   Compose 中的事件传递有三个阶段，可以通过 `PointerEventPass` 参数控制：
    - `Initial`：初始阶段，从根到叶
    - `Main`：主要阶段，从叶到根
    - `Final`：最终阶段，从根到叶

   ```kotlin
   // 在初始阶段接收事件
   awaitPointerEvent(PointerEventPass.Initial)
   
   // 在主要阶段接收事件（默认）
   awaitPointerEvent(PointerEventPass.Main)
   
   // 在最终阶段接收事件
   awaitPointerEvent(PointerEventPass.Final)
   ```

### 2. 如何实现自定义手势检测器？

**回答**：实现自定义手势检测器的步骤：

1. **定义手势参数**：
   确定手势的特征参数，如最小距离、最大持续时间等。

   ```kotlin
   // 手势参数
   val minSwipeDistance = 50f // 最小滑动距离
   val maxTapDuration = 300L // 最大点击持续时间（毫秒）
   ```

2. **创建状态跟踪变量**：
   使用状态变量跟踪触摸点的位置、时间和其他相关信息。

   ```kotlin
   // 状态变量
   var touchStartTime = 0L
   var touchStartPosition = Offset.Zero
   ```

3. **实现基本触摸事件处理**：
   使用 `pointerInput` 和 `awaitPointerEventScope` 处理基本触摸事件。

   ```kotlin
   Modifier.pointerInput(Unit) {
       awaitPointerEventScope {
           while (true) {
               // 等待触摸开始
               val down = awaitFirstDown()
               touchStartTime = System.currentTimeMillis()
               touchStartPosition = down.position
               
               // 跟踪触摸移动
               do {
                   val event = awaitPointerEvent()
                   // 处理移动
               } while (event.changes.any { it.pressed })
               
               // 触摸结束，判断手势类型
               val touchEndTime = System.currentTimeMillis()
               val touchDuration = touchEndTime - touchStartTime
               // 根据持续时间和移动距离判断手势类型
           }
       }
   }
   ```

4. **实现手势识别逻辑**：
   根据触摸事件的特征（如速度、方向、持续时间）来识别特定手势。

   ```kotlin
   // 计算移动距离和方向
   val touchEndPosition = event.changes.first().position
   val distance = (touchEndPosition - touchStartPosition).getDistance()
   val direction = touchEndPosition - touchStartPosition
   
   // 判断手势类型
   val gesture = when {
       distance < 10f && touchDuration < maxTapDuration -> "点击"
       distance >= minSwipeDistance -> {
           when {
               abs(direction.x) > abs(direction.y) && direction.x > 0 -> "右滑"
               abs(direction.x) > abs(direction.y) && direction.x < 0 -> "左滑"
               abs(direction.y) > abs(direction.x) && direction.y > 0 -> "下滑"
               abs(direction.y) > abs(direction.x) && direction.y < 0 -> "上滑"
               else -> "未知"
           }
       }
       else -> "未知"
   }
   ```

5. **提供回调接口**：
   定义回调接口，让使用者可以响应检测到的手势。

   ```kotlin
   // 定义手势回调
   fun detectCustomGesture(
       onTap: () -> Unit = {},
       onSwipeLeft: () -> Unit = {},
       onSwipeRight: () -> Unit = {},
       onSwipeUp: () -> Unit = {},
       onSwipeDown: () -> Unit = {}
   ) = pointerInput(Unit) {
       // 手势检测逻辑
       // ...
       
       // 触发回调
       when (gesture) {
           "点击" -> onTap()
           "左滑" -> onSwipeLeft()
           "右滑" -> onSwipeRight()
           "上滑" -> onSwipeUp()
           "下滑" -> onSwipeDown()
       }
   }
   ```

6. **处理多点触摸**：
   如果需要支持多点触摸，需要跟踪多个触摸点的状态。

   ```kotlin
   // 跟踪多个触摸点
   val touchPoints = mutableMapOf<PointerId, TouchPoint>()
   
   // 处理触摸事件
   event.changes.forEach { change ->
       val id = change.id
       
       when {
           change.pressed && !change.previousPressed -> {
               // 新触摸点按下
               touchPoints[id] = TouchPoint(change.position, System.currentTimeMillis())
           }
           change.pressed && change.previousPressed -> {
               // 触摸点移动
               touchPoints[id]?.currentPosition = change.position
           }
           !change.pressed && change.previousPressed -> {
               // 触摸点抬起
               touchPoints.remove(id)
           }
       }
   }
   ```

7. **实现手势状态机**：

   ```kotlin
   // 定义手势状态
   sealed class GestureState {

   // 当前状态
   var currentState: GestureState = GestureState.Idle

               currentState = GestureState.Scaling(distance)

       }
       is GestureState.Scaling -> {
           // 处理缩放状态
       }
   }
   ```

### 3. 如何处理触摸事件的时间和速度计算？

**回答**：处理触摸事件的时间和速度计算的方法：

1. **使用系统时间戳**：
   使用 `System.currentTimeMillis()` 或 `System.nanoTime()` 记录触摸事件的时间戳。

   ```kotlin
   // 记录触摸开始时间
   val touchStartTime = System.currentTimeMillis()
   
   // 计算触摸持续时间
   val touchDuration = System.currentTimeMillis() - touchStartTime
   ```

2. **使用事件时间戳**：
   使用 `PointerInputChange.uptimeMillis` 获取事件的系统时间戳。

   ```kotlin
   // 获取事件时间戳
   val eventTime = change.uptimeMillis
   ```

3. **计算速度**：
   根据位置变化和时间差计算速度。

   ```kotlin
   // 计算速度
   val distance = (currentPosition - previousPosition).getDistance()
   val timeDelta = (currentTime - previousTime).coerceAtLeast(1L) // 避免除以零
   val speed = distance / timeDelta * 1000 // 像素/秒
   ```

4. **使用 VelocityTracker**：
   使用 `VelocityTracker` 类来跟踪触摸点的速度。

   ```kotlin
   // 创建速度跟踪器
   val velocityTracker = VelocityTracker()
   
   // 添加位置样本
   velocityTracker.addPosition(
       change.uptimeMillis,
       change.position
   )
   
   // 计算速度
   val velocity = velocityTracker.calculateVelocity()
   val speedX = velocity.x // X 方向速度（像素/秒）
   val speedY = velocity.y // Y 方向速度（像素/秒）
   ```

5. **实现惯性滚动**：
   根据速度实现惯性滚动或甩动效果。

   ```kotlin
   // 计算最终速度
   val finalVelocity = velocityTracker.calculateVelocity()
   
   // 启动惯性动画
   launch {
       // 初始速度
       var velocity = Offset(finalVelocity.x, finalVelocity.y)
       // 阻尼系数
       val dampingFactor = 0.98f
       // 最小速度阈值
       val minVelocity = 10f
       
       // 惯性滚动循环
       while (velocity.getDistance() > minVelocity) {
           // 计算位移
           val displacement = velocity * 0.016f // 假设 16ms 每帧
           
           // 更新位置
           position += displacement
           
           // 应用阻尼
           velocity *= dampingFactor
           
           // 等待下一帧
           delay(16)
       }
   }
   ```

6. **平滑速度**：
   使用移动平均或其他平滑算法减少速度计算中的噪声。

   ```kotlin
   // 速度历史记录
   val velocityHistory = ArrayDeque<Float>(5) // 保存最近 5 个速度样本
   
   // 添加新速度样本
   velocityHistory.addLast(speed)
   if (velocityHistory.size > 5) {
       velocityHistory.removeFirst()
   }
   
   // 计算平均速度
   val averageSpeed = velocityHistory.average().toFloat()
   ```

7. **处理速度异常**：
   处理速度计算中的异常情况，如触摸点突然跳变。

   ```kotlin
   // 检测速度异常
   if (speed > maxSpeed) {
       // 速度异常，可能是触摸点跳变
       // 使用上一帧的速度或限制速度
       speed = maxSpeed
   }
   ```

### 4. 如何优化自定义触摸处理的性能？

**回答**：优化自定义触摸处理性能的几种方法：

1. **减少状态更新频率**：
   不要在每个触摸事件中都更新状态，可以使用节流技术。

   ```kotlin
   // 上次更新时间
   var lastUpdateTime = 0L
   // 最小更新间隔
   val minUpdateInterval = 16L // 约 60fps
   
   // 节流更新
   val currentTime = System.currentTimeMillis()
   if (currentTime - lastUpdateTime >= minUpdateInterval) {
       // 更新状态
       state = newState
       lastUpdateTime = currentTime
   }
   ```

2. **使用 `remember` 缓存计算结果**：
   缓存计算结果，避免重复计算。

   ```kotlin
   // 缓存计算结果
   val cachedResult = remember(key1, key2) {
       // 复杂计算
       complexCalculation(key1, key2)
   }
   ```

3. **使用 `derivedStateOf` 减少重组**：
   对于依赖于其他状态的计算，使用 `derivedStateOf` 可以减少重组次数。

   ```kotlin
   // 原始状态
   var touchPosition by remember { mutableStateOf(Offset.Zero) }
   
   // 派生状态
   val formattedPosition by remember {
       derivedStateOf {
           "位置: (${touchPosition.x.toInt()}, ${touchPosition.y.toInt()})"
       }
   }
   ```

4. **使用 `mutableStateListOf` 和 `mutableStateMapOf`**：
   对于需要跟踪多个触摸点的情况，使用这些集合可以提高性能。

   ```kotlin
   // 使用 mutableStateMapOf 跟踪触摸点
   val touchPoints = remember { mutableStateMapOf<Int, Offset>() }
   
   // 更新触摸点
   touchPoints[pointerId] = position
   
   // 移除触摸点
   touchPoints.remove(pointerId)
   ```

5. **使用 `Canvas` 而不是组合多个组件**：
   对于需要绘制大量触摸点或轨迹的情况，使用 `Canvas` 比组合多个组件更高效。

   ```kotlin
   Canvas(modifier = Modifier.fillMaxSize()) {
       // 绘制所有触摸点
       touchPoints.forEach { (_, position) ->
           drawCircle(
               color = Color.Red,
               radius = 20f,
               center = position
           )
       }
   }
   ```

6. **使用 `LaunchedEffect` 处理副作用**：
   将耗时操作放在 `LaunchedEffect` 中执行，避免阻塞主线程。

   ```kotlin
   LaunchedEffect(key1) {
       // 耗时操作
       val result = withContext(Dispatchers.Default) {
           // 在后台线程执行
           heavyComputation()
       }
       
       // 更新状态
       state = result
   }
   ```

7. **使用 `graphicsLayer` 进行硬件加速**：
   对于需要频繁变换的元素，使用 `graphicsLayer` 可以提高性能。

   ```kotlin
   Box(
       modifier = Modifier
           .graphicsLayer(
               translationX = offset.x,
               translationY = offset.y,
               scaleX = scale,
               scaleY = scale,
               rotationZ = rotation
           )
   )
   ```

8. **使用 `key` 优化重组**：
   为动态内容添加 `key`，帮助 Compose 更高效地进行重组。

   ```kotlin
   touchPoints.forEach { (id, position) ->
       key(id) {
           // 为每个触摸点创建组件
           TouchPoint(position = position)
       }
   }
   ```

9. **批量更新状态**：
   将多个状态更新合并为一个操作，减少重组次数。

   ```kotlin
   // 不好的做法：多次单独更新
   position = newPosition
   scale = newScale
   rotation = newRotation
   
   // 好的做法：使用数据类合并更新
   state = state.copy(
       position = newPosition,
       scale = newScale,
       rotation = newRotation
   )
   ```

10. **使用 `produceState` 处理异步数据**：
    对于需要从异步源获取的数据，使用 `produceState` 可以更高效地管理状态。

    ```kotlin
    val touchData = produceState(initialValue = TouchData()) {
        // 异步获取触摸数据
        while (true) {
            val newData = getTouchDataAsync()
            value = newData
            delay(16) // 约 60fps
        }
    }
    ```
