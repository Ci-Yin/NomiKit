## 概念介绍

在Compose的修饰符体系中，`DrawModifier`是专门负责自定义绘制的关键接口。与`LayoutModifier`负责布局计算不同，
`DrawModifier`
允许我们直接介入组件的绘制过程，在Canvas上绘制自定义的图形、效果和装饰。

`DrawModifier`
的核心在于它能够在组件的标准绘制流程中插入自定义的绘制代码，这些代码可以在组件绘制前（背景）、组件绘制后（前景），或者完全替代组件的绘制。通过这种机制，我们可以实现各种视觉效果，如自定义背景、边框、阴影、滤镜、装饰等。

在Compose中，`DrawModifier`通常通过`Modifier.drawBehind()`、`Modifier.drawWithContent()`和
`Modifier.drawWithCache()`
等扩展函数来使用。这些函数提供了不同级别的控制和性能优化选项，使我们能够根据需求选择最合适的绘制方式。

本节作为DrawModifier系列的第一部分，我们将重点介绍DrawModifier的基本工作原理、绘制顺序以及最常用的绘制函数
`drawBehind()`和
`drawWithContent()`的用法和应用场景。

## 知识要点

- **DrawModifier的基本原理**：
    - DrawModifier是Compose修饰符体系中专门负责自定义绘制的接口
    - 它允许在组件的标准绘制流程中插入自定义绘制代码
    - 可以在组件绘制前、绘制后或替代组件绘制

- **绘制顺序**：
    - 修饰符链中的绘制顺序遵循从外到内的规则
    - 外层修饰符的背景绘制先于内层修饰符
    - 内层修饰符的内容绘制先于外层修饰符的前景绘制

- **主要绘制函数**：
    - `Modifier.drawBehind()`：在组件内容绘制前执行绘制（背景）
    - `Modifier.drawWithContent()`：可以在绘制组件内容前后执行自定义绘制
    - `Modifier.drawWithCache()`：提供绘制缓存机制，优化性能

- **Canvas绘制API**：
    - DrawScope提供了丰富的绘制API，如drawRect、drawCircle等
    - 支持路径绘制、图像绘制、文本绘制等多种绘制操作
    - 可以设置颜色、透明度、混合模式、画笔样式等属性

- **坐标系统**：
    - DrawScope中的坐标系原点(0,0)位于组件的左上角
    - X轴向右为正，Y轴向下为正
    - 所有尺寸单位均为像素（px）

- **绘制状态**：
    - 可以通过State对象控制绘制效果的动态变化
    - 结合动画系统可以创建流畅的视觉过渡效果

- **性能考虑**：
    - 绘制操作是CPU和GPU密集型的，应避免不必要的重绘
    - 复杂的绘制逻辑应使用drawWithCache来缓存绘制结果
    - 避免在绘制回调中创建大量临时对象

```kotlin
@Composable
fun CustomBackgroundExample() {
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp)
    ) {
        Text(
            text = "使用drawBehind绘制自定义背景",
            style = MaterialTheme.typography.headlineSmall,
            modifier = Modifier.padding(bottom = 16.dp)
        )
        
        // 简单的纯色背景
        Text(
            text = "纯色背景",
            modifier = Modifier
                .padding(8.dp)
                .drawBehind {
                    // 绘制一个填充整个组件的矩形作为背景
                    drawRect(
                        color = Color(0xFFE3F2FD),
                        size = size
                    )
                }
                .padding(16.dp),
            style = MaterialTheme.typography.bodyLarge
        )
        
        Spacer(modifier = Modifier.height(16.dp))
        
        // 渐变背景
        Text(
            text = "渐变背景",
            modifier = Modifier
                .padding(8.dp)
                .drawBehind {
                    // 绘制一个线性渐变背景
                    drawRect(
                        brush = Brush.linearGradient(
                            colors = listOf(
                                Color(0xFFE1BEE7),
                                Color(0xFFBBDEFB)
                            ),
                            start = Offset(0f, 0f),
                            end = Offset(size.width, size.height)
                        ),
                        size = size
                    )
                }
                .padding(16.dp),
            style = MaterialTheme.typography.bodyLarge
        )
        
        Spacer(modifier = Modifier.height(16.dp))
        
        // 圆角背景
        Text(
            text = "圆角背景",
            modifier = Modifier
                .padding(8.dp)
                .drawBehind {
                    // 绘制一个圆角矩形作为背景
                    drawRoundRect(
                        color = Color(0xFFFFCDD2),
                        cornerRadius = CornerRadius(16.dp.toPx(), 16.dp.toPx()),
                        size = size
                    )
                }
                .padding(16.dp),
            style = MaterialTheme.typography.bodyLarge
        )
        
        Spacer(modifier = Modifier.height(16.dp))
        
        // 自定义形状背景
        Text(
            text = "自定义形状背景",
            modifier = Modifier
                .padding(8.dp)
                .drawBehind {
                    // 创建一个自定义路径
                    val path = Path().apply {
                        // 起始点
                        moveTo(0f, 0f)
                        // 右上角
                        lineTo(size.width, 0f)
                        // 右下角（带波浪效果）
                        val waveHeight = 20.dp.toPx()
                        val segmentWidth = size.width / 10
                        var x = size.width
                        var y = 0f
                        
                        while (x > 0) {
                            x -= segmentWidth / 2
                            y = if (y == 0f) waveHeight else 0f
                            lineTo(x, y)
                        }
                        
                        // 左下角
                        lineTo(0f, size.height)
                        // 闭合路径
                        close()
                    }
                    
                    // 绘制路径
                    drawPath(
                        path = path,
                        color = Color(0xFFDCEDC8)
                    )
                }
                .padding(16.dp),
            style = MaterialTheme.typography.bodyLarge
        )
    }
}
```

### 使用drawWithContent控制绘制顺序

```kotlin
@Composable
fun DrawWithContentExample() {
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp)
    ) {
        Text(
            text = "使用drawWithContent控制绘制顺序",
            style = MaterialTheme.typography.headlineSmall,
            modifier = Modifier.padding(bottom = 16.dp)
        )

        // 在内容前后绘制
        Box(
            modifier = Modifier
                .padding(8.dp)
                .size(200.dp)
                .drawWithContent {
                    // 在内容前绘制（背景）
                    drawRect(
                        color = Color(0xFFBBDEFB),
                        size = size
                    )

                    // 绘制内容
                    drawContent()

                    // 在内容后绘制（前景）
                    drawCircle(
                        color = Color(0x33FF4081),
                        radius = 50.dp.toPx(),
                        center = Offset(size.width * 0.75f, size.height * 0.25f)
                    )
                },
            contentAlignment = Alignment.Center
        ) {
            Text(
                text = "在内容前后绘制",
                style = MaterialTheme.typography.bodyLarge,
                modifier = Modifier
                    .background(Color.White, RoundedCornerShape(8.dp))
                    .padding(16.dp)
            )
        }

        Spacer(modifier = Modifier.height(24.dp))

        // 创建蒙版效果
        Box(
            modifier = Modifier
                .padding(8.dp)
                .size(200.dp)
                .drawWithContent {
                    // 先绘制内容
                    drawContent()

                    // 创建半透明蒙版
                    drawRect(
                        color = Color(0x66000000),
                        size = size
                    )

                    // 在蒙版上绘制文本
                    val textPaint = Paint().asFrameworkPaint().apply {
                        color = android.graphics.Color.WHITE
                        textSize = 18.sp.toPx()
                        textAlign = android.graphics.Paint.Align.CENTER
                    }

                    drawContext.canvas.nativeCanvas.drawText(
                        "蒙版效果",
                        center.x,
                        center.y,
                        textPaint
                    )
                }
        ) {
            // 这里放置一张图片作为内容
            Image(
                painter = painterResource(id = R.drawable.compose_multiplatform),
                contentDescription = "示例图片",
                contentScale = ContentScale.Crop,
                modifier = Modifier.fillMaxSize()
            )
        }
    }
}
```

```kotlin
@Composable
fun CustomBackgroundEffectsExample() {
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp)
    ) {
        Text(
            text = "自定义背景效果",
            style = MaterialTheme.typography.headlineSmall,
            modifier = Modifier.padding(bottom = 16.dp)
        )
        
        // 网格背景
        Card(
            modifier = Modifier
                .fillMaxWidth()
                .padding(8.dp),
            elevation = CardDefaults.cardElevation(4.dp)
        ) {
            Column(
                modifier = Modifier.padding(16.dp)
            ) {
                Text(
                    text = "网格背景",
                    style = MaterialTheme.typography.titleMedium,
                    modifier = Modifier.padding(bottom = 8.dp)
                )
                
                Box(
                    modifier = Modifier
                        .fillMaxWidth()
                        .height(150.dp)
                        .drawBehind {
                            // 绘制网格背景
                            val gridSize = 20.dp.toPx()
                            val strokeWidth = 1.dp.toPx()
                            val color = Color(0x1A000000)
                            
                            // 绘制横线
                            var y = 0f
                            while (y <= size.height) {
                                drawLine(
                                    color = color,
                                    start = Offset(0f, y),
                                    end = Offset(size.width, y),
                                    strokeWidth = strokeWidth
                                )
                                y += gridSize
                            }
                            
                            // 绘制竖线
                            var x = 0f
                            while (x <= size.width) {
                                drawLine(
                                    color = color,
                                    start = Offset(x, 0f),
                                    end = Offset(x, size.height),
                                    strokeWidth = strokeWidth
                                )
                                x += gridSize
                            }
                        }
                        .padding(16.dp),
                    contentAlignment = Alignment.Center
                ) {
                    Text(
                        text = "网格背景示例",
                        style = MaterialTheme.typography.bodyLarge
                    )
                }
            }
        }
        
        Spacer(modifier = Modifier.height(16.dp))
        
        // 波浪背景
        Card(
            modifier = Modifier
                .fillMaxWidth()
                .padding(8.dp),
            elevation = CardDefaults.cardElevation(4.dp)
        ) {
            Column(
                modifier = Modifier.padding(16.dp)
            ) {
                Text(
                    text = "波浪背景",
                    style = MaterialTheme.typography.titleMedium,
                    modifier = Modifier.padding(bottom = 8.dp)
                )
                
                val infiniteTransition = rememberInfiniteTransition(label = "wave animation")
                val phase by infiniteTransition.animateFloat(
                    initialValue = 0f,
                    targetValue = 2 * PI.toFloat(),
                    animationSpec = infiniteRepeatable(
                        animation = tween(2000, easing = LinearEasing),
                        repeatMode = RepeatMode.Restart
                    ),
                    label = "phase animation"
                )
                
                Box(
                    modifier = Modifier
                        .fillMaxWidth()
                        .height(150.dp)
                        .drawBehind {
                            // 绘制波浪背景
                            val waveColor = Color(0xFF2196F3)
                            val waveAmplitude = 20.dp.toPx()
                            val waveLength = size.width / 2
                            
                            // 创建波浪路径
                            val path = Path()
                            path.moveTo(0f, size.height)
                            
                            var x = 0f
                            while (x <= size.width) {
                                val y = size.height - 50.dp.toPx() + 
                                      sin((x / waveLength + phase) * 2 * PI.toFloat()) * waveAmplitude
                                path.lineTo(x, y)
                                x += 5f
                            }
                            
                            path.lineTo(size.width, size.height)
                            path.close()
                            
                            // 绘制波浪
                            drawPath(
                                path = path,
                                color = waveColor.copy(alpha = 0.3f)
                            )
                            
                            // 绘制第二个波浪（错开相位）
                            val path2 = Path()
                            path2.moveTo(0f, size.height)
                            
                            x = 0f
                            while (x <= size.width) {
                                val y = size.height - 50.dp.toPx() + 
                                      sin((x / waveLength + phase + PI.toFloat() / 4) * 2 * PI.toFloat()) * waveAmplitude
                                path2.lineTo(x, y)
                                x += 5f
                            }
                            
                            path2.lineTo(size.width, size.height)
                            path2.close()
                            
                            // 绘制第二个波浪
                            drawPath(
                                path = path2,
                                color = waveColor.copy(alpha = 0.15f)
                            )
                        },
                    contentAlignment = Alignment.Center
                ) {
                    Text(
                        text = "波浪背景示例",
                        style = MaterialTheme.typography.bodyLarge,
                        modifier = Modifier
                            .background(Color.White.copy(alpha = 0.7f), RoundedCornerShape(4.dp))
                            .padding(8.dp)
                    )
                }
            }
        }
        
        Spacer(modifier = Modifier.height(16.dp))
        
        // 点阵背景
        Card(
            modifier = Modifier
                .fillMaxWidth()
                .padding(8.dp),
            elevation = CardDefaults.cardElevation(4.dp)
        ) {
            Column(
                modifier = Modifier.padding(16.dp)
            ) {
                Text(
                    text = "点阵背景",
                    style = MaterialTheme.typography.titleMedium,
                    modifier = Modifier.padding(bottom = 8.dp)
                )
                
                Box(
                    modifier = Modifier
                        .fillMaxWidth()
                        .height(150.dp)
                        .drawBehind {
                            // 绘制点阵背景
                            val dotSpacing = 20.dp.toPx()
                            val dotRadius = 2.dp.toPx()
                            val dotColor = Color(0xFF9E9E9E)
```

## 常见问题

### 1. DrawModifier和LayoutModifier的区别是什么？

**问题**：DrawModifier和LayoutModifier有什么区别？什么情况下应该使用DrawModifier而不是LayoutModifier？

**解答**：DrawModifier和LayoutModifier在功能和使用场景上有明显区别：

1. **功能区别**：
    - `DrawModifier`：专注于视觉效果的绘制，如背景、边框、装饰等
    - `LayoutModifier`：专注于布局计算，如尺寸、位置、约束等

2. **影响范围**：
    - `DrawModifier`：不会改变组件的尺寸和位置，只影响其外观
    - `LayoutModifier`：可以改变组件的尺寸和位置，影响布局结构

3. **使用场景**：
    - 使用`DrawModifier`的情况：
        - 添加自定义背景或前景
        - 绘制边框、阴影、装饰
        - 应用视觉效果如渐变、滤镜
        - 不需要改变组件尺寸的情况

    - 使用`LayoutModifier`的情况：
        - 需要修改组件尺寸
        - 需要调整组件位置
        - 需要修改布局约束
        - 实现自定义布局逻辑

4. **组合使用**：
    - 在实际应用中，两者经常结合使用
    - 例如，先使用`LayoutModifier`确定尺寸和位置，再使用`DrawModifier`添加视觉效果

简而言之，如果你只需要改变组件的外观而不改变其尺寸和位置，应该使用DrawModifier；如果需要改变组件的尺寸、位置或布局逻辑，应该使用LayoutModifier。

### 2. 为什么我的绘制效果没有显示？

**问题**：我使用了drawBehind或drawWithContent，但是绘制的内容没有显示出来，这是为什么？

**解答**：绘制效果不显示通常有以下几个常见原因：

1. **绘制区域大小为零**：
    - 如果组件的尺寸为0，那么绘制区域也为0，不会显示任何内容
    - 解决方法：确保组件有明确的尺寸，如使用`size()`、`width()`、`height()`或`fillMaxSize()`等修饰符

2. **绘制顺序问题**：
    - 如果在`drawWithContent()`中忘记调用`drawContent()`，内容将不会显示
    - 解决方法：确保在适当的位置调用`drawContent()`

3. **颜色透明度问题**：
    - 使用完全透明的颜色（alpha = 0）进行绘制
    - 解决方法：检查颜色的alpha值，确保不是完全透明

4. **修饰符顺序问题**：
    - 修饰符的应用顺序会影响最终效果
    - 例如，`Modifier.drawBehind {...}.padding(10.dp)`和`Modifier.padding(10.dp).drawBehind {...}`
      的效果不同
    - 解决方法：调整修饰符顺序，确保绘制修饰符在正确的位置

5. **裁剪问题**：
    - 父组件可能应用了裁剪，导致绘制内容被裁剪掉
    - 解决方法：检查父组件是否有`clip()`修饰符，或者绘制内容是否超出了边界

6. **坐标系统问题**：
    - 使用了错误的坐标系统或坐标转换
    - 解决方法：确保使用正确的坐标系统，注意DrawScope中的坐标原点(0,0)位于组件的左上角

7. **绘制API使用错误**：
    - 使用了不适合的绘制API或参数
    - 解决方法：仔细检查API文档，确保正确使用绘制函数

通过检查这些常见问题，你通常可以找出绘制效果不显示的原因并解决它。

### 3. 如何优化DrawModifier的性能？

**问题**：使用DrawModifier进行复杂绘制时，有时会感觉性能下降，如何优化？

**解答**：优化DrawModifier性能的关键策略包括：

1. **使用drawWithCache代替drawBehind**：
    - `drawWithCache`可以缓存绘制结果，避免每次重组都重新计算
    - 特别适合复杂的绘制操作或路径计算
   ```kotlin
   Modifier.drawWithCache {
       // 在这里进行一次性计算
       val path = Path().apply {
           // 复杂路径计算...
       }
       
       onDrawBehind {
           // 使用预计算的path进行绘制
           drawPath(path, color)
       }
   }
   ```

2. **避免在绘制回调中创建对象**：
    - 每次重绘都创建新对象会增加GC压力
    - 预先计算并重用Path、Paint等对象
   ```kotlin
   // 不好的做法
   drawBehind {
       val paint = Paint()  // 每次重绘都创建新对象
       // ...
   }
   
   // 好的做法
   val paint = remember { Paint() }  // 只创建一次
   drawBehind {
       // 使用已创建的paint
   }
   ```

3. **使用remember缓存计算结果**：
    - 对于不经常变化的值，使用remember缓存
   ```kotlin
   val animatedValue by animateFloatAsState(/* ... */)
   val pathEffect = remember(animatedValue) {
       PathEffect.dashPathEffect(floatArrayOf(10f, 10f), animatedValue)
   }
   ```

4. **减少绘制区域**：
    - 只在必要的区域进行绘制
    - 使用clipRect限制绘制范围
   ```kotlin
   drawWithContent {
       clipRect(0f, 0f, size.width, size.height / 2) {
           // 只在上半部分绘制
           drawRect(color, size = size)
       }
       drawContent()
   }
   ```

5. **简化绘制操作**：
    - 复杂的路径可以考虑使用位图预渲染
    - 使用更简单的图形代替复杂路径
    - 减少不必要的透明度和混合模式

6. **避免频繁重绘**：
    - 控制状态变化的频率，避免不必要的重绘
    - 使用`derivedStateOf`或`snapshotFlow`减少状态更新

7. **使用硬件加速**：
    - 确保应用启用了硬件加速
    - 某些复杂的绘制操作可能不支持硬件加速，需要寻找替代方案

通过这些优化策略，你可以显著提高DrawModifier的性能，特别是在处理复杂绘制操作时。

### 4. 如何在DrawModifier中使用图像？

**问题**：我想在DrawModifier中绘制图像，应该如何操作？

**解答**：在DrawModifier中绘制图像有几种方法：

1. **使用drawImage函数**：
   ```kotlin
   Modifier.drawWithContent {
       // 先绘制内容
       drawContent()
       
       // 绘制图像
       drawImage(
           image = imageResource,
           topLeft = Offset(x, y)
       )
   }
   ```

2. **使用ImageBitmap**：
   ```kotlin
   // 加载图像资源
   val imageBitmap = ImageBitmap.imageResource(id = R.drawable.my_image)
   
   Modifier.drawWithContent {
       drawContent()
       
       // 绘制图像
       drawImage(
           image = imageBitmap,
           dstSize = IntSize(width, height),
           srcOffset = IntOffset(0, 0),
           srcSize = IntSize(imageBitmap.width, imageBitmap.height)
       )
   }
   ```

3. **应用图像滤镜效果**：
   ```kotlin
   val imageBitmap = ImageBitmap.imageResource(id = R.drawable.my_image)
   
   Modifier.drawWithContent {
       drawContent()
       
       // 应用滤镜效果
       val colorMatrix = ColorMatrix().apply {
           setToSaturation(0f)  // 黑白滤镜
       }
       
       val colorFilter = ColorFilter.colorMatrix(colorMatrix)
       
       drawImage(
           image = imageBitmap,
           colorFilter = colorFilter
       )
   }
   ```

4. **绘制图像作为背景或前景**：
   ```kotlin
   val imageBitmap = ImageBitmap.imageResource(id = R.drawable.my_image)
   
   Modifier.drawBehind {
       // 作为背景绘制图像
       drawImage(
           image = imageBitmap,
           dstSize = size.toIntSize(),
           alpha = 0.5f  // 半透明
       )
   }
   ```

5. **使用原生Canvas API**：
   ```kotlin
   val bitmap = BitmapFactory.decodeResource(context.resources, R.drawable.my_image)
   
   Modifier.drawWithContent {
       drawContent()
       
       // 使用原生Canvas API
       drawContext.canvas.nativeCanvas.drawBitmap(
           bitmap,
           null,
           android.graphics.Rect(0, 0, size.width.toInt(), size.height.toInt()),
           null
       )
   }
   ```

注意事项：

- 图像资源应该在绘制回调外加载，避免重复加载
- 大图像应考虑缩放处理，避免内存问题
- 使用`drawWithCache`缓存绘制结果，提高性能
- 考虑图像的尺寸和组件尺寸的关系，可能需要缩放或裁剪

通过这些方法，你可以在DrawModifier中灵活地使用图像资源，创建丰富的视觉效果。

### 5. 绘制顺序如何影响最终效果？

**问题**：在使用多个DrawModifier或组合drawBehind和drawWithContent时，绘制顺序如何影响最终效果？

**解答**：绘制顺序对最终视觉效果有重要影响，理解这些规则可以帮助你创建预期的效果：

1. **修饰符链中的绘制顺序**：
    - 修饰符链从外到内执行
    - 外层修饰符的背景绘制先于内层修饰符
    - 内层修饰符的内容绘制先于外层修饰符的前景绘制

   例如，在`Modifier.drawBehind { A }.drawBehind { B }`中：
    - 先绘制A（外层背景）
    - 再绘制B（内层背景）
    - 最后绘制内容

2. **drawWithContent中的绘制顺序**：
    - 绘制顺序完全由你的代码控制
    - `drawContent()`调用决定了内容的绘制时机
    - `drawContent()`之前的绘制作为背景
    - `drawContent()`之后的绘制作为前景

   ```kotlin
   drawWithContent {
       // 1. 这里的绘制先执行（背景）
       drawRect(Color.Blue)
       
       // 2. 然后绘制内容
       drawContent()
       
       // 3. 最后执行这里的绘制（前景）
       drawCircle(Color.Red)
   }
   ```

3. **组合多个绘制修饰符**：
    - 当组合多个绘制修饰符时，顺序非常重要

   ```kotlin
   // 示例1：先绘制蓝色背景，再绘制红色圆形
   Modifier
       .drawBehind { drawRect(Color.Blue) }
       .drawWithContent {
           drawContent()
           drawCircle(Color.Red)
       }
   
   // 示例2：先绘制红色圆形，再绘制蓝色背景（圆形会被背景覆盖）
   Modifier
       .drawWithContent {
           drawContent()
           drawCircle(Color.Red)
       }
       .drawBehind { drawRect(Color.Blue) }
   ```

4. **透明度和混合模式**：
    - 透明度和混合模式会影响叠加效果
    - 后绘制的内容会覆盖先绘制的内容，除非使用特殊的混合模式

   ```kotlin
   drawWithContent {
       // 使用半透明色
       drawRect(Color.Blue.copy(alpha = 0.5f))
       
       // 使用混合模式
       drawRect(
           color = Color.Red,
           blendMode = BlendMode.Multiply
       )
       
       drawContent()
   }
   ```

5. **裁剪区域**：
    - 裁剪操作会限制后续所有绘制的可见区域
    - 一旦设置了裁剪区域，无法扩大它，只能进一步缩小

   ```kotlin
   drawWithContent {
       // 设置裁剪区域为圆形
       clipPath(Path().apply {
           addOval(Rect(0f, 0f, size.width, size.height))
       }) {
           // 这里的所有绘制都被限制在圆形区域内
           drawRect(Color.Blue)
           drawContent()
       }
       
       // 这里的绘制不受上面裁剪的影响
       drawCircle(Color.Red)
   }
   ```

理解这些绘制顺序规则，可以帮助你精确控制视觉效果的叠加和组合，创建复杂而精美的UI效果。

```kotlin
@Composable
fun CustomBackgroundAnimationExercise() {
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp)
    ) {
        Text(
            text = "练习3：自定义背景动画",
            style = MaterialTheme.typography.headlineSmall,
            modifier = Modifier.padding(bottom = 16.dp)
        )
        
        // 创建动画状态
        val infiniteTransition = rememberInfiniteTransition(label = "background animation")
        val animatedValue by infiniteTransition.animateFloat(
            initialValue = 0f,
            targetValue = 1f,
            animationSpec = infiniteRepeatable(
                animation = tween(2000, easing = LinearEasing),
                repeatMode = RepeatMode.Restart
            ),
            label = "value animation"
        )
        
        // 粒子背景
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(300.dp)
                .padding(vertical = 16.dp)
                .clip(RoundedCornerShape(16.dp))
                .drawWithCache {
                    // 预先计算粒子位置
                    val random = Random(0)  // 固定种子以保持一致性
                    val particleCount = 50
                    val particles = List(particleCount) {
                        Particle(
                            x = random.nextFloat() * size.width,
                            y = random.nextFloat() * size.height,
                            radius = random.nextFloat() * 4.dp.toPx() + 1.dp.toPx(),
                            color = Color(
                                red = random.nextFloat(),
                                green = random.nextFloat(),
                                blue = random.nextFloat(),
                                alpha = random.nextFloat() * 0.5f + 0.1f
                            ),
                            speed = random.nextFloat() * 20.dp.toPx() + 5.dp.toPx()
                        )
                    }
                    
                    onDrawBehind {
                        // 绘制渐变背景
                        drawRect(
                            brush = Brush.linearGradient(
                                colors = listOf(
                                    Color(0xFF1A237E),
                                    Color(0xFF303F9F),
                                    Color(0xFF3949AB)
                                ),
                                start = Offset(0f, 0f),
                                end = Offset(size.width, size.height)
                            )
                        )
                        
                        // 绘制移动的粒子
                        particles.forEach { particle ->
                            // 计算动画后的Y位置
                            val animatedY = (particle.y + animatedValue * particle.speed) % size.height
                            
                            // 绘制粒子
                            drawCircle(
                                color = particle.color,
                                radius = particle.radius,
                                center = Offset(particle.x, animatedY)
                            )
                        }
                    }
                },
            contentAlignment = Alignment.Center
        ) {
            Text(
                text = "粒子动画背景",
                style = MaterialTheme.typography.headlineMedium,
                color = Color.White,
                fontWeight = FontWeight.Bold,
                modifier = Modifier
                    .background(Color.Black.copy(alpha = 0.3f), RoundedCornerShape(8.dp))
                    .padding(horizontal = 16.dp, vertical = 8.dp)
            )
        }
        
        Spacer(modifier = Modifier.height(32.dp))
        
        // 挑战提示
        Card(
            modifier = Modifier.fillMaxWidth(),
            elevation = CardDefaults.cardElevation(4.dp)
        ) {
            Column(
                modifier = Modifier.padding(16.dp)
            ) {
                Text(
                    text = "挑战：",
                    fontWeight = FontWeight.Bold,
                    modifier = Modifier.padding(bottom = 8.dp)
                )
                
                Text("1. 实现一个波浪动画背景")
                Text("2. 创建一个星空背景，带有闪烁效果")
                Text("3. 实现一个带有交互效果的背景，如触摸时产生涟漪效果")
            }
        }
    }
```
