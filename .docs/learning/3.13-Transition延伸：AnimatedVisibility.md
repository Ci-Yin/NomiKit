## 概念介绍

在Jetpack Compose的动画系统中，`AnimatedVisibility`是一个强大而灵活的API，它专门用于处理UI元素的显示和隐藏过程。与简单地设置
`visible = true/false`不同，`AnimatedVisibility`为这一过程添加了平滑的动画效果，使UI变化更加自然和专业。

`AnimatedVisibility`实际上是建立在我们前面学习的`Transition`
基础上的高级API，它封装了复杂的状态管理和动画逻辑，让开发者能够轻松实现元素的进入(Enter)和退出(Exit)
动画。

`AnimatedVisibility`的核心特点包括：

1. **声明式API**：符合Compose的声明式编程范式，使用简单直观。
2. **内置多种动画效果**：提供了丰富的预设动画，如淡入淡出、滑动、缩放等。
3. **可组合性**：可以组合多种动画效果，创建复杂的进入和退出动画。
4. **内容感知**：动画会考虑内容的尺寸变化，确保动画过程平滑。
5. **生命周期管理**：自动处理组件的生命周期，确保动画完成后才真正移除不可见的组件。

`AnimatedVisibility`特别适合以下场景：

- 对话框、提示框的显示和隐藏
- 列表项的添加和删除
- 详情页面的展开和折叠
- 导航转场效果
- 任何需要平滑过渡的UI元素可见性变化

通过掌握`AnimatedVisibility`，你将能够为应用添加专业的动画效果，提升用户体验，使界面变化更加流畅自然。

## 知识要点

- **核心API**：
    - `AnimatedVisibility()`：主要的可组合函数
    - `EnterTransition`：定义进入动画
    - `ExitTransition`：定义退出动画
    - `MutableTransitionState`：用于更精细地控制动画状态

- **基本参数**：
    - `visible`：控制可见性的布尔值
    - `enter`：进入动画效果
    - `exit`：退出动画效果
    - `modifier`：应用于容器的修饰符
    - `label`：用于调试的标签
    - `content`：要显示的内容

- **预设动画效果**：
    - **进入动画**：
        - `fadeIn`：淡入效果
        - `slideIn`：滑动进入
        - `expandIn`：从中心点扩展
        - `scaleIn`：缩放进入

    - **退出动画**：
        - `fadeOut`：淡出效果
        - `slideOut`：滑动退出
        - `shrinkOut`：向中心点收缩
        - `scaleOut`：缩放退出

- **动画组合**：
    - 使用`+`操作符组合多个动画效果
    - 例如：`fadeIn() + slideInVertically()`

- **动画自定义**：
    - 通过`tween`、`spring`等指定动画规格
    - 自定义初始偏移量和方向
    - 调整动画时序和缓动函数

- **内容变化处理**：
    - `AnimatedVisibility`会自动处理内容大小的变化
    - 可以使用`SizeTransform`自定义大小变化动画

- **高级用法**：
    - `MutableTransitionState`：手动控制动画状态
    - `animateEnterExit`修饰符：为现有组件添加动画
    - 子元素的单独动画：使用`animateEnterExit`修饰符

- **性能考虑**：
    - 不可见状态下的组合树管理
    - 避免在动画过程中进行复杂计算
    - 合理使用`remember`缓存状态

## 基础代码示例

### 简单的淡入淡出效果

下面是一个基本的例子，展示了如何使用`AnimatedVisibility`创建一个带有淡入淡出效果的卡片：

```kotlin
@Composable
fun SimpleAnimatedVisibilityExample() {
    // 控制可见性的状态
    var isVisible by remember { mutableStateOf(false) }
    
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(
            text = "AnimatedVisibility 基础示例",
            style = MaterialTheme.typography.headlineMedium,
            modifier = Modifier.padding(bottom = 32.dp)
        )
        
        // 切换按钮
        Button(
            onClick = { isVisible = !isVisible },
            modifier = Modifier.padding(bottom = 24.dp)
        ) {
            Text(if (isVisible) "隐藏卡片" else "显示卡片")
        }
        
        // AnimatedVisibility组件
        AnimatedVisibility(
            visible = isVisible,
            enter = fadeIn(animationSpec = tween(durationMillis = 500)),
            exit = fadeOut(animationSpec = tween(durationMillis = 500))
        ) {
            Card(
                modifier = Modifier
                    .fillMaxWidth()
                    .height(200.dp)
                    .padding(16.dp),
                elevation = CardDefaults.cardElevation(defaultElevation = 4.dp),
                colors = CardDefaults.cardColors(containerColor = Color(0xFF6200EE))
            ) {
                Box(
                    modifier = Modifier.fillMaxSize(),
                    contentAlignment = Alignment.Center
                ) {
                    Text(
                        text = "这是一个带有动画效果的卡片",
                        color = Color.White,
                        fontWeight = FontWeight.Bold
                    )
                }
            }
        }
    }
}
```

### 使用不同的进入和退出方向

下面的例子展示了如何为列表项创建不同方向的进入和退出动画：

```kotlin
@Composable
fun DirectionalAnimatedVisibilityExample() {
    // 列表项状态
    val items = remember { mutableStateListOf("项目 1", "项目 2", "项目 3") }
    
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp)
    ) {
        Text(
            text = "方向性动画示例",
            style = MaterialTheme.typography.headlineMedium,
            modifier = Modifier.padding(bottom = 32.dp)
        )
        
        // 添加和删除按钮
        Row(
            modifier = Modifier
                .fillMaxWidth()
                .padding(bottom = 16.dp),
            horizontalArrangement = Arrangement.SpaceBetween
        ) {
            Button(
                onClick = {
                    items.add("项目 ${items.size + 1}")
                }
            ) {
                Text("添加项目")
            }
            
            Button(
                onClick = {
                    if (items.isNotEmpty()) {
                        items.removeLast()
                    }
                },
                enabled = items.isNotEmpty()
            ) {
                Text("删除项目")
            }
        }
        
        // 列表项
        LazyColumn(
            modifier = Modifier.fillMaxWidth()
        ) {
            items(items) { item ->
                // 为每个列表项添加动画
                AnimatedVisibility(
                    visible = true,
                    enter = slideInHorizontally(
                        initialOffsetX = { fullWidth -> fullWidth }, // 从右侧进入
                        animationSpec = tween(
                            durationMillis = 300,
                            easing = FastOutSlowInEasing
                        )
                    ) + fadeIn(
                        animationSpec = tween(durationMillis = 300)
                    ),
                    exit = slideOutHorizontally(
                        targetOffsetX = { fullWidth -> -fullWidth }, // 向左侧退出
                        animationSpec = tween(
                            durationMillis = 300,
                            easing = FastOutSlowInEasing
                        )
                    ) + fadeOut(
                        animationSpec = tween(durationMillis = 300)
                    )
                ) {
                    Card(
                        modifier = Modifier
                            .fillMaxWidth()
                            .padding(vertical = 8.dp),
                        elevation = CardDefaults.cardElevation(defaultElevation = 2.dp)
                    ) {
                        Text(
                            text = item,
                            modifier = Modifier
                                .fillMaxWidth()
                                .padding(16.dp),
                            style = MaterialTheme.typography.bodyLarge
                        )
                    }
                }
            }
        }
    }
}
```

### 使用MutableTransitionState手动控制动画

在某些情况下，你可能需要更精细地控制动画状态，这时可以使用`MutableTransitionState`：

```kotlin
@Composable
fun MutableTransitionStateExample() {
    // 创建并记住一个MutableTransitionState
    val state = remember {
        MutableTransitionState(false).apply {
            // 初始状态为false（不可见），但立即开始向true（可见）过渡
            targetState = true
        }
    }
    
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(
            text = "MutableTransitionState示例",
            style = MaterialTheme.typography.headlineMedium,
            modifier = Modifier.padding(bottom = 32.dp)
        )
        
        // 显示当前状态
        Text(
            text = "当前状态: ${if (state.currentState) "可见" else "不可见"}",
            style = MaterialTheme.typography.bodyLarge,
            modifier = Modifier.padding(bottom = 8.dp)
        )
        
        Text(
            text = "目标状态: ${if (state.targetState) "可见" else "不可见"}",
            style = MaterialTheme.typography.bodyLarge,
            modifier = Modifier.padding(bottom = 16.dp)
        )
        
        // 状态控制按钮
        Button(
            onClick = { state.targetState = !state.targetState },
            modifier = Modifier.padding(bottom = 24.dp)
        ) {
            Text("切换目标状态")
        }
        
        // 使用MutableTransitionState
        AnimatedVisibility(
            visibleState = state,
            enter = expandIn(
                animationSpec = spring(
                    dampingRatio = Spring.DampingRatioMediumBouncy,
                    stiffness = Spring.StiffnessLow
                ),
                expandFrom = Alignment.Center
            ) + fadeIn(),
            exit = shrinkOut(
                animationSpec = tween(durationMillis = 300),
                shrinkTowards = Alignment.Center
            ) + fadeOut()
        ) {
            Card(
                modifier = Modifier
                    .size(200.dp)
                    .padding(16.dp),
                colors = CardDefaults.cardColors(containerColor = Color(0xFF6200EE))
            ) {
                Box(
                    modifier = Modifier.fillMaxSize(),
                    contentAlignment = Alignment.Center
                ) {
                    Text(
                        text = "使用MutableTransitionState\n控制动画状态",
                        color = Color.White,
                        fontWeight = FontWeight.Bold,
                        textAlign = TextAlign.Center
                    )
                }
            }
        }
        
        // 显示动画状态
        if (state.isIdle) {
            Text(
                text = "动画已完成",
                style = MaterialTheme.typography.bodyMedium,
                color = Color.Gray,
                modifier = Modifier.padding(top = 16.dp)
            )
        } else {
            Text(
                text = "动画进行中...",
                style = MaterialTheme.typography.bodyMedium,
                color = Color(0xFF03DAC5),
                modifier = Modifier.padding(top = 16.dp)
            )
        }
    }
}
```

```kotlin
@Composable
fun CustomEnterExitAnimationExample() {
    var isVisible by remember { mutableStateOf(false) }
    
    // 自定义进入动画 - 旋转淡入
    val customEnterTransition = remember {
        fadeIn(animationSpec = tween(durationMillis = 500)) +
        scaleIn(
            animationSpec = tween(durationMillis = 500),
            initialScale = 0.8f
        ) + 
        // 添加旋转效果
        EnterTransition.None.plus(
            createFloatAnimationSpec = { tween<Float>(durationMillis = 500) },
            initialValue = -30f,
            targetValue = 0f,
            createAnimator = { _, _, animationSpec, finishedListener ->
                Animatable(-30f).apply {
                    updateBehavior = SnapToNewValues
                    animateTo(0f, animationSpec, finishedListener)
                }
            },
            onAnimationUpdate = { value, target ->
                target.rotationZ = value
            }
        )
    }
    
    // 自定义退出动画 - 旋转淡出
    val customExitTransition = remember {
        fadeOut(animationSpec = tween(durationMillis = 500)) +
        scaleOut(
            animationSpec = tween(durationMillis = 500),
            targetScale = 0.8f
        ) + 
        // 添加旋转效果
        ExitTransition.None.plus(
            createFloatAnimationSpec = { tween<Float>(durationMillis = 500) },
            initialValue = 0f,
            targetValue = 30f,
            createAnimator = { _, _, animationSpec, finishedListener ->
                Animatable(0f).apply {
                    updateBehavior = SnapToNewValues
                    animateTo(30f, animationSpec, finishedListener)
                }
            },
            onAnimationUpdate = { value, target ->
                target.rotationZ = value
            }
        )
    }
    
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(
```

## 常见问题

### AnimatedVisibility和if条件渲染的区别

**问题**：为什么要使用AnimatedVisibility而不是简单的if条件渲染？

**解答**：
虽然使用if条件可以控制组件的显示和隐藏，但`AnimatedVisibility`提供了几个关键优势：

1. **平滑过渡**：`AnimatedVisibility`添加动画效果，使UI变化更加自然流畅，而if条件会导致组件突然出现或消失。

2. **生命周期管理**：`AnimatedVisibility`在动画完成后才真正移除组件，而if条件会立即添加或移除组件。

3. **内容保留**：在退出动画过程中，内容仍然存在，这允许动画正确完成。

4. **状态保持**：`AnimatedVisibility`可以在动画过程中保持组件的状态。

示例对比：

```kotlin
// 使用if条件（没有动画）
if (isVisible) {
    Card { /* 内容 */ }
}

// 使用AnimatedVisibility（有动画）
AnimatedVisibility(visible = isVisible) {
    Card { /* 内容 */ }
}
```

当需要平滑的过渡效果时，`AnimatedVisibility`是更好的选择。

### 如何处理AnimatedVisibility中的内容大小变化

**问题**：当AnimatedVisibility中的内容大小在动画过程中变化时，如何确保平滑过渡？

**解答**：
`AnimatedVisibility`内部使用`SizeTransform`来处理内容大小的变化。默认情况下，它会自动处理大小变化，但你也可以自定义这一行为：

**方法1：使用默认行为**

默认情况下，`AnimatedVisibility`会平滑处理内容大小的变化：

```kotlin
AnimatedVisibility(visible = isVisible) {
    // 内容大小可以变化，AnimatedVisibility会自动处理
    if (isExpanded) {
        LargeContent()
    } else {
        SmallContent()
    }
}
```

**方法2：自定义SizeTransform**

对于更精细的控制，可以使用`sizeTransform`参数：

```kotlin
AnimatedVisibility(
    visible = isVisible,
    enter = fadeIn() + expandIn(
        expandFrom = Alignment.TopStart,
        // 自定义大小变化动画
        sizeTransform = SizeTransform { initialSize, targetSize ->
            if (targetSize.width > initialSize.width) {
                // 当宽度增加时，先水平扩展，再垂直扩展
                keyframes {
                    // 先水平扩展
                    IntSize(targetSize.width, initialSize.height) at 150
                    // 然后垂直扩展
                    durationMillis = 300
                }
            } else {
                // 当宽度减少时，先垂直收缩，再水平收缩
                keyframes {
                    // 先垂直收缩
                    IntSize(initialSize.width, targetSize.height) at 150
                    // 然后水平收缩
                    durationMillis = 300
                }
            }
        }
    )
) {
    // 内容
}
```

通过自定义`SizeTransform`，你可以精确控制内容大小变化的动画过程。

### 如何在列表中使用AnimatedVisibility

**问题**：如何在LazyColumn或LazyRow中为列表项添加动画？

**解答**：
在列表中使用`AnimatedVisibility`需要注意几个关键点：

**方法1：基本用法**

将`AnimatedVisibility`包装在列表项内部：

```kotlin
LazyColumn {
    items(itemList) { item ->
        AnimatedVisibility(
            visible = item.isVisible,
            enter = slideInVertically() + fadeIn(),
            exit = slideOutVertically() + fadeOut()
        ) {
            ListItemContent(item)
        }
    }
}
```

**方法2：使用key确保正确的动画**

为了确保正确的动画行为，特别是在项目添加或删除时，使用`key`参数：

```kotlin
LazyColumn {
    items(
        items = itemList,
        key = { it.id } // 使用唯一标识符作为key
    ) { item ->
        AnimatedVisibility(
            visible = true, // 始终可见，但会在添加/删除时触发动画
            enter = slideInVertically() + fadeIn(),
            exit = slideOutVertically() + fadeOut()
        ) {
            ListItemContent(item)
        }
    }
}
```

**方法3：使用animateItemPlacement**

对于项目位置变化的动画，可以结合使用`animateItemPlacement`修饰符：

```kotlin
LazyColumn {
    items(
        items = itemList,
        key = { it.id }
    ) { item ->
        AnimatedVisibility(
            visible = item.isVisible,
            enter = slideInVertically() + fadeIn(),
            exit = slideOutVertically() + fadeOut()
        ) {
            ListItemContent(
                item = item,
                modifier = Modifier.animateItemPlacement(
                    animationSpec = spring(
                        dampingRatio = Spring.DampingRatioMediumBouncy
                    )
                )
            )
        }
    }
}
```

通过这些技术，你可以为列表项添加流畅的进入、退出和位置变化动画。

### 如何处理AnimatedVisibility的性能问题

**问题**：在使用AnimatedVisibility时，如何避免性能问题？

**解答**：
`AnimatedVisibility`虽然强大，但不当使用可能导致性能问题。以下是一些优化建议：

1. **避免嵌套过多的AnimatedVisibility**：
   嵌套多层`AnimatedVisibility`会增加布局复杂度和动画计算开销。

   ```kotlin
   // 不推荐
   AnimatedVisibility(visible = isVisible) {
       AnimatedVisibility(visible = isExpanded) {
           AnimatedVisibility(visible = isSelected) {
               // 内容
           }
       }
   }
   
   // 推荐：合并条件或使用不同的动画方式
   AnimatedVisibility(visible = isVisible && isExpanded && isSelected) {
       // 内容
   }
   ```

2. **使用remember缓存状态和动画规格**：
   避免在每次重组时创建新的动画规格。

   ```kotlin
   // 推荐：缓存动画规格
   val enterTransition = remember {
       fadeIn() + slideInVertically()
   }
   
   AnimatedVisibility(
       visible = isVisible,
       enter = enterTransition
   ) {
       // 内容
   }
   ```

3. **避免在动画过程中进行复杂计算**：
   在动画过程中，尽量避免执行复杂的计算或操作。

4. **使用LaunchedEffect处理副作用**：
   如果需要在可见性变化时执行副作用，使用`LaunchedEffect`而不是在内容中直接执行。

   ```kotlin
   AnimatedVisibility(visible = isVisible) {
       // 使用LaunchedEffect处理副作用
       LaunchedEffect(Unit) {
           // 执行副作用，例如加载数据
           loadData()
       }
       
       // 内容
   }
   ```

5. **考虑使用animateContentSize替代**：
   对于简单的大小变化动画，可以考虑使用`Modifier.animateContentSize()`，它的开销可能更小。

   ```kotlin
   Box(
       modifier = Modifier
           .animateContentSize()
           .height(if (isExpanded) 200.dp else 100.dp)
   ) {
       // 内容
   }
   ```

通过这些优化技术，你可以在保持流畅动画效果的同时，最小化性能开销。
