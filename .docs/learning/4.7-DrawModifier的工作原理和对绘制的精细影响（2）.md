## 概念介绍

在上一节中，我们学习了DrawModifier的基本原理和常用的绘制函数`drawBehind()`和`drawWithContent()`
。本节将深入探讨DrawModifier的高级特性，特别是性能优化相关的`drawWithCache()`
函数，以及更复杂的绘制技术，如混合模式、裁剪操作和图层效果。

`drawWithCache()`
是DrawModifier提供的一个强大优化工具，它允许我们缓存绘制操作的计算结果，避免在每次重组时重新计算复杂的绘制逻辑。这对于包含复杂路径计算、大量对象创建或其他计算密集型操作的绘制尤为重要。

混合模式（Blend
Modes）允许我们控制绘制内容如何与下层内容混合，创造出丰富的视觉效果。Compose支持多种混合模式，如正片叠底（Multiply）、滤色（Screen）、叠加（Overlay）等，每种模式都有其独特的视觉效果。

裁剪操作（Clipping）允许我们限制绘制区域，确保绘制内容只在特定形状内可见。这对于创建不规则形状的UI组件、蒙版效果或特殊视觉效果非常有用。

图层效果（Layer Effects）如阴影、模糊等，可以增强UI的深度感和视觉层次。通过DrawModifier，我们可以精确控制这些效果的应用方式和参数。

本节将通过实际示例，展示这些高级特性如何应用于实际开发中，以创建更加精美和高效的UI效果。

## 知识要点

- **drawWithCache的使用**：
    - 缓存绘制计算结果，提高性能
    - 适用于复杂路径计算和大量对象创建的场景
    - 通过`onDrawBehind`、`onDrawWithContent`等回调控制绘制

- **混合模式（Blend Modes）**：
    - 控制绘制内容如何与下层内容混合
    - 常用混合模式：SrcOver、SrcIn、SrcOut、DstIn、Multiply、Screen、Overlay等
    - 通过`blendMode`参数应用于绘制操作

- **裁剪操作（Clipping）**：
    - `clipRect`：矩形裁剪
    - `clipRoundRect`：圆角矩形裁剪
    - `clipPath`：自定义路径裁剪
    - `clipOval`：椭圆裁剪
    - 裁剪操作的嵌套和组合

- **图层效果**：
    - 使用`graphicsLayer`应用变换和效果
    - 阴影效果的实现
    - 模糊效果的实现
    - 透明度和色彩滤镜

- **绘制状态管理**：
    - 使用`remember`缓存绘制相关对象
    - 状态变化时的绘制更新策略
    - 避免不必要的重绘

- **坐标变换**：
    - `translate`：平移变换
    - `rotate`：旋转变换
    - `scale`：缩放变换
    - 变换的组合和顺序

- **高级绘制技术**：
    - 渐变填充：线性渐变、径向渐变、扫描渐变
    - 路径动画和变形
    - 蒙版效果和图像处理

### 使用drawWithCache优化性能

```kotlin
@Composable
fun DrawWithCacheExample() {
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp)
    ) {
        Text(
            text = "使用drawWithCache优化性能",
            style = MaterialTheme.typography.headlineSmall,
            modifier = Modifier.padding(bottom = 16.dp)
        )

        // 简单的drawWithCache示例
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(150.dp)
                .padding(8.dp)
                .drawWithCache {
                    // 在这里进行一次性计算
                    val width = size.width
                    val height = size.height
                    val path = Path().apply {
                        // 创建一个波浪形状
                        moveTo(0f, height * 0.6f)

                        val segmentWidth = width / 10
                        for (i in 1..10) {
                            val x = i * segmentWidth
                            val y = height * 0.6f + 
                                    sin(i * Math.PI / 5) * height * 0.1f
                            lineTo(x.toFloat(), y.toFloat())
                        }

                        lineTo(width, height)
                        lineTo(0f, height)
                        close()
                    }

                    // 创建渐变
                    val brush = Brush.linearGradient(
                        colors = listOf(
                            Color(0xFF2196F3),
                            Color(0xFF03A9F4),
                            Color(0xFF00BCD4)
                        ),
                        start = Offset(0f, 0f),
                        end = Offset(width, height)
                    )

                    // 返回绘制操作
                    onDrawBehind {
                        // 绘制背景
                        drawRect(
                            color = Color(0xFFF5F5F5),
                            size = size
                        )

                        // 绘制波浪
                        drawPath(
                            path = path,
                            brush = brush
                        )
                    }
                },
            contentAlignment = Alignment.Center
        ) {
            Text(
                text = "缓存的波浪背景",
                color = Color.White,
                fontWeight = FontWeight.Bold,
                modifier = Modifier
                    .align(Alignment.BottomCenter)
                    .padding(bottom = 16.dp)
            )
        }

        Spacer(modifier = Modifier.height(24.dp))

        // 复杂路径计算的缓存示例
        val animatedProgress = remember { Animatable(0f) }

        LaunchedEffect(Unit) {
            animatedProgress.animateTo(
                targetValue = 1f,
                animationSpec = tween(2000, easing = LinearEasing)
            )
        }

        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(150.dp)
                .padding(8.dp)
                .drawWithCache {
                    // 预计算星形路径
                    val starPath = Path()
                    val centerX = size.width / 2
                    val centerY = size.height / 2
                    val outerRadius = minOf(centerX, centerY) * 0.8f
                    val innerRadius = outerRadius * 0.4f

                    val angleStep = 360f / 10
                    val startAngle = -90f

                    // 创建星形路径
                    for (i in 0..10) {
                        val angle = startAngle + i * angleStep
                        val radius = if (i % 2 == 0) outerRadius else innerRadius
                        val x = centerX + radius * cos(Math.toRadians(angle.toDouble())).toFloat()
                        val y = centerY + radius * sin(Math.toRadians(angle.toDouble())).toFloat()

                        if (i == 0) {
                            starPath.moveTo(x, y)
                        } else {
                            starPath.lineTo(x, y)
                        }
                    }

                    starPath.close()

                    onDrawBehind {
                        // 绘制背景
                        drawRect(
                            color = Color(0xFFFFF8E1),
                            size = size
                        )

                        // 应用动画进度
                        val progress = animatedProgress.value

                        // 创建裁剪路径
                        val clipPath = Path().apply {
                            addPath(starPath)

                            // 创建一个矩形路径用于裁剪
                            val clipRect = Rect(
                                left = 0f,
                                top = 0f,
                                right = size.width * progress,
                                bottom = size.height
                            )

                            op(asAndroidPath(), 
                               Path().apply { addRect(clipRect) }.asAndroidPath(), 
                               PathOperation.INTERSECT)
                        }

                        // 绘制星形
                        drawPath(
                            path = starPath,
                            color = Color.LightGray,
                            style = Stroke(width = 2.dp.toPx())
                        )

                        // 绘制填充部分
                        drawPath(
                            path = clipPath,
                            color = Color(0xFFFFC107)
                        )
                    }
                },
            contentAlignment = Alignment.Center
        ) {
            Text(
                text = "进度动画 ${(animatedProgress.value * 100).toInt()}%",
                fontWeight = FontWeight.Bold,
                modifier = Modifier
                    .background(Color.White.copy(alpha = 0.7f), RoundedCornerShape(4.dp))
                    .padding(horizontal = 8.dp, vertical = 4.dp)
            )
        }
    }
}
```

```kotlin
@Composable
fun ClippingExample(
    title: String,
    clipBlock: DrawScope.(content: DrawScope.() -> Unit) -> Unit
) {
    Column(
        modifier = Modifier.fillMaxWidth()
    ) {
        Text(
            text = title,
            style = MaterialTheme.typography.titleMedium,
            modifier = Modifier.padding(bottom = 8.dp)
        )

        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(200.dp)
                .background(Color.LightGray)
                .drawWithContent {
                    // 应用裁剪
                    clipBlock {
                        // 绘制网格背景
                        val gridSize = 20.dp.toPx()
                        val strokeWidth = 1.dp.toPx()

                        // 绘制横线
                        var y = 0f
                        while (y <= size.height) {
                            drawLine(
                                color = Color.White,
                                start = Offset(0f, y),
                                end = Offset(size.width, y),
                                strokeWidth = strokeWidth
                            )
                            y += gridSize
                        }

                        // 绘制竖线
                        var x = 0f
                        while (x <= size.width) {
                            drawLine(
                                color = Color.White,
                                start = Offset(x, 0f),
                                end = Offset(x, size.height),
                                strokeWidth = strokeWidth
                            )
                            x += gridSize
                        }

                        // 绘制彩色圆形
                        val colors = listOf(
                            Color.Red, Color.Green, Color.Blue,
                            Color.Yellow, Color.Cyan, Color.Magenta
                        )

                        for (i in 0 until 6) {
                            val cx = size.width * (0.2f + 0.15f * i)
                            val cy = size.height * (0.3f + 0.1f * sin(i * Math.PI / 3))

                            drawCircle(
                                color = colors[i],
                                radius = 30.dp.toPx(),
                                center = Offset(cx, cy)
                            )
                        }
                    }

                    // 绘制边框
                    drawRect(
                        color = Color.Black,
                        style = Stroke(width = 2.dp.toPx())
                    )
                }
        )
    }
}
```

```kotlin
@Composable
fun LayerEffectsExample() {
    Column(
        modifier = Modifier

    ) {
        Text(

            style = MaterialTheme.typography.headlineSmall,

            modifier = Modifier
                .fillMaxWidth()
                .padding(8.dp),
            elevation = CardDefaults.cardElevation(0.dp)
        ) {
            Column(
                modifier = Modifier.padding(16.dp)
            ) {
                Text(
                    text = "自定义阴影效果",
                    style = MaterialTheme.typography.titleMedium,
                    modifier = Modifier.padding(bottom = 8.dp)
                )

                Box(
                    modifier = Modifier
                        .fillMaxWidth()
                        .height(150.dp)
                        .drawWithCache {
                            val shadowColor = Color.Black.copy(alpha = 0.3f)
                            val shadowRadius = 16.dp.toPx()
                            val shadowOffset = Offset(8f, 8f)

                            val transparentColor = Color.Transparent
                            val path = Path().apply {
                                addRoundRect(
                                    RoundRect(
                                        rect = Rect(
                                            left = 0f,
                                            top = 0f,
                                            right = size.width,
                                            bottom = size.height
                                        ),
                                        cornerRadius = CornerRadius(16.dp.toPx(), 16.dp.toPx())
                                    )
                                )
                            }

                            onDrawBehind {
                                // 绘制阴影
                                translate(shadowOffset.x, shadowOffset.y) {
                                    drawPath(
                                        path = path,
                                        color = shadowColor,
                                        style = Fill,
                                        blendMode = BlendMode.SrcOver
                                    )
                                }

                                // 绘制主体
                                drawPath(
                                    path = path,
                                    color = Color.White,
                                    style = Fill
                                )

                                // 绘制边框
                                drawPath(
                                    path = path,
                                    color = Color(0xFFE0E0E0),
                                    style = Stroke(width = 1.dp.toPx())
                                )
                            }
                        },
                    contentAlignment = Alignment.Center
                ) {
                    Text(
                        text = "自定义阴影",
                        style = MaterialTheme.typography.bodyLarge
                    )
                }
            }
        }

        Spacer(modifier = Modifier.height(16.dp))

        // 模糊效果
        Card(
            modifier = Modifier
                .fillMaxWidth()
                .padding(8.dp),
            elevation = CardDefaults.cardElevation(0.dp)
        ) {
            Column(
                modifier = Modifier.padding(16.dp)
            ) {
                Text(
                    text = "模糊效果",
                    style = MaterialTheme.typography.titleMedium,
                    modifier = Modifier.padding(bottom = 8.dp)
                )

                var blurRadius by remember { mutableStateOf(5.dp) }

                // 滑块控制模糊半径
                Column(
                    modifier = Modifier.padding(vertical = 8.dp)
                ) {
                    Text(
                        text = "模糊半径: ${blurRadius.value.toInt()} dp",
                        style = MaterialTheme.typography.bodyMedium
                    )

                    Slider(
                        value = blurRadius.value,
                        onValueChange = { blurRadius = it.dp },
                        valueRange = 0f..20f,
                        modifier = Modifier.padding(vertical = 8.dp)
                    )
                }

                // 模糊效果示例
                Box(
                    modifier = Modifier
                        .fillMaxWidth()
                        .height(150.dp)
                        .clip(RoundedCornerShape(8.dp))
                        .background(Color.White)
                ) {
                    // 背景内容
                    Box(
                        modifier = Modifier.fillMaxSize()
                    ) {
                        // 绘制一些彩色圆形作为背景
                        Canvas(modifier = Modifier.fillMaxSize()) {
                            val colors = listOf(
                                Color(0xFF2196F3), Color(0xFF4CAF50), 
                                Color(0xFFFFC107), Color(0xFFF44336),
                                Color(0xFF9C27B0), Color(0xFF009688)
                            )

                            for (i in 0 until 20) {
                                val x = Random.nextFloat() * size.width
                                val y = Random.nextFloat() * size.height
                                val radius = (10 + Random.nextFloat() * 30).dp.toPx()

                                drawCircle(
                                    color = colors[i % colors.size].copy(alpha = 0.7f),
                                    radius = radius,
                                    center = Offset(x, y)
                                )
                            }
                        }
                    }

                    // 模糊层
                    Box(
                        modifier = Modifier
                            .fillMaxWidth()
                            .height(70.dp)
                            .align(Alignment.BottomCenter)
                            .graphicsLayer {
                                if (blurRadius > 0.dp) {
                                    renderEffect = BlurEffect(
                                        radiusX = blurRadius.toPx(),
                                        radiusY = blurRadius.toPx(),
                                        edgeTreatment = TileMode.Decal
                                    )
                                }
                                alpha = 0.9f
                            }
                            .background(Color.White.copy(alpha = 0.5f)),
                        contentAlignment = Alignment.Center
                    ) {
                        Text(
                            text = "模糊效果示例",
                            style = MaterialTheme.typography.titleMedium,
                            fontWeight = FontWeight.Bold
                        )
                    }
                }
            }
        }
    }
}
```

## 常见问题

### 1. drawWithCache和drawBehind的区别是什么？

**问题**：`drawWithCache`和`drawBehind`有什么区别？什么情况下应该使用`drawWithCache`？

**解答**：`drawWithCache`和`drawBehind`的主要区别在于性能优化和使用场景：

1. **缓存机制**：
    - `drawWithCache`：提供缓存机制，可以缓存绘制计算结果，避免在每次重组时重新计算
    - `drawBehind`：每次重组都会重新执行所有绘制计算

2. **使用场景**：
    - 使用`drawWithCache`的情况：
        - 复杂的路径计算
        - 需要创建大量临时对象的绘制操作
        - 计算密集型的绘制逻辑
        - 绘制内容不经常变化的情况

    - 使用`drawBehind`的情况：
        - 简单的绘制操作
        - 绘制逻辑依赖于频繁变化的状态
        - 不需要复杂计算的场景

3. **API结构**：
    - `drawWithCache`：提供`onDrawBehind`、`onDrawWithContent`等回调函数，可以更灵活地控制绘制
    - `drawBehind`：直接提供一个绘制回调函数，更简洁但功能相对有限

4. **代码示例对比**：

```kotlin
// drawBehind示例
Modifier.drawBehind {
    // 每次重组都会执行的计算
    val path = Path().apply {
        // 复杂路径计算...
    }
    drawPath(path, color)
}

// drawWithCache示例
Modifier.drawWithCache {
    // 只在缓存失效时执行的计算
    val path = Path().apply {
        // 复杂路径计算...
    }

    onDrawBehind {
        // 使用缓存的path进行绘制
        drawPath(path, color)
    }
}
```

总之，如果你的绘制操作包含复杂计算或创建大量对象，应该使用`drawWithCache`
来提高性能；如果是简单的绘制操作或依赖于频繁变化的状态，可以使用更简洁的
`drawBehind`。

### 2. 如何正确使用混合模式？

**问题**：Compose中的混合模式（BlendMode）有很多种，如何选择合适的混合模式来实现特定效果？

**解答**：混合模式控制了绘制内容如何与下层内容混合，选择合适的混合模式需要了解各种模式的特性：

1. **常用混合模式及其效果**：
    - `SrcOver`（默认）：新内容覆盖在旧内容上，考虑透明度
    - `Multiply`（正片叠底）：混合颜色总是更暗，类似两张透明胶片叠加
    - `Screen`（滤色）：混合颜色总是更亮，适合创建发光效果
    - `Overlay`（叠加）：保留高光和阴影，增强对比度
    - `Darken`（变暗）：保留两层中较暗的部分
    - `Lighten`（变亮）：保留两层中较亮的部分
    - `ColorDodge`（颜色减淡）：使底层颜色更亮，创建发光效果
    - `ColorBurn`（颜色加深）：使底层颜色更暗，增加对比度
    - `Difference`（差值）：从较亮的颜色中减去较暗的颜色，创建反相效果

2. **选择混合模式的指南**：
    - 创建阴影或深色效果：使用`Multiply`或`ColorBurn`
    - 创建发光或高光效果：使用`Screen`或`ColorDodge`
    - 增强对比度：使用`Overlay`
    - 创建蒙版效果：使用`DstIn`（保留重叠部分的底层）或`SrcIn`（保留重叠部分的顶层）
    - 创建剪切效果：使用`DstOut`（移除重叠部分的底层）或`SrcOut`（移除重叠部分的顶层）

3. **实际应用示例**：

```kotlin
// 创建发光效果
drawCircle(
    color = Color.Yellow,
    radius = 50f,
    blendMode = BlendMode.Screen
)

// 创建阴影效果
drawCircle(
    color = Color.Black.copy(alpha = 0.5f),
    radius = 50f,
    blendMode = BlendMode.Multiply
)

// 创建蒙版效果
drawRect(
    color = Color.White,
    blendMode = BlendMode.DstIn
)
```

4. **测试和实验**：
    - 混合模式的效果可能难以预测，特别是与透明度结合时
    - 建议创建一个测试组件，尝试不同的混合模式来找到最适合的效果
    - 记住混合模式的顺序很重要，A混合B与B混合A的结果可能完全不同

通过理解各种混合模式的特性并进行实验，你可以创建出丰富多样的视觉效果，如发光按钮、动态阴影、创意蒙版等。

### 3. 裁剪操作的性能影响是什么？

**问题**：裁剪操作（如clipRect、clipPath等）会对性能产生什么影响？有哪些优化策略？

**解答**：裁剪操作对性能的影响及优化策略如下：

1. **性能影响**：
    - 简单形状裁剪（如矩形）：性能影响较小，通常可以被硬件加速
    - 复杂路径裁剪：可能导致性能下降，特别是在动画或频繁重绘时
    - 嵌套裁剪：多层嵌套的裁剪操作会累积性能开销
    - 抗锯齿裁剪：启用抗锯齿会增加性能开销，但提高视觉质量

2. **优化策略**：
    - **使用简单形状**：尽可能使用矩形或圆形等简单形状进行裁剪

  ```kotlin
  // 优先使用这个（性能更好）
  clipRect(left = 0f, top = 0f, right = 100f, bottom = 100f) // 示例参数

  // 而不是这个（对于矩形裁剪）
  clipPath(Path().apply { addRect(0f, 0f, 100f, 100f) }) // 示例参数
  ```

- **缓存复杂路径**：使用`drawWithCache`缓存复杂的裁剪路径

  ```kotlin
  drawWithCache {
      val clipPath = Path().apply {
          // 复杂路径计算...
      }

      onDrawWithContent {
          clipPath(clipPath) {
              drawContent()
          }
      }
  }
  ```

- **减少裁剪区域变化**：避免频繁改变裁剪区域，特别是在动画中

- **合并裁剪操作**：将多个裁剪操作合并为一个

  ```kotlin
  // 不好的做法
  clipRect(left = 0f, top = 0f, right = 100f, bottom = 100f) {
      clipRect(left = 25f, top = 25f, right = 75f, bottom = 75f) {
          // 绘制内容
      }
  }

  // 更好的做法
  val combinedPath = Path().apply {
      // 合并多个裁剪区域...
  }
  clipPath(combinedPath) {
      // 绘制内容
  }
  ```

- **使用图层**：对于复杂的裁剪效果，考虑使用离屏渲染

  ```kotlin
  Canvas(modifier = Modifier.fillMaxSize()) {
      // 创建离屏图层
      withLayer {
          // 应用裁剪
          clipPath(Path().apply { 
              addOval(Rect(100f, 100f, 300f, 300f)) 
          }) {
              // 绘制内容
          }
      }
  }
  ```

- **避免透明度裁剪**：结合透明度和裁剪可能导致额外的渲染通道

3. **监测性能**：
    - 使用Android Profiler监测绘制性能
    - 在复杂UI中，考虑使用Systrace分析渲染瓶颈
    - 测试在低端设备上的性能表现

通过合理使用裁剪操作并应用这些优化策略，你可以在保持视觉效果的同时最小化性能影响。

### 4. 如何处理不同屏幕密度下的绘制？

**问题**：在不同屏幕密度的设备上，自定义绘制的内容可能看起来不一致，如何确保绘制内容在各种设备上都有良好的显示效果？

**解答**：处理不同屏幕密度下的绘制需要注意以下几点：

1. **使用密度无关单位**：
    - 始终使用`dp`或`sp`单位，然后在绘制时转换为像素
    - 使用`Dp.toPx()`方法进行转换，这会自动考虑设备的屏幕密度

```kotlin
val strokeWidth = 2.dp.toPx()  // 正确做法
val radius = 20.dp.toPx()      // 正确做法

// 错误做法
val strokeWidth = 2f  // 这是原始像素，在高密度屏幕上会显得很细
```

2. **避免硬编码像素值**：
    - 不要直接使用像素值定义尺寸
    - 使用相对尺寸或基于组件大小的计算

```kotlin
// 好的做法
val circleRadius = minOf(size.width, size.height) * 0.4f

// 不好的做法
val circleRadius = 100f  // 固定像素值
```

3. **考虑屏幕方向和尺寸变化**：
    - 设计自适应的绘制逻辑，考虑不同的宽高比
    - 使用百分比或相对值定位元素

```kotlin
// 使用相对位置
val centerX = size.width * 0.5f
val centerY = size.height * 0.5f
```

4. **图像资源处理**：
    - 对于位图资源，使用适当的缩放模式
    - 考虑使用矢量图形（如SVG）代替位图

```kotlin
drawImage(
    image = imageBitmap,
    dstSize = IntSize(width.toInt(), height.toInt()),
    filterQuality = FilterQuality.High  // 使用高质量滤镜进行缩放
)
```

5. **文本绘制**：
    - 使用`sp`单位定义文本大小，这会考虑用户的字体大小设置
    - 考虑文本的可访问性和可读性

```kotlin
val textPaint = Paint().asFrameworkPaint().apply {
    textSize = 16.sp.toPx()  // 使用sp单位
    // ...
}
```

6. **测试不同设备**：
    - 在不同屏幕密度的设备上测试你的UI
    - 使用Android Studio的预览功能查看不同设备上的效果
    - 考虑极端情况，如非常小或非常大的屏幕

7. **性能考虑**：
    - 高密度屏幕需要绘制更多像素，可能影响性能
    - 对于复杂绘制，考虑在高密度屏幕上简化某些细节

```kotlin
val density = LocalDensity.current.density
val detailLevel = if (density > 2.5f) 5 else 10  // 根据密度调整细节级别
```

通过遵循这些最佳实践，你可以确保你的自定义绘制内容在各种设备上都有一致且高质量的显示效果。

```kotlin
fun ClippingAnimationExercise() {

        // 启动动画
        LaunchedEffect(currentClipType, animationPlaying) {

                animatedProgress.snapTo(0f)

                // 播放动画
                animatedProgress.animateTo(

                ) {

                        selected = currentClipType == ClipType.CIRCLE,
                        onClick = { currentClipType = ClipType.CIRCLE }
                    )

                    ClipTypeButton(
                        type = ClipType.SQUARE,
                        selected = currentClipType == ClipType.SQUARE,
                        onClick = { currentClipType = ClipType.SQUARE }
                    )

                    ClipTypeButton(
                        type = ClipType.STAR,
                        selected = currentClipType == ClipType.STAR,
                        onClick = { currentClipType = ClipType.STAR }
                    )

                    ClipTypeButton(
                        type = ClipType.WIPE,
                        selected = currentClipType == ClipType.WIPE,
                        onClick = { currentClipType = ClipType.WIPE }
                    )
                }

                // 播放按钮
                Button(
                    onClick = { animationPlaying = true },
                    modifier = Modifier.align(Alignment.End)
                ) {
                    Text("播放动画")
                }
            }
        }

        // 动画展示区域
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(300.dp)
                .clip(RoundedCornerShape(16.dp))
                .background(Color.LightGray)
                .drawWithCache {
                    // 预计算参数
                    val progress = animatedProgress.value
                    val width = size.width
                    val height = size.height
                    val center = Offset(width / 2, height / 2)

                    // 创建裁剪路径
                    val clipPath = Path()

                    when (currentClipType) {
                        ClipType.CIRCLE -> {
                            // 圆形裁剪
                            val maxRadius = sqrt(width * width + height * height) / 2
                            val currentRadius = progress * maxRadius
                            clipPath.addOval(
                                Rect(
                                    center.x - currentRadius,
                                    center.y - currentRadius,
                                    center.x + currentRadius,
                                    center.y + currentRadius
                                )
                            )
                        }

                        ClipType.SQUARE -> {
                            // 方形裁剪
                            val maxSize = maxOf(width, height)
                            val currentSize = progress * maxSize
                            clipPath.addRect(
                                Rect(
                                    center.x - currentSize / 2,
                                    center.y - currentSize / 2,
                                    center.x + currentSize / 2,
                                    center.y + currentSize / 2
                                )
                            )
                        }

                        ClipType.STAR -> {
                            // 星形裁剪
                            val maxRadius = minOf(width, height) * 0.4f
                            val currentOuterRadius = progress * maxRadius
                            val currentInnerRadius = currentOuterRadius * 0.4f

                            val angleStep = 360f / 10
                            val startAngle = -90f

                            // 创建星形路径
                            for (i in 0..10) {
                                val angle = startAngle + i * angleStep
                                val radius = if (i % 2 == 0) currentOuterRadius else currentInnerRadius
                                val x = center.x + radius * cos(Math.toRadians(angle.toDouble())).toFloat()
                                val y = center.y + radius * sin(Math.toRadians(angle.toDouble())).toFloat()

                                if (i == 0) {
                                    clipPath.moveTo(x, y)
                                } else {
                                    clipPath.lineTo(x, y)
                                }
                            }

                            clipPath.close()
                        }

                        ClipType.WIPE -> {
                            // 擦除效果
                            clipPath.addRect(
                                Rect(
                                    left = 0f,
                                    top = 0f,
                                    right = width * progress,
                                    bottom = height
                                )
                            )
                        }
                    }

                    onDrawWithContent {
                        // 使用裁剪路径
                        clipPath(clipPath) {
                            // 绘制内容
                            drawContent()
                        }
                    }
                }
```
