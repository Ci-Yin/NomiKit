# 1.5 从按钮到 MD3 ：Compose 为啥这么分包？

> "Compose的包结构就像一个精心设计的乐高积木盒，每个包都有自己的位置，拼起来就是一座UI王国！" 🧩

## 概念介绍

Jetpack Compose的包结构设计经过精心规划，从最基础的Button组件到完整的Material Design
3（MD3）实现，每个包都有其特定的职责和抽象级别。这种分层设计不仅使框架更加灵活和可扩展，还允许开发者根据需求选择合适的抽象级别。

理解Compose的包结构，不仅有助于更好地使用API，还能帮助我们设计出更加模块化、可维护的应用架构。本节将从一个简单的Button组件入手，探索Compose的分包逻辑和背后的设计哲学。

## 知识要点

- **Compose的核心包结构**：从foundation到material的层次关系
- **抽象级别**：不同包提供的抽象级别和自由度
- **Material Design实现**：Compose如何实现MD3规范
- **主题化**：不同层级的主题定制能力
- **自定义组件**：如何基于不同抽象级别创建自定义组件
- **包依赖关系**：各包之间的依赖和使用建议

## 基础代码示例

### 不同抽象级别的Button实现

#### 1. Foundation级别（最底层）

```kotlin
@Composable
fun FoundationLevelButton() {
    // 使用最基础的Canvas绘制
    Canvas(
        modifier = Modifier
            .size(width = 120.dp, height = 40.dp)
            .clickable { /* 处理点击 */ }
    ) {
        // 绘制按钮背景
        drawRoundRect(
            color = Color.Blue,
            cornerRadius = CornerRadius(8.dp.toPx(), 8.dp.toPx())
        )

        // 绘制文本
        val textPaint = Paint().apply {
            color = android.graphics.Color.WHITE
            textAlign = Paint.Align.CENTER
            textSize = 14.sp.toPx()
        }

        drawContext.canvas.nativeCanvas.drawText(
            "点击我",
            size.width / 2,
            size.height / 2 + textPaint.textSize / 3,
            textPaint
        )
    }
}
```

#### 2. UI级别（中间层）

```kotlin
@Composable
fun UILevelButton() {
    Box(
        modifier = Modifier
            .size(width = 120.dp, height = 40.dp)
            .clip(RoundedCornerShape(8.dp))
            .background(Color.Blue)
            .clickable { /* 处理点击 */ },
        contentAlignment = Alignment.Center
    ) {
        Text(
            text = "点击我",
            color = Color.White,
            fontSize = 14.sp
        )
    }
}
```

#### 3. Material级别（高层抽象）

```kotlin
@Composable
fun MaterialLevelButton() {
    Button(
        onClick = { /* 处理点击 */ },
        colors = ButtonDefaults.buttonColors(
            containerColor = MaterialTheme.colorScheme.primary
        )
    ) {
        Text("点击我")
    }
}
```

### Compose主要包的使用示例

```kotlin
@Composable
fun ComposePackagesExample() {
    Column(
        modifier = Modifier
            .padding(16.dp)
            .fillMaxWidth()
    ) {
        // 1. androidx.compose.foundation
        // 提供基础UI构建块
        Text("Foundation包示例：")
        Canvas(
            modifier = Modifier
                .size(100.dp)
                .padding(8.dp)
        ) {
            drawCircle(Color.Red, radius = 40.dp.toPx())
        }

        Spacer(modifier = Modifier.height(16.dp))

        // 2. androidx.compose.ui
        // 提供核心UI组件
        Text("UI包示例：")
        Box(
            modifier = Modifier
                .size(100.dp)
                .padding(8.dp)
                .background(Color.Blue),
            contentAlignment = Alignment.Center
        ) {
            Text("Box", color = Color.White)
        }

        Spacer(modifier = Modifier.height(16.dp))

        // 3. androidx.compose.material3
        // 提供Material Design 3实现
        Text("Material3包示例：")
        Button(
            onClick = { /* 处理点击 */ },
            modifier = Modifier.padding(8.dp)
        ) {
            Icon(
                imageVector = Icons.Default.Favorite,
                contentDescription = "收藏",
                modifier = Modifier.size(ButtonDefaults.IconSize)
            )
            Spacer(modifier = Modifier.width(ButtonDefaults.IconSpacing))
            Text("收藏")
        }
    }
}
```

```kotlin
            large = RoundedCornerShape(16.dp)

        content = content

// 3. 创建自定义按钮
@Composable
fun GradientButton(
    text: String,
    onClick: () -> Unit,
    modifier: Modifier = Modifier,
    enabled: Boolean = true,
    startColor: Color = Color(0xFF6200EE),
    endColor: Color = Color(0xFF03DAC5)
) {
    Button(
        onClick = onClick,
        modifier = modifier,
        enabled = enabled,
        colors = ButtonDefaults.buttonColors(
            containerColor = Color.Transparent,
            disabledContainerColor = Color.Transparent
        ),
        contentPadding = PaddingValues()
    ) {
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .background(
                    brush = Brush.horizontalGradient(
                        colors = listOf(startColor, endColor)
                    ),
                    shape = MaterialTheme.shapes.small
                )
                .padding(horizontal = 16.dp, vertical = 8.dp),
            contentAlignment = Alignment.Center
        ) {
            Text(
                text = text,
                color = Color.White
            )
        }
    }
}
```

## 常见问题

### 1. Compose为什么要分这么多包？各包之间有什么关系？

**答**：Compose的分包设计遵循关注点分离和抽象层次原则。主要包括：

- **foundation**：最底层，提供基础绘制和布局能力
- **ui**：中间层，提供核心UI组件和交互
- **material/material3**：高层抽象，实现Material Design规范
- **runtime**：提供Compose运行时支持

这种分层设计使开发者可以根据需求选择合适的抽象级别，同时保证了框架的灵活性和可扩展性。低层包不依赖高层包，而高层包依赖低层包，形成清晰的依赖关系。

### 2. 什么时候应该使用foundation包，什么时候使用material包？

**答**：选择取决于你的需求：

- 使用**foundation**包：当你需要完全自定义UI，不想遵循Material Design，或者需要最大的灵活性和控制力
- 使用**ui**包：当你需要基础UI组件但不需要Material Design风格
- 使用**material/material3**包：当你想快速构建符合Material Design规范的应用，或者想利用现成的主题系统

大多数应用应该从material包开始，只有在特殊需求下才考虑使用更低层的包。

### 3. Material 2和Material 3在Compose中有什么区别？

**答**：Material 3（也称为Material You）是Google最新的设计系统，相比Material 2有以下主要区别：

- 更丰富的颜色系统，支持动态颜色（基于壁纸提取）
- 更现代的组件设计，如更大的圆角和更明显的阴影
- 更好的可访问性支持
- 更强的个性化能力

在Compose中，Material 3使用`androidx.compose.material3`包，而Material 2使用`androidx.compose.material`
包。Google推荐新项目使用Material 3。

### 4. 如何在不使用Material包的情况下创建自定义设计系统？

**答**：可以基于foundation和ui包创建完全自定义的设计系统：

1. 定义自己的颜色、排版和形状系统
2. 创建基础组件（按钮、卡片等）
3. 实现自定义CompositionLocal提供主题值
4. 创建主题包装器Composable函数
5. 构建更高级的复合组件

这需要更多工作，但提供了最大的自由度，适合有独特设计需求的应用。

## 实践练习

1. **基础练习**：尝试使用不同层级的API（foundation、ui、material3）实现同一个按钮，比较代码复杂度和灵活性差异。

2. **中级练习**：创建一个自定义主题，包括颜色方案、排版和形状，并应用到一个简单的表单界面。

3. **高级练习**：实现一个不基于Material Design的自定义设计系统，包括至少5个基础组件（按钮、输入框、卡片等）。

4. **思考题**：分析一个现有应用的UI设计，思考如何使用Compose的不同抽象层级实现它，特别是考虑哪些部分应该使用高层API，哪些部分可能需要低层API来实现特殊效果。
