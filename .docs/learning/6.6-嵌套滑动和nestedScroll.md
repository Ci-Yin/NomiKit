# 6.6 嵌套滑动和 nestedScroll()

> "在 Compose 的世界里，嵌套滑动就像是一场精心编排的舞蹈，父子组件之间优雅地协调滑动，让用户体验如丝般顺滑。掌握了
> nestedScroll()，你的 App 就能实现那种'手指一滑，页面如行云流水'的丝滑感！" 🌊

## 概念介绍

嵌套滑动（Nested Scrolling）是现代移动应用中常见的交互模式，它允许多个可滚动组件协同工作，共同响应用户的滑动手势。在
Jetpack
Compose 中，嵌套滑动通过 `nestedScroll()` 修饰符实现，它提供了一种优雅的方式来处理复杂的滑动交互场景。

传统的滑动处理方式往往面临"滑动冲突"
的问题，例如当一个可滚动列表嵌套在另一个可滚动容器内时，用户的滑动手势可能会被其中一个组件"独占"
，导致另一个组件无法正常响应。嵌套滑动机制通过建立父子组件之间的协作关系，解决了这一问题，使得滑动事件可以在组件层次结构中合理分配和传递。

在 Compose 中，嵌套滑动基于"消费-分发"
模型：当用户进行滑动操作时，滑动距离首先提供给父组件消费，父组件消费后剩余的滑动距离再传递给子组件；同时，子组件也可以将未消费的滑动距离回传给父组件。这种双向通信机制确保了滑动事件能够被最合适的组件处理，从而创造出流畅、直观的用户体验。

## 基础代码示例

下面是一个简单的例子，展示如何使用 `nestedScroll()` 修饰符实现一个可折叠的顶部栏：

```kotlin
@Composable
fun CollapsingToolbarExample() {
    // 定义顶部栏的高度范围
    val minHeight = 56.dp
    val maxHeight = 200.dp

    // 创建嵌套滑动连接
    val nestedScrollConnection = remember {
        object : NestedScrollConnection {
            // 顶部栏的当前高度
            var toolbarHeight by mutableStateOf(maxHeight)

            // 前置滑动处理：在子组件处理滚动前，先处理顶部栏的折叠
            override fun onPreScroll(available: Offset, source: NestedScrollSource): Offset {
                // 只处理向上滑动（折叠顶部栏）
                val delta = available.y
                if (delta < 0) {
                    // 计算新的高度
                    val newHeight = (toolbarHeight - abs(delta).toDp()).coerceAtLeast(minHeight)
                    // 计算实际消费的滑动距离
                    val consumed = if (newHeight > minHeight) {
                        // 如果顶部栏还没完全折叠，消费部分或全部滑动
                        val consumed = (toolbarHeight - newHeight).toPx()
                        toolbarHeight = newHeight
                        Offset(0f, -consumed)
                    } else {
                        // 如果顶部栏已经完全折叠，不消费滑动
                        Offset.Zero
                    }
                    return consumed
                }
                return Offset.Zero
            }

            // 后置滑动处理：在子组件处理完滚动后，处理顶部栏的展开
            override fun onPostScroll(
                consumed: Offset,
                available: Offset,
                source: NestedScrollSource
            ): Offset {
                // 只处理向下滑动（展开顶部栏）
                val delta = available.y
                if (delta > 0) {
                    // 计算新的高度
                    val newHeight = (toolbarHeight + delta.toDp()).coerceAtMost(maxHeight)
                    // 计算实际消费的滑动距离
                    val consumed = if (newHeight < maxHeight) {
                        // 如果顶部栏还没完全展开，消费部分或全部滑动
                        val consumed = (newHeight - toolbarHeight).toPx()
                        toolbarHeight = newHeight
                        Offset(0f, consumed)
                    } else {
                        // 如果顶部栏已经完全展开，不消费滑动
                        Offset.Zero
                    }
                    return consumed
                }
                return Offset.Zero
            }
        }
    }

    // 使用 Box 作为根容器
    Box(
        modifier = Modifier
            .fillMaxSize()
            .nestedScroll(nestedScrollConnection)
    ) {
        // 可滚动的内容
        LazyColumn(
            modifier = Modifier
                .fillMaxSize()
                // 添加顶部内边距，为顶部栏留出空间
                .padding(top = nestedScrollConnection.toolbarHeight)
        ) {
            // 生成一些示例项目
            items(50) { index ->
                ListItem(
                    headlineContent = { Text("项目 ${index + 1}") },
                    supportingContent = { Text("这是项目 ${index + 1} 的描述文本") },
                    leadingContent = {
                        Icon(
                            imageVector = Icons.Default.Info,
                            contentDescription = null
                        )
                    }
                )
                Divider()
            }
        }

        // 顶部栏
        Surface(
            modifier = Modifier
                .fillMaxWidth()
                .height(nestedScrollConnection.toolbarHeight)
                .align(Alignment.TopCenter),
            color = MaterialTheme.colorScheme.primary,
            shadowElevation = 4.dp
        ) {
            Box(
                modifier = Modifier.fillMaxSize(),
                contentAlignment = Alignment.BottomStart
            ) {
                // 标题
                Text(
                    text = "可折叠顶部栏",
                    style = MaterialTheme.typography.headlineMedium,
                    color = MaterialTheme.colorScheme.onPrimary,
                    modifier = Modifier
                        .padding(16.dp)
                        .align(
                            // 根据顶部栏高度调整标题位置
                            if (nestedScrollConnection.toolbarHeight > minHeight + 32.dp) {
                                Alignment.BottomStart
                            } else {
                                Alignment.CenterStart
                            }
                        )
                )
            }
        }
    }
}

// 辅助扩展函数：将像素转换为 dp
private fun Float.toDp(): Dp {
    return (this / density).dp
}

// 辅助扩展函数：将 dp 转换为像素
private fun Dp.toPx(): Float {
    return this.value * density
}
```

在这个例子中，我们创建了一个 `NestedScrollConnection` 对象来处理嵌套滑动事件。当用户向上滑动时，
`onPreScroll`
方法会被调用，我们在这里处理顶部栏的折叠；当用户向下滑动时，`onPostScroll`
方法会被调用，我们在这里处理顶部栏的展开。通过这种方式，顶部栏和列表内容可以协同响应用户的滑动操作，创造出流畅的交互体验。

## 进阶用法

### 1. 实现下拉刷新功能

下面是一个使用嵌套滑动实现下拉刷新功能的例子：

```kotlin
@Composable
fun PullToRefreshExample() {
    // 刷新状态
    var isRefreshing by remember { mutableStateOf(false) }
    // 下拉进度（0.0 - 1.0）
    var pullProgress by remember { mutableStateOf(0f) }
    // 下拉阈值（超过这个值松手后会触发刷新）
    val pullThreshold = 0.7f
    // 最大下拉距离
    val maxPullDistance = 120.dp

    // 创建嵌套滑动连接
    val nestedScrollConnection = remember {
        object : NestedScrollConnection {
            // 前置滑动处理：处理下拉手势
            override fun onPreScroll(available: Offset, source: NestedScrollSource): Offset {
                // 如果正在刷新，不处理滑动
                if (isRefreshing) return Offset.Zero

                // 只处理向下滑动，且列表已经滚动到顶部
                if (available.y > 0 && source == NestedScrollSource.Drag) {
                    // 计算新的下拉进度
                    val newProgress = (pullProgress + (available.y / maxPullDistance.toPx()))
                        .coerceIn(0f, 1f)

                    // 计算实际消费的滑动距离
                    val consumed = if (newProgress > pullProgress) {
                        val consumed = (newProgress - pullProgress) * maxPullDistance.toPx()
                        pullProgress = newProgress
                        Offset(0f, consumed)
                    } else {
                        Offset.Zero
                    }

                    return consumed
                }

                return Offset.Zero
            }

            // 处理松手事件
            override suspend fun onPreFling(available: Velocity): Velocity {
                // 如果下拉进度超过阈值，触发刷新
                if (pullProgress > pullThreshold && !isRefreshing) {
                    isRefreshing = true

                    // 模拟网络请求
                    delay(2000)

                    // 刷新完成
                    isRefreshing = false
                    pullProgress = 0f
                } else if (!isRefreshing) {
                    // 如果下拉进度未超过阈值，回弹到初始状态
                    pullProgress = 0f
                }

                return Velocity.Zero
            }
        }
    }

    // 计算刷新指示器的偏移量
    val refreshOffset = maxPullDistance * pullProgress

    // 使用 Box 作为根容器
    Box(
        modifier = Modifier
            .fillMaxSize()
            .nestedScroll(nestedScrollConnection)
    ) {
        // 可滚动的内容
        LazyColumn(
            modifier = Modifier
                .fillMaxSize()
                // 添加顶部内边距，为刷新指示器留出空间
                .padding(top = if (isRefreshing) maxPullDistance else 0.dp)
                // 添加下拉偏移
                .offset(y = if (!isRefreshing) refreshOffset else 0.dp)
        ) {
            // 生成一些示例项目
            items(20) { index ->
                ListItem(
                    headlineContent = { Text("项目 ${index + 1}") },
                    supportingContent = { Text("下拉顶部可以刷新列表") },
                    leadingContent = {
                        Icon(
                            imageVector = Icons.Default.Info,
                            contentDescription = null
                        )
                    }
                )
                Divider()
            }
        }

        // 刷新指示器
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(maxPullDistance)
                .offset(y = -maxPullDistance + refreshOffset + if (isRefreshing) maxPullDistance else 0.dp)
                .background(MaterialTheme.colorScheme.primaryContainer),
            contentAlignment = Alignment.Center
        ) {
            if (isRefreshing) {
                // 显示加载动画
                CircularProgressIndicator(
                    modifier = Modifier.size(36.dp),
                    color = MaterialTheme.colorScheme.primary
                )
            } else {
                // 显示下拉提示
                Row(
                    verticalAlignment = Alignment.CenterVertically,
                    horizontalArrangement = Arrangement.Center
                ) {
                    // 旋转箭头图标
                    Icon(
                        imageVector = Icons.Default.ArrowDownward,
                        contentDescription = null,
                        modifier = Modifier.rotate(180 * pullProgress),
                        tint = MaterialTheme.colorScheme.primary
                    )

                    Spacer(modifier = Modifier.width(8.dp))

                    Text(
                        text = if (pullProgress > pullThreshold) "释放刷新" else "下拉刷新",
                        color = MaterialTheme.colorScheme.primary
                    )
                }
            }
        }
    }
}
```

在这个例子中，我们使用 `NestedScrollConnection` 来处理下拉手势，并根据下拉距离显示刷新指示器。当用户下拉距离超过阈值并松手时，会触发刷新操作。

### 2. 实现底部弹出菜单（Bottom Sheet）

下面是一个使用嵌套滑动实现底部弹出菜单的例子：

```kotlin
@Composable
fun BottomSheetExample() {
    // 底部菜单的状态
    val states = listOf("Collapsed", "Peek", "Expanded")
    var currentState by remember { mutableStateOf(states[1]) }

    // 底部菜单的高度范围
    val collapsedHeight = 0.dp
    val peekHeight = 64.dp
    val expandedHeight = 300.dp

    // 当前高度
    val currentHeight = when (currentState) {
        "Collapsed" -> collapsedHeight
        "Peek" -> peekHeight
        "Expanded" -> expandedHeight
        else -> peekHeight
    }

    // 创建嵌套滑动连接
    val nestedScrollConnection = remember {
        object : NestedScrollConnection {
            // 处理拖动手势
            override fun onPreScroll(available: Offset, source: NestedScrollSource): Offset {
                // 只处理垂直拖动
                val delta = available.y

                // 根据当前状态和拖动方向决定是否消费滑动
                return when {
                    // 向上拖动且不是完全展开状态
                    delta < 0 && currentState != "Expanded" -> {
                        // 切换到展开状态
                        currentState = "Expanded"
                        // 消费部分滑动
                        Offset(0f, delta / 2)
                    }
                    // 向下拖动且不是折叠状态
                    delta > 0 && currentState != "Collapsed" -> {
                        // 如果是展开状态，先切换到半展开状态
                        if (currentState == "Expanded") {
                            currentState = "Peek"
                            // 消费部分滑动
                            Offset(0f, delta / 2)
                        } else {
                            // 如果是半展开状态，切换到折叠状态
                            currentState = "Collapsed"
                            // 消费部分滑动
                            Offset(0f, delta / 2)
                        }
                    }
                    else -> Offset.Zero
                }
            }
        }
    }

    // 使用 Box 作为根容器
    Box(
        modifier = Modifier
            .fillMaxSize()
            .nestedScroll(nestedScrollConnection)
    ) {
        // 主要内容
        LazyColumn(
            modifier = Modifier
                .fillMaxSize()
                // 添加底部内边距，为底部菜单留出空间
                .padding(bottom = currentHeight)
        ) {
            // 生成一些示例项目
            items(20) { index ->
                ListItem(
                    headlineContent = { Text("项目 ${index + 1}") },
                    supportingContent = { Text("向上滑动展开底部菜单，向下滑动折叠底部菜单") },
                    leadingContent = {
                        Icon(
                            imageVector = Icons.Default.Info,
                            contentDescription = null
                        )
                    }
                )
                Divider()
            }
        }

        // 底部菜单
        Surface(
            modifier = Modifier
                .fillMaxWidth()
                .height(currentHeight)
                .align(Alignment.BottomCenter)
                // 添加动画
                .animateContentSize(
                    animationSpec = spring(
                        dampingRatio = 0.8f,
                        stiffness = Spring.StiffnessLow
                    )
                ),
            color = MaterialTheme.colorScheme.surfaceVariant,
            shadowElevation = 8.dp,
            shape = RoundedCornerShape(topStart = 16.dp, topEnd = 16.dp)
        ) {
            Column(
                modifier = Modifier
                    .fillMaxSize()
                    .padding(16.dp)
            ) {
                // 拖动手柄
                Box(
                    modifier = Modifier
                        .fillMaxWidth()
                        .padding(bottom = 16.dp),
                    contentAlignment = Alignment.Center
                ) {
                    Box(
                        modifier = Modifier
                            .width(40.dp)
                            .height(4.dp)
                            .background(
                                color = MaterialTheme.colorScheme.onSurfaceVariant.copy(alpha = 0.5f),
                                shape = RoundedCornerShape(2.dp)
                            )
                    )
                }

                // 底部菜单内容
                if (currentHeight > peekHeight) {
                    Text(
                        text = "底部菜单",
                        style = MaterialTheme.typography.headlineSmall,
                        color = MaterialTheme.colorScheme.onSurfaceVariant
                    )

                    Spacer(modifier = Modifier.height(16.dp))

                    // 菜单选项
                    repeat(5) { index ->
                        ListItem(
                            headlineContent = { Text("选项 ${index + 1}") },
                            leadingContent = {
                                Icon(
                                    imageVector = when (index) {
                                        0 -> Icons.Default.Settings
                                        1 -> Icons.Default.Share
                                        2 -> Icons.Default.Favorite
                                        3 -> Icons.Default.Info
                                        else -> Icons.Default.Star
                                    },
                                    contentDescription = null,
                                    tint = MaterialTheme.colorScheme.primary
                                )
                            },
                            modifier = Modifier.clickable { /* 处理点击 */ }
                        )
                    }
                } else {
                    // 半展开状态只显示标题
                    Row(
                        modifier = Modifier.fillMaxWidth(),
                        verticalAlignment = Alignment.CenterVertically
                    ) {
                        Text(
                            text = "上滑查看更多选项",
                            style = MaterialTheme.typography.titleMedium,
                            color = MaterialTheme.colorScheme.onSurfaceVariant
                        )

                        Spacer(modifier = Modifier.weight(1f))

                        Icon(
                            imageVector = Icons.Default.KeyboardArrowUp,
                            contentDescription = "展开",
                            tint = MaterialTheme.colorScheme.onSurfaceVariant
                        )
                    }
                }
            }
        }
    }
}
```

在这个例子中，我们使用 `NestedScrollConnection`
来处理底部菜单的拖动手势。底部菜单有三种状态：折叠、半展开和完全展开。用户可以通过上下滑动在这些状态之间切换。

### 3. 实现协调布局（Coordinator Layout）

下面是一个使用嵌套滑动实现协调布局的例子，它结合了可折叠顶部栏和底部导航栏的动态显示/隐藏：

```kotlin
@Composable
fun CoordinatorLayoutExample() {
    // 顶部栏状态
    val minToolbarHeight = 56.dp
    val maxToolbarHeight = 200.dp
    var toolbarHeight by remember { mutableStateOf(maxToolbarHeight) }

    // 底部导航栏状态
    var bottomNavVisible by remember { mutableStateOf(true) }
    val bottomNavHeight = 56.dp

    // 上次滚动方向
    var lastScrollDirection by remember { mutableStateOf(0) }
    // 方向变化计数器（用于防止轻微抖动导致底部导航栏频繁显示/隐藏）
    var directionChangeCounter by remember { mutableStateOf(0) }

    // 创建嵌套滑动连接
    val nestedScrollConnection = remember {
        object : NestedScrollConnection {
            // 前置滑动处理
            override fun onPreScroll(available: Offset, source: NestedScrollSource): Offset {
                // 处理顶部栏折叠
                val delta = available.y

                // 更新滚动方向计数器
                if (delta < 0 && lastScrollDirection >= 0) {
                    // 方向从向下变为向上
                    lastScrollDirection = -1
                    directionChangeCounter = 0
                } else if (delta > 0 && lastScrollDirection <= 0) {
                    // 方向从向上变为向下
                    lastScrollDirection = 1
                    directionChangeCounter = 0
                } else {
                    // 方向保持不变，增加计数器
                    directionChangeCounter++
                }

                // 只有当方向变化计数器超过阈值时，才更新底部导航栏状态
                if (directionChangeCounter > 5) {
                    bottomNavVisible = lastScrollDirection > 0
                }

                // 处理顶部栏折叠/展开
                return if (delta < 0) {
                    // 向上滚动，折叠顶部栏
                    val newHeight = (toolbarHeight - abs(delta).toDp()).coerceAtLeast(minToolbarHeight)
                    val consumed = if (newHeight > minToolbarHeight) {
                        val consumed = (toolbarHeight - newHeight).toPx()
                        toolbarHeight = newHeight
                        Offset(0f, -consumed)
                    } else {
                        Offset.Zero
                    }
                    consumed
                } else if (delta > 0) {
                    // 向下滚动，展开顶部栏
                    val newHeight = (toolbarHeight + delta.toDp()).coerceAtMost(maxToolbarHeight)
                    val consumed = if (newHeight < maxToolbarHeight) {
                        val consumed = (newHeight - toolbarHeight).toPx()
                        toolbarHeight = newHeight
                        Offset(0f, consumed)
                    } else {
                        Offset.Zero
                    }
                    consumed
                } else {
                    Offset.Zero
                }
            }
        }
    }

    // 使用 Box 作为根容器
    Box(
        modifier = Modifier
            .fillMaxSize()
            .nestedScroll(nestedScrollConnection)
    ) {
        // 可滚动的内容
        LazyColumn(
            modifier = Modifier
                .fillMaxSize()
                // 添加顶部和底部内边距
                .padding(
                    top = toolbarHeight,
                    bottom = if (bottomNavVisible) bottomNavHeight else 0.dp
                )
        ) {
            // 生成一些示例项目
            items(50) { index ->
                ListItem(
                    headlineContent = { Text("项目 ${index + 1}") },
                    supportingContent = { 
                        Text("向上滚动折叠顶部栏和隐藏底部导航栏，向下滚动展开顶部栏和显示底部导航栏") 
                    },
                    leadingContent = {
                        Icon(
                            imageVector = Icons.Default.Info,
                            contentDescription = null
                        )
                    }
                )
                Divider()
            }
        }

        // 顶部栏
        Surface(
            modifier = Modifier
                .fillMaxWidth()
                .height(toolbarHeight)
                .align(Alignment.TopCenter),
            color = MaterialTheme.colorScheme.primary,
            shadowElevation = 4.dp
        ) {
            Box(
                modifier = Modifier.fillMaxSize(),
                contentAlignment = Alignment.BottomStart
            ) {
                // 标题
                Text(
                    text = "协调布局示例",
                    style = MaterialTheme.typography.headlineMedium,
                    color = MaterialTheme.colorScheme.onPrimary,
                    modifier = Modifier
                        .padding(16.dp)
                        .align(
                            if (toolbarHeight > minToolbarHeight + 32.dp) {
                                Alignment.BottomStart
                            } else {
                                Alignment.CenterStart
                            }
                        )
                )
            }
        }

        // 底部导航栏
        AnimatedVisibility(
            visible = bottomNavVisible,
            modifier = Modifier.align(Alignment.BottomCenter),
            enter = slideInVertically(initialOffsetY = { it }),
            exit = slideOutVertically(targetOffsetY = { it })
        ) {
            NavigationBar(
                modifier = Modifier
                    .fillMaxWidth()
                    .height(bottomNavHeight),
                containerColor = MaterialTheme.colorScheme.surfaceVariant
            ) {
                // 导航项
                val items = listOf("首页", "搜索", "收藏", "设置")
                val icons = listOf(
                    Icons.Default.Home,
                    Icons.Default.Search,
                    Icons.Default.Favorite,
                    Icons.Default.Settings
                )

                items.forEachIndexed { index, item ->
                    NavigationBarItem(
                        icon = { 
                            Icon(
                                imageVector = icons[index],
                                contentDescription = item
                            )
                        },
                        label = { Text(item) },
                        selected = index == 0,
                        onClick = { /* 处理点击 */ }
                    )
                }
            }
        }
    }
}
```

在这个例子中，我们使用 `NestedScrollConnection`
来同时处理顶部栏的折叠/展开和底部导航栏的显示/隐藏。当用户向上滚动时，顶部栏会折叠，底部导航栏会隐藏；当用户向下滚动时，顶部栏会展开，底部导航栏会显示。为了防止轻微的滚动抖动导致底部导航栏频繁显示/隐藏，我们添加了方向变化计数器，只有当滚动方向稳定变化时才更新底部导航栏状态。

## 常见问题

### 1. 嵌套滑动与普通滑动有什么区别？

**回答**：嵌套滑动和普通滑动的主要区别在于：

1. **事件处理机制**：
    - 普通滑动：滑动事件通常由单个组件独占处理，不会在组件之间传递。
    - 嵌套滑动：滑动事件可以在父子组件之间协同处理，通过"消费-分发"模型实现组件间的协作。

2. **滑动冲突处理**：
    - 普通滑动：当多个可滚动组件嵌套时，容易发生滑动冲突，通常需要手动干预来决定哪个组件应该响应滑动。
    - 嵌套滑动：提供了内置的冲突解决机制，父子组件可以根据自身状态决定消费多少滑动距离，剩余的滑动距离可以传递给其他组件。

3. **实现方式**：
    - 普通滑动：通常通过 `Modifier.scrollable()` 或 `Modifier.verticalScroll()` /
      `Modifier.horizontalScroll()` 实现。
    - 嵌套滑动：通过 `Modifier.nestedScroll()` 和 `NestedScrollConnection` 接口实现。

4. **适用场景**：
    - 普通滑动：适用于简单的滚动场景，如单个列表或网格。
    - 嵌套滑动：适用于复杂的交互场景，如可折叠顶部栏、下拉刷新、协调布局等。

5. **用户体验**：
    - 普通滑动：在复杂布局中可能导致生硬的交互体验，如滚动突然被"卡住"或跳转到另一个组件。
    - 嵌套滑动：提供更流畅、直观的交互体验，滚动可以在组件间平滑过渡。

### 3. 如何在嵌套滑动中处理惯性滑动？

**回答**：在嵌套滑动中处理惯性滑动需要实现 `onPreFling` 和 `onPostFling` 方法：

```kotlin
val nestedScrollConnection = remember {
    object : NestedScrollConnection {
        // 处理拖动滑动
        override fun onPreScroll(available: Offset, source: NestedScrollSource): Offset {
            // 处理拖动滑动逻辑...
            return Offset(/* 消费的滑动距离 */)
        }

        // 处理惯性滑动开始前
        override suspend fun onPreFling(available: Velocity): Velocity {
            // 在惯性滑动开始前消费部分速度
            val consumedY = if (available.y > 0) {
                // 消费垂直方向的速度
                available.y * 0.5f
            } else {
                0f
            }

            return Velocity(0f, consumedY)
        }

        // 处理惯性滑动结束后
        override suspend fun onPostFling(consumed: Velocity, available: Velocity): Velocity {
            // 在惯性滑动结束后，处理剩余的速度
            val consumedY = if (available.y > 0) {
                // 消费剩余的垂直方向速度
                available.y * 0.3f
            } else {
                0f
            }

            return Velocity(0f, consumedY)
        }
    }
}
```

在这个例子中：

1. `onPreFling` 在惯性滑动开始前被调用，可以消费部分初始速度。
2. `onPostFling` 在惯性滑动结束后被调用，可以处理剩余的速度。

这两个方法返回的是消费的速度，而不是偏移量。通过合理设置这些方法，可以实现更自然的惯性滑动效果，例如：

- 在可折叠顶部栏完全折叠/展开后，将剩余的惯性传递给内容列表
- 在下拉刷新中，根据下拉距离决定是否触发刷新或回弹
- 在底部弹出菜单中，根据滑动速度决定是展开还是折叠

### 4. 如何优化嵌套滑动的性能？

1. **减少不必要的计算**：

   ```kotlin
               }

               // 避免重复计算
               if (toolbarHeight == minToolbarHeight && available.y < 0) {
                   return Offset.Zero
               }

               // 其他逻辑...
           }
       }
   }
   ```

2. **使用 `remember` 缓存嵌套滑动连接**：

   ```kotlin

   val nestedScrollConnection = remember {
       object : NestedScrollConnection {
           // 实现...
       }
   }
   ```

3. **避免在滑动处理中触发重组**：

   ```kotlin
   val nestedScrollConnection = remember {
       object : NestedScrollConnection {
           // 使用 MutableState 而不是普通变量
           var toolbarHeightPx by mutableStateOf(maxToolbarHeight.toPx())

           override fun onPreScroll(available: Offset, source: NestedScrollSource): Offset {
               // 更新像素值而不是 Dp 值，减少转换开销
               val newHeight = (toolbarHeightPx + available.y).coerceIn(
                   minToolbarHeight.toPx(),
                   maxToolbarHeight.toPx()
               )

               val consumed = newHeight - toolbarHeightPx
               toolbarHeightPx = newHeight

               return Offset(0f, consumed)
           }
       }
   }

   // 在布局中使用
   val toolbarHeight = with(LocalDensity.current) {
       nestedScrollConnection.toolbarHeightPx.toDp()
   }
   ```

4. **使用 `derivedStateOf` 减少不必要的重组**：

   ```kotlin
   // 原始状态
   var scrollOffsetY by remember { mutableStateOf(0f) }

   // 派生状态
   val toolbarHeight by remember {
       derivedStateOf {
           (maxToolbarHeight.toPx() - scrollOffsetY).coerceAtLeast(minToolbarHeight.toPx()).toDp()
       }
   }

   val nestedScrollConnection = remember {
       object : NestedScrollConnection {
           override fun onPreScroll(available: Offset, source: NestedScrollSource): Offset {
               // 更新原始状态
               val newOffset = (scrollOffsetY - available.y).coerceIn(
                   0f,
                   maxToolbarHeight.toPx() - minToolbarHeight.toPx()
               )

               val consumed = newOffset - scrollOffsetY
               scrollOffsetY = newOffset

               return Offset(0f, -consumed)
           }
       }
   }
   ```

5. **使用 `LaunchedEffect` 处理动画，而不是在滑动处理中**：

   ```kotlin

   var bottomNavVisible by remember { mutableStateOf(true) }

   LaunchedEffect(isScrollingUp) {
       bottomNavVisible = !isScrollingUp
   }

   val nestedScrollConnection = remember {
       object : NestedScrollConnection {
           override fun onPreScroll(available: Offset, source: NestedScrollSource): Offset {
               // 只更新滑动方向状态，不直接触发动画
               isScrollingUp = available.y < 0

               // 其他逻辑...
           }
       }
   }
   ```
