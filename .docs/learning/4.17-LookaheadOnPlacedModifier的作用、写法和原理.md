# 4.17 LookaheadOnPlacedModifier 的作用、写法和原理

> "预知未来不是魔法，是 Compose 的
> LookaheadOnPlacedModifier！让你提前洞察布局变化，就像拥有了时间宝石一样强大！" ⏱️

## 概念介绍

LookaheadOnPlacedModifier 是 Jetpack Compose
中一个强大的布局修饰符，它允许我们在组件实际放置到屏幕上之前，预先获取其位置和尺寸信息。这种"预知"
能力使我们能够基于即将发生的布局变化提前做出反应，从而实现更加流畅和复杂的 UI 效果。

与普通的 OnPlacedModifier 不同，LookaheadOnPlacedModifier 工作在 Compose 的"预览"
阶段，它能够在布局计算完成但尚未应用到屏幕之前获取组件的位置信息。这对于需要平滑过渡动画或者需要提前知道布局变化的场景非常有用。

## 知识要点

- LookaheadOnPlacedModifier 的核心功能是预先获取组件的位置和尺寸信息
- 它与 LookaheadLayout 配合使用，是实现高级动画效果的关键工具
- 相比 OnPlacedModifier，它能够在布局实际应用前获取信息
- 使用场景包括：复杂的布局过渡动画、预加载内容、位置感知的 UI 效果
- 它是 Compose 布局系统中的高级特性，需要谨慎使用以避免性能问题

## 基础代码示例

下面是一个简单的例子，展示如何使用 LookaheadOnPlacedModifier 来跟踪一个组件的位置变化：

```kotlin
@Composable
fun LookaheadOnPlacedExample() {
    var expanded by remember { mutableStateOf(false) }
    
    Box(
        modifier = Modifier.fillMaxSize(),
        contentAlignment = Alignment.Center
    ) {
        // 使用LookaheadLayout包装内容
        LookaheadLayout(
            content = {
                Box(
                    modifier = Modifier
                        .animateContentSize()
                        .background(
                            color = MaterialTheme.colorScheme.primary,
                            shape = RoundedCornerShape(8.dp)
                        )
                        .clickable { expanded = !expanded }
                        .size(if (expanded) 200.dp else 100.dp)
                        // 使用lookaheadOnPlaced获取位置信息
                        .lookaheadOnPlaced { coordinates, layoutCoordinates ->
                            // coordinates: 当前位置
                            // layoutCoordinates: 即将应用的位置
                            Log.d("LookaheadExample", "Current position: ${coordinates.size}")
                            Log.d("LookaheadExample", "Future position: ${layoutCoordinates.size}")
                            
                            // 这里可以基于位置变化做一些准备工作
                        }
                ) {
                    Text(
                        text = if (expanded) "点击收起" else "点击展开",
                        modifier = Modifier.align(Alignment.Center),
                        color = Color.White
                    )
                }
            },
            modifier = Modifier.fillMaxSize(),
            measurePolicy = { measurables, constraints ->
                // 测量所有子元素
                val placeables = measurables.map { it.measure(constraints) }
                
                // 返回布局的尺寸
                layout(constraints.maxWidth, constraints.maxHeight) {
                    // 放置所有子元素
                    placeables.forEach { placeable ->
                        placeable.place(
                            x = (constraints.maxWidth - placeable.width) / 2,
                            y = (constraints.maxHeight - placeable.height) / 2
                        )
                    }
                }
            }
        )
    }
}
```

## 进阶用法

### 1. 实现平滑的位置过渡动画

LookaheadOnPlacedModifier 最强大的用途之一是实现元素位置变化的平滑过渡。下面是一个更复杂的例子，展示如何使用它来创建一个元素从一个位置到另一个位置的平滑动画：

```kotlin
@Composable
fun SmoothPositionTransition() {
    var items by remember { mutableStateOf(List(5) { "Item $it" }) }
    var selectedItem by remember { mutableStateOf<String?>(null) }
    
    // 记录每个项目的位置信息
    val itemPositions = remember { mutableStateMapOf<String, Rect>() }
    // 动画位置
    val animatedPositions = remember { mutableStateMapOf<String, Rect>() }
    
    Box(modifier = Modifier.fillMaxSize()) {
        LookaheadLayout(
            content = {
                LazyColumn {
                    items(items) { item ->
                        Box(
                            modifier = Modifier
                                .fillMaxWidth()
                                .height(60.dp)
                                .padding(8.dp)
                                .background(
                                    color = if (item == selectedItem) 
                                        MaterialTheme.colorScheme.primaryContainer 
                                    else 
                                        MaterialTheme.colorScheme.surfaceVariant,
                                    shape = RoundedCornerShape(8.dp)
                                )
                                .clickable { selectedItem = if (selectedItem == item) null else item }
                                .lookaheadOnPlaced { currentCoordinates, lookaheadCoordinates ->
                                    // 获取当前和未来的位置
                                    val currentRect = currentCoordinates.boundsInRoot()
                                    val futureRect = lookaheadCoordinates.boundsInRoot()
                                    
                                    if (currentRect != futureRect) {
                                        // 位置发生变化，更新记录
                                        itemPositions[item] = futureRect
                                        
                                        // 启动动画
                                        animatedPositions[item]?.let { currentAnimatedRect ->
                                            // 使用协程启动动画
                                            CoroutineScope(Dispatchers.Main).launch {
                                                val animator = ValueAnimator.ofFloat(0f, 1f)
                                                animator.duration = 300
                                                animator.interpolator = FastOutSlowInInterpolator()
                                                
                                                animator.addUpdateListener { animation ->
                                                    val fraction = animation.animatedValue as Float
                                                    // 计算插值位置
                                                    val animatedRect = Rect(
                                                        lerp(currentAnimatedRect.left, futureRect.left, fraction),
                                                        lerp(currentAnimatedRect.top, futureRect.top, fraction),
                                                        lerp(currentAnimatedRect.right, futureRect.right, fraction),
                                                        lerp(currentAnimatedRect.bottom, futureRect.bottom, fraction)
                                                    )
                                                    animatedPositions[item] = animatedRect
                                                }
                                                
                                                animator.start()
                                            }
                                        } ?: run {
                                            // 首次记录，直接设置
                                            animatedPositions[item] = futureRect
                                        }
                                    }
                                }
                        ) {
                            Text(
                                text = item,
                                modifier = Modifier
                                    .align(Alignment.CenterStart)
                                    .padding(start = 16.dp)
                            )
                        }
                    }
                }
            },
            measurePolicy = { measurables, constraints ->
                // 测量所有子元素
                val placeables = measurables.map { it.measure(constraints) }
                
                // 返回布局的尺寸
                layout(constraints.maxWidth, constraints.maxHeight) {
                    // 放置所有子元素
                    placeables.forEach { placeable ->
                        placeable.place(0, 0)
                    }
                }
            }
        )
    }
}

// 辅助函数：线性插值
private fun lerp(start: Float, end: Float, fraction: Float): Float {
    return start + (end - start) * fraction
}
```

### 2. 实现共享元素过渡

LookaheadOnPlacedModifier 还可以用于实现类似 Material Design 中的共享元素过渡效果：

```kotlin
@Composable
fun SharedElementTransition() {
    var isDetailView by remember { mutableStateOf(false) }
    var sharedElementRect by remember { mutableStateOf<Rect?>(null) }
    var targetRect by remember { mutableStateOf<Rect?>(null) }
    
    // 动画进度
    val transitionProgress = animateFloatAsState(
        targetValue = if (isDetailView) 1f else 0f,
        animationSpec = tween(durationMillis = 500)
    )
    
    Box(modifier = Modifier.fillMaxSize()) {
        if (!isDetailView) {
            // 列表视图
            LookaheadLayout(
                content = {
                    LazyColumn {
                        items(10) { index ->
                            Row(
                                modifier = Modifier
                                    .fillMaxWidth()
                                    .height(80.dp)
                                    .padding(8.dp)
                                    .background(
                                        color = MaterialTheme.colorScheme.surfaceVariant,
                                        shape = RoundedCornerShape(8.dp)
                                    )
                                    .clickable { 
                                        isDetailView = true 
                                    },
                                verticalAlignment = Alignment.CenterVertically
                            ) {
                                Box(
                                    modifier = Modifier
                                        .padding(8.dp)
                                        .size(64.dp)
                                        .background(
                                            color = MaterialTheme.colorScheme.primary,
                                            shape = CircleShape
                                        )
                                        .lookaheadOnPlaced { currentCoordinates, _ ->
                                            // 记录共享元素的当前位置
                                            if (index == 0) {
                                                sharedElementRect = currentCoordinates.boundsInRoot()
                                            }
                                        }
                                ) {
                                    Text(
                                        text = "${index + 1}",
                                        color = Color.White,
                                        modifier = Modifier.align(Alignment.Center)
                                    )
                                }
                                
                                Text(
                                    text = "Item ${index + 1}",
                                    style = MaterialTheme.typography.titleMedium,
                                    modifier = Modifier.padding(start = 16.dp)
                                )
                            }
                        }
                    }
                },
                measurePolicy = { measurables, constraints ->
                    val placeables = measurables.map { it.measure(constraints) }
                    layout(constraints.maxWidth, constraints.maxHeight) {
                        placeables.forEach { it.place(0, 0) }
                    }
                }
            )
        } else {
            // 详情视图
            Box(
                modifier = Modifier
                    .fillMaxSize()
                    .background(MaterialTheme.colorScheme.background)
            ) {
                // 返回按钮
                IconButton(
                    onClick = { isDetailView = false },
                    modifier = Modifier.padding(16.dp)
                ) {
                    Icon(
                        imageVector = Icons.Default.ArrowBack,
                        contentDescription = "返回"
                    )
                }
                
                // 共享元素在详情页的位置
                Box(
                    modifier = Modifier
                        .padding(top = 100.dp)
                        .align(Alignment.TopCenter)
                        .size(200.dp)
                        .background(
                            color = MaterialTheme.colorScheme.primary,
                            shape = CircleShape
                        )
                        .lookaheadOnPlaced { currentCoordinates, _ ->
                            // 记录目标位置
                            targetRect = currentCoordinates.boundsInRoot()
                        }
                ) {
                    Text(
                        text = "1",
                        color = Color.White,
                        style = MaterialTheme.typography.headlineLarge,
                        modifier = Modifier.align(Alignment.Center)
                    )
                }
                
                // 详情内容
                Text(
                    text = "这是详情页面的内容",
                    style = MaterialTheme.typography.bodyLarge,
                    modifier = Modifier
                        .padding(32.dp)
                        .align(Alignment.Center)
                )
            }
        }
        
        // 绘制过渡动画
        sharedElementRect?.let { startRect ->
            targetRect?.let { endRect ->
                // 计算当前动画位置
                val currentLeft = lerp(startRect.left, endRect.left, transitionProgress.value)
                val currentTop = lerp(startRect.top, endRect.top, transitionProgress.value)
                val currentRight = lerp(startRect.right, endRect.right, transitionProgress.value)
                val currentBottom = lerp(startRect.bottom, endRect.bottom, transitionProgress.value)
                
                // 绘制过渡元素
                Box(
                    modifier = Modifier
                        .offset { IntOffset(currentLeft.roundToInt(), currentTop.roundToInt()) }
                        .size(
                            width = (currentRight - currentLeft).dp,
                            height = (currentBottom - currentTop).dp
                        )
                        .background(
                            color = MaterialTheme.colorScheme.primary,
                            shape = CircleShape
                        )
                ) {
                    Text(
                        text = "1",
                        color = Color.White,
                        style = MaterialTheme.typography.headlineMedium,
                        modifier = Modifier.align(Alignment.Center)
                    )
                }
            }
        }
    }
}
```

## 常见问题

### 1. LookaheadOnPlacedModifier 和 OnPlacedModifier 有什么区别？

**回答**：主要区别在于获取位置信息的时机：

- `OnPlacedModifier` 在组件已经放置到屏幕上后才获取位置信息，此时布局已经完成
- `LookaheadOnPlacedModifier` 可以在组件实际放置之前获取即将应用的位置信息，让你能够"预知"布局变化
- 使用 `LookaheadOnPlacedModifier` 需要配合 `LookaheadLayout` 使用，而 `OnPlacedModifier` 可以独立使用

### 2. 为什么我的 LookaheadOnPlacedModifier 没有被调用？

**回答**：可能的原因包括：

- 没有将组件包裹在 `LookaheadLayout` 中
- 布局位置没有发生变化，所以没有触发回调
- 组件被移出了视图层次结构
- Compose 版本过低，不支持此功能（需要较新版本的 Compose）

### 3. 使用 LookaheadOnPlacedModifier 会影响性能吗？

**回答**：是的，它可能会影响性能，因为：

- 它需要额外的布局计算和预测
- 过度使用可能导致不必要的重组和布局计算
- 在大型列表或复杂 UI 中使用时应特别小心
- 建议只在真正需要预知布局变化的场景中使用

### 4. 如何在 LazyColumn 中正确使用 LookaheadOnPlacedModifier？

**回答**：在 LazyColumn 中使用时需要注意：

- 确保 LazyColumn 被包裹在 LookaheadLayout 中
- 为列表项设置稳定的 key，以便正确跟踪位置变化
- 避免在滚动过程中进行复杂的动画计算
- 考虑使用 rememberLazyListState() 来获取更多滚动相关信息

## 实践练习

### 练习 1：基础位置跟踪

创建一个简单的应用，使用 LookaheadOnPlacedModifier
跟踪一个按钮的位置变化，并在控制台打印出当前位置和预测位置。当用户点击按钮时，按钮应该在屏幕上的两个不同位置之间切换。

### 练习 2：动态列表项动画

实现一个待办事项列表，当用户添加或删除项目时，使用 LookaheadOnPlacedModifier
创建平滑的插入和删除动画。列表项应该从上方滑入，并在删除时向左滑出。

### 练习 3：高级共享元素过渡

创建一个图片库应用，使用 LookaheadOnPlacedModifier
实现从缩略图网格到全屏详情视图的平滑过渡动画。当用户点击缩略图时，图片应该平滑地扩展到详情视图，同时背景色和其他元素也应该平滑过渡。

### 练习 4：自定义布局过渡

设计一个自定义的折叠面板，使用 LookaheadOnPlacedModifier
实现内容展开和折叠时的平滑动画。面板应该能够记住其中内容的位置，并在展开/折叠状态之间平滑过渡。
