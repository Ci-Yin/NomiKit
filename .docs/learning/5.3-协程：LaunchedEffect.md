# 5.3 协程：LaunchedEffect()

> "在 Compose 的世界里，LaunchedEffect 就像是你的专属'快递员'，负责在后台默默完成那些耗时的任务，让 UI
> 线程轻松自如地处理用户交互！" 📦

## 概念介绍

LaunchedEffect 是 Jetpack Compose 中用于在组合中安全执行异步操作的关键
API。它在组合过程中启动一个协程，并将该协程绑定到调用它的组合点的生命周期。这意味着当组件进入组合时，协程会启动；当组件离开组合或键值变化时，协程会被取消。

与 SideEffect 和 DisposableEffect 不同，LaunchedEffect 专门设计用于处理可能需要时间完成的操作，如网络请求、数据库访问、动画或其他异步任务。它利用
Kotlin 协程的强大功能，使得在 Compose 中处理异步操作变得简单而优雅。

LaunchedEffect 接受一个或多个键值参数，当这些键值变化时，当前运行的协程会被取消，并启动一个新的协程。这种机制确保了异步操作始终基于最新的状态执行，避免了过时操作的问题。

## 知识要点

- LaunchedEffect 用于在 Compose 中执行异步操作，如网络请求、动画等
- 它在组件进入组合时启动一个协程，在组件离开组合或键值变化时取消该协程
- LaunchedEffect 接受一个或多个键值参数，当这些键值变化时，会重新启动协程
- 协程在 Compose 的 CoroutineScope 中运行，默认使用 Dispatchers.Main
- LaunchedEffect 内部的代码可以调用挂起函数，如 delay、withContext 等
- 与 SideEffect 不同，LaunchedEffect 适合执行耗时操作，不会阻塞 UI 线程
- 与 DisposableEffect 不同，LaunchedEffect 专注于异步操作，而不是资源管理

## 基础代码示例

下面是一个简单的例子，展示如何使用 LaunchedEffect 执行延迟操作：

```kotlin
@Composable
fun AutoDismissMessage(
    message: String,
    onDismiss: () -> Unit,
    dismissTimeMillis: Long = 3000
) {
    // 显示消息
    Card(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp),
        colors = CardDefaults.cardColors(
            containerColor = MaterialTheme.colorScheme.primaryContainer
        )
    ) {
        Column(
            modifier = Modifier.padding(16.dp)
        ) {
            Text(
                text = message,
                style = MaterialTheme.typography.bodyLarge,
                color = MaterialTheme.colorScheme.onPrimaryContainer
            )
            
            // 使用 LaunchedEffect 在指定时间后自动关闭消息
            LaunchedEffect(message) {
                delay(dismissTimeMillis)
                onDismiss()
            }
        }
    }
}

@Composable
fun MessageDemo() {
    var showMessage by remember { mutableStateOf(false) }
    var messageCount by remember { mutableStateOf(0) }
    
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(16.dp)
    ) {
        Button(
            onClick = {
                messageCount++
                showMessage = true
            }
        ) {
            Text("显示消息")
        }
        
        if (showMessage) {
            AutoDismissMessage(
                message = "这是第 $messageCount 条消息，将在 3 秒后自动关闭",
                onDismiss = { showMessage = false }
            )
        }
    }
}
```

### 1. 执行网络请求

LaunchedEffect 非常适合执行网络请求等异步操作：

```kotlin
@Composable
fun UserProfile(userId: String) {
    // 用户数据状态
    var user by remember { mutableStateOf<User?>(null) }
    var isLoading by remember { mutableStateOf(true) }
    var error by remember { mutableStateOf<String?>(null) }
    
    // 使用 LaunchedEffect 加载用户数据
    LaunchedEffect(userId) {
        isLoading = true
        error = null
        
        try {
            // 模拟网络请求
            val result = withContext(Dispatchers.IO) {
                delay(1500) // 模拟网络延迟
                UserRepository.fetchUser(userId)
            }
            
            user = result
            isLoading = false
        } catch (e: Exception) {
            error = "加载用户数据失败: ${e.message}"
            isLoading = false
        }
    }
    
    // UI 展示
    Box(
        modifier = Modifier.fillMaxSize(),
        contentAlignment = Alignment.Center
    ) {
        when {
            isLoading -> {
                CircularProgressIndicator()
            }
            error != null -> {
                ErrorMessage(error!!)
            }

    }
```

### 2. 实现动画效果

LaunchedEffect 可以用于实现复杂的动画效果：

```kotlin
@Composable
fun AnimatedCounter(
    targetValue: Int,
    duration: Int = 1000,
    animationSpec: AnimationSpec<Float> = tween(
        durationMillis = duration,
        easing = FastOutSlowInEasing
    )
) {
    // 当前显示的值
    var displayedValue by remember { mutableStateOf(0f) }
    
    // 使用 LaunchedEffect 执行动画
    LaunchedEffect(targetValue) {
        // 如果目标值与当前值相同，不执行动画
        if (targetValue.toFloat() == displayedValue) {
            return@LaunchedEffect
        }
        
        // 记录起始值
        val startValue = displayedValue
        
        // 使用 animate 函数执行动画
        animate(
            initialValue = startValue,
            targetValue = targetValue.toFloat(),
            animationSpec = animationSpec
        ) { value, _ ->
            displayedValue = value
        }
    }
    
    // 显示当前值
    Text(
        text = displayedValue.toInt().toString(),
        style = MaterialTheme.typography.displayLarge,
        modifier = Modifier.padding(16.dp)
    )
}

@Composable
fun CounterDemo() {
    var counter by remember { mutableStateOf(0) }
    
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.Center

        Row(

                Text("-1")

                Text("+10")

        }
    }
```

### 3. 实现倒计时功能

LaunchedEffect 可以用于实现倒计时等需要定时更新的功能：

```kotlin
@Composable
fun Countdown(
    seconds: Int,
    onFinish: () -> Unit
) {
    // 剩余时间
    var remainingSeconds by remember { mutableStateOf(seconds) }
    
    // 格式化时间显示
    val formattedTime = remember(remainingSeconds) {
        val minutes = remainingSeconds / 60
        val seconds = remainingSeconds % 60
        String.format("%02d:%02d", minutes, seconds)
    }
    
    // 使用 LaunchedEffect 实现倒计时
    LaunchedEffect(seconds) {
        // 重置剩余时间
        remainingSeconds = seconds
        
        // 每秒更新一次
        while (remainingSeconds > 0) {
            delay(1000)
            remainingSeconds--
        }
        
        // 倒计时结束
        onFinish()
    }
    
    // UI 显示
    Column(
        modifier = Modifier
            .fillMaxWidth()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(
            text = "倒计时",
            style = MaterialTheme.typography.headlineMedium
        )
        
        Spacer(modifier = Modifier.height(16.dp))
        
        // 倒计时显示
        Box(
            modifier = Modifier
                .size(200.dp)
                .border(
                    width = 4.dp,
                    color = MaterialTheme.colorScheme.primary,
                    shape = CircleShape
                )
                .padding(4.dp),
            contentAlignment = Alignment.Center
        ) {
            // 进度环
            CircularProgressIndicator(
                progress = remainingSeconds.toFloat() / seconds,
                modifier = Modifier.fillMaxSize(),
                strokeWidth = 8.dp
            )
            
            // 时间文本
            Text(
                text = formattedTime,
                style = MaterialTheme.typography.displayMedium
            )
        }
    }
}

@Composable
fun CountdownDemo() {
    var isCountdownActive by remember { mutableStateOf(false) }
    var selectedTime by remember { mutableStateOf(60) } // 默认 60 秒
    
    Column(

            .fillMaxSize()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally,
        verticalArrangement = Arrangement.Center
    ) {
        if (isCountdownActive) {
            // 显示倒计时
            Countdown(
                seconds = selectedTime,

            )

            // 取消按钮

                )
            ) {
                Text("取消倒计时")
            }
        } else {
            // 时间选择
            Text(
                text = "选择倒计时时间",
                style = MaterialTheme.typography.headlineMedium
            )
            
            Spacer(modifier = Modifier.height(16.dp))
            
            // 时间选项

                horizontalArrangement = Arrangement.spacedBy(8.dp)
            ) {
                TimeOption(30, selectedTime) { selectedTime = it }
                TimeOption(60, selectedTime) { selectedTime = it }
                TimeOption(120, selectedTime) { selectedTime = it }
                TimeOption(300, selectedTime) { selectedTime = it }
            }
            
            Spacer(modifier = Modifier.height(32.dp))
            
            // 开始按钮
            Button(
                onClick = { isCountdownActive = true },
                modifier = Modifier.width(200.dp)
            ) {
                Text("开始倒计时")
            }
        }
    }
}

@Composable
private fun TimeOption(
    seconds: Int,
    selectedTime: Int,
    onSelect: (Int) -> Unit
) {
    val isSelected = seconds == selectedTime
    val minutes = seconds / 60
    val remainingSeconds = seconds % 60
    
    val timeText = if (minutes > 0) {
        if (remainingSeconds > 0) {
            "$minutes 分 $remainingSeconds 秒"
        } else {
            "$minutes 分钟"
        }
    } else {
        "$seconds 秒"
    }
    
    OutlinedButton(
        onClick = { onSelect(seconds) },
        border = BorderStroke(
            width = 2.dp,
            color = if (isSelected) MaterialTheme.colorScheme.primary
                   else MaterialTheme.colorScheme.outline
        ),
        colors = ButtonDefaults.outlinedButtonColors(
            containerColor = if (isSelected) 
                MaterialTheme.colorScheme.primaryContainer
            else
                MaterialTheme.colorScheme.surface
        )
    ) {
        Text(timeText)
    }
}
```

## 常见问题

### 1. LaunchedEffect 和 DisposableEffect 有什么区别？

**回答**：两者都用于处理副作用，但有几个关键区别：

- `LaunchedEffect` 专门用于执行异步操作，如网络请求、动画等
- `DisposableEffect` 专门用于管理需要清理的资源，如监听器、连接等
- `LaunchedEffect` 启动一个协程，可以调用挂起函数
- `DisposableEffect` 不启动协程，主要关注资源的获取和释放
- `LaunchedEffect` 在键值变化时会取消并重新启动协程
- `DisposableEffect` 在键值变化时会执行清理操作并重新初始化资源

选择指南：

- 如果需要执行异步操作，使用 `LaunchedEffect`
- 如果需要管理需要清理的资源，使用 `DisposableEffect`
- 如果两者都需要，可以同时使用它们，或者在 `DisposableEffect` 中启动协程并在清理时取消

### 2. 为什么我的 LaunchedEffect 没有执行或者执行多次？

**回答**：LaunchedEffect 的执行受其键值和组合状态的影响。常见问题包括：

1. **没有执行**：
    - 组件可能没有进入组合
    - 键值可能与预期不符
    - 可能有条件逻辑阻止了 LaunchedEffect 的执行

   解决方法：
    - 确保 LaunchedEffect 在组件的主要组合路径上
    - 检查键值是否正确
    - 使用日志或调试工具确认组件是否进入了组合

2. **执行多次**：
    - 键值可能频繁变化
    - 父组件可能频繁重组
    - 可能有状态变化导致组件重组

   解决方法：
    - 使用更稳定的键值
    - 使用 `remember` 或 `rememberUpdatedState` 捕获频繁变化的值
    - 使用 `key` 参数确保组件的稳定性

### 3. 如何在 LaunchedEffect 中处理异常？

**回答**：在 LaunchedEffect 中处理异常有几种方法：

1. **使用 try-catch 块**：

```kotlin
LaunchedEffect(key) {
    try {
        // 可能抛出异常的代码
    } catch (e: Exception) {
        // 处理异常
        Log.e("LaunchedEffect", "Error: ${e.message}")
    }
}
```

2. **使用 CoroutineExceptionHandler**：

```kotlin
val exceptionHandler = CoroutineExceptionHandler { _, throwable ->
    Log.e("LaunchedEffect", "Error: ${throwable.message}")
    // 更新 UI 状态
    error = throwable.message
}

LaunchedEffect(key) {
    withContext(exceptionHandler) {
        // 可能抛出异常的代码
    }
}
```

3. **使用 supervisorScope**：

```kotlin
LaunchedEffect(key) {
    supervisorScope {
        launch {
            try {
                // 操作 1
            } catch (e: Exception) {
                // 处理操作 1 的异常
            }
        }
        
        launch {
            try {
                // 操作 2
            } catch (e: Exception) {
                // 处理操作 2 的异常
            }
        }
    }
}
```

### 4. 如何在 LaunchedEffect 中执行多个并行任务？

**回答**：在 LaunchedEffect 中执行多个并行任务有几种方法：

1. **使用 launch 启动多个协程**：

```kotlin
LaunchedEffect(key) {
    coroutineScope {
        // 任务 1
        launch {
            // 异步操作 1
        }
        
        // 任务 2
        launch {
            // 异步操作 2
        }
        
        // 任务 3
        launch {
            // 异步操作 3
        }
    }
}
```

2. **使用 async 和 await 并行执行并等待结果**：

```kotlin
LaunchedEffect(key) {
    coroutineScope {
        val result1 = async {
            // 异步操作 1
            "结果 1"
        }
        
        val result2 = async {
            // 异步操作 2
            "结果 2"
        }
        
        // 等待所有结果
        val combinedResult = "${result1.await()} 和 ${result2.await()}"
    }
}
```

3. **使用 awaitAll 等待多个任务完成**：

```kotlin
LaunchedEffect(key) {
    coroutineScope {
        val deferreds = listOf(
            async { /* 任务 1 */ },
            async { /* 任务 2 */ },
            async { /* 任务 3 */ }
        )
        
        // 等待所有任务完成
        val results = deferreds.awaitAll()
    }
}
```
