# 3.12 Transition：多属性的状态切换

> "
>
如果说单个属性的动画是独奏，那么Transition就是一支交响乐团！它让多个属性可以同时变化，协调一致地完成状态转换，就像一场精心编排的舞蹈，每个舞者都按照自己的节奏，却又浑然一体地展现出完美的视觉盛宴！"
> 🎭

## 概念介绍

在Jetpack Compose的动画系统中，我们经常需要同时改变多个属性来实现复杂的UI状态转换。例如，当一个卡片展开时，可能需要同时改变它的高度、透明度、圆角大小等多个属性。如果使用单独的
`animateXxxAsState`或`Animatable`来处理每个属性，不仅代码冗长，还难以协调这些动画的时间和行为。

这就是`Transition`API的用武之地。`Transition`
是Compose动画系统中专门用于处理多属性状态转换的高级工具，它提供了一种声明式的方式来定义和管理多个属性在不同状态之间的动画过渡。

`Transition`的核心特点包括：

1. **状态驱动**：整个动画过程由状态变化驱动，符合Compose的声明式理念。
2. **多属性协调**：可以同时为多个属性定义动画，并且每个属性可以有不同的动画规格。
3. **类型安全**：通过泛型确保状态类型的安全性。
4. **灵活配置**：每个属性的动画可以单独配置，包括动画规格、延迟时间等。
5. **可组合**：可以与其他Compose动画API结合使用。

`Transition`特别适合以下场景：

- 复杂UI元素的展开/折叠动画
- 多步骤的引导动画
- 状态机驱动的UI转换
- 需要精确控制多个属性动画时序的场景
- 主题切换或模式转换（如日间/夜间模式）

通过掌握`Transition`，你将能够创建更加复杂、协调和专业的动画效果，提升应用的用户体验。

## 知识要点

- **核心API**：
    - `updateTransition()`：创建和更新Transition对象
    - `animate*AsState()`：为特定类型的属性定义动画
    - `transitionSpec`：定义动画规格
    - `targetState`：目标状态
    - `currentState`：当前状态
    - `label`：为调试提供标签

- **状态定义**：
    - 使用枚举类型定义离散状态
    - 使用数据类定义复合状态
    - 使用基本类型（Int、Float等）定义连续状态

- **动画属性类型**：
    - `animateFloat`：浮点值动画
    - `animateColor`：颜色动画
    - `animateValue`：自定义类型动画（需提供TwoWayConverter）
    - `animateDp`：尺寸动画
    - `animateInt`：整数动画
    - `animateRect`：矩形区域动画
    - `animateSize`：大小动画

- **动画规格配置**：
    - 为不同状态转换定义不同的动画规格
    - 使用`spring`、`tween`等动画规格
    - 配置动画延迟和持续时间

- **状态转换条件**：
    - `using`子句定义动画规格
    - 基于初始状态和目标状态的条件配置

- **多属性协调**：
    - 同步多个属性的动画
    - 为不同属性设置不同的动画时序
    - 属性动画的顺序控制

- **与其他动画API的集成**：
    - 与`AnimatedVisibility`的关系
    - 与`AnimatedContent`的关系
    - 与`Crossfade`的关系

- **性能考虑**：
    - 避免不必要的状态更新
    - 合理使用`remember`缓存Transition对象
    - 动画规格的性能影响

## 基础代码示例

### 简单的两状态切换

下面是一个简单的例子，展示了如何使用`Transition`在两个状态之间切换一个卡片的多个属性：

```kotlin
@Composable
fun SimpleTransitionExample() {
    // 定义两个状态
    enum class BoxState { Collapsed, Expanded }
    
    // 当前状态
    var currentState by remember { mutableStateOf(BoxState.Collapsed) }
    
    // 创建Transition
    val transition = updateTransition(
        targetState = currentState,
        label = "Box Transition"
    )
    
    // 定义多个动画属性
    val backgroundColor by transition.animateColor(
        transitionSpec = { tween(durationMillis = 500) },
        label = "backgroundColor"
    ) { state ->
        when (state) {
            BoxState.Collapsed -> Color(0xFF6200EE)
            BoxState.Expanded -> Color(0xFF03DAC5)
        }
    }
    
    val roundedCorners by transition.animateDp(
        transitionSpec = { tween(durationMillis = 500) },
        label = "roundedCorners"
    ) { state ->
        when (state) {
            BoxState.Collapsed -> 8.dp
            BoxState.Expanded -> 24.dp
        }
    }
    
    val width by transition.animateDp(
        transitionSpec = { tween(durationMillis = 500) },
        label = "width"
    ) { state ->
        when (state) {
            BoxState.Collapsed -> 100.dp
            BoxState.Expanded -> 300.dp
        }
    }
    
    val height by transition.animateDp(
        transitionSpec = { tween(durationMillis = 500) },
        label = "height"
    ) { state ->
        when (state) {
            BoxState.Collapsed -> 100.dp
            BoxState.Expanded -> 200.dp
        }
    }
    
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(
            text = "简单Transition示例",
            style = MaterialTheme.typography.headlineMedium,
            modifier = Modifier.padding(bottom = 32.dp)
        )
        
        // 显示当前状态
        Text(
            text = "当前状态: ${currentState.name}",
            style = MaterialTheme.typography.bodyLarge,
            modifier = Modifier.padding(bottom = 16.dp)
        )
        
        // 动画Box
        Box(
            modifier = Modifier
                .width(width)
                .height(height)
                .background(
                    color = backgroundColor,
                    shape = RoundedCornerShape(roundedCorners)
                )
                .clickable {
                    // 点击切换状态
                    currentState = when (currentState) {
                        BoxState.Collapsed -> BoxState.Expanded
                        BoxState.Expanded -> BoxState.Collapsed
                    }
                },
            contentAlignment = Alignment.Center
        ) {
            Text(
                text = "点击切换",
                color = Color.White,
                fontWeight = FontWeight.Bold
            )
        }
        
        Spacer(modifier = Modifier.height(32.dp))
        
        Text(
            text = "👆 点击卡片切换状态",
            style = MaterialTheme.typography.bodyMedium,
            color = Color.Gray
        )
    }
}
```

### 使用不同的动画规格

下面的例子展示了如何为不同的属性和不同的状态转换配置不同的动画规格：

```kotlin
@Composable
fun DifferentSpecsTransitionExample() {
    // 定义三个状态
    enum class CardState { Small, Medium, Large }
    
    // 当前状态
    var currentState by remember { mutableStateOf(CardState.Small) }
    
    // 创建Transition
    val transition = updateTransition(
        targetState = currentState,
        label = "Card Transition"
    )
    
    // 大小动画 - 使用不同的动画规格
    val size by transition.animateDp(
        // 为不同的状态转换定义不同的动画规格
        transitionSpec = {
            when {
                // Small -> Medium: 使用tween
                CardState.Small isTransitioningTo CardState.Medium -> 
                    tween(durationMillis = 300, easing = FastOutSlowInEasing)
                
                // Medium -> Large: 使用spring
                CardState.Medium isTransitioningTo CardState.Large -> 
                    spring(dampingRatio = Spring.DampingRatioMediumBouncy)
                
                // 其他任何转换: 使用默认tween
                else -> tween(durationMillis = 500)
            }
        },
        label = "size"
    ) { state ->
        when (state) {
            CardState.Small -> 100.dp
            CardState.Medium -> 200.dp
            CardState.Large -> 300.dp
        }
    }
    
    // 颜色动画 - 使用延迟
    val color by transition.animateColor(
        // 为所有转换使用相同的规格，但添加延迟
        transitionSpec = { 
            tween(
                durationMillis = 500, 
                delayMillis = 100, // 延迟100毫秒
                easing = LinearEasing
            ) 
        },
        label = "color"
    ) { state ->
        when (state) {
            CardState.Small -> Color(0xFF6200EE)
            CardState.Medium -> Color(0xFF03DAC5)
            CardState.Large -> Color(0xFFFF5722)
        }
    }
    
    // 旋转动画 - 使用spring
    val rotation by transition.animateFloat(
        transitionSpec = { 
            spring(
                dampingRatio = Spring.DampingRatioMediumBouncy,
                stiffness = Spring.StiffnessLow
            ) 
        },
        label = "rotation"
    ) { state ->
        when (state) {
            CardState.Small -> 0f
            CardState.Medium -> 180f
            CardState.Large -> 360f
        }
    }
    
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(
            text = "不同动画规格的Transition",
            style = MaterialTheme.typography.headlineMedium,
            modifier = Modifier.padding(bottom = 32.dp)
        )
        
        // 显示当前状态
        Text(
            text = "当前状态: ${currentState.name}",
            style = MaterialTheme.typography.bodyLarge,
            modifier = Modifier.padding(bottom = 16.dp)
        )
        
        // 动画卡片
        Box(
            modifier = Modifier
                .size(size)
                .graphicsLayer { 
                    rotationY = rotation
                }
                .background(
                    color = color,
                    shape = RoundedCornerShape(16.dp)
                )
                .clickable {
                    // 点击循环切换状态
                    currentState = when (currentState) {
                        CardState.Small -> CardState.Medium
                        CardState.Medium -> CardState.Large
                        CardState.Large -> CardState.Small
                    }
                },
            contentAlignment = Alignment.Center
        ) {
            Text(
                text = "点击切换",
                color = Color.White,
                fontWeight = FontWeight.Bold
            )
        }
        
        Spacer(modifier = Modifier.height(32.dp))
        
        // 状态切换按钮
        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.SpaceEvenly
        ) {
            Button(
                onClick = { currentState = CardState.Small },
                enabled = currentState != CardState.Small
            ) {
                Text("小")
            }
            
            Button(
                onClick = { currentState = CardState.Medium },
                enabled = currentState != CardState.Medium
            ) {
                Text("中")
            }
            
            Button(
                onClick = { currentState = CardState.Large },
                enabled = currentState != CardState.Large
            ) {
                Text("大")
            }
        }
    }
}
```

### 使用复合状态

在更复杂的场景中，我们可能需要使用复合状态来驱动Transition。下面的例子展示了如何使用数据类作为状态：

```kotlin
@Composable
fun ComplexStateTransitionExample() {
    // 使用数据类定义复合状态
    data class CardState(
        val expanded: Boolean = false,
        val highlighted: Boolean = false,
        val selected: Boolean = false
    )
    
    // 当前状态
    var currentState by remember { mutableStateOf(CardState()) }
    
    // 创建Transition
    val transition = updateTransition(
        targetState = currentState,
        label = "Complex Card Transition"
    )
    
    // 高度动画
    val height by transition.animateDp(
        transitionSpec = { 
            if (targetState.expanded) {
                // 展开动画使用spring
                spring(dampingRatio = Spring.DampingRatioLowBouncy)
            } else {
                // 折叠动画使用tween
                tween(durationMillis = 300)
            }
        },
        label = "height"
    ) { state ->
        if (state.expanded) 200.dp else 100.dp
    }
    
    // 颜色动画
    val backgroundColor by transition.animateColor(
        label = "backgroundColor"
    ) { state ->
        when {
            state.selected && state.highlighted -> Color(0xFFE91E63) // 选中且高亮
            state.selected -> Color(0xFF9C27B0) // 仅选中
            state.highlighted -> Color(0xFF2196F3) // 仅高亮
            else -> Color(0xFF6200EE) // 默认
        }
    }
    
    // 边框动画
    val borderWidth by transition.animateDp(
        label = "borderWidth"
    ) { state ->
        if (state.selected) 4.dp else 0.dp
    }
    
    // 阴影动画
    val elevation by transition.animateDp(
        label = "elevation"
    ) { state ->
        if (state.highlighted) 8.dp else 2.dp
    }
    
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(
            text = "复合状态Transition示例",
            style = MaterialTheme.typography.headlineMedium,
            modifier = Modifier.padding(bottom = 32.dp)
        )
        
        // 显示当前状态
        Text(
            text = "展开: ${if (currentState.expanded) "是" else "否"} | " +
                  "高亮: ${if (currentState.highlighted) "是" else "否"} | " +
                  "选中: ${if (currentState.selected) "是" else "否"}",
            style = MaterialTheme.typography.bodyLarge,
            modifier = Modifier.padding(bottom = 16.dp)
        )
        
        // 动画卡片
        Card(
            modifier = Modifier
                .fillMaxWidth()
                .height(height)
                .padding(8.dp)
                .clickable {
                    // 点击切换展开状态
                    currentState = currentState.copy(
                        expanded = !currentState.expanded
                    )
                },
            colors = CardDefaults.cardColors(
                containerColor = backgroundColor
            ),
            elevation = CardDefaults.cardElevation(
                defaultElevation = elevation
            ),
            border = if (borderWidth > 0.dp) {
                BorderStroke(borderWidth, Color.White)
            } else {
                null
            }
        ) {
            Box(
                modifier = Modifier.fillMaxSize(),
                contentAlignment = Alignment.Center
            ) {
                Text(
                    text = "点击展开/折叠",
                    color = Color.White,
                    fontWeight = FontWeight.Bold
                )
            }
        }
        
        Spacer(modifier = Modifier.height(32.dp))
        
        // 控制按钮
        Row(
            modifier = Modifier.fillMaxWidth(),
            horizontalArrangement = Arrangement.SpaceEvenly
        ) {
            // 高亮切换
            Button(
                onClick = {
                    currentState = currentState.copy(
                        highlighted = !currentState.highlighted
                    )
                },
                colors = ButtonDefaults.buttonColors(
                    containerColor = if (currentState.highlighted) 
                        Color(0xFF2196F3) else Color.Gray
                )
            ) {
                Text("高亮")
            }
            
            // 选中切换
            Button(
                onClick = {
                    currentState = currentState.copy(
                        selected = !currentState.selected
                    )
                },
                colors = ButtonDefaults.buttonColors(
                    containerColor = if (currentState.selected) 
                        Color(0xFF9C27B0) else Color.Gray
                )
            ) {
                Text("选中")
            }
        }
    }
}
```

### 创建自定义动画类型

对于Compose没有直接提供动画支持的类型，我们可以使用`animateValue`和`TwoWayConverter`来创建自定义类型的动画：

```kotlin
@Composable
fun CustomTypeTransitionExample() {
    // 自定义数据类
    data class CirclePosition(val x: Float, val y: Float, val radius: Float)
    
    // 为自定义类型创建转换器
    val circlePositionConverter = TwoWayConverter<CirclePosition, AnimationVector3D>(
        convertToVector = { circle ->
            AnimationVector3D(circle.x, circle.y, circle.radius)
        },
        convertFromVector = { vector ->
            CirclePosition(vector.v1, vector.v2, vector.v3)
        }
    )
    
    // 定义状态
    enum class CircleState { Start, End }
    
    // 当前状态
    var currentState by remember { mutableStateOf(CircleState.Start) }
    
    // 创建Transition
    val transition = updateTransition(
        targetState = currentState,
        label = "Circle Transition"
    )
    
    // 使用自定义类型动画
    val circlePosition by transition.animateValue(
        typeConverter = circlePositionConverter,
        transitionSpec = { 
            spring(
                dampingRatio = Spring.DampingRatioMediumBouncy,
                stiffness = Spring.StiffnessLow
            ) 
        },
        label = "circlePosition"
    ) { state ->
        when (state) {
            CircleState.Start -> CirclePosition(100f, 100f, 50f)
            CircleState.End -> CirclePosition(300f, 300f, 100f)
        }
    }
    
    // 颜色动画
    val circleColor by transition.animateColor(
        label = "circleColor"
    ) { state ->
        when (state) {
            CircleState.Start -> Color(0xFF6200EE)
            CircleState.End -> Color(0xFF03DAC5)
        }
    }
    
    Column(
        modifier = Modifier
            .fillMaxSize()
            .padding(16.dp),
        horizontalAlignment = Alignment.CenterHorizontally
    ) {
        Text(
            text = "自定义类型Transition示例",
            style = MaterialTheme.typography.headlineMedium,
            modifier = Modifier.padding(bottom = 32.dp)
        )
        
        // 显示当前状态
        Text(
            text = "当前状态: ${currentState.name}",
            style = MaterialTheme.typography.bodyLarge,
            modifier = Modifier.padding(bottom = 16.dp)
        )
        
        // 绘制区域
        Box(
            modifier = Modifier
                .fillMaxWidth()
                .height(400.dp)
                .background(Color.LightGray.copy(alpha = 0.3f))
                .border(1.dp, Color.Gray)
                .clickable {
                    // 点击切换状态
                    currentState = when (currentState) {
                        CircleState.Start -> CircleState.End
                        CircleState.End -> CircleState.Start
                    }
                }
        ) {
            // 绘制圆形
            Canvas(modifier = Modifier.fillMaxSize()) {
                drawCircle(
                    color = circleColor,
                    radius = circlePosition.radius,
                    center = Offset(circlePosition.x, circlePosition.y)
                )
            }
            
            // 指示文本
            Box(
                modifier = Modifier.fillMaxSize(),
                contentAlignment = Alignment.Center
            ) {
                Text(
                    text = "点击切换",
                    color = Color.Black,
                    fontWeight = FontWeight.Bold
                )
            }
        }
        
        Spacer(modifier = Modifier.height(16.dp))
        
        // 显示当前位置信息
        Text(
            text = "位置: (${circlePosition.x.roundToInt()}, ${circlePosition.y.roundToInt()}), " +
                  "半径: ${circlePosition.radius.roundToInt()}",
            style = MaterialTheme.typography.bodyMedium
        )
    }
}
```

## 常见问题

### Transition和AnimateXxxAsState的区别

**问题**：为什么要使用Transition而不是多个AnimateXxxAsState？

**解答**：
虽然`AnimateXxxAsState`和`Transition`都可以创建动画，但它们有几个关键区别：

1. **协调性**：`Transition`可以协调多个属性的动画，确保它们作为一个整体进行状态转换。而多个独立的
   `AnimateXxxAsState`
   之间没有内在的协调机制。

2. **状态管理**：`Transition`基于单一的状态对象，使状态管理更加清晰。使用多个`AnimateXxxAsState`
   时，每个动画都需要单独的状态触发。

3. **动画规格灵活性**：`Transition`允许基于起始状态和目标状态定义不同的动画规格，而`AnimateXxxAsState`
   只能为所有状态变化使用相同的动画规格。

4. **代码组织**：对于多属性动画，`Transition`提供了更好的代码组织结构，使代码更易于理解和维护。

5. **性能**：`Transition`内部优化了状态变化的处理，可能比多个独立的`AnimateXxxAsState`更高效。

示例对比：

```kotlin
// 使用多个AnimateXxxAsState
val color by animateColorAsState(
    targetValue = if (isExpanded) Color.Red else Color.Blue
)
val size by animateDpAsState(
    targetValue = if (isExpanded) 200.dp else 100.dp
)

// 使用Transition
val transition = updateTransition(targetState = isExpanded)
val color by transition.animateColor { if (it) Color.Red else Color.Blue }
val size by transition.animateDp { if (it) 200.dp else 100.dp }
```

当需要协调多个属性的动画时，`Transition`通常是更好的选择。

### 处理Transition中的动画顺序

**问题**：如何让Transition中的某些动画先开始，某些动画后开始？

**解答**：
`Transition`提供了几种方式来控制动画的顺序：

**方法1：使用delayMillis**

在`transitionSpec`中设置不同的延迟时间：

```kotlin
val color by transition.animateColor(
    transitionSpec = { tween(delayMillis = 0) } // 立即开始
) { ... }

val size by transition.animateDp(
    transitionSpec = { tween(delayMillis = 300) } // 延迟300ms开始
) { ... }
```

**方法2：基于状态转换的条件**

为不同的状态转换定义不同的动画规格：

```kotlin
val size by transition.animateDp(
    transitionSpec = {
        when {
            // A->B转换：先执行此动画
            State.A isTransitioningTo State.B -> 
                tween(delayMillis = 0)
            
            // B->C转换：后执行此动画
            State.B isTransitioningTo State.C -> 
                tween(delayMillis = 200)
            
            // 其他情况
            else -> tween()
        }
    }
) { ... }
```

**方法3：使用不同的动画持续时间**

通过控制动画的持续时间，也可以影响动画的结束顺序：

```kotlin
val color by transition.animateColor(
    transitionSpec = { tween(durationMillis = 300) } // 较短的动画
) { ... }

val size by transition.animateDp(
    transitionSpec = { tween(durationMillis = 600) } // 较长的动画
) { ... }
```

通过组合这些技术，你可以创建复杂的动画序列，实现精确的时序控制。

### Transition中的中断处理

**问题**：如果在动画过程中状态再次改变，Transition会如何处理？

**解答**：
`Transition`内部已经处理了动画中断的情况，当状态在动画过程中再次改变时：

1. **平滑过渡**：`Transition`会自动从当前值开始创建新的动画，而不是突然跳转，确保视觉上的平滑过渡。

2. **动画规格重新评估**：`Transition`会重新评估`transitionSpec`，基于新的起始状态和目标状态选择合适的动画规格。

3. **资源管理**：之前的动画会被适当地取消，避免资源泄漏。

示例：

```kotlin
// 在动画过程中改变状态
Button(onClick = { currentState = newState }) {
    Text("改变状态")
}

// Transition会自动处理中断
val transition = updateTransition(targetState = currentState)
val size by transition.animateDp { state ->
    when (state) {
        State.A -> 100.dp
        State.B -> 200.dp
        State.C -> 300.dp
    }
}
```

如果需要更精细地控制中断行为，可以在`transitionSpec`中使用条件逻辑：

```kotlin
val size by transition.animateDp(
    transitionSpec = {
        when {
            // 检测到中断时使用不同的动画规格
            initialState == State.A && targetState == State.C && 
            !transition.currentState.equals(initialState) -> 
                spring(dampingRatio = Spring.DampingRatioHighBouncy)
            
            // 正常转换
            else -> tween()
        }
    }
) { ... }
```

### 在Transition中使用自定义Easing函数

**问题**：如何在Transition中应用自定义的缓动函数？

**解答**：
在`Transition`中使用自定义缓动函数非常简单，你可以在`transitionSpec`中的`tween`动画规格中指定：

**使用预定义的Easing**：

```kotlin
val size by transition.animateDp(
    transitionSpec = { 
        tween(
            durationMillis = 500,
            easing = FastOutSlowInEasing // 预定义的缓动函数
        ) 
    }
) { ... }
```

**使用自定义的Easing**：

```kotlin
// 定义自定义缓动函数
val customEasing = Easing { fraction ->
    // 实现自定义缓动逻辑
    // 例如：弹跳效果
    val bounce = sin(fraction * Math.PI * 2).toFloat()
    fraction + bounce * 0.1f
}

// 在Transition中使用
val size by transition.animateDp(
    transitionSpec = { 
        tween(
            durationMillis = 500,
            easing = customEasing
        ) 
    }
) { ... }
```

**组合多个Easing**：

```kotlin
// 组合两个缓动函数
val combinedEasing = Easing { fraction ->
    if (fraction < 0.5f) {
        // 前半段使用一种缓动
        FastOutSlowInEasing.transform(fraction * 2) / 2
    } else {
        // 后半段使用另一种缓动
        0.5f + LinearOutSlowInEasing.transform((fraction - 0.5f) * 2) / 2
    }
}
```

通过自定义缓动函数，你可以创建独特的动画效果，使UI交互更加生动和有趣。
